# 에셋 작업 절차

역할: [AGENTS.md](../AGENTS.md#ui시각-에셋)의 도구 선택·표현 계약을 유지하는 실행 절차. 외형·완료 기준은 [DESIGNS.md](../DESIGNS.md)를 따른다.

## 기존 작업과 연결 보존

- GIMP 작업 전 실행 중인 인스턴스·MCP 연결·열린 문서를 확인하고 기존 인스턴스를 재사용한다. 연결 실패만으로 새 인스턴스를 띄우지 않는다.
- 연결 실패 원인을 확인하고 기존 연결 복구를 먼저 시도한다. 실행 중인 인스턴스가 없거나 사용할 수 없다는 근거가 있을 때만 새로 실행하며, 기존 문서와 미저장 작업을 보존한다.
- 같은 실패를 상태 변화 없이 반복하지 않는다. [도구 복구와 대체 경로](in_app_test_guide.md#도구-복구와-대체-경로)를 따르며, 사용자 지정 도구나 합의한 표현 방식을 임의로 바꾸지 않는다.
- Blender의 기존 Python/bpy 제작·수정·내보내기 경로를 재사용한다. 독립 background 실행이 필요하면 열린 원본과 미저장 작업을 보존한다.

## 작업 완료와 프로세스 종료

- 작업 완료·커밋 시에는 관련 편집 원본과 최종 산출물을 저장하고, 실제 파일 존재·저장 성공·미저장 변경 여부를 확인한다. 커밋은 저장을 대신하지 않으며 기존 승인 범위에서만 수행한다.
- GIMP는 레이어를 보존하는 XCF, Blender는 `.blend` 등 다시 편집할 수 있는 원본을 저장한다. 이름 없는 문서나 같은 경로에서 파생된 여러 작업은 서로 덮어쓰지 않는 별도 경로로 보존한다. 저장 도구가 미저장 표시를 해제하지 않는 경우 저장 파일을 다시 열어 확인한 뒤 문서를 닫는다.
- 필요한 검증까지 마쳤으면 현재 작업에서 사용한 GIMP·Blender·미리보기·임시 렌더의 문서·프로세스와 공유 여부를 확인한다. 사용자·다른 채팅·하위 에이전트가 사용하지 않는다고 확인된 대상만 정상 종료하고 실제 종료 여부를 확인한다. 현재 작업의 완료·커밋이나 파일 저장만으로 공유 인스턴스 전체의 사용이 끝났다고 판단하지 않는다.
- 다른 작업이 사용 중이거나 소유·사용 여부가 불명확한 파일·문서·프로세스는 임의로 삭제·덮어쓰기·닫기·종료하지 않는다. 종료 대상인지 확인할 수 없으면 유지하고, 필요한 경우 해당 대상만 사용자에게 확인한다. 프로세스명으로 일괄 종료하거나 공유 앱의 문서를 일괄 닫지 않는다.
- 저장 실패·출처 불명 문서·진행 중인 렌더가 있으면 먼저 보존·완료 상태를 해결한다. 복구본을 저장했다는 이유로 다른 작업의 열린 문서나 미저장 변경을 버리지 않으며, 강제 종료하지 않는다. 보존한 원본·복구본의 삭제는 프로세스 종료와 별개로 판단한다.

## 산출물 점검

- 제작 원본·중간 산출물과 게임용 최종 파일의 위치는 AGENTS.md를 따른다. 게임용 결과는 기존 로딩 경로에 연결한다.
- 크기·프레임·투명 배경·형식은 실제 사용처에 맞춘다. 움직이는 에셋은 순서·여백·루프·게임 크기를 확인한다.
- 표면 텍스처·렌더 후처리는 원본의 입체 표현을 대체하지 않는다. 회전·조명 변화·애니메이션과 실제 게임 크기에서 합의한 특징을 확인한다.
