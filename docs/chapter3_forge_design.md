# 챕터 3 공명 용광로 설계

## 목적

챕터 3은 스테이지 11~15 구간이다. 균열 에너지가 지하 제련 시설에 흘러들어간 과열 전장으로 두고, 신규 적 타입이나 신규 전투 시스템 없이 기존 적 조합, 새 타일 테마, 새 맵 구조로 압박 체감을 만든다.

## 시각 컨셉

- 검은 금속, 식은 용암 균열, 주황 열광, 청록 코어 에너지
- 맵 타일 테마: `chapterThreeForgeTileTheme`
- 챕터 배너: `assets/images/chapter_3_banner.png`
- 맵 에디터 미리보기와 실제 전투 보드는 같은 용광로 타일 장식을 사용한다.

## 맵 역할

| 스테이지 | 역할 | 의도 |
| ---: | --- | --- |
| 11 | 용광로 입문 | 챕터 2보다 무거운 장갑/탱커 압박을 보여주되, 경로는 과하게 꺾지 않는다. |
| 12 | 긴 직선 | 긴 사거리와 누적 화력 가치를 올리고, 빠른 적 삽입으로 단일 정답을 막는다. |
| 13 | 좁은 목 | 병목 구간에서 범위 피해와 타겟 선택의 압박을 만든다. |
| 14 | 급회전 | 화력 낭비가 생기기 쉬운 회전 경로로 배치 방향성을 요구한다. |
| 15 | 코어 앞 압축 | 코어 근처에서 장갑병, 탱커, 보호막병, 보스 호위가 겹치는 최종 압박을 만든다. |

## 웨이브 문법

- 장갑병과 탱커를 중심축으로 둔다.
- 보호막병은 챕터 2의 주역에서 챕터 3의 보조 차폐 역할로 재사용한다.
- 빠른 적은 내구 적 뒤나 사이에 삽입해 과도한 중화기 편중을 막는다.
- 보스 웨이브는 `용광로 파쇄자` 1마리를 유지하고, 장갑/탱커 호위 구조로 방어구 돌파 압박을 강화한다.

## 장갑 보스: 용광로 파쇄자

챕터 3 최종 보스 계열은 `용광로 파쇄자`로 둔다.
챕터 1 보스와 같은 다각 실루엣과 코어 맥동은 유지하되, 검은 금속 장갑판과 주황 균열광, 청록 코어로 챕터 3의 공명 용광로 테마를 만든다.
보스 1마리 원칙은 유지하고, 보호막 재생이 아니라 방어구 감쇄를 돌파하는 보스로 설계한다.

역할:

- 방어구가 남아 있는 동안 작은 타격과 약한 지속 피해 효율을 낮춘다.
- 대포, 저격, 치명타, 장갑 관통 젬의 체감 가치를 높인다.
- 장갑병/탱커 호위와 겹쳐 타겟 우선순위와 누적 화력 배치를 요구한다.

초기 수치 기준:

| 항목 | 기준 |
| --- | ---: |
| 체력 | 760 |
| 방어구 | 520 |
| 보호막 | 없음 |
| 방어구 산식 | 최대 방어구 기준 공통 감쇄 |
| 속도 | 13.5 |
| 처치 골드 | 58 |
| 코어 피해 | 12 |
| 저항 | 없음 |

페이즈:

| 페이즈 | 조건 | 전투 의도 |
| --- | --- | --- |
| 제련 장갑 | 방어구 남아 있음 | 큰 피해와 장갑 관통 가치 강조 |
| 코어 노출 | 방어구 0 | 방어구 돌파 후 마무리 화력 보상 |
| 용광로 호위 | 웨이브 구성 | 장갑병/탱커/빠른 적 후속 압박 |

주의:

- 보호막을 넣지 않는다. 챕터 3의 핵심 학습은 방어구다.
- 방어구 재생을 넣지 않는다. 챕터 2 보호막 보스와 역할이 겹치고 전투가 지연된다.
- 별도 소환 패턴은 1차 구현에서 넣지 않고, 기존 웨이브 호위 그룹으로 표현한다.
- 방어구 감쇄는 `docs/damage_calculation_rules.md`의 최대 방어구 기준 공통 계위 규칙을 따른다.
