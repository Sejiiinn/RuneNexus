챕터 2 그래픽 배경 시안

챕터 탭은 번호만 남기고, 선택된 챕터의 지역성은 스테이지 리스트 뒤쪽의 인게임풍 배경 그래픽으로 전달하는 방향입니다. 단순 색상표 대신 포탈, 갈라진 길, 크리스탈 지형, 균열 에너지 레이어를 넣었습니다.

탭

챕터 1, 챕터 2, 챕터 3으로 단순 표기. 지역명은 탭에 넣지 않습니다.

테마명

테마명은 리스트 영역 위의 짧은 band에서만 보조적으로 표시합니다.

그래픽

균열 포탈, 보라색 경로, 청록 균열, 크리스탈 지형으로 실제 인게임 배경처럼 구성합니다.

구현

Flutter에서는 CustomPainter 또는 재사용 가능한 배경 painter로 챕터별 그래픽만 교체하면 됩니다.
