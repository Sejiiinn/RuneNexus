넥서스 그래픽 후보

현재 보드 톤을 유지하면서, 넥서스를 핵심 방어 대상처럼 보이게 만드는 4가지 방향입니다. 실제 구현은 `GridComponent._drawNexus()`에 옮기기 쉬운 벡터/캔버스형 구조를 기준으로 잡았습니다.

이미지 에셋 없이 Canvas 구현 가능

A. 수정 첨탑형

선택 방향
의도 원형 링은 빼고, 받침대와 크리스탈 면 분할만 강화합니다. 현재 게임 톤을 유지하면서 가장 자연스럽게 고급화하는 방향입니다.

B. 룬 링 코어형

추천
의도 보드 중앙 장치 느낌이 강합니다. 링은 피격/쿨다운/보호막 반응으로 확장하기 좋아 1차 구현 후보로 적합합니다.

C. 봉인 오벨리스크형

무거운 톤
의도 방어 대상이 더 견고하고 고대 장치처럼 보입니다. 단, 현재 포탈/크리스탈 톤과 연결하려면 빛을 조금 더 추가해야 합니다.

D. 보호막 발생기형

상태 표현 강함
의도 피격, 보호, 위험 체력 상태를 시각화하기 가장 좋습니다. 대신 기본 실루엣이 조금 복잡해서 크기를 잘 제한해야 합니다.
