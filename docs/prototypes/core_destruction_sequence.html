패배 직전 코어 파괴 연출 프로토타입

결과 패널을 바로 띄우지 않고, 코어로 카메라를 당긴 뒤 파괴 모션이 끝나는 순간 기존 실패 결과 화면으로 넘어가는 흐름을 기준으로 잡았다.

카메라 코어 중심 1.7~1.8배 확대 연출 입력 잠금, HUD 감광, 붉은 경고광, 균열, 충격파 전환 파괴 잔광 이후에만 실패 결과 패널 표시

재생 예시

0.00s · HP 0
0 / 20 Wave 17 1.0x

구현 기준 프레임

1.5초 내외

0.00s · 패배 확정

HP가 0이 되는 순간 결과 정산은 보류하고 스폰과 입력을 먼저 멈춘다.

0.45s · 코어로 확대

기존 보드 줌/팬 값을 보간해 코어를 화면 중앙보다 살짝 아래로 둔다.

1.10s · 균열과 충격파

코어 렌더링에 파괴 진행도를 넘겨 균열, 파편, 붉은 충격파를 그린다.

1.55s · 실패 패널 전환

잔광이 꺼진 뒤 기존 실패 결과 패널을 띄워 정산 흐름을 재사용한다.
