# Flutter 원본 보관

2026-09-24 Godot 단독 Android 전환으로 활성 경로에서 제거한 Flutter/Dart 및 종전 플랫폼 호스트 소스의 역사 자료다. 실행·빌드·검사 입력으로 사용하지 않는다.

- 파일: `flutter_reference_20260924.tar.gz`, 목록·메타데이터: `flutter_reference_20260924.json`.
- 삭제 직전 실제 작업 파일 545개를 보존했으며 파일별 SHA-256을 대조했다. 기존 미커밋 Android 변경도 포함한다.
- 압축 파일 SHA-256: `8c3e08c78f6b5f0025f61042b8ebf48123d69facb9e12206cccaccb55ce49e99`.
- 공통 JSON 테스트 fixture와 서버·에셋은 활성 경로에 유지한다. 기존 로컬 설정·무시된 생성 파일은 사용자 환경 보존을 위해 삭제하지 않았다.

현행 구현·검증은 [Godot 전환 상태](../godot_unified_app_roadmap.md)를 따른다. 필요한 역사 파일만 별도 임시 디렉터리에 추출한다.
