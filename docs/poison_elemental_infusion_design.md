# 독 포탑·속성 부여 젬·지속피해 규칙 설계

역할: 독 포탑 추가, 속성 부여 젬, 지속피해·감속 공통 규칙에 대해 사용자와 합의한 설계. 정리: 2026-10-20 KST.
상태: 규칙과 시작 수치를 정했다. 2026-10-20에 지속피해 공통 규칙(화상의 포탑별 합산, 방어구 비율, 독의 포탑별 중첩·개별 타이머·상한·중첩 보너스)과 보스 둔화 저항을 구현했다. 그 현행 동작은 [지속피해와 방어구](damage_calculation_rules.md#지속피해와-방어구)와 [지속피해의 만료 구간](damage_calculation_rules.md#지속피해의-만료-구간)이 기준이다. 독 포탑·부여 젬과 독의 치명타·저장 처리는 구현하지 않았다. 나머지는 구현하지 않았으며, 구현할 때 [데미지 계층 규칙](damage_calculation_rules.md)과 [밸런스 기준](gameplay_balance_reference.md)을 갱신한다. 우선순위·일정은 미정이다([TODO](TODO.md#독-포탑속성-부여-젬)).

수치는 모두 시뮬레이션으로 정한 시작값이다. 실제 실행기 측정은 하지 않았다([근거와 한계](#근거와-한계)).

## 결정 요약

- 지속피해 중 독만 방어구 감쇄를 무시하고, 나머지 지속피해는 방어구에 고정 50%만 들어간다.
- 화상·독은 속성 공통 규칙으로 정의하고, 화염·독 포탑은 고유 특성으로 그 효과를 증폭한다.
- 화상은 포탑마다 따로 걸려 합산된다. 같은 포탑 안에서는 가장 강한 화상 하나만 적용한다.
- 독은 명중마다 개별 타이머를 가진 중첩을 쌓고, 같은 포탑의 중첩 수에 비례한 보너스를 받는다.
- 보스는 모든 감속에 둔화 저항 50%를 가진다.
- 독 포탑은 원소 계열·지속피해 태그·투사체 공격이며 2-8에서 해금한다.
- 속성 부여 젬(화염·냉기·독)은 물리 포탑의 피해를 해당 원소로 변환하고, 직격을 유지한 채 공통 규칙의 부가 효과를 준다. 명시적 상한은 두지 않는다.

## 지속피해 공통 규칙

### 방어구

| 피해 | 방어구에 들어가는 비율 |
| --- | --- |
| 직격·폭발 주변·연쇄 등 타격 피해 | 기존 방어구 감쇄 공식 |
| 독 | 100% (감쇄 무시) |
| 독을 제외한 지속피해 (화상 등) | 고정 50% |

- 50%는 틱 크기와 무관한 고정 계수다. 틱마다 크기 기반 공식을 적용하지 않는다(구현됨).
- 장갑 관통 젬을 장착한 포탑은 타격 피해와 지속피해 모두 방어구 감쇄를 받지 않는다.
- 이 방어구 규칙은 지속피해를 주는 방식에 따라 정한다. 속성별로 보호막·방어구·체력 배율을 다르게 두는 약점표는 도입하지 않는다.

### 치명타

- 치명타 여부는 발사 시 한 번만 판정하고, 직격과 그 명중으로 생긴 지속피해가 같은 판정을 쓴다.
- 지속피해의 기준은 치명타 배율을 적용하기 전의 기본 명중 피해다.
- 치명타 명중으로 생긴 지속피해는 치명타 추가분의 50%를 반영한다. 예를 들어 2배 치명타면 지속피해는 1.5배다.

### 화상

- 화염 명중 피해는 기본 명중 피해의 초당 25%를 2초 동안 주는 화상을 남긴다.
- 같은 포탑의 화상은 가장 강한 하나만 적용하고, 다시 맞으면 지속시간을 갱신한다.
- 포탑이 다르면 각자의 화상이 동시에 피해를 주고 합산된다(구현됨).
- 화염 포탑은 고유 특성으로 화상 효과 100% 증폭을 가진다. 그래서 현재와 같은 초당 50%를 유지한다. 지금은 화염 포탑만 화상을 걸어 수치가 같으므로, 공통 계수와 고유 특성의 분리는 부여 젬 구현 때 넣는다.

### 독

- 독 중첩은 타격 피해(직격, 폭발 주변, 연쇄 등)에서만 생긴다. 화상 등 지속피해의 틱에서는 생기지 않는다.
- 명중 한 번마다 중첩 하나가 생긴다. 그 명중 피해의 30%를 5초에 균등하게 나눠 준다(초당 6%). 폭발 주변·연쇄 타격은 감폭된 그 타격 피해를 기준으로 한다.
- 중첩마다 개별 타이머가 있다. 새 명중은 이미 쌓인 중첩의 남은 시간을 늘리지 않는다.
- 중첩은 출처 포탑별로 따로 쌓는다. 포탑별 상한은 20이고, 상한에서 명중하면 남은 시간이 가장 짧은 중첩을 새 중첩으로 바꾼다.
- 중첩 보너스: 독 피해 = 그 포탑 중첩 피해의 합 × (1 + 5% × 그 포탑의 중첩 수). 상한 20에서 2배다. 다른 포탑의 중첩은 보너스에 포함하지 않는다.
- 중첩 구조·개별 타이머·상한·중첩 보너스는 구현했다. 명중당 30%와 치명타 반영은 독을 거는 공격을 만들 때 넣는다.
- 기존 지속피해 공통 보정(지속피해 젬, K3 가속 연소, 대형 표적 훈련, 최종 증폭, 균열 낙인)은 독에도 적용한다.

### 감속

- 감속은 가장 강한 하나만 적용하는 현행 규칙을 유지한다.
- 보스는 출처와 관계없이 모든 감속에 둔화 저항 50%를 가진다(구현됨). 희귀 몬스터 옵션 "둔화 저항"과 같은 장치를 쓴다. 냉각 포탑도 보스 상대로 약해지므로 보스 난이도를 다시 확인한다.

## 독 포탑

| 항목 | 시작값 |
| --- | --- |
| 계열·태그 | 원소 · 지속피해 |
| 공격 | 단일 대상 투사체. 판정은 기존 투사체와 같고, 화면에는 포물선을 그리는 라임그린 독액으로 표현 |
| 비용 | 100 |
| 직격 피해 / 연사 / 사거리 | 5 / 1.2회/s / 100 |
| 치명타 | 5% / 1.5배 |
| 독 | 고유 특성으로 공통 독을 증폭해 명중당 총량 200%를 5초에 나눠 줌 (중첩당 초당 40%) |
| 해금 | 2-8 최초 클리어 |

- 정체성: 첫 명중은 약하고, 오래 맞는 적에게 중첩을 쌓아 강해진다. 방어구에 강하고, 빨리 지나가는 적에게 약하다.
- 화염과의 차이: 화염은 직격이 크고 화상이 짧다. 독은 직격이 작고 독이 길게 쌓이며 방어구를 무시한다.
- 투사체 속도는 시뮬레이션에서 화염과 같은 420으로 가정했다.

## 속성 부여 젬

화염·냉기·독 부여 젬 3종을 추가한다.

- 물리 포탑에만 장착하며, 포탑 하나에 속성 부여 젬은 하나만 장착한다.
- 변환: 장착하면 포탑 피해가 원소 계열로 바뀐다. 직격 피해는 그대로 준다. 변환 뒤에는 원소 계열의 젬·훈련·취약만 적용하며, 물리 계열 보정을 함께 받지 않는다.
- 부가 효과는 위 공통 규칙을 그대로 따른다. 부여 젬 전용 계수나 명시적 피해 상한은 두지 않는다.

| 젬 | 부가 효과 |
| --- | --- |
| 화염 부여 | 화상: 기본 명중 피해의 초당 25%, 2초, 방어구 50% |
| 독 부여 | 독 중첩: 명중의 30%를 5초, 중첩 보너스, 방어구 무시 |
| 냉기 부여 | 감속 10%, 1초, 보스에게는 5% |

- 모듈 등의 "젬 효과 증가" 보정은 부여 젬의 화상·독·감속 계수를 키우지 않는다.
- 구조적 상한: 화상의 출처별 최강 하나와 짧은 지속시간, 독 상한 20, 방어구 50%, 변환으로 잃는 물리 보정, 젬 슬롯 하나가 과도한 강화를 막는다.
- 의도한 상성: 큰 한 방 포탑(저격·대포)은 화염, 작은 연사 포탑(기관총)은 독, 감속 보조는 냉기가 유리하다.

### 효과 없는 젬 표시

장착한 젬이 그 포탑의 능력치를 하나도 바꾸지 못하면, 젬의 효과를 끄고 비활성으로 표시한다. 특정 젬 조합을 지정하지 않는 일반 규칙이다. 예를 들어 변환한 포탑의 물리 피해 증폭 젬이 해당한다.

## 예상 효과

1레벨, 젬 1개, 방어구 없는 적, 직선 경로에서 한 타일 떨어진 포탑 기준의 사거리 안 실효 DPS 증가율이다. 방어구 열은 용광로 파쇄자(기본 방어구 468)의 방어구를 깎는 속도다.

| 조합 | 일반 몹 통과 | 보스 통과 | 방어구 구간 |
| --- | ---: | ---: | ---: |
| 기관총 + 화염 | +11% | +12% | +31% |
| 기관총 + 독 | +22% | +33% | +199% |
| 대포 + 화염 | +46% | +39% | +66% |
| 대포 + 독 | +19% | +22% | +83% |
| 저격 + 화염 | +36% | +41% | +44% |
| 저격 + 독 | +20% | +24% | +55% |

| 포탑 | 일반 몹 실효 DPS | 보스 실효 DPS | 방어구 구간 DPS |
| --- | ---: | ---: | ---: |
| 화염 포탑 | 18.7 | 18.3 | 7.4 |
| 독 포탑 | 15.3 | 18.1 | 15.4 |

방어구가 없는 적 상대로는 큰 한 방 + 화염이 기관총 + 독보다 이득이 크다. 이 차이는 받아들이기로 했다. 독은 방어구 구간에서 크게 앞서고, 기관총은 골드 효율이 높기 때문이다.

## 근거와 한계

- 기관총·대포·저격·화염의 기본 수치는 `godot/content/source/turrets.json`, 적 속도와 방어구는 `godot/content/source/enemies.json`, 방어구 감쇄식과 화상 처리는 `godot/combat/native_enemy_state.gd`에서 확인했다.
- 위 표는 별도로 작성한 Python 시뮬레이션으로 계산했다. 시뮬레이션 스크립트는 저장소에 추적하지 않는다.
  - 반영: 치명타 확률 판정, 공격 간격 흔들림, 투사체 비행시간, 저격 조준 시간
  - 미반영: 젬·모듈·코어 보정, 대상 전환, 여러 포탑과 여러 적
- 게임 실행기로 측정하지 않았다. 구현 후 네이티브 회귀와 실제 전투로 다시 확인해야 한다.

## 미정

- 독 포탑 특성 4종. 후보는 다음과 같다.
  - 1차: 독소 축적(최대 중첩 증가), 속효 독(명중당 2중첩)
  - 2차: 부식(중첩당 장갑 압박값 감소), 역병 전파(처치 시 남은 중첩 일부 이전), 독 웅덩이
- 지속피해별 고유 동작(확산 등). 아직 정의하지 않았다.
- 부여 젬의 해금 시점, 보상 풀 희석 대응, 이름·효과 문구
- 챕터 3과 보스 난이도 재확인. 화상 방어구 50%, 화상 포탑별 합산, 보스 둔화 저항, 독 포탑 추가가 함께 영향을 준다.
- 남은 구현 순서. 제안은 독 포탑 → 부여 젬이다.
  - 독 포탑 전에 독 중첩 목록(`poisonInstances`)의 저장 스키마를 추가해야 한다. 지금은 진행 중 저장에서 독 중첩이 기록되지 않는다. 클라이언트 저장 해시와 서버의 저장 세대 검사를 함께 바꾼다.
  - 서버의 젬 지급·검증과 포탑 해금표도 바뀐다.
