# Godot 최적화 A/B 로그 집계

분할 로그의 완성된 JSON만 사용한다. 프레임 간격은 모든 원시 표본을 합친 뒤 nearest-rank p50/p95/p99를 계산한다. FPS는 표본 수 × 1000 / 간격 합(ms)이다.

apply/json/render는 해당 프로파일 표본 수로 가중 평균한다. draw/primitives/메모리는 측정 창별 값의 산술 평균이다. 변화율은 (개선본/기준본 − 1) × 100이며 FPS 외에는 대체로 음수가 감소를 뜻한다. GPU timing이 모두 0이면 미지원으로 표시한다.
