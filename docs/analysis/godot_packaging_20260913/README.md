# APK 자산 중복 수정 검증

2026-09-13~14, APK 6024 배포 전 점검. 이전 공개본은 6023이다.

| 항목 | 공개 6023 | 수정 전 로컬 6024 | 수정 후 로컬 6024 |
| --- | ---: | ---: | ---: |
| APK bytes | 384,821,388 | 479,597,500 | 411,355,548 |
| Godot PCK bytes | 59,999,688 | 154,448,120 | 86,206,168 |
| PCK 완전 중복 bytes | 3,749,782 | 45,847,930 | 0 |
| PCK 항목 수 | 167 | 370 | 218 |

수정 전에는 동일 석재 텍스처가 GLB별로 추출되어 중복 패키징됐고, 빌드 폴더의 이전 PNG와 편집기 자동 VRAM 압축 설정도 남았다. 런타임 재질 공유만으로는 디스크 중복이 없어지지 않았다. GLB 외부 이미지 공유·빌드 자산 폴더 재준비·명시적 무손실 import·다이아 아이콘 경로 공유로 정리했다. 기존 포탄 데이터 14,155,776 bytes는 원본과 완전히 동일하게 복원되는 4,402,221 bytes gzip으로 패키징한다.

전체 APK는 문제 빌드 대비 68,241,952 bytes(65.08 MiB) 줄었다. 공개본 대비 증가량은 26,534,160 bytes(25.30 MiB, 6.90%)다. 남은 PCK 증가의 주된 구성은 2~10장 환경·최적화 타일 등 scene 리소스 증가 약 29.59 MiB, 중복 제거 후 텍스처 순증 약 4.64 MiB, 기존 포탄 압축 감소 약 9.30 MiB다. Scene 리소스도 Godot의 압축 형식으로 저장된다. 이번 검사는 완전 동일 파일 중복 제거를 확인하며, 서로 다른 메시 내부의 부분 중복까지 없다는 뜻은 아니다. 세 ABI와 이미지 해상도·모델 기하를 유지했다.

검증:

- 전체 실제 34개 GLB의 images 외 JSON과 BIN 전체가 제작 원본과 일치한다.
- 146개 재질의 167개 참조가 37개 Texture2D 객체를 공유한다. 37개 이미지 모두 원본 PNG와 base-level RGBA8 픽셀이 완전히 일치한다. [텍스처 검사](textures.log).
- 포탄 gzip 원본 바이트·격자·RGBA8·32프레임·1.1초·공유 캐시·기존 raw 경로 검사 통과. [효과 검사](field.log).
- 다시 준비한 팩도 동일 218개 경로와 중복 0 bytes를 유지했다. 재import UID 등에 따른 압축 차이로 총 크기는 86,206,216 bytes였다.
- Flutter analyze 통과, 전체 Flutter 테스트 829개 통과·기존 skip 11개, Python APK 검사 23개 통과.
- 일반 lib/main.dart Android 에뮬레이터에서 메모리 저장 검수 상태를 사용해 [스테이지 1](android-stage1.png), [스테이지 10 고정](android-stage10.png)·[드론](android-stage10-drone.png), 대포 설치·실제 웨이브 [전투 영상](android-cannon.mp4)을 확인했다. 석재·식생·절벽·환경 장식과 HUD가 유지된다. 에뮬레이터 검증이며 실기기 지속 성능 결과가 아니다.
- CI는 실제 서명 APK 팩 감사 JSON을 workflow 아티팩트로 저장한다. 공개 파일 수치는 [배포 상태](../../deployment_status.md)에서 최종 확인한다.

집계 원자료: [summary.json](summary.json). 전체 항목 감사는 scripts/audit_godot_pack.py로 APK/PCK에서 재생성할 수 있다.

공개 6024 최종 APK는 411,353,104 bytes, PCK는 86,203,724 bytes·217항목·중복 0 bytes다. 로컬 전용 미사용 core_crystal.gdshader는 공개본에 포함되지 않았다. 실제 공개 파일·패치·최신 메타데이터·서명 대조를 완료했다.
