## 기존 기준 적용

[이전 측정](../fps_20260920/README.md)과 같은 Android 17 ARM64 에뮬레이터, 1080×2424·60Hz, 일반 lib/main.dart profile 0.1.19+6027을 사용했다. API·업데이트 주소·디버그 패널은 켜지 않았다. 기존 저장의 스테이지 1·23웨이브·드론 시점·대포 레벨1 6개/마법 레벨4 1개/화살 레벨1 1개, 기본 MSAA 2×·그림자 2048을 유지했다.

Android SurfaceFlinger --latency에서 실제 표시 시각을 제공하는 Godot SurfaceView #7391을 골라 약 0.7초마다 수집·중복 제거했다. 웨이브 시작 뒤 2초를 제외하고 약 12초만 측정했다. FPS는 프레임 간격 개수×1000/간격 합(ms), p95/p99는 nearest-rank다. 측정 중 화면 캡처·녹화·빌드·테스트는 하지 않았다.

전장 초기화 ACK→웨이브 시작 대기는 이번 124.33초, 이전 약 49초로 달랐다. 레이어 이름 조회 형식과 shell 인용 처리 때문에 준비 대기가 길어졌으며 전투는 한 번만 시작했다. 동일한 측정 방식의 참고 비교이며 엄격한 A/B 또는 반복 측정은 아니다.
