# 스테이지 난이도·웨이브 합류 검토

상태: 2026-09-10 내구도 하향 이전의 분석 기록. 표와 CSV는 기본 내구도 10% 하향 및 스테이지 증가율 20%→15% 변경 전 수치다. 아래 웨이브 구성·합류 조정안은 미적용 제안이며, 현행 수치는 `../../gameplay_balance_reference.md`를 따른다.
목표: 신규 유저가 고도의 최적화나 반복 영구성장 없이 스테이지 1을 클리어할 수 있고, 이후 난이도가 완만하게 증가하는 방향 검토.
사용자 조건: 겹침 자체를 없애지 않는다. 밀집의 빈도·연속성을 조절하면서 대포 등 범위피해의 활약 구간을 보존한다.

## 방법과 한계

- 실제 `gameStages`, `gameEnemies`와 `WaveSpawner.start`/`toSaveData`를 사용하는 임시 Flutter 분석에서 15×40=600개 웨이브의 스폰 큐를 추출했다. 그룹 적 수와 큐 적 수, 전체 웨이브 수 검증 통과. 분석용 임시 Dart 파일은 제거했다.
- 기존 `tool/stage_difficulty_analysis.dart` 실행 통과. 이 도구는 실전 승률 시뮬레이션이 아니다. 탐욕 강화 모델의 결과는 확정 난이도로 사용하지 않았다.
- 경로 길이는 실제 맵 좌표 간 거리 합×기준 타일 48. 이동은 적 기본 속도 기준 연속 운동. 실제 프레임별 코너 이동, 처치, 둔화, 타겟 변경, 재생, 저항, 장갑 감쇄, 포탑 배치와 구매 순서를 시뮬레이션하지 않았다.
- 분석값은 모든 적이 살아서 이동하는 경우의 구조적 합류 가능성이다. 실제로 그만큼 겹친다거나, 그만큼 어렵다는 의미가 아니다. 밀집은 범위피해 효율을 올려 오히려 쉬워질 수도 있다.
- 동일 시각 스폰의 정렬 등은 재구현하지 않고 실제 스포너 결과를 사용했다. 공통 초기 경고 지연은 상대 간격과 합류 위치에 영향을 주지 않으므로 0으로 두었다.
- CSV의 `gold`는 전원 처치 시 처치 골드+웨이브 완료 보상. 시작 골드와 영구·런·연구 보너스 제외. `durability`는 HP+보호막+방어구 단순 합이다.
- `spawnPeak`/`peak25/50/75/Core`는 출발/경로 해당 지점에서 임의의 1초 구간에 통과하는 최대 적 수. `catchPairs`는 경로 내에서 빠른 후속 적이 선행 적을 추월할 수 있는 쌍 수이며 밀집 웨이브 판정값이 아니다.
- `mid2TilePeak`는 경로 중앙 앞뒤 각 1타일, 총 2타일 구간의 최대 동시 적 수. `mid2TileDenseSeconds`는 그 구간에 6기 이상이 있는 누적 시간. 6기는 비교용 임시 기준으로, 실제 대포 폭발 범위나 최종 밸런스 합격 기준이 아니다.

## 스테이지 1

- 시작 골드 170, 기본 넥서스 체력 20. 전체 751기: 일반436, 빠름259, 탱커52, 보스4.
- 라운드 내구 배율은 `2^((round-1)/10)`. W40은 W1의 **14.9285배**다. 일반 기본 체력35→약522.5, 보스623→약9300.5. 보스는 각 웨이브에서 1기다.
- W5→6 총 내구 +41.8%, W8→9 +66.0%, W9→10 +85.7%. 보스는 느리므로 이 수치가 같은 비율의 실전 난도 상승은 아니다. 다만 초기 성장의 급증 후보로 우선 검증할 필요가 있다.
- 보스 누수 피해8: 회복·방어가 없는 기본 체력20에서 세 번 누수는 실패. W1~5만 학습형이라는 이유로 전체 40웨이브를 신규 유저가 클리어할 수 있다고 볼 수 없다.

## 합류 빈도와 원인

- 스포너는 시간만 사용한다. 그룹 뒤따르기는 앞 그룹의 마지막 생성 시각 기준이며, 최소 생성 간격0.18초는 이동 후 밀집을 제어하지 않는다.
- 일반/빠름/탱커의 기본 속도는31.5/54.6/21. 일반 기준형 웨이브도 일반 후0.75초 뒤 빠른 적이 나온다.
- S1 W6: 마지막 일반13.64초, 첫 빠름14.39초. 두 적이 살아 있다면 약1.16타일 지점에서 합류한다. S1 W5: 탱커0초, 일반1.6초 → 약2.1타일에서 합류한다.
- 빠른 후속 적이 느린 선행 적을 따라잡는 거리: `d = (후속 생성시각-선행 생성시각)/(1/선행속도-1/후속속도)`.
- 전체600개 중562개, S1 40개 중37개에서 적어도 한 쌍의 경로 내 추월이 가능하다. 이 비율을 실제 밀집 웨이브 비율로 해석하면 안 된다.
- S1 40개 중30개는 경로 중앙의 1초 최대 통과 수가 출발점보다 많다. 중앙2타일에6기 이상이 한 번이라도 있는 웨이브는26개지만, 해당 밀집의 누적 시간이1초 이상인 웨이브는10개다. 짧은 합류와 지속 밀집은 구분해야 한다.
- 기존 `test/game_balance_test.dart`의 `only dedicated pressure waves overlap major spawn groups`는 일부 웨이브의 출발시각만 검사한다. 게임 내 이동 후 합류/빈도/지속시간은 검사하지 않는다.

## 조정 제안 — 아직 게임에 미적용

1. S1 전체40웨이브를 무영구강화·무연구·무모듈·무코어투자 기준으로 검증한다. 적당한 경로 커버리지와 기본 구매·강화·젬 사용을 하되 최적 조합/정밀 타이밍을 전제하지 않는 여러 운영을 사용한다. 젬 운이 나쁜 경우도 포함한다.
2. 밀집을 금지하지 않는다. 일반 진행, 가벼운 합류, 분명한 밀집의 세 강도를 나누어 배치한다. 초기 후보는 5웨이브에 강한 밀집1회, 가벼운 합류1회, 나머지 일반 진행. 보스 호위가 강한 밀집이면 그 구간의 밀집 예산에 포함해 추가 중첩을 피한다. 이는 운영 템플릿 후보이며 모든 5웨이브를 동일 패턴으로 고정한다는 뜻이 아니다.
3. 일반 웨이브에서도 작은 적 묶음은 남기고, 강한 밀집과 기동·탱커·보스 압박이 연속되지 않게 한다. 범위피해가 빛나는 적절한 크기·지속시간의 묶음을 의도적으로 배치한다.
4. 스폰 간격의 일괄 확대나 전원 속도 통일 대신, 그룹 순서·그룹 크기·간격·합류 목표 위치를 조정한다. 시작/중앙/후반 전투 구간의 도착 분포를 함께 본다. 긴 맵에서는 무조건 끝까지 추월 금지를 적용하지 않는다.
5. S1 초기 W3~10의 밀집/기믹 연속 소개와 후반 내구 증가를 우선 완화 후보로 검증한다. 적 수를 줄여 후속 성장 자금까지 줄이는 부작용을 피하고, 감소 시 보상 예산을 함께 확인한다.
6. S6·S8의 구성 급증, S11·S13의 골드 단절과 경로 변화부터 완화한 뒤 전역 스테이지 배율 하향 필요성을 판단한다. 전역 배율 하향은 고스테이지에 누적해서 크게 작용하므로 국소 변경과 중복되지 않게 한다.
7. 같은 성장 조건에서 클리어 여부·누수·잔여HP·웨이브별 가용골드·대포의 실효 피해·밀집 지속시간을 비교한다. 실전 검증 전에는 하향 퍼센트와 목표 승률을 확정하지 않는다.
