# 스테이지 1 표면 질감·전투 효과

역할: 밝기를 유지하는 스테이지 1 재질·이펙트 개선 설계와 적용 기록. 2026-09-13 사용자 요청 기준.

## 목표와 보존 범위

[참고 영상](https://www.instagram.com/p/DbcypbCMd6r/)의 석재 질감과 공간 안에서 겹치는 전투 효과를 참고한다. 사용자가 추가 전달한 [최소 외형 기준](../design/stage1_3d/surface_effects/target-reference.jpg)은 두꺼운 석재 측면, 깊게 읽히는 틈, 선명한 요철, 겹치는 식생, 기단과 잎 아래의 접촉 그림자다. 거칠기 숫자만 바꾸거나 약한 cavity를 추가한 첫 결과는 이 기준을 충족하지 못했다.

어두운 던전 조명·청회색 색보정을 따라 하는 작업은 아니다. 밝은 윗면·길과 건설칸의 구분·맵 형태·고정/드론 시점·HUD를 유지하며, 시안의 입체감에 필요한 측면·접촉부 명암 차이는 살린다. Godot Mobile을 유지하고 전투 수치·저장·엔진 연결은 변경하지 않는다.

포탈·코어의 승인 형태·면색·유리 표현은 별도 확정 기준을 유지한다. 직전 불투명 코어 실험은 사용자가 거절한 결과이며 승인 시안을 대체하지 않는다. 이번 전장 표면 작업의 성공을 코어 유리 이관 완료로 보고하지 않는다.

## 구현 설계

| 영역 | 적용 방식 | 시각 판정 |
| --- | --- | --- |
| 길·건설석판 | 위치별 상면 색·노멀 atlas를 보존한다. 평면 투영에서 붕괴했던 슬랩 측면 UV를 수직면 기준으로 복구하고 원본 석재 PBR을 연결한다. 높이 cavity에 실제 정적 지형의 근거리 AO를 합쳐 ORM에 베이크한다. | 돌 윗면의 색을 유지하면서 측면·돌 사이 틈과 마모가 읽힌다. 전체를 검게 칠하지 않는다. |
| 석재 표면 | 돌·이끼의 거칠기를 구분하고 건설석판/길 노멀 강도를 실제 게임 크기에 맞춘다. 공용 StandardMaterial3D와 mipmap 필터를 사용한다. | 넓은 흰 광택으로 면이 지워지지 않고, 거친 돌·이끼·금속이 구분된다. |
| 빛 반응 | 주광을 보이는 측면 반대쪽으로 돌리고 환경광·보조광을 줄이되 상면 총광량을 주광으로 보정한다. 작은 전장에 직교 그림자를 사용하고 bias를 낮춰 기단의 접촉을 유지한다. 식생도 양면 그림자를 만든다. | 밝은 윗면과 어두운 측면이 분리되고, 잎 밑과 기단이 바닥에 붙는다. 전체 bloom으로 지형 텍스처를 덮지 않는다. |
| 기관총·대포 효과 | 승인된 3D 화염·공유 체적 캐시·입체 파편·예광을 유지한다. 실제 카메라와 불투명 장면 깊이를 사용해 연기·폭발의 교차를 수정한다. | 섬광·파편·먼지가 지형 및 적과 자연스럽게 앞뒤로 겹치고, 평면 판이나 경계 상자가 드러나지 않는다. |
| 비용 | 고정된 24,000삼각형 상한으로 목표 외형을 제한하지 않는다. 실제 병목이 확인된 영역을 최적화하며 기존 atlas·캐시·풀은 재사용한다. | Android 게임 크기에서 차이가 보이며 불필요한 원본·중간 파일은 APK에 포함되지 않는다. 실기기 측정 없이 성능 한계를 단정하지 않는다. |

## 실행과 완료

### 시안의 재질·명암을 맞추는 후속 구현 계획

석재 반사와 공통 조명은 앞 단계에서 조정했다. 이후 사용자 요청에 따라 고사리 전용 외피를 공통 그림자 기준으로 대체한다. [공통 그림자 검토](../design/stage1_3d/surface_effects/verification/common-shadow-review-20260913/README.md)에서 직교 카메라의 과도한 깊이 범위와 자동 LOD에 의한 실제 잎 차폐 손실을 확인했다.

| 담당 | 구현 책임 | 완료 판정 |
| --- | --- | --- |
| Astra · 카메라 | 전장·모델·탄체·효과와 전환 중 방향을 포함하는 깊이 범위를 계산한다. 구도와 HUD 배치를 보존한다. | 고정·드론·전환 및 큰 적·폭발이 잘리지 않고 공통 그림자의 유효 범위가 줄어든다. |
| Astra · 식생 | 얇은 잎의 투영 면적·겹침을 보존하는 import 기준을 적용한다. 고사리 전용 외피·셰이더·점유 재질을 제거한다. | 실제 식생 메시의 양면 그림자로 모든 잎 아래 음영이 유지되고, 건설 점유·철거·바람이 같은 기하에 반영된다. |
| Astra · 성능 조사 | 기존 Android 측정 경로와 비교 가능 범위를 확인한다. | 에뮬레이터 관측값과 실기기 성능을 구분한다. |
| 주 에이전트 · 통합 | 공유 파일 통합, 시각 판정, Android 일반 본게임 APK 검수와 용량 점검을 수행한다. | 실제 고정·드론 화면과 관련 깊이 효과를 확인하고 적용 기록을 제공한다. |

지형·포탑·적·식생은 Godot 공통 주광 그림자를 사용한다. 얇은 식생은 실제 잎의 형태를 보존하며 다른 지형·바위·포탑·적의 LOD를 일괄 해제하지 않는다. 투명 코어·포탈 에너지·미리보기·전투 효과의 기존 그림자 생성 예외는 유지한다. 정적 지형 AO는 틈의 표면 데이터로 유지한다. 과거 [고사리 전용 외피 기록](../design/stage1_3d/environment_dressing/verification/fern-shadow-20260913/README.md)은 제작 이력이며 현행 제작 요구가 아니다.

현재 실제 전장 화면을 기준으로 변경 전후를 비교한다. 기존 Godot 장면 캡처에서 첫 대표 결과를 확인한 뒤 Android 일반 본게임 APK의 고정/드론 시점과 관련 전투 효과를 확인한다. 시각적으로 실패하면 확대 적용·추가 패키징을 진행하지 않는다. 새로운 비교 UI나 대량 캡처 도구를 만들지 않는다.

구현 파일·실제 이미지·검사 결과와 APK 크기는 [적용 기록](../design/stage1_3d/surface_effects/README.md)에 정리한다. 실기기가 없으면 에뮬레이터 검증과 실기기 성능 미검증을 구분한다.
