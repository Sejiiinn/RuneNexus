균열 결정체 몹 외형 시안

같은 진영에서 나온 적처럼 보이도록 공통 코어, 결정 파편, 금속 외곽선을 공유하고 역할별 실루엣만 다르게 잡은 초안입니다.

균열 보행체기준형

마름모 몸체와 중앙 코어를 기본 골격으로 사용합니다.

균열 척후체고속형

앞으로 쏠린 쐐기 실루엣과 청록 추진 흔적으로 속도를 강조합니다.

장갑 파편체방어형

양옆 금속판과 넓은 육각 몸체로 방어구 몹임을 먼저 읽히게 합니다.

균열 수호체보스형

기준 골격을 크게 확장하고 붉은 코어와 다중 파편으로 위계를 줍니다.

외형 규칙

모든 몹은 어두운 결정 몸체, 밝은 외곽선, 중앙 코어를 공유합니다. 역할 차이는 몸체 비율, 파편 방향, 포인트 컬러, 장갑판 개수로만 구분합니다.

내구도 표시

보호막은 위쪽 파란 줄, 체력과 방어구는 아래쪽 줄의 붉은 체력 구간과 회색 방어구 구간으로 표시합니다.
