# 포탑 모듈 설계

## 목적

포탑 모듈은 오래 플레이할수록 포탑별 성장 목표가 쌓이는 계정 단위 장기 성장 시스템이다.

현재 Rune Nexus는 런 안에서 포탑, 젬, 링크, 특성을 통해 빌드 선택을 만든다. 포탑 모듈은 런 밖에서 특정 포탑을 꾸준히 강화하는 목표를 담당한다. 단, 1차 구현은 특수 능력보다 이해하기 쉬운 수치 성장과 장착 UX 검증에 집중한다.

## 현재 우선순위

포탑 모듈 MVP는 다음 최우선 구현 과제로 둔다.

1차 구현 목표:

- 메인 메뉴 하단 탭에서 포탑 모듈 화면 진입
- 모듈권 기반 뽑기
- 포탑 선택
- 코어, 포신, 프레임 3부위 장착
- 선택 부위에 맞는 모듈 후보 표시
- 일반, 마법, 희귀 3등급
- 중복 조각 수집과 수동 합성
- 희귀 보정 게이지

1차 구현에서 제외:

- 스킬 트리
- 유니크 등급
- 특수 능력
- 분해
- 지정 뽑기
- 새 포탑 해금 보급 세트 UI
- 보유 효과

## 핵심 결정

- 모듈은 포탑별 장착물이다.
- 모든 포탑은 `코어`, `포신`, `프레임` 3부위를 가진다.
- 스킬 트리는 이번 MVP에서 탭과 화면에 노출하지 않는다.
- 모듈 뽑기는 해금된 포탑 전체 풀을 대상으로 한다.
- 지정 뽑기는 넣지 않는다.
- 뒤늦게 해금된 포탑의 모듈 획득 부담은 새 포탑 해금 시 별도 보급 보상으로 완화할 수 있지만, 보급 세트는 모듈 화면에 상시 표시하지 않는다.
- 1차 등급은 `일반`, `마법`, `희귀`만 사용한다.
- 유니크와 특수 능력은 MVP 이후 확장 후보로 둔다.

## 부위별 역할

부위별 역할은 겹치지 않게 고정한다.

| 부위 | 담당 효과 | 설계 의도 |
| --- | --- | --- |
| 프레임 | 업그레이드 비용 감소 | 전투력 직접 증가와 분리된 장기 효율 |
| 포신 | 공격력 증가, 공격속도 소폭 증가 | 순수 화력 성장 |
| 코어 | 포탑별 특징 스탯 증가 | 포탑 정체성 강화 |

### 프레임

프레임은 비용 효율 전용 부위다.

허용 효과:

- 해당 포탑 업그레이드 비용 감소

보류 효과:

- 공격력 증가
- 공격속도 증가
- 범위, 둔화, 치명타 등 전투 역할 보정
- 특수 발동 효과

초안 수치:

| 등급 | 효과 |
| --- | --- |
| 일반 | 업그레이드 비용 -1% |
| 마법 | 업그레이드 비용 -2% |
| 희귀 | 업그레이드 비용 -3.5% |

### 포신

포신은 순수 화력 부위다.

허용 효과:

- 공격력 증가
- 공격속도 소폭 증가

공격속도는 체감은 주되 포탑 정체성을 바꾸지 않는 낮은 수치로 제한한다.

초안 수치:

| 등급 | 효과 |
| --- | --- |
| 일반 | 공격력 +2% |
| 마법 | 공격력 +4%, 공격속도 +1% |
| 희귀 | 공격력 +6%, 공격속도 +2% |

### 코어

코어는 포탑별 특징을 강화한다.

코어도 MVP에서는 특수 능력을 갖지 않는다. 유니크 등급을 쓰지 않으므로, 코어 역시 일반/마법/희귀 수치 차이만 가진다.

포탑별 코어 효과 후보:

| 포탑 | 코어 효과 방향 |
| --- | --- |
| 기관총 | 일반몹 피해 증가 또는 연속 타격 계열 피해 증가 |
| 대포 | 범위 피해 증가 또는 폭발 반경 소폭 증가 |
| 화염 | 지속 피해 증가 |
| 냉각 | 둔화 효과 증가 또는 냉각 지속시간 증가 |
| 저격 | 정예/보스 피해 증가 또는 치명타 피해 증가 |
| 라이트닝 | 연쇄 피해 증가 또는 연쇄 감쇠 완화 |

기관총 코어 초안:

| 등급 | 효과 |
| --- | --- |
| 일반 | 일반몹 피해 +3% |
| 마법 | 일반몹 피해 +5% |
| 희귀 | 일반몹 피해 +8% |

## 등급

MVP 등급은 3개만 사용한다.

| 등급 | 역할 |
| --- | --- |
| 일반 | 자주 나오며 별 성장이 쉬운 기본 등급 |
| 마법 | 체감 가능한 중간 등급 |
| 희귀 | MVP의 최고 목표 등급 |

유니크 등급은 제외한다.

제외 이유:

- 특수 능력 설계와 밸런싱 범위가 크게 늘어난다.
- 코어와 프레임은 유니크여도 별도 특수 능력이 어울리지 않는다.
- 희귀까지의 수치 성장과 보정 뽑기만으로도 MVP 검증이 가능하다.

## 중복, 조각, 합성

모듈을 중복 획득하면 해당 모듈의 조각 수가 증가한다.

합성 조건:

```text
같은 포탑 + 같은 부위 + 같은 모듈 계열 + 같은 등급
조각 5개 이상 보유
```

합성은 자동으로 일어나지 않는다. 사용자가 `합성` 버튼을 눌러야 한다.

성장 규칙:

```text
0성 + 조각 5개 -> 합성 -> 1성
1성 + 조각 5개 -> 합성 -> 2성
2성 + 조각 5개 -> 합성 -> 3성
3성 + 조각 5개 -> 합성 -> 다음 등급 0성
```

예시:

```text
기관총 / 코어 / 과열 연산 / 일반 2성 / 6/5
-> 합성 가능
-> 합성 시 일반 3성

기관총 / 코어 / 과열 연산 / 일반 3성 / 5/5
-> 합성 가능
-> 합성 시 마법 0성

기관총 / 코어 / 과열 연산 / 마법 3성 / 5/5
-> 합성 가능
-> 합성 시 희귀 0성
```

희귀 3성은 MVP 최대 성장이다.

희귀 3성 이후 같은 조각을 더 얻는 경우는 우선 보유만 한다. 분해나 공용 조각 전환은 MVP 이후 확장 후보로 둔다.

## 뽑기와 모듈권

모듈 뽑기는 모듈권을 사용한다.

기본 비용:

| 뽑기 | 비용 |
| --- | --- |
| 1회 | 모듈권 1장 |
| 5회 | 모듈권 5장 |

모듈권 수급:

- 스테이지 진행 보상
- 주간 과제
- 장기 플레이 보상
- 이벤트 또는 접속 보상

모듈권이 부족한 상태에서 뽑기를 누르면, 부족한 모듈권을 다이아로 구매할 수 있게 한다.

예시:

```text
보유 모듈권: 3장
5회 뽑기 선택
부족 모듈권: 2장

모듈권 2장을 구매하고 5회 뽑기를 진행할까요?
필요 다이아: 160
```

초안 가격:

| 상품 | 가격 |
| --- | --- |
| 모듈권 1장 | 다이아 80 |

MVP에서는 5회 뽑기 할인은 넣지 않는다.

## 뽑기 확률과 희귀 보정

확률은 완전 고정값만 쓰지 않는다.

기본 확률 초안:

| 등급 | 기본 확률 |
| --- | ---: |
| 일반 | 68% |
| 마법 | 27% |
| 희귀 | 5% |

희귀 보정:

```text
15회 연속 희귀 미획득 후부터
뽑기 1회마다 희귀 확률 +3%p
35회째 희귀 확정
희귀 획득 시 보정 초기화
```

5회 뽑기는 내부적으로 1회씩 순서대로 처리한다. 중간에 희귀가 나오면 그 시점에서 보정 게이지를 초기화한다.

희귀 보정은 모듈권으로 뽑든, 부족분을 다이아로 구매해서 뽑든 동일하게 누적한다.

목표:

- 초반에 희귀를 바로 얻어도 과도하게 강해지지 않게 한다.
- 오래 플레이해도 희귀를 못 얻는 상황을 줄인다.
- 희귀 직뽑 운과 장기 누적 성장이 함께 작동하게 한다.

## 뽑기 풀

뽑기 대상은 해금된 포탑 전체 풀이다.

필터:

- 지정 포탑 뽑기 없음
- 지정 부위 뽑기 없음
- 해금되지 않은 포탑 모듈은 등장하지 않음

획득 결과는 다음 조합 중 하나다.

```text
포탑 + 부위 + 모듈 계열 + 등급
```

예시:

```text
기관총 / 코어 / 과열 연산 / 희귀
대포 / 포신 / 중장 포신 / 마법
화염 / 프레임 / 안정 프레임 / 일반
```

새 포탑 해금 직후 해당 포탑 모듈을 얻기 어려운 문제는 별도 보급 보상으로 완화한다. 단, 이 보상은 포탑 해금 보상 화면이나 우편/보상 팝업에서 처리하고, 모듈 장착 화면에는 상시 노출하지 않는다.

## UI 기준

현재 UX 초안:

- `docs/prototypes/turret_module_equipment_ux_draft.html`

화면 흐름:

```text
모듈 뽑기
-> 포탑 선택
-> 포탑 장비창
-> 선택 모듈 상세
-> 선택 부위의 모듈 후보
```

장비창:

- 왼쪽에는 실제 포탑을 둔다.
- 오른쪽에는 코어, 포신, 프레임 슬롯을 세로로 둔다.
- 포탑과 각 슬롯은 선으로 연결한다.
- 슬롯을 누르면 해당 부위 후보만 하단에 보여준다.

상세 스트립:

- 장비창 바로 아래, 모듈 후보 바로 위에 둔다.
- 선택한 모듈의 등급, 이름, 부위, 대상 포탑, 장착 효과, 장착/합성 액션을 보여준다.
- 합성 가능 조건이면 `합성` 버튼을 노출한다.
- 합성 불가능 상태에서는 MVP 기준으로 버튼을 숨긴다.

모듈 후보:

- 선택 부위에 장착 가능한 모듈만 표시한다.
- MVP 초안은 `일반`, `마법`, `희귀` 3칸 한 줄로 보여준다.
- 각 칸은 등급, 레벨, 아이콘, 별, 조각 수를 표시한다.
- 효과 설명은 후보 칸이 아니라 상세 스트립에서 보여준다.

후보 정렬:

```text
일반 -> 마법 -> 희귀
```

향후 같은 부위에 여러 모듈 계열이 생기면, 각 계열을 행으로 나누고 행 내부는 같은 정렬을 유지한다.

```text
과열 연산: 일반 / 마법 / 희귀
약점 추적: 일반 / 마법 / 희귀
```

## 구현 메모

저장 데이터는 최소한 다음 정보를 표현해야 한다.

```text
turretType
modulePart
moduleFamily
grade
stars
shards
equipped
```

계정 단위 상태:

```text
moduleTickets
rarePityCounter
ownedModules
equippedModulesByTurret
```

주의사항:

- 포탑별/부위별 장착 슬롯은 저장되어야 한다.
- 합성은 수동 액션으로 처리한다.
- 희귀 보정 카운터는 뽑기 결과가 확정된 뒤 저장한다.
- 5회 뽑기는 중간 결과마다 보정 카운터를 갱신한다.
- 모듈권 부족 시 다이아 구매 확인을 먼저 거친다.
- 모듈 효과는 포탑 스탯 보정 계층에 들어가며, 피해 관련 표현은 `docs/damage_calculation_rules.md`의 `증가`, `증폭`, `저항` 용어를 따른다.

## 확장 후보

MVP 이후 검토:

- 유니크 등급
- 유니크 전용 특수 능력
- 초과 희귀 조각의 공용 조각 전환
- 분해
- 새 포탑 해금 보급 세트 UI
- 모듈 필터와 정렬
- 포탑별 모듈 도감
- 보유 효과
- 계열별 스킬 트리
