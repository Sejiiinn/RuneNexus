# 포탑 모듈 설계

## 목적

포탑 모듈은 런 밖에서 특정 포탑을 꾸준히 강화하는 계정 단위 장기 성장 시스템이다.

현재 구현은 별 성장, 조각 합성, 고정 수치 모듈을 사용하지 않는다. 모듈 뽑기로 개별 아이템을 획득하고, 각 아이템은 등급과 부위에 맞는 랜덤 옵션을 가진다. 플레이어는 보유 인벤토리에서 원하는 아이템을 선택해 포탑의 코어, 포신, 프레임 슬롯에 장착한다.

모듈 뽑기는 모듈 화면에서 현재 선택한 포탑을 대상으로 한다. 포탑 종류는 뽑기 전에 플레이어가 확정하며, 결과에서는 해당 포탑의 부위, 등급, 옵션만 무작위로 결정된다.

## 핵심 결정

- 등급은 `일반`, `마법`, `희귀`, `유니크`를 사용한다.
- 뽑기 대상 포탑은 현재 선택한 포탑으로 고정한다. 해금된 포탑 전체 중 하나를 다시 무작위로 고르지 않는다.
- 유니크는 전용 특수 능력 없이 희귀보다 높은 수치 등급으로 둔다.
- 아이템 하나는 `포탑 + 부위 + 계열 + 등급 + 옵션 목록`으로 구성된다.
- 일반/마법은 1-2개 옵션, 희귀는 1-3개 옵션, 유니크는 2-3개 옵션을 가진다.
- 같은 부위에 장착 가능한 아이템은 여러 개 보유할 수 있으며, 장착은 부위당 1개만 가능하다.
- 조각 합성과 별 성장은 폐기한다.
- 불필요한 아이템은 분해해 다이아로 환급한다.
- 레거시 저장 데이터 마이그레이션은 고려하지 않는다. 배포 전 기능이므로 기존 조각/별 데이터는 보존 대상이 아니다.

## 등급과 뽑기

- 모듈권 스테이지 보상은 스테이지 11 최초 클리어의 5장만 지급한다.
- 다른 스테이지 최초 클리어와 모든 재클리어에는 모듈권을 지급하지 않는다.
- 1회/5회 뽑기를 지원하며 모듈 1개당 모듈권 1장을 소비한다.
- 모듈권이 부족하면 부족분 1장당 다이아 80개로 보충한 뒤 뽑을 수 있다.
- 선택한 포탑 안에서 부위, 등급, 옵션 종류와 수치를 무작위로 결정한다.

뽑기 확률:

| 등급 | 확률 |
| --- | ---: |
| 일반 | 65% |
| 마법 | 26% |
| 희귀 | 7% |
| 유니크 | 2% |

옵션 개수 확률:

| 등급 | 1옵션 | 2옵션 | 3옵션 |
| --- | ---: | ---: | ---: |
| 일반 | 85% | 15% | 0% |
| 마법 | 40% | 60% | 0% |
| 희귀 | 10% | 55% | 35% |
| 유니크 | 0% | 40% | 60% |

분해 환급:

| 등급 | 다이아 |
| --- | ---: |
| 일반 | 2 |
| 마법 | 5 |
| 희귀 | 20 |
| 유니크 | 50 |

장착 중인 아이템은 분해할 수 없다. 모든 모듈 분해는 반환 다이아를 보여주는 확인 팝업을 거친다.
일괄 분해는 현재 선택한 포탑과 인벤토리 부위 필터에 표시되는 모듈만 대상으로 한다. 일반 등급은 기본 선택하고 마법·희귀 등급은 추가 선택할 수 있으며, 유니크와 장착 중인 모듈은 대상에서 제외한다. 확인 팝업에서는 실제 분해 대상별 선택을 해제할 수 있고 선택 개수와 총 반환 다이아를 함께 표시한다.

## 부위별 옵션 풀

### 포신

포신은 공격 성능을 직접 강화한다.

- 피해 증가
- 공격속도 증가
- 치명타 확률 증가
- 치명타 피해 증가
- 사거리 증가

### 프레임

프레임은 전투 직접 화력보다 투자 효율과 장착한 젬 보조에 둔다. 공격 옵션은 아직 넣지 않는다.

- 레벨업 비용 감소
- 링크 확장 비용 감소
- 설치 비용 감소
- 고레벨 강화 비용 감소
- 장착 젬 효과 증가

설치 비용 감소는 최종 설치 비용이 기본 비용의 80% 밑으로 내려가지 않게 제한한다.

### 코어

코어는 포탑별 정체성을 강화한다.

| 포탑 | 옵션 풀 |
| --- | --- |
| 기관총 | 피해 증가, 공격속도 증가, 치명타 확률 증가, 투사체 속도 증가 |
| 대포 | 피해 증가, 폭발 반경 증가, 광역 보조 피해 증가, 공격속도 증가 |
| 화염 | 피해 증가, 지속피해 증가, 화상 지속시간 증가, 공격속도 증가 |
| 냉각 | 피해 증가, 둔화 지속시간 증가, 둔화 강도 증가, 사거리 증가 |
| 저격 | 피해 증가, 치명타 확률 증가, 치명타 피해 증가, 조준속도 증가 |
| 라이트닝 | 피해 증가, 연쇄 피해 증가, 연쇄 거리 증가, 공격속도 증가 |

## UI 기준

- 기본 목록은 선택한 포탑의 모든 보유 모듈을 보여준다.
- 코어, 포신, 프레임은 선택 대상이 아니라 필터로만 둔다.
- 장착된 아이템에는 `장착됨` 태그를 붙인다.
- 장착 슬롯 영역은 현재 장착 상태를 보여주는 요약 영역이다.
- 상세 패널은 선택한 아이템의 등급, 부위, 옵션, 장착/해제/분해 액션을 보여준다.
- 인벤토리 빈 슬롯은 마지막 row의 남은 칸 보정용으로만 추가한다.
- 모듈명, 옵션, 장착 상태 같은 핵심 텍스트는 잘림 없이 읽히게 처리한다.
- 뽑기 결과는 등급, 옵션 개수, 획득 순서가 잘 읽히게 정렬한다.

## 효과 적용 규칙

- 피해 증가는 포탑 스탯 보정 계층의 증가값으로 합산한다.
- 치명타 피해는 `docs/damage_calculation_rules.md` 기준에 따라 기본 치명타 추가 피해율에 `%p`로 합산한다.
- 장착 젬 효과 증가는 피해, 공격속도, 사거리, 지속피해, 치명타, 조준속도, 폭발 반경처럼 수치형 젬 효과에만 적용한다.
- 체인 수 증가, 방어구 관통 같은 구조형 젬 효과에는 장착 젬 효과 증가를 적용하지 않는다.
- 고레벨 강화 비용 감소는 현재 포탑 레벨 5 이상 강화에만 적용한다.
