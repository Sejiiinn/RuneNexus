# Rune Nexus 구현 현황

마지막 갱신 기준: 현재 로컬 `main` 브랜치, 커밋 `af5bc9c` 이후 작업 전 상태.

## 요약

Rune Nexus는 현재 Flutter + Flame 기반의 플레이 가능한 웹 데모 단계입니다. 초기 기본 타워 디펜스 루프를 넘어, 로컬 저장/복구, 스테이지 선택, 룬 기반 영구 업그레이드 기초, 젬 링크 조합, 일부 밸런스 조정까지 구현되어 있습니다.

## 실행 및 검증 상태

현재 로컬 환경에서 다음 검증이 통과합니다.

```bash
flutter analyze
flutter test
flutter build web --pwa-strategy=none
```

Flutter Web 데모는 `build/web`을 정적 서버로 띄워 인앱 브라우저에서 확인했습니다. Web 빌드는 서비스 워커 캐시의 영향을 받을 수 있으므로 개발 중에는 `--pwa-strategy=none` 사용을 권장합니다.

## 구현된 항목

### 앱/화면 구조

- Flutter 앱 진입점과 `MaterialApp` 구성
- Flame `GameWidget` 기반 게임 화면
- 메인 화면과 인스테이지 화면 분리
- 메인 화면 탭
  - 스테이지
  - 영구 업그레이드
- 상단 룬 보유 카드
- 한국어/영어 문구 확장 구조

### 스테이지/진행

- 스테이지 1~5 정의
- 현재는 스테이지 1만 기본 해금
- 스테이지 클리어 시 다음 스테이지 해금
- 스테이지별 최고 라운드 기록
- 50라운드 클리어 시 최고 라운드 대신 클리어 표시
- 진행 중인 스테이지 요약 카드
- 다른 스테이지 시작 시 기존 진행을 실패 정산 후 전환하는 경고 흐름
- 저장된 진행이 있을 때 스테이지 선택 화면에 진행 상태 표시

### 전투 기본 루프

- 8 x 10 고정 Grid 맵 데이터
- 타일 타입
  - 경로
  - 배치 가능
  - 배치 불가
  - Spawn
  - Core
- 고정 경로 기반 적 이동
- Core 도착 시 Nexus HP 감소
- 자동 타겟팅
- 투사체 이동과 충돌 판정
- 단일 피해
- 대포 범위 피해
- 화염 포탑 화상 지속피해
- 연쇄 보조 투사체
- 적 처치 보상 골드
- 라운드 시작/진행/보상/성공/실패 상태
- 다음 라운드 적 아이콘 예고
- 1x/2x/4x 배속

### 콘텐츠 데이터

- 포탑 3종
  - 기관총: 물리/경량화기
  - 대포: 물리/중화기/범위 피해
  - 화염: 마법/지속피해
- 적 4종
  - 일반
  - 빠름
  - 탱커
  - 보스
- 적 저항 프로필
  - 빠른 적은 경량화기에 약하고 중화기에 강함
  - 탱커는 물리에 강하고 중화기에 약함
  - 보스는 물리/마법 및 일부 태그 저항 보유
- 50라운드 데모 웨이브
- 9종 젬
  - 가속
  - 사거리
  - 물리 피해 증폭
  - 마법 피해 증폭
  - 경량화기 증폭
  - 중화기 증폭
  - 지속피해 증폭
  - 폭발
  - 연쇄

### 젬/포탑 성장

- 라운드 클리어 후 젬 3장 보상 선택
- 젬 인벤토리
- 설치된 포탑 선택
- 포탑 링크 슬롯
- 준비 단계에서 젬 장착/해제
- 링크 선택 전에는 보유 젬 목록 숨김
- 골드 소모 2링크/3링크 확장
  - 2링크 비용은 포탑 비용의 1.5배
  - 3링크 비용은 포탑 비용의 3배
- 포탑 레벨업
- 선택 포탑 능력치 표시
- 화염 포탑의 DPS 표시에 지속피해를 별도 색상으로 표시
- 지속피해 지속시간 표시
- 전투 중 포탑 설치, 레벨업, 링크 확장 허용

### 저장/복구

- 로컬 저장소 기반 진행 저장
- 저장 대상
  - 스테이지 번호
  - 라운드/완료 라운드
  - 골드/넥서스 HP
  - 포탑 위치, 레벨, 링크, 장착 젬
  - 적 HP와 경로 진행도
  - 스폰 큐
  - 보유 젬/보상 후보
  - 룬/영구 업그레이드/스테이지 기록
- 저장 제외
  - 현재 날아가는 투사체
- 준비 단계 저장은 앱 재시작 시 바로 메인 화면에 진행 정보로 표시
- 전투 중 저장은 재시작 시 일시정지 상태로 복구되며, 사용자가 `계속 진행`을 눌러야 재개

### 영구 성장

- 룬 재화
- 런 종료/포기 정산 시 룬 지급
- 메인 화면 영구 업그레이드 탭
- 시작 골드 업그레이드
- 넥서스 체력 업그레이드

### 결과/메뉴

- 성공/실패 결과 오버레이
- 획득 룬 표시
- 재도전
- 메인 화면 이동
- 스테이지 선택 화면에서 진행/잠금/기록 표시

### 테스트

- 스테이지 정의와 선택
- 스테이지 클리어 시 다음 스테이지 해금
- 포기 정산
- 저장/복구
- 라운드/웨이브/적 스케일링
- 포탑 비용/레벨업/링크 비용
- 젬 효과와 장착 제한
- 적 저항 배율
- 화상 지속피해와 표시용 스냅샷
- 메인 메뉴 위젯 렌더링

## 아직 구현하지 않은 항목

- 결과 화면 액션 세분화
  - 영구 업그레이드 탭으로 바로 이동
  - 다음 스테이지 바로 시작
  - 최고 기록 갱신/해금 정보 강조
- 스테이지별 고유 맵/웨이브/보상 차별화
- 영구 업그레이드 종류 확장
- 온라인 저장 실제 연동
  - 현재는 온라인 저장을 붙일 구조만 열어둔 상태
- 픽셀 스프라이트 에셋
- 사운드/효과음
- Android/iOS 실기 실행 검증
- 인앱 브라우저가 아닌 실제 앱 패키지 기준 QA
