# Rune Nexus 구현 현황

## 현재 구현 단계

문서상 첫 번째 마일스톤인 "젬 없는 기본 타워 디펜스"의 코드 초안을 작성했다.

현재 작업 환경에는 Flutter/Dart SDK가 설치되어 있지 않아 실제 빌드와 실행 검증은 아직 수행하지 못했다.

## 구현된 항목

- Flutter 앱 진입점
- Flame `GameWidget` 기반 게임 화면
- 세로형 HUD 오버레이
- 8 x 10 고정 Grid 맵 데이터
- 타일 타입
  - 경로
  - 배치 가능
  - 배치 불가
  - Spawn
  - Core
- 포탑 3종 데이터
  - 기관총
  - 대포
  - 마법
- 적 3종 + 미니 보스 1종 데이터
  - 일반
  - 빠른 적
  - 탱커
- 10라운드 웨이브 데이터
- 경로 기반 적 이동
- Core 도착 시 Nexus HP 감소
- 포탑 타입 선택 UI
- 준비 단계에서 포탑 배치
- 빈 빌드 타일 선택 후 포탑 버튼으로 설치
- 빈 빌드 타일 선택 시 기존 포탑 정보 패널 닫힘
- 골드 차감
- 자동 타겟팅
- 투사체 이동
- 단일 피해
- 대포 범위 피해
- 적 처치 보상 골드
- 라운드 시작/진행/클리어 상태
- 라운드 클리어 후 젬 3장 보상 선택
- 젬 인벤토리
- 설치된 포탑 선택
- 포탑 1링크 젬 장착
- 골드 소모 2링크 확장
- 포탑당 젬 2개 조합 장착
- 포탑 레벨 1~5 골드 강화
- 선택 포탑 능력치 표시
- 선택 슬롯 기반 젬 교체
- 장착 젬 시각 표시
- 공격속도/사거리/독/둔화/폭발/연쇄 젬 효과
- 일반 투사체 직선 발사 및 충돌 판정
- 총알형 점 투사체와 잔상 이펙트
- 연쇄 젬 총알형 보조 투사체 확산
- 테스트용 젬 즉시 지급 패널

- 다음 라운드 적 아이콘 예고 및 툴팁
- 성공/실패 결과 오버레이
- 데모 재시작

## 아직 구현하지 않은 항목

- 로컬 저장
- 픽셀 스프라이트 에셋
- 사운드
- Android/iOS 플랫폼 폴더 생성
- 실제 기기 실행 검증

## 실행 준비

Flutter SDK 설치 후 프로젝트 루트에서 다음 명령을 실행한다.

```bash
flutter create .
flutter pub get
flutter run
```

플랫폼 폴더가 생성된 뒤에는 `flutter create .`를 반복 실행할 필요가 없다.

## 다음 추천 작업

1. Flutter SDK 설치 및 `flutter create .` 실행
2. `flutter analyze`로 컴파일/린트 오류 확인
3. `flutter run`으로 맵 렌더링과 터치 배치 확인
4. 젬 보상 선택과 포탑 장착 흐름 확인
5. 포탑 레벨업 또는 2링크 확장 추가
