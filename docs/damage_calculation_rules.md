# 데미지 계산식 기준

이 문서는 Rune Nexus의 데미지 계산식을 추가하거나 변경할 때 따라야 하는 기준이다.
새 젬, 특성, 적 저항, 포탑 피해 보정, 특정 대상 피해 보정을 만들 때는 이 문서를 먼저 확인한다.

## 용어

- 저항: 적이 받는 피해를 줄이거나 늘리는 방어 계층 수치다. `10% 저항`은 피해 배율 `90%`를 의미한다.
- 취약: 저항을 낮추는 음수 방향 보정이다. `물리 저항 -20%`처럼 표현한다.
- 배율: 별도의 피해 계층에서 곱해지는 공격 쪽 보정이다. `물리 피해 배율 +30%`는 `1.3x` 계층이다.
- 증가: 같은 계층 안에서 더해지는 보정에 사용한다.
- 증폭: 합산이 끝난 계층 결과에 곱해지는 보정에 사용한다.

## 기본 원칙

같은 계층 안에서는 합연산을 먼저 끝낸다.
서로 다른 계층끼리는 그 결과를 곱한다.

```text
최종 피해 = 기본 피해 * 저항 계층 * 피해 배율 계층 * 최종 증폭 계층
```

계층 내부에 합연산 보정과 곱연산 보정이 같이 있다면, 합연산 보정을 먼저 계산한 뒤 곱연산을 적용한다.

치명타는 저항이 아니라 공격 쪽 피해 배율 계층으로 본다. 예를 들어 치명타 피해 배율 `1.5x`는 기본 피해와 포탑/젬/특성 피해 보정이 반영된 공격 피해에 곱하고, 이후 적 저항 계층과 함께 최종 피해를 만든다.

## 저항 계층

저항은 배율 데이터가 아니라 저항률 데이터로 저장한다.

```text
저항 0% = 피해 배율 100%
저항 30% = 피해 배율 70%
저항 -30% = 피해 배율 130%
저항 -110% = 피해 배율 210%
```

산식:

```text
피해 배율 = 1 - 저항률
```

저항률은 양수 방향으로만 상한을 둔다. 아무리 높은 저항이 쌓여도 실제 적용 저항은 최대 `90%`다.
음수 저항, 즉 취약은 이 상한으로 막지 않는다.

```text
저항 150% => 적용 저항 90% => 피해 배율 10%
저항 -110% => 피해 배율 210%
```

## 저항 데이터 표현

적 데이터에는 `0.9` 같은 피해 배율을 쓰지 않는다.
저항률로 표현한다.

```text
기존 표현: 물리 피해 배율 0.9
새 표현: 물리 저항 0.10
```

예시:

```text
보스 물리 저항 10%
파쇄 충격: 적 물리 저항 -20%

최종 물리 저항 = 10% - 20% = -10%
물리 저항 계층 피해 배율 = 110%
```

## 계층 분리

물리 저항과 물리 취약은 같은 계층이다.
따라서 먼저 합산한다.

```text
물리 저항 10% + 물리 저항 -20% = 물리 저항 -10%
```

반면 `보스 피해 배율 +10%` 같은 효과는 저항 계층이 아니다.
저항 계층 결과와 별도로 곱한다.

```text
물리 저항 계층 110% * 보스 피해 배율 110% = 최종 121%
```

## 태그 저항

계열 저항과 태그 저항은 서로 다른 저항 계층으로 본다.
각 계층 안에서는 저항률을 합산하고, 계층 결과끼리는 곱한다.

```text
물리 저항 20%, 중화기 저항 -20%

물리 계층 = 1 - 0.20 = 80%
중화기 계층 = 1 - (-0.20) = 120%
최종 저항 계층 = 80% * 120% = 96%
```

공격이 여러 태그를 가진다면 각 태그 저항 계층을 차례로 곱한다.

## 포탑 스탯 보정

포탑 스탯도 같은 원칙을 따른다.

폭발 반경 예시:

```text
(기본 반경 + 중화기 젬 증가 + 파편 장전 증가 + 확장 폭심 증가) * 폭발 젬 증폭
```

합연산 증가가 모두 끝난 뒤 곱연산 증폭을 적용한다.

## 방어 계위 설계 초안

방어 계위는 아직 구현 전 설계 기준이다.
1차 구현에서는 속성 약점표를 전면 규칙으로 두지 않고, 내구도 계위가 요구하는 공격 방식 차이를 먼저 검증한다.

피해 적용 순서:

```text
보호막 -> 방어구 -> 체력 -> 사망 판정
```

기존 저항, 피해 배율, 최종 증폭 계산이 끝난 값을 계위 입력 피해로 본다.
이후 보호막, 방어구, 체력 계위가 순서대로 피해를 흡수한다.

### 계위 역할

- 보호막: 별도 내구도를 가진 재생 외피다. 체력보다 먼저 피해를 받으며, 순간 피해보다 지속 화력과 집중 공격으로 돌파하는 계위로 둔다.
- 방어구: 별도 내구도를 가진 장갑이다. 체력보다 먼저 피해를 받으며, 남아 있는 동안 작은 타격을 감쇄한다. 속사와 약한 지속피해보다 한 방 피해가 큰 포탑이 유리한 계위로 둔다.
- 체력: 최종 생명력이다. 보호막과 방어구를 통과한 남은 피해를 받는다.

1차 구현에서는 `화염은 체력에 강함`, `전기는 보호막에 강함`, `부식은 방어구에 강함` 같은 속성 약점표를 넣지 않는다.
화상, 전기 과부하, 부식 약화, 냉각 둔화 같은 효과는 젬, 특성, 특정 포탑의 개성으로 확장한다.

### 데이터 모델

내구도 계위는 적 정의와 전투 중 상태를 분리한다.

적 정의에는 최대값과 규칙값을 둔다.

```text
maxShield
shieldRegenRate
maxArmor
armorReductionRate
armorMinimumDamageRate
maxHp
```

전투 중 적 상태에는 현재값과 파괴 여부를 둔다.

```text
shield
shieldBroken
armor
hp
```

`maxShield`, `maxArmor`가 0이면 해당 계위가 없는 적으로 본다.
방어구는 보호막처럼 재생하지 않는다.
보호막은 `shieldBroken`이 `true`가 되면 더 이상 재생하지 않는다.

### 방어구 감쇄

방어구가 남아 있는 동안에는 피해마다 고정 감쇄값을 적용한 뒤, 그 결과 피해를 방어구 내구도에 먼저 적용한다.
감쇄값은 현재 방어구 기준 비율로 계산한다.
감쇄율은 전역 고정값으로 두고, 적별 차이는 방어구 최대값과 현재 방어구량으로 조절한다.

```text
방어구 감쇄값 = 현재 방어구 * 방어구 감쇄율
방어구 피해 = max(입력 피해 * 최소 피해율, 입력 피해 - 방어구 감쇄값)
체력 관통 피해 = max(0, 방어구 피해 - 현재 방어구)
```

방어구 피해가 현재 방어구보다 작거나 같으면 체력은 피해를 받지 않는다.
방어구 피해가 현재 방어구보다 크면 방어구를 0으로 만들고, 남은 방어구 피해만 체력으로 넘어간다.
체력으로 넘어간 피해에는 방어구 감쇄를 다시 적용하지 않는다.

권장 시작값:

```text
방어구 감쇄율: 5%
최소 피해율: 25%
```

최소 피해율은 속사, 지속피해, 보조 피해가 완전히 무력화되는 것을 막기 위한 하한이다.
스테이지 2의 첫 장갑 적은 방어구 감쇄율 `5%`, 최소 피해율 `25%`를 기준으로 검증한다.
방어구가 줄어들수록 감쇄값도 함께 줄어들기 때문에, 방어구 바가 약해지는 시각 피드백과 실제 피해 효율이 같은 방향으로 움직인다.

예시:

```text
적 최대 체력 1000
현재 방어구 120
방어구 감쇄율 5%
방어구 감쇄값 6
최소 피해율 25%

입력 피해 7   -> 방어구 피해 max(1.75, 1) = 1.75, 체력 피해 0
입력 피해 25  -> 방어구 피해 max(6.25, 19) = 19, 체력 피해 0
입력 피해 40  -> 방어구 피해 max(10, 34) = 34, 체력 피해 0
입력 피해 150 -> 방어구 피해 max(37.5, 144) = 144, 체력 피해 24
```

### 보호막 재생

보호막은 매초 최대 보호막의 일정 비율만큼 재생한다.
1차 구현에서는 피격 시 재생 지연을 두지 않는다.
다만 보호막이 0이 되면 해당 보호막은 파괴된 것으로 보고 더 이상 재생하지 않는다.
플레이어가 `보호막 재생량보다 높은 지속 DPS로 한 번 돌파해야 한다`고 이해할 수 있게 단순하게 유지한다.

이 규칙은 보호막이 전투를 계속 지연시키는 장기 재생 체력이 아니라, 돌파 전까지만 압박을 주는 추가 보호 계위로 동작하게 하기 위한 기준이다.

보호막 피해는 별도 감쇄 없이 현재 보호막에 먼저 적용한다.
입력 피해가 현재 보호막보다 크면 보호막을 0으로 만들고 남은 피해가 방어구로 넘어간다.
보호막이 0이 된 순간 `shieldBroken`을 `true`로 기록한다.

보호막 초과 피해는 사라지지 않는다.
예를 들어 현재 보호막이 100이고 입력 피해가 120이면 보호막은 0이 되고, 남은 20 피해가 방어구 계위로 넘어간다.
방어구가 남아 있다면 그 20 피해는 방어구 감쇄 규칙을 거친 뒤 방어구 내구도에 적용된다.
방어구가 없거나 이미 0이면 남은 피해는 체력으로 넘어간다.

예시:

```text
최대 보호막 200
초당 재생률 5%
초당 재생량 10

DPS 8  -> 보호막 돌파 불가
DPS 20 -> 천천히 돌파, 보호막 파괴 뒤 재생 없음
DPS 100 -> 빠르게 돌파, 보호막 파괴 뒤 재생 없음
```

### 저장과 복구

진행 저장에는 내구도 계위의 현재 상태를 포함한다.

저장 대상:

- 현재 보호막
- 보호막 파괴 여부
- 현재 방어구
- 현재 체력

저장하지 않는 항목:

- 보호막 최대값
- 방어구 최대값
- 보호막 재생률
- 방어구 감쇄율
- 방어구 최소 피해율

최대값과 규칙값은 적 정의에서 다시 읽는다.
저장 데이터가 오래되어 보호막/방어구 필드가 없으면 0으로 복구해 기존 저장과 호환한다.
복구 시 현재 보호막과 현재 방어구는 각 최대값 범위로 clamp한다.

### UI 표시

하단 적 미리보기와 실제 적 표시 모두 같은 계위 정보를 보여준다.

- 보호막: 위쪽 줄에 파란색 바를 표시한다.
- 체력과 방어구: 아래쪽 줄에 `체력 | 방어구` 형태로 함께 표시한다.
- 아래쪽 줄의 비율 기준은 `최대 체력 + 최대 방어구`다.
- 방어구가 남아 있으면 체력 구간 오른쪽에 회색/금속색 방어구 구간을 표시한다.
- 방어구가 0이 되면 아래쪽 줄은 기존 체력 바처럼 체력만 1줄로 표시한다.
- 보호막이 없거나 0이면 보호막 줄을 표시하지 않는다.
- 적 미리보기에는 체력, 방어구, 보호막 수치를 함께 보여준다.

바 표기는 계위 순서와 체력 대비 방어구 비율을 시각적으로 보여주기 위한 표시다.
실제 피해 적용 순서는 항상 `보호막 -> 방어구 -> 체력`을 따른다.

### 1차 콘텐츠 적용

방어구는 공통 내구도 보정이 아니라 장갑병 전용 정체성으로 둔다.
일반, 빠름, 탱커, 보스는 기본 방어구가 없고 각자의 속도/체력/보스 역할로 구분한다.

```text
장갑병
- 보호막 없음
- 방어구 많음
- 체력 보통
- 방어구 감쇄율 5%
- 최소 피해율 25%
- 속사 포탑으로 잡히지만 비효율적
- 대포/저격처럼 한 방 피해가 큰 포탑이 유리
```

장갑병의 시작 수치는 다음을 기준으로 한다.

```text
체력: 40
방어구: 28
방어구 비율: 체력의 70%
속도: 28
보상: 7골드
```

스테이지 2~5는 우선 장갑병 구성을 공유해 스테이지 1 클리어 후 해금되는 저격 포탑의 장거리 단타 가치를 보여준다.
다만 저격만 정답이 되지 않도록 일반, 빠름, 탱커와 섞어 장갑병을 압박 요소로 사용한다.

보호막 몹, 속성 상호작용, 상태이상 확장은 방어구 몹의 체감 검증 뒤에 추가한다.
