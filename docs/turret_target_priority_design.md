# 포탑 공격 명령 우선순위 설계

## 목적

포탑별 공격 명령은 플레이어가 같은 포탑이라도 전투 역할을 다르게 지정할 수 있게 하는 기능이다.

현재 포탑은 기본적으로 선두 적을 우선 공격한다. 1차 구현에서는 기본 다섯 명령을 모두 추가하고, 선택 포탑 UI와 저장/복구까지 연결한다.

## 명령 타입

1차 후보는 다음 다섯 가지다.

| 명령 | 의미 | 우선순위 계산 기준 |
| --- | --- | --- |
| 선두 적 공격 | 현재 기본 동작 | 경로 진행도 `distanceTravelled`가 가장 큰 적 |
| 후방 적 공격 | 뒤처진 적 정리 | 경로 진행도 `distanceTravelled`가 가장 작은 적 |
| 가장 센 적 공격 | 탱커, 보스, 보호막병 집중 | 현재 내구도 총합이 가장 큰 적 |
| 가장 약한 적 공격 | 마무리와 누수 방지 | 현재 내구도 총합이 가장 작은 적 |
| 가장 가까운 적 공격 | 포탑 주변 방어 | 포탑과의 거리 제곱이 가장 작은 적 |

현재 내구도 총합은 아래 기준으로 시작한다.

```text
현재 체력 + 현재 방어구 + 현재 보호막
```

최대 체력 기준이 아니라 현재 내구도 기준을 우선한다.
이렇게 해야 이미 거의 잡힌 보스보다 새로 들어온 튼튼한 적을 더 센 적으로 볼 수 있고, 가장 약한 적 공격도 실제 마무리 기능을 한다.

## 구현 가능성

가능하다. 현재 `lib/game/components/turret_component.dart`에는 다음 구조가 있다.

- `TurretTargetPriority`
- `targetPriority`
- `setTargetPriority`
- `_findTarget`
- `_isPreferredTarget`

1차 구현 범위:

- 선두 적 공격
- 후방 적 공격
- 가장 가까운 적 공격
- 가장 센 적 공격
- 가장 약한 적 공격
- 적 현재 내구도 계산 기준
- 선택 포탑 UI 명령 선택 메뉴
- 저장/복구
- 선택 포탑 스냅샷 노출
- 타겟 선택과 저장 회귀 테스트

## UI 방향

선택한 포탑 상세 패널에 작은 명령 선택 영역을 둔다.

권장 형태:

- 제목: `공격 명령`
- 현재 선택 명령은 짧은 버튼 또는 segmented control로 표시
- 터치하면 5개 명령을 고르는 작은 메뉴를 연다.
- 명령 설명은 화면에 길게 늘어놓지 않고, 선택 메뉴 안에서 짧게만 보인다.

라벨:

| 명령 | 짧은 라벨 |
| --- | --- |
| 선두 적 공격 | 선두 |
| 후방 적 공격 | 후방 |
| 가장 센 적 공격 | 강한 적 |
| 가장 약한 적 공격 | 약한 적 |
| 가장 가까운 적 공격 | 근접 |

모바일 하단 패널 폭을 고려하면 5개 버튼을 항상 펼치는 방식보다, 현재 명령 버튼 하나와 선택 메뉴를 조합하는 편이 안전하다.

## 저장과 복구

공격 명령은 포탑 개체별 상태이므로 저장 대상이다.

저장 위치:

- `SavedTurret.targetPriority`

호환 기준:

- 기존 저장에 값이 없으면 `first`로 복구한다.
- 알 수 없는 값이면 `first`로 복구한다.

포탑 환불 시 명령 상태는 포탑과 함께 사라진다.

## 타겟팅 규칙

공통 필터:

- 살아 있는 적
- mounted 상태인 적
- 포탑 사거리 안에 몸체가 들어온 적

동률 처리:

| 명령 | 1차 기준 | 동률 기준 |
| --- | --- | --- |
| 선두 | 진행도 높음 | 가까운 적 |
| 후방 | 진행도 낮음 | 가까운 적 |
| 강한 적 | 현재 내구도 높음 | 진행도 높음 |
| 약한 적 | 현재 내구도 낮음 | 진행도 높음 |
| 근접 | 거리 가까움 | 진행도 높음 |

동률 기준을 정해야 타겟이 매 프레임 불필요하게 흔들리는 현상을 줄일 수 있다.

## 포탑별 활용 기대

- 기관총: 약한 적, 근접, 선두 명령과 잘 맞는다.
- 대포: 강한 적 또는 선두 명령으로 폭발 중심을 잡기 쉽다.
- 화염: 강한 적 명령으로 오래 타는 대상에 화상을 붙일 수 있다.
- 냉각: 선두 또는 근접 명령으로 경로 제어 역할을 유지한다.
- 저격: 강한 적 명령으로 장갑병, 보호막병, 보스 대응 역할이 명확해진다.

## 주의점

- 모든 포탑의 기본값은 기존과 같은 `선두 적 공격`으로 둔다.
- 명령 UI와 명령 변경은 스테이지 2 클리어 후 `전술 명령` 연구를 완료해야 열린다.
- `전술 명령` 연구는 80룬, 20분, 최대 1레벨로 시작한다.
- 연구 완료 후 명령 변경은 골드 비용 없이 즉시 가능하게 시작한다.
- 자동 타겟팅이 너무 자주 바뀌면 저격 포탑의 조준이 끊길 수 있으므로, 저격은 현재 조준 중인 대상이 유효하면 기존처럼 유지한다.
- 주변 보호형 적을 추가하기 전에는 이 기능이 특히 중요하다. 보호형 적을 우선 공격하도록 `강한 적` 또는 별도 `지원 적 우선` 명령이 필요할 수 있기 때문이다.

## 구현 단계

상태: 1차 구현 완료

1. enum 확장: `strongest`, `weakest`
2. `EnemyComponent` 또는 `TurretComponent` 쪽에 현재 내구도 계산 추가
3. `_isPreferredTarget` 비교 로직 확장
4. `SavedTurret`에 명령 저장 필드 추가
5. `GameSnapshot`에 선택 포탑 명령 노출
6. 선택 포탑 UI에 명령 선택 메뉴 추가
7. 테스트 추가

첫 구현에서는 `지원 적 우선`, `보스 우선`, `보호막 우선` 같은 특수 명령은 넣지 않는다.
기본 다섯 명령으로 플레이 체감을 먼저 검증한다.
