# 챕터 2 웨이브와 신규 몹 설계

## 목적

챕터 2는 챕터 1 후반의 장갑병 중심 압박에서 벗어나, 보호막과 재생 압박을 통해 포탑 조합을 다르게 요구하는 구간으로 둔다.

스테이지 2~5는 챕터 1 후반 구간으로 유지한다. 스테이지 3~5만 억지로 다른 웨이브처럼 보이게 만들기보다, 챕터 2 진입 시 신규 몹과 웨이브 문법이 함께 바뀌는 체감을 우선한다.

## 설계 기준

- 신규 몹은 1차 구현에서 1종만 추가해도 된다.
- 신규 몹 2종을 동시에 구현하더라도 새 전투 시스템을 한 번에 여러 개 추가하지 않는다.
- 보호막은 `docs/damage_calculation_rules.md`의 `보호막 -> 방어구 -> 체력` 계위를 따른다.
- 적 저항은 피해 배율이 아니라 저항률 데이터로 표현한다.
- 챕터 2의 핵심 체감은 "더 많은 적"이 아니라 "방어 계위와 타이밍이 달라져 포탑 배치가 달라지는 것"이다.
- 챕터 1에서 해금된 저격 포탑이 계속 유효하되, 저격만 정답이 되지 않도록 지속 화력과 광역 정리도 함께 요구한다.

## 챕터 2 핵심 테마

챕터 1은 다음을 학습시킨다.

- 일반 적 처리
- 빠른 적 대응
- 탱커 대응
- 장갑병의 방어구 계위
- 저격 포탑의 장거리 단타 가치

챕터 2는 다음을 추가한다.

- 보호막을 가진 적의 선행 압박
- 보호막 재생을 뚫기 위한 지속 DPS 요구
- 장갑병과 보호막병이 섞였을 때 단타/연사 선택이 갈리는 압박
- 보스 웨이브에서 보호막 호위가 만드는 타겟 분산

## 신규 몹 후보

### 1. 보호막병

1차 구현 우선 후보다. 이미 구현된 보호막과 보호막 재생 규칙을 활용할 수 있어 신규 시스템 부담이 작다.
현재 `EnemyType.shielded`와 적 데이터는 추가됐고, 웨이브 배치는 아직 하지 않았다.

역할:

- 보호막을 먼저 깨야 체력을 줄일 수 있는 중형 적
- 재생 보호막 때문에 낮은 지속 DPS 조합을 압박
- 장갑병과 달리 방어구 감쇄가 없으므로 빠른 연사와 지속피해가 더 잘 작동
- 주변 적을 보호하지 않고, 자기 보호막만 가진다.

초기 수치 기준:

| 항목 | 기준 |
| --- | ---: |
| 체력 | 36 |
| 보호막 | 42 |
| 보호막 재생률 | 초당 최대 보호막의 4% |
| 방어구 | 없음 |
| 속도 | 29 |
| 처치 골드 | 8 |
| 코어 피해 | 1 |
| 저항 | 없음 |

의도:

- 기관총, 화염, 냉각 보조처럼 지속적으로 때리는 조합의 가치를 올린다.
- 대포와 저격은 여전히 유효하지만, 보호막을 조금씩 재생시키는 긴 간격 공격만으로는 효율이 떨어지게 둔다.
- 보호막이 깨지면 재생하지 않으므로, 플레이어가 "한 번 집중해서 뚫어야 한다"고 이해하기 쉽다.

주의:

- 보호막 재생률은 4~6% 범위에서 시작한다.
- 초반 보호막병 비중은 낮게 둔다. 너무 많이 나오면 화력 부족이 아니라 진행 지연처럼 느껴질 수 있다.
- 방어구와 보호막을 한 적에게 동시에 주는 것은 보류한다.
- 주변 적에게 보호막을 부여하는 역할은 보호막병에 섞지 않고, 후속 몹인 `방벽 수호병` 후보로 분리한다.

### 보호 역할 분리

보호막병은 1차 구현에서 자기 보호막만 가진다.
주변 적을 보호하는 기능은 챕터 2 중후반 또는 보스 호위용 별도 몹으로 분리한다.

이유:

- 자동 타겟팅 중심 전투에서 주변 보호 몹을 먼저 공격하고 싶어도 플레이어가 직접 통제하기 어렵다.
- 보호막병이 자기 보호막과 주변 보호를 모두 가지면 첫 신규 몹치고 역할이 너무 무겁다.
- 자체 보호막은 지속 DPS 학습용, 주변 보호는 타겟 우선순위와 범위 표시가 준비된 뒤 넣는 전술용으로 나누는 편이 명확하다.

후속 후보:

| 후보 | 역할 | 적용 시점 |
| --- | --- | --- |
| 방벽 수호병 | 주변 적에게 약한 보호막을 부여하는 보호형 탱커 | 챕터 2 중후반 또는 보스 호위 |

방벽 수호병 기준:

- 보호 효과는 중첩하지 않는다.
- 보호 범위와 보호 대상은 전투 화면에서 명확히 표시해야 한다.
- 피해를 대신 받는 방식보다, 주변 적에게 소량의 보호막을 부여하는 방식이 우선이다.
- 구현 전 포탑별 공격 명령 우선순위와 함께 검토한다.

### 2. 균열 정찰병

2차 후보 또는 챕터 2 중반 이후 후보로 둔다. 기존 빠른 적보다 코어 피해가 크고, 중화기에는 강하지만 마법에는 약한 적이다.

역할:

- 빠른 적보다 수는 적지만 놓치면 손실이 큰 돌파형 적
- 대포만 과하게 깔았을 때 생기는 사각을 압박
- 화염/냉각/기관총의 전방 안정화 가치를 높인다.

초기 수치 기준:

| 항목 | 기준 |
| --- | ---: |
| 체력 | 30 |
| 보호막 | 없음 |
| 방어구 | 없음 |
| 속도 | 48 |
| 처치 골드 | 7 |
| 코어 피해 | 2 |
| 마법 저항 | -15% |
| 중화기 저항 | 25% |

의도:

- 기존 빠른 적의 단순 강화판이 아니라, 놓쳤을 때 더 아픈 소수 돌파 적으로 둔다.
- 중화기 저항은 대포 과투자를 견제하고, 마법 취약은 화염/냉각 조합을 자연스럽게 열어준다.

주의:

- 기존 `빠름` 적과 역할이 겹치지 않도록 대량 러시로 쓰지 않는다.
- 1차 구현에서는 보호막병만 먼저 넣고, 균열 정찰병은 문서 기준으로만 남겨도 된다.

## 챕터 2 웨이브 문법

챕터 2는 5웨이브 단위 사이클을 유지하되, 사이클 의미를 챕터 1과 다르게 둔다.

| 사이클 | 챕터 1 후반 | 챕터 2 |
| --- | --- | --- |
| 1 | 장갑 혼합 | 보호막 선행 + 일반 후속 |
| 2 | 빠른 적 러시 | 보호막 후 빠른 적 삽입 |
| 3 | 장갑 대열 | 장갑병 + 보호막병 교차 |
| 4 | 분산 압박 | 탱커/보호막병 전방 고정 + 후속 러시 |
| 5 | 장갑 압축 | 보호막병 소수 + 일반/빠름 압축 |
| 10의 배수 | 장갑 호위 보스 | 보호막 호위 보스 |

### 초반 1~5웨이브

| 웨이브 | 의도 | 구성 |
| --- | --- | --- |
| 1 | 챕터 전환 후 기준 확인 | 일반 중심, 소수 빠른 적 |
| 2 | 보호막병 첫 등장 | 일반 후속 뒤 보호막병 1~2마리 |
| 3 | 보호막 집중 학습 | 보호막병 선두 + 일반 후속 |
| 4 | 보호막 뒤 빠른 적 | 보호막병으로 타겟을 잡아두고 빠른 적 삽입 |
| 5 | 보호막/장갑 비교 | 보호막병과 장갑병을 모두 소수 등장 |

### 6웨이브 이후 반복 사이클

| 사이클 | 구성 원칙 |
| --- | --- |
| 보호막 혼합 | 일반 -> 보호막병 -> 빠른 적 순서로 타겟 전환 요구 |
| 재생 압박 | 보호막병을 약간 긴 간격으로 보내 집중 화력 부족을 노출 |
| 계위 교차 | 장갑병과 보호막병을 교차시켜 대포/저격과 연사 포탑의 역할을 분리 |
| 돌파 압박 | 탱커 또는 보호막병이 전방을 잡고 빠른 적이 뒤따름 |
| 보상 전 압축 | 일반/빠름/보호막병을 짧은 간격으로 압축하되, 보호막병 수는 제한 |

보호막병은 한 웨이브의 주력 압박이 될 수 있지만, 전체 적 수의 20~30%를 넘기지 않는 것을 시작점으로 둔다.

## 보스 웨이브

챕터 2 보스 웨이브는 보스 자체를 바로 바꾸기보다 호위 구조를 먼저 바꾼다.

기준:

- 보스는 여전히 1마리만 등장한다.
- 보스 전 1차 호위에 보호막병을 섞는다.
- 보스 뒤 2차 호위는 일반/빠른 적을 짧게 겹쳐 타겟 분산을 만든다.
- 30웨이브 이후에는 장갑병 또는 탱커를 소량 섞어 단타 포탑의 역할을 다시 만든다.

피해야 할 방향:

- 보호막병 다수와 보스를 동시에 오래 겹쳐 진행 지연만 커지는 구조
- 보스에게 보호막과 방어구를 동시에 부여하는 구조
- 보스 수를 늘려 난이도를 올리는 구조

## 진입 조건과 보상 연결

챕터 2 진입:

- 스테이지 5 클리어 후 챕터 2 첫 스테이지를 해금한다.
- 현재 스테이지 챕터 UI는 5스테이지 단위이므로, 챕터 2는 스테이지 6~10 구간으로 설계한다.

보상 연결:

- 스테이지 5 클리어: 링크 확장 I 연구 조건과 연결된 현재 구조를 유지한다.
- 챕터 2 첫 클리어: 보호막 대응 또는 포탑 계열 연구의 진입 조건 후보로 둔다.
- 채굴 자원 MVP가 먼저 들어간다면 챕터 2 초반 보상은 마력석 수급/연구 트리 안내와 연결한다.

보류:

- 챕터 2 진입과 동시에 신규 포탑을 바로 지급하지 않는다.
- 챕터 2 신규 몹 구현과 채굴 자원 구현을 한 커밋에 묶지 않는다.
- 저장 포맷 변경이 필요한 보상 구조는 별도 작업으로 분리한다.

## 구현 MVP

가장 작은 구현 단위:

1. `EnemyType.shielded` 추가: 완료
2. 보호막병 데이터 추가: 완료
3. 챕터 2용 웨이브 빌더 추가
4. 스테이지 6 정의 1개 추가
5. 스테이지 선택 UI에서 챕터 2 첫 스테이지 표시
6. 웨이브 미리보기와 적 상세에서 보호막 수치가 정상 표시되는지 테스트

MVP에서 제외:

- 균열 정찰병 구현
- 신규 보스 타입
- 신규 포탑
- 채굴 자원과 포탑 계열 연구 구현
- 신규 스프라이트/사운드

## 테스트 기준

- 보호막병 기본 수치와 보호막 재생률이 기대값과 일치한다.
- 보호막병의 보호막/체력은 라운드 보정과 스테이지 보정을 받는다.
- 챕터 2 첫 스테이지는 스테이지 5 클리어 이후 접근 가능하다.
- 챕터 2 웨이브에는 보호막병이 등장하지만 한 웨이브의 보호막병 비중이 과도하지 않다.
- 10의 배수 웨이브는 보스 1마리 원칙을 유지한다.
- 위젯 테스트에서 챕터 2 스테이지 잠금/해금 표시가 깨지지 않는다.

## 다음 결정 지점

구현 전에 결정할 항목:

- 챕터 2 첫 스테이지를 바로 스테이지 6으로 열지, 기존 1~5만 유지하고 내부 프로토타입으로 둘지
- 보호막병 이름을 `보호막병`, `방벽병`, `수호병` 중 무엇으로 확정할지
- 챕터 2 첫 클리어 보상을 연구 조건으로만 둘지, 신규 성장 축의 첫 안내로 둘지

권장 기본값:

- 스테이지 6으로 공개한다.
- 이름은 시스템 의미가 바로 드러나는 `보호막병`으로 시작한다.
- 첫 구현에서는 보상을 새 시스템에 묶지 않고, 웨이브와 적 체감 검증을 먼저 끝낸다.
