# 넥서스 코어 설계 방향

## 목적

넥서스 코어는 Rune Nexus의 장기 정체성과 애착 대상을 만들기 위한 중심 성장 시스템이다.

현재 Rune Nexus는 포탑, 젬, 링크, 포탑 특성, 룬 영구 업그레이드, 연구를 갖추고 있지만 플레이어가 "내가 이것을 키우고 있다"라고 느낄 중심 대상이 약하다. 넥서스 코어는 단순히 방어해야 하는 HP가 아니라, 플레이어가 오래 키우고 젬으로 공명시키며 전투에 지속적으로 관여하는 핵심 성장체로 둔다.

## 핵심 결정

- 코어는 여러 종류를 갈아끼우는 장비가 아니라 하나의 넥서스 코어로 둔다.
- 플레이어는 하나의 코어를 스킬트리, 젬 공명, 전투 스킬 슬롯과 패시브 슬롯으로 성장시킨다.
- 코어 기능은 게임 정체성을 위해 초반부터 노출한다.
- 모듈, 가챠, 단계별 확률 상승 같은 후반 수집 요소는 코어 정체성이 자리 잡은 뒤 열어도 된다.
- 첫 코어 전투 기능은 액티브 버튼보다 지속적으로 도움을 주는 자동 전투 스킬로 시작한다.
- 기본 전투 스킬은 `수호 광선`으로 둔다.
- 젬 공명은 코어 시스템의 필수 축으로 둔다.

## 코어가 맡는 역할

### 애착 대상

코어는 플레이어 계정 또는 진행 전체에 걸쳐 성장한다.

표시 후보:

- 코어 레벨
- 코어 경험치
- 코어 포인트
- 장착 전투 스킬과 패시브
- 코어 젬 슬롯
- 스킬트리 노드
- 보스 처치 기여, 코어 광선 처치 수, 최고 도달 스테이지 같은 전적

성능 수치만 올리는 것이 아니라, 플레이어가 "내 코어는 이런 방향으로 성장했다"라고 설명할 수 있어야 한다.

### 전투 보조

코어는 포탑을 대체하지 않는다.

권장 전투 관여도:

| 상황 | 권장 기여도 |
| --- | ---: |
| 일반 웨이브 | 전체 전투 기여의 5~10% |
| 보스 웨이브 | 체감 기여 10~20% |
| 누수 대응 | 한두 마리 마무리 가능 |
| 웨이브 단독 정리 | 금지 |

코어는 "전황을 바꾸는 중심체"가 아니라 "플레이어 빌드를 지속적으로 보조하고 위기 순간에 존재감을 주는 중심체"로 둔다.

### 빌드 정체성

코어 빌드는 포탑 빌드와 젬 빌드에 연결되어야 한다.

예시:

- 조준경 공명 + 정밀 타겟 노드: 보스/탱커 대응형 코어
- 폭발 공명 + 분산 광선 노드: 잡몹 정리 보조형 코어
- 가속 공명 + 발사 주기 노드: 안정적인 지속 보조형 코어
- 연쇄 공명 + 마무리 노드: 누수 정리형 코어

## 코어 전투 스킬 슬롯

수호 광선을 코어 스킬트리의 고정 노드로 두기보다, 코어에 `전투 스킬 슬롯`을 두고 기본 전투 스킬로 장착하는 구조를 권장한다.

이유:

- 수호 광선이 코어 전체 정체성을 독점하지 않는다.
- 후속 전투 스킬을 모듈, 연구, 보상, 가챠로 추가하기 쉽다.
- 스킬트리는 특정 스킬 자체가 아니라 슬롯, 공명, 타겟, 효율, 상한을 강화하는 역할이 된다.
- 플레이어가 "내 코어에 어떤 전투 스킬을 장착할지"를 고민할 수 있다.

초기 구조:

| 항목 | 초기값 |
| --- | --- |
| 전투 스킬 슬롯 | 1칸 |
| 기본 장착 스킬 | 수호 광선 |
| 코어 젬 슬롯 | 0~1칸, 초반 해금 |
| 패시브 슬롯 확장 | 후속 스킬트리 또는 연구 |

후속 전투 스킬 후보:

| 전투 스킬 | 역할 |
| --- | --- |
| 수호 광선 | 가까운 적에게 주기적 집중 피해 |
| 균열 낙인 | 체력이 높은 적에게 받는 피해 증가 낙인 |
| 봉인장 | 코어 근처 적 둔화 또는 속박 |
| 증폭 맥동 | 가까운 포탑 또는 전체 포탑을 짧게 강화 |
| 방벽 응답 | 넥서스 피해 일부 감소 또는 1회 무효 |

현재 구현에서는 `수호 광선`과 `균열 낙인`을 전투 스킬로 제공한다.

## 기본 전투 스킬: 수호 광선

### 컨셉

넥서스 코어가 일정 주기마다 밝아지며 코어에 가까운 적에게 1초 동안 빠른 틱 피해를 준다.

즉발 단일 피해보다 1초 집중 광선 방식을 우선한다.

이유:

- 코어가 에너지를 모아 방출한다는 느낌이 강하다.
- 젬 공명 효과를 시각적으로 표현하기 쉽다.
- 타겟이 죽으면 다음 적으로 광선이 옮겨가며 누수 정리 체감이 생긴다.
- 코어가 항상 전투에 참여한다는 존재감이 생긴다.

### MVP 규칙

| 항목 | 기준 |
| --- | --- |
| 발동 간격 | 5초 |
| 발동 시간 | 1초 |
| 피해 틱 | 0.1초마다 1회, 총 10틱 |
| 기본 대상 | 코어에 가장 가까운 적 |
| 타겟 사망 시 | 남은 시간 동안 다음 가까운 적으로 전환 |
| 기본 역할 | 누수 마무리와 지속 보조 |

### 피해 기준

적 체력 기준보다 전체 포탑 전투력 기준을 우선한다.

권장 공식:

```text
발동 1회 총 피해 = 현재 전체 포탑 DPS * 발동 간격 * 코어 계수
틱 피해 = 발동 1회 총 피해 / 틱 수
```

초기값:

```text
발동 간격 = 5초
코어 계수 = 0.08
틱 수 = 10
```

예시:

```text
전체 포탑 DPS 100
5초 * 0.08 = 0.4
수호 광선 1회 총 피해 = 40
틱 피해 = 4
```

이 구조는 코어가 전체 포탑 DPS의 약 8%를 장기적으로 보조한다는 의미다.

### 피해 상한

전체 포탑 DPS 기준만 사용하면 강한 빌드가 코어까지 과도하게 강해질 수 있으므로 대상별 상한을 둔다.

권장 상한:

| 대상 | 1회 발동 총 피해 상한 |
| --- | ---: |
| 일반 적 | 대상 최대 HP의 35% |
| 보스 | 대상 최대 HP의 2.5% |

권장 최소 피해:

```text
현재 라운드 일반 적 최대 HP의 8~10%
```

최소 피해는 초반 포탑 수가 적어 코어 존재감이 사라지는 문제를 막기 위한 장치다.

## 젬 공명

젬 공명은 코어 시스템의 핵심 차별화 축이다.

포탑 젬은 개별 포탑을 바꾸고, 코어 젬은 코어 전투 스킬을 변형한다.

### 코어 젬 슬롯

MVP에서는 코어 전체에 젬 슬롯을 둔다.

- 코어 젬 1개가 장착된 전투 스킬에 영향을 준다.
- 전투 스킬별 젬 슬롯은 후속 고급 기능으로 보류한다.
- 코어 젬 슬롯은 초반에 해금해 Rune Nexus의 젬 정체성을 빠르게 보여준다.

### 초기 공명 후보

처음부터 모든 젬을 지원하지 않아도 된다. 체감이 큰 젬부터 시작한다.

| 젬 | 수호 광선 공명 효과 후보 |
| --- | --- |
| 가속 | 발동 간격 감소 또는 틱 간격 감소 |
| 폭발 | 광선 종료 또는 적중 지점에 작은 폭발 |
| 연쇄 | 보조 대상 1명에게 약한 분기 광선 |
| 조준경 | 보스/탱커 우선 조준, 광선 타겟 전환 개선 |
| 급소 | 틱 피해에 치명타 확률 부여 |
| 장갑 관통 | 방어구 감쇄 무시, 피해 상한은 유지 |
| 위력 증폭 | 코어 계수 증가 |

MVP 우선 후보:

1. 가속
2. 폭발
3. 연쇄
4. 조준경

이 네 가지는 효과가 직관적이고 시각 피드백을 만들기 쉽다.

## 코어 스킬트리

스킬트리는 수호 광선 자체를 고정으로 찍는 트리가 아니라, 코어의 규칙을 열고 강화하는 구조로 둔다.

역할:

- 패시브 슬롯 해금
- 코어 젬 슬롯 해금
- 젬 공명 해금
- 타겟 우선순위 선택
- 피해 계수와 발동 간격 조정
- 보스 피해 상한 조정
- 공명 효과 강화

초기 노드 후보:

| 노드 | 효과 |
| --- | --- |
| 코어 젬 슬롯 | 코어에 젬 1개 장착 가능 |
| 공명 해석 | 장착 젬이 수호 광선을 변형 |
| 연산 가속 | 전투 스킬 재사용 대기시간 10% 감소 |
| 봉인 광선 | 수호 광선 적중 대상 짧은 둔화 |
| 절약 설계 | 포탑 건설 비용 15% 감소 |
| 보스 동조 | 보스 대상 피해 상한 소폭 증가 |
| 분기 회로 | 연쇄/폭발 계열 공명 효과 강화 |

스킬트리는 처음부터 거대하게 만들지 않는다. 1차 구현에서는 6개 내외 노드로 시작한다.

## 성장과 오픈 타이밍

코어는 게임 정체성을 위해 이른 시점에 보여준다.

권장 흐름:

| 시점 | 오픈 내용 |
| --- | --- |
| 게임 시작 직후 | 코어 화면 표시, 수호 광선 기본 장착 |
| 스테이지 1 | 수호 광선이 전투 중 자동 발동 |
| 스테이지 1 클리어 | 코어 경험치/레벨업/포인트 안내 |
| 스테이지 2 전 | 첫 코어 노드 선택 |
| 스테이지 2~3 | 코어 젬 슬롯과 기본 공명 해금 |
| 스테이지 5 클리어 | 공명 노드 확장, 챕터 2 대응 빌드 유도 |
| 챕터 2 이후 | 코어 모듈, 후속 패시브, 조율 시스템 예고 |

초반에 가챠를 먼저 보여주지 않는다. 먼저 코어에 애착을 만든 뒤, 후속 수집 시스템을 붙인다.

## 전투 스킬 후보: 균열 낙인

균열 낙인은 수호 광선과 같은 전투 스킬 슬롯에서 교체해 쓰는 약화형 전투 스킬이다.
챕터 2가 해금되면 사용할 수 있다.

MVP 규칙:

| 항목 | 기준 |
| --- | --- |
| 발동 간격 | 10초 |
| 지속 시간 | 5초 |
| 대상 수 | 현재 체력+보호막+방어구가 높은 적 4명 |
| 동률 기준 | 더 앞서 이동한 적 우선 |
| 일반 적 효과 | 받는 최종 피해 25% 증가 |
| 보스 효과 | 받는 최종 피해 12.5% 증가 |
| 중첩 | 중첩 없음, 재적용 시 지속시간 갱신 |

균열 낙인은 저항/취약 계층이 아니라 최종 증폭 계층이다.
따라서 포탑 직접 피해, 폭발, 연쇄, 지속피해, 코어 피해가 모두 증폭된다.
보호막/방어구/체력 계위에 피해가 들어가기 전에 최종 입력 피해를 증폭한다.

## 코어 조율과 단계별 확률 상승

전투 스킬 변형 또는 모듈 수집은 후속 시스템으로 둔다.

권장 명칭:

- 코어 조율
- 공명 해석
- 모듈 복원

가챠 대상은 기본 전투 스킬 자체보다 모듈 또는 전투 스킬 변형이 더 안전하다.

이유:

- 기본 전투 기능을 운에 묶지 않는다.
- 수호 광선 같은 핵심 전투 스킬은 무료 기본 지급으로 유지한다.
- 가챠는 빌드 변형과 장기 수집 목표에 집중할 수 있다.

단계별 확률 상승 후보:

```text
기본 전설 확률: 2%
30회 이후부터 매회 +2%p
50회에 전설 확정
전설 획득 시 안정도 초기화
10회마다 희귀 이상 확정
```

세계관 표현:

```text
조율 실패 시 공명 안정도 +1
공명 안정도가 높을수록 희귀/전설 확률 증가
전설 모듈 획득 시 안정도 초기화
```

UI에는 확률과 확정 횟수를 명확히 보여준다.

예:

- `공명 안정도 24/50`
- `전설 확률 2% -> 14%`
- `50회 이내 전설 확정`

### 가챠 설계 주의점

- 코어 정체성보다 먼저 가챠를 노출하지 않는다.
- 특정 모듈이 없으면 진행이 막히는 구조를 만들지 않는다.
- 모듈은 단순 피해 증가보다 플레이 방식 변형을 우선한다.
- 중복 모듈은 강화 재료 또는 공명 파편으로 환급한다.
- 젬 파편과 역할이 겹치지 않도록 조율 전용 재화는 별도 검토한다.

모듈 예시:

| 모듈 | 효과 |
| --- | --- |
| 분광 렌즈 | 수호 광선이 2명에게 나뉘지만 각 피해 감소 |
| 초점 렌즈 | 단일 대상 피해 증가, 타겟 전환 불가 |
| 보스 추적기 | 보스 대상 상한 증가, 일반 적 피해 감소 |
| 응급 회로 | 넥서스 HP가 낮을수록 광선 발동 간격 감소 |
| 폭발 공명핵 | 폭발 젬 공명 반경 증가, 기본 피해 감소 |

## UI 방향

### 메인 메뉴

코어를 게임 정체성으로 밀려면 메인 메뉴 하단 탭에 코어를 넣는 것을 검토한다.

후보:

```text
스테이지 / 코어 / 강화 / 연구
```

코어가 강화보다 앞에 있어야 메인 성장축으로 인식된다.

### 코어 화면

초기 코어 화면에 필요한 정보:

- 넥서스 코어 레벨
- 경험치와 다음 레벨 보상
- 코어 포인트
- 장착 전투 스킬과 패시브
- 수호 광선 광선 피해, 누적 총 피해, 발동 간격
- 균열 낙인 현재 효과와 누적 총 추가 피해
- 코어 젬 슬롯
- 해금된 공명 효과
- 작은 스킬트리

### 전투 HUD

전투 중에는 액티브 버튼보다 패시브 상태 표시가 우선이다.

표시 후보:

- 코어 광선 충전 링
- 다음 발동까지 게이지
- 장착 코어 젬 아이콘
- 광선 발동 시 코어 밝기 증가
- 보스 웨이브에서 보스 HP 바 근처에 코어 동조 상태 표시

## MVP 구현 범위

가장 작은 1차 구현은 다음으로 잡는다.

1. 메인 메뉴에 코어 탭 추가
2. 코어 화면 추가
3. 코어 기본 전투 스킬 슬롯 1개 추가
4. `수호 광선` 기본 장착
5. 전투 중 5초마다 1초 집중 광선 자동 발동
6. 피해는 전체 포탑 DPS 기준으로 계산
7. 일반/보스 대상 피해 상한 적용
8. 전투 HUD에 코어 광선 충전 상태 표시
9. 스테이지 1 클리어 또는 보스 처치 시 코어 경험치 지급
10. 코어 젬 슬롯과 최소 공명 2~4종 추가

MVP에서 보류:

- 코어 모듈
- 코어 조율/가챠
- 전투 스킬 다종 추가
- 전투 스킬별 젬 슬롯
- 대형 스킬트리
- 코어 외형 진화

## 위험 요소와 대응

### 포탑 역할 침식

위험:

- 코어 광선이 강하면 포탑 배치 의미가 약해진다.

대응:

- 장기 DPS 기여도를 5~10% 수준으로 둔다.
- 대상별 피해 상한을 둔다.
- 보스 피해 상한은 별도로 낮게 둔다.

### 시스템 과밀

위험:

- 포탑, 젬, 링크, 포탑 특성, 연구, 영구 업그레이드에 코어까지 더해져 초반 이해 부담이 커질 수 있다.

대응:

- 초반에는 수호 광선 자동 발동만 보여준다.
- 스킬트리와 젬 공명은 단계적으로 해금한다.
- 코어 화면은 현재 효과와 다음 해금 목표 중심으로 구성한다.

### 젬 역할 충돌

위험:

- 포탑 젬과 코어 젬이 같은 젬을 두고 경쟁하면 플레이어가 손해를 보는 느낌을 받을 수 있다.

대응:

- 코어 젬 슬롯은 초반 1개만 둔다.
- 코어 젬은 포탑 젬과 다른 효과를 제공한다.
- 공명 효과는 빌드 변형 중심으로 두고 단순 수치 효율만 과도하게 주지 않는다.

### 가챠 인상

위험:

- 코어 정체성을 보여주기 전에 가챠가 보이면 게임 인상이 나빠질 수 있다.

대응:

- 기본 코어, 수호 광선, 첫 공명은 무료/진행 해금으로 둔다.
- 코어 조율은 챕터 2 이후 장기 수집 시스템으로 연다.
- 확률과 천장 정보를 투명하게 표시한다.

## 추천 개발 순서

1. 코어 기본 설계와 UI 문구 확정

3. 수호 광선 전투 스킬 구현
4. 코어 광선 HUD 상태 표시
5. 코어 경험치와 레벨 저장 구조 추가
6. 코어 젬 슬롯 1개 추가
7. 가속/폭발/연쇄/조준경 공명 중 2~4개 구현
8. 작은 코어 스킬트리 추가
9. 보스 웨이브 경고, 보스 HP 바, 보스 처치 피드백과 연결
10. 챕터 2 이후 코어 조율/모듈 수집 설계로 확장
