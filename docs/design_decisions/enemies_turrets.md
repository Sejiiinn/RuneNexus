# 적·포탑 3D 디자인 결정

역할: 적·보스·포탑 3D 외형, 애니메이션, 상태 효과, 장착 젬 궤도, 텍스처 예산의 확정 결정과 기준 자료. 공통 원칙·검증 기준은 [DESIGNS.md](../../DESIGNS.md)를 함께 따른다.
정리: 2026-10-11, DESIGNS.md 영역 분리. 결정 내용은 2026-10-11 시점 DESIGNS.md와 같다.

## 적

일반형 적은 [승인된 갈색 이끼 석재 골렘과 v2 보행 원본](../../design/enemy_concepts/2026-10-08/normal-ingame-v2/README.md)을 사용한다. 큰 머리·짧고 두꺼운 팔다리·보라색 이마 룬·붉은 눈과 핵·실제 tangent normal을 보존한다. 팔꿈치의 25~35° 굽힘과 팔의 시차를 가진 1.6초 Walk의 팔·상체를 보존하고 게임용 발 IK 보폭 0.44를 실제 이동 거리에 맞춰 재생하며, 기존 일반 적 표시 크기를 유지한다. 코너에서는 이동 경로를 유지하고 몸만 최단 방향으로 부드럽게 회전한다(90° 기준 약 0.12 전투초, 회전 끝 감속). 같은 승인 원본의 1.4초 Death를 그대로 재생한 뒤 마지막 자세를 잠시 유지하고 탱커·보스와 같은 석재 퇴장 방식으로 잔해 표면이 점진적으로 사라진다. 실시간 물리나 별도 조각 삭제로 바꾸지 않는다.

빠른 적은 청록색 눈·등 룬과 청회색 석판을 가진 사족 룬 사냥개를 사용한다. [승인된 달리기 원본](../../design/enemy_concepts/2026-09-27/fast-rune-hound/run/gallop-kick-v9/fast-rune-hound-run.blend)의 좌우 시차·앞발 뒤밀기·뒷다리 신장과 회수를 보존하고 실제 이동 거리에 맞춰 재생한다. 기존 빠른 적의 능력치·이동 경로를 유지한다. 사망 시 [승인 시안](../../design/enemy_concepts/2026-09-27/fast-rune-hound/death/game-review/approved-curl.png)처럼 낮게 떠오르며 고개·네 다리·꼬리를 안쪽으로 모아 점점 웅크리고, 몸체가 옅어지며 0.55 전투초에 사라진다. 고정 애니메이션을 사용하며 실시간 물리나 조각별 비산은 사용하지 않는다. 화상·냉각은 공통 효과에 종별 부착 자료를 적용한다. 일반형은 기존 표시 대비 15% 크게, 빠른형은 10% 작게 표시하며 보폭과 일반형 사망 크기도 함께 맞춘다. 청록 석재를 룬으로 오판하지 않도록 빠른형 냉각의 룬 보호와 상태 부착은 실제 발광 텍스처를 기준으로 한다. 일반형과 빠른 적은 챕터 공통 기본형으로 두고, 챕터별 특수 적을 추가하는 방향으로 확장한다.

보스 신규 외형의 제작 참조는 사용자가 선택한 [무기 없는 16번 유적 감시대장](../../design/enemy_concepts/2026-10-03/boss-unarmed/README.md)을 따른다. 작은 각진 돌머리·근엄한 얼굴, 붉은 눈·룬·구형 가슴핵, 청동 띠와 리벳을 가진 두꺼운 석재 어깨, 굵은 석재 팔다리와 맨주먹을 유지한다. 같은 기록의 멀티뷰로 측면·후면·상면 구조를 보완한다.

## 포탑

기관총·대포 본체와 냉각 포탑 외형, 대포 탄체·폭발, 적 화상 기준은 [전장 문서의 스테이지 1 행](battlefield.md#챕터-1-스테이지-15)에 있다.

| 영역 | 유지할 결정 | 참고 자료 |
| --- | --- | --- |
| 냉각 포탑 충전·방출 | 승인된 냉각핀형 본체·상부 셔터·렌즈를 고정하고 적 방향으로 회전하지 않는다. 상부 청동 연결부·수직 기둥·하부 지지발은 이어지는 구조로 읽혀야 한다. 상단 6장 곡선 판은 같은 방향으로 휘어진 배치를 유지하되 서로 겹치지 않고, 판 사이 틈과 충분한 옆면 두께를 가진다. [승인 표면 서리 시안](../../design/frost_tower_concepts/2026-09-23/surface-frost-concept/frost-coated.png)처럼 상판 표면·가장자리·볼트 주변·기둥 테두리·하부 접합부에 청백색 결정성 서리를 더한다. 기존 형태·판 사이 틈을 보존하고, 서리 아래 금속·청동과 청록 냉각광이 드러나게 한다. 실제 공격 쿨타임 동안 측면 냉각핀이 아래에서 위로 청록빛으로 충전되며, 준비 후 적이 없으면 충전 상태를 유지한다. 발사하면 충전광이 줄고 포탑 중심에서 현재 공격 반경에 맞춰 두께와 불규칙한 경계가 있는 입체 서리 안개가 퍼졌다 사라진다. 기존 총구 섬광·연기로 대체하거나 겹쳐 표시하지 않는다. 안개는 승인된 Blender 부피 메시·공유 자원과 GPU 운동을 사용하고, 정지·배속·복원은 전투 시계를 따른다. 기존 범위 피해·감속 수치와 적의 3D 성에는 유지한다. | [승인 애니메이션 시안](../../design/frost_tower_concepts/2026-09-23/charge-mist-concept/README.md) |

라이트닝 포탑은 [승인 A와 구형 아우라 기준](../../design/lightning_tower_concepts/approved_a/README.md)을 따른다. 낮은 쌍전극 몸체·여섯 보라색 코일·중앙 사각 코어를 유지하며, 전방에 입체 전류가 구형으로 충전된 뒤 강하게 분기 방출된다. 반투명 보라색 아우라는 구형 경계가 읽히되 내부 전류를 가리지 않으며, 카메라 이동에서 앞뒤 가지의 깊이와 가림을 유지한다. 일반 총구 화약 연기나 총기식 반동을 섞지 않는다. 게임 적용·실기기 검증 상태는 해당 기록에서 구분한다.

저격 포탑의 신규 3D 제작은 [2026-09-26 C / SWIFT 승인 기준](../../design/sniper_tower_concepts/2026-09-26/README.md)을 따른다. 낮춘 수직 기둥·긴 단일 포신·금속 표현을 유지하고, 상부는 01 SWIFT의 유선형 쐐기·매립 조준 렌즈·곡선 은색 요크로 개선한다. 후방 경사와 포신 단축을 적용한 v3는 채택하지 않는다. 조준 효과는 [승인 에너지 응축 시안 v2](../../design/sniper_tower_concepts/2026-09-26/production/aim-vfx-concepts/2026-09-30-energy-charge-v2.png)를 따른다. 얇은 중심광·부드러운 국소 청록 광채·소수 미세 glints가 렌즈에서 실제 대상 첫 표면까지 이어지며, 실제 조준 진행도에 따라 흰청록 에너지로 응축되고 발사하거나 대상이 해제되면 숨긴다. S26 Ultra QHD+ 원거리 비교 후 승인한 9,816삼각형 경량본을 최종 사용 모델로 삼고, 고해상도 원본은 제작용으로 보관한다. 제작 결과와 게임 적용 여부는 해당 기록에서 구분한다.

화염 포탑은 2026-09-22 요청에 따라 모델 전체와 부착 불꽃을 기존 대비 90%로 표시한다([원본·검증](../../design/fire_tower_concepts/runic_3d/scale-90/README.md)). 형태·재질·고정 아이콘 카메라는 유지한다.

화염 포탑의 3D 디자인은 [14번 룬 기계형 시안](../../design/fire_tower_concepts/2026-09-14/14-runic-mechanism.png)을 따른다. 길쭉한 팔각 몸체·주황 룬 홈·음각 문양의 청동 지지대·앞쪽 단일 총구·몸체에 매립된 작은 상부 화염구를 유지하고, 숯이나 큰 화로 형태를 넣지 않는다. 게임용 `magic.glb`는 같은 외형과 90% 배율을 보존한 [11,411삼각형 경량본](../../design/fire_tower_concepts/runic_3d/optimized-game-distance/README.md)을 사용하며, 고해상도 Blender 원본은 제작용으로 보관한다. 금속은 색·거칠기·노멀을 구운 기본 PBR 재질을 사용하고, 불꽃·화구·화염 발사체는 입체 메시와 Godot 기본 재질·GPU 파티클로 구성한다. 새 전용 셰이더나 카메라 정면의 평면 효과로 대체하지 않는다. [이관 및 검수 기록](../../design/fire_tower_concepts/runic_3d/migration/README.md)을 따른다.

## 장착 젬 궤도 효과

장착 젬은 작은 입체 위성 젬과 뒤쪽으로만 이어지는 단일 테이퍼 리본으로 표시한다. 젬은 진행 방향의 맨 앞이며 앞쪽으로 선이 연장되지 않는다. 동일 궤도에서 균등 간격·동일 속도로 회전하고, 장착 개수에 따라 꼬리 길이를 줄여 다음 젬과 빈 간격을 유지한다. 궤도는 건설 타일 안에 두고 기존 포탑 모델·장착 색상·게임 계약을 보존한다. [승인 범위·제작 원본](../../design/gem_orbit/2026-09-26/README.md)을 따른다.

## 3D 적·포탑 텍스처 예산

- 일반 적·포탑의 게임용 텍스처는 1K를 기본 출발점으로 삼고, 512로 충분한 맵은 유지한다. 보스나 중요한 세부 표현에만 필요에 따라 2K를 사용한다. 기존·신규 자산을 일괄 축소하지 않는다.
- 실제 게임에서 보이는 룬·눈·재질의 느낌을 유지하는 범위에서 해상도를 정한다. 고해상도 제작 원본과 UV·형태·애니메이션은 보존하고, 게임용 크기와 압축은 [import 정책](../stage1_native_material_workflow.md#게임용-텍스처-import-정책)으로 분리한다.
