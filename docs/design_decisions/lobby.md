# 로비·메뉴 화면 디자인 결정

역할: 로비·메뉴·연구·계정·우편·리더보드·포탑 모듈·코어 트리 화면의 확정 결정과 기준 자료. 공통 원칙·검증 기준은 [DESIGNS.md](../../DESIGNS.md)를 함께 따른다.
정리: 2026-10-11, DESIGNS.md 영역 분리. 결정 내용은 2026-10-11 시점 DESIGNS.md와 같다.

## 로비 공통

- 로비의 코어·연구·포탑 모듈·계정 등 일반 작업 버튼은 기존 공용 금속 PNG로 통일한다. 주요·보조·위험·비활성과 눌림 상태를 구분하고, 이미 전용 이미지가 있는 버튼·탭과 투명 닫기 버튼은 해당 형태를 유지하며 상태별 공통 스타일 노출을 막는다. [적용·검증](../../design/reviews/2026-09-26-gradient-buttons/README.md).
- 코어 스킬·노드 상세의 닫기는 전용 정사각형 × 에셋을 전체 비율대로 표시한다. 긴 작업 버튼 프레임을 작은 닫기에 늘려 쓰지 않는다.
- 로비 하위 화면의 저장 성공은 하단 안내 문구로 표시하지 않는다. 코어 스킬 장착·해제와 성장 변경 뒤에도 본문 영역 크기를 유지한다. 저장 실패·조건 미충족 안내와 연구 완료·반환 등 결과 정보는 유지한다.
