## 전장 시점·표시·피드백

전장 시점 조작은 현재 시점 이름과 전환 아이콘을 표시하는 작은 버튼 하나를 사용한다. 누를 때마다 고정↔드론으로 전환하며 별도 버튼 두 개를 나란히 두지 않는다. 드론은 수직에서 전방으로 25° 기울인 정투영 시점을 사용해 전장 전체와 적·포탑·타일의 측면을 함께 보여 준다.

이동 경로선은 출현 포탈별로 구분한다. 원래 포탈에서 나온 선은 연한 파랑, 다른 포탈에서 나온 선은 연한 주황을 사용하며 같은 포탈에서 갈라지는 길은 같은 색을 유지한다. 서로 다른 포탈의 길이 겹치는 구간은 약간 벌어진 평행선 두 개로 표시하고 코너·합류에서 끊기거나 포개지지 않게 잇는다. 기존 은은한 반투명 선·전투 시계 맥동과 승인된 지형을 유지하며 포탈 자체의 색·재질·모델은 바꾸지 않는다. 순간이동 입출구 사이에는 보행선을 그리지 않는다. [구현·검사](../../godot/presentation/battlefield_path.gd), [챕터 3 적용](../../design/chapter3_map_expansion/README.md).

포탑 사거리 원은 2D·3D 모두 평소 숨기고 선택한 포탑만 표시한다. 빈 건설칸을 선택해 설치 패널이 열린 동안에는 기존 모든 포탑의 원을 표시하고, 설치할 포탑의 사거리 미리보기도 유지한다. 설치 완료 후에는 새로 선택된 포탑만 표시하며, 설치 취소·선택 해제 시에는 숨긴다. 선택 포탑의 업그레이드 사거리 미리보기와 보상 대상 지정의 기존 표시 우선순위는 유지한다. [실제 적용·검증](../../design/stage1_3d/range_visibility/README.md).

포탑 설치는 실제 건설 성공 직후 포탑을 지면에 즉시 배치하고, 약 0.22초 동안 위아래 최대 2픽셀의 짧은 전장 충격·감쇠하는 잔진동과 받침 주변으로 흩날리는 3D 먼지를 사용한다. 좌우 흔들림 없이 HUD는 고정하고, 먼지는 낮은 높이에서 불균일하게 바깥으로 퍼져 약 0.5~0.7초에 사라지는 회갈색 구름으로 표현한다. 실제 입체 기하·재질과 지형·포탑 깊이에 따른 가림을 유지하며, 평면 스프라이트·딱딱한 구슬 고리·불꽃·발광 충격파로 대체하지 않는다. 포탑의 형태·크기·재질·지면 배치와 즉시 공격을 유지한다. 새로 설치하는 방향형 포탑과 설치 미리보기의 초기 포구는 타일 기준 남서쪽을 향하고, 목표를 획득하면 기존 전투 조준을 따른다. 포구가 없는 냉각타워의 고정 방향, 기존 저장 형식과 복원된 포탑의 조준값 처리는 유지한다. 설치 피드백은 일시정지·배속과 무관한 실제 시간으로 진행하고 다른 전투 효과의 시계는 유지한다. 저장 복원·프레임 갱신·선택 변경·실패한 건설에는 재생하지 않는다. [포탑 표시](../../godot/presentation/battlefield_units.gd).

다이아 보상 적은 기존 본체를 유지하며 체력 표시 위에 화면 크기를 유지하는 다이아 표식과 은은한 청록 반짝임으로 구분한다. 실제 처치 보상 발생 시 다이아 아이콘·정확한 `+획득량`·위로 떠오르는 반짝임을 표시하고, 배속에서도 수치를 읽을 시간을 확보한다. 보상 계산·저장·정산 계약은 기존 경로를 유지한다.

## 전장 배경

전장 배경은 [우주 배경 B안](../../design/stage_background_concepts/2026-09-28/chapter1-space-25deg-comparison.png)의 구도·짙은 남청색 우주·작고 드문 별을 공통으로 사용하고, 외곽 성운의 색감만 챕터에 맞춘다. 1장은 짙은 청록·푸른빛, 2장은 남보라·자주빛, 3장은 어두운 적갈색·은은한 구릿빛을 사용한다. 중앙은 어둡게 유지하고 별은 공통의 차가운 흰빛을 보존한다. 성운과 별의 위치는 고정하고 일부 별의 밝기만 서로 다른 느린 주기로 은은하게 변화시킨다. 성운 흐름·패럴랙스·챕터별 별도 풍경은 넣지 않는다. 현재 타일·지형·소품·카메라·전장 조명·HUD와 타일 가독성을 보존한다. [적용·검증](../../design/stage_background_concepts/2026-09-28/README.md).

## 포탈·코어·순간이동 장치

순간이동 기믹의 전송 포탈은 [승인된 파랑·주황 입출구 시안](../../design/teleport_device_concepts/2026-09-30/12-in-out-vortex-single-tile.png)을 따른다. 한 타일 상면 전체를 얇은 모서리 깎인 사각 금속 테두리와 전송면으로 덮고, 기존 층진 석재 측면과 주변 길의 높이를 유지한다. 본체·전송면·움직이는 효과의 수평 범위는 한 타일 경계 안에 둔다. 파랑은 파랑으로, 주황은 주황으로 연결하며 각 쌍의 본체는 동일하다. 입구는 가장자리에서 어두운 중심으로 모이는 소용돌이, 출구는 밝은 중심에서 바깥으로 퍼지는 소용돌이를 사용한다. 회전 방향 차이만으로 입출구를 구분하지 않는다. [제작 원본·확인 범위](../../design/teleport_device_concepts/2026-09-30/README.md#입출구-소용돌이-흐름-구분).

| 영역 | 유지할 결정 | 참고 자료 |

## 챕터 1 (스테이지 1~5)

스테이지 1 행에는 기관총·대포·냉각 포탑 외형, 화상, 대포 탄체·폭발, 시점 전환 이동, Android 본게임 로딩 기준도 함께 있다.

| 영역 | 유지할 결정 | 참고 자료 |
| --- | --- | --- |
| 스테이지 1 3D 시험 화면 | 승인된 Blender 원본의 전체 지형·바위·이끼·풀·뿌리를 보존하고, 위치별 돌 무늬·이끼 변화와 면광원의 석재 반사·음영을 실제 3D 전장에 적용한다. 새 환경 장식 제작은 독립 에셋 원본의 조형을 먼저 완성하고 실제 게임 카메라 방향의 정지 이미지로 검수한 뒤 군락 구성·맵 배치로 진행한다. 밀도 확대를 식물 자체의 형태 검수 대신 사용하지 않는다. 추가 환경 장식은 승인 시안의 풀·고사리·넓은 잎·지피·작은 흰 꽃·이끼 바위·납작한 돌·돌멩이·낮은 이끼·늘어진 덩굴·짧은 뿌리를 외곽과 타일 틈, 빈 건설칸 내부에 불규칙한 군락으로 배치한다. 꽃과 덩굴은 선택한 지점에 두고, 원본 조형을 보존한 맵용 복사본을 병합한다. 대표 군락은 빈 타일 안쪽까지 넓은 고사리·중층 잎·낮은 지피가 연속해서 겹쳐 시안의 풍성함을 살린다. 환경 장식은 모바일 성능을 고려한 스타일화된 3D를 목표로 하며, 시안과 같은 비스듬한 원거리 시점에서 군락의 부피·겹침·형태·색 조화와 명암이 충분히 살아나는 것을 기준으로 한다. 과도한 사실 묘사나 확대해야 보이는 미세 표현은 요구하지 않으며, 기존 렌더링 예산 안의 재배치·형태 재구성을 기본으로 한다. 포탑 설치 시 해당 타일의 중앙 식생만 숨기고 철거 시 다시 표시하며, 가장자리·틈 식생은 남긴다. 이동 경로는 비운다. 풀·고사리는 뿌리를 고정한 채 최대 0.022타일로 살짝 흔들리며, 전투 배속과 독립적인 공유 GPU 셰이더와 두 병합 메시를 사용한다. 기관총은 기존 본체·탄창을 입체화하고 대포는 채도를 낮춘 주황 무광, 냉각은 [승인 냉각핀형](../../design/frost_tower_concepts/2026-09-23/iris-variants/03-ribbed-reactor.png)의 중간 높이 원통·6장 곡선 셔터·중앙 얼음 렌즈·수직 베이 안의 적층 냉각핀·4방 지지발을 사용한다. [제작·단계별 검수](../../design/frost_tower_concepts/2026-09-23/production/README.md)를 따른다. 게임에는 이 외형과 충전·방출 연결을 보존한 [냉각 경량본](../../design/frost_tower_concepts/2026-09-23/optimized-game-distance/README.md)을 사용한다. 적의 화상은 [승인 V3](../../design/fire_tower_concepts/enemy_burn/README.md)의 짧은 불꽃 입자가 몸체 주변에서 솟고 흩어지는 형태를 따른다. 공통 불꽃 아틀라스·종별 공유 부착 자료·단일 MultiMesh를 사용하고, 입자 운동과 소멸은 GPU에서 공유 전투 시계로 계산한다. 원래 장갑색·전면 핵과 기존 화상 판정·지속시간을 유지한다. 비스듬한 시점·깊은 재질 음영을 적용하고, Android Godot 기관총은 좌우 교대 입체 포구 화염·짧은 체적 연기·작은 불티를 사용하며, 연기와 불티는 발사 위치에 남아 흩어진다. 기관총의 탄체와 짧은 입체 예광은 총구에서 이어진다. 기관총 명중은 [도탄 불티 A안](../../design/turret_vfx_concepts/machinegun_hit/README.md)을 따른다. 맞은 몸체 표면 앞의 짧은 백열 접점·십자 섬광, 탄이 들어온 반대 방향과 위로 튀어 떨어지며 식는 입체 불티 7개, 짧은 주황 표면광을 사용하고 평면 별모양 캔버스 섬광은 쓰지 않는다. 저격 명중 섬광은 이 결정의 범위가 아니다. 대포 비행체는 `design/stage1_3d/projectile_concepts/04-round-ironball.png`의 둥근 불투명 검은 철구를 따르며, 얕은 단조 표면과 뒤쪽의 작은 열 표현을 유지한다. 몸체 뒤 화염·회색 체적 연기는 한 지름 이내로 짧게 두고 긴 예광이나 뾰족한 탄두를 쓰지 않는다. 실제 비행·명중점을 유지하며 명중한 탄체는 즉시 숨기고 잔여 효과만 140ms 동안 남긴다. 대포는 무거운 반동과 함께 PoE2풍 사실 표현의 포탄 폭발을 사용한다. 짧은 백황색 화구가 주황·숯색 화염으로 식으며 낮은 회색 먼지로 퍼지고, 입체 흙 파편·둥근 잉걸불·불 잔재·그을음 자국이 뒤따른다. 툰·2D 장식 겹치기와 긴 궤적 선은 쓰지 않는다. 화구와 먼지는 게임 시점에서 렌더한 Blender 연기 시뮬레이션 플립북을 화면과 평행한 카드로 재생하며, 진한 부분이 폭발 반경과 같은 크기로 보인다. 전체 효과는 1.1초이며 화구가 먼저 꺼지고 먼지·잉걸불이 뒤따라 걷힌다. 착탄 섬광 빛은 주변 지형·포탑에 반응한다. [제작·검수](../../design/effects/cannon_explosion_flipbook/README.md). 현재 2.5D 고정 시점과 위에서 내려다보는 드론 시점에서 입체감과 가독성을 유지한다. Godot 시점 버튼은 전장 중심을 바라보며 약 0.7초간 빠르게 출발해 도착 직전에 감속한다. 전환 중 재입력은 현재 위치에서 이어지고, 전투 정지·배속과 독립적으로 움직인다. 기존 HUD와 정보 의미를 유지한다. 포탑 레벨 배지는 기존 모양을 보존하고 실제 고정 받침 하단에 붙이며, 시점 전환 중에도 포탑과 같은 렌더 프레임에 움직인다. 일반 시각 수정은 Godot 직접 실행으로 먼저 확인한다. Android 전용 시각·성능 확인과 최종 배포 검증은 별도 설치용 Android APK로 진행하며 웹 렌더·브라우저 검수로 대신하지 않는다. 성능 수용 기준은 모바일 실기기의 4배속 다중 착탄이다. Android 본게임 스테이지 1~15은 Godot 전장과 기존 HUD를 연결한다. 진입 시 3D 전장 적용 응답을 받을 때까지 청록빛 진행 표시가 있는 불투명 로딩 화면으로 전장과 HUD를 가리고 전투 진행·입력을 막는다. 정상 준비 중에는 2D 전장을 노출하지 않으며, 초기화 오류에만 기존 2D 전장으로 복귀한다. 별도 검수 앱도 같은 카메라·장면 코드를 사용하며, 스테이지 16 이후와 다른 플랫폼은 기존 2D 전장을 유지한다. | [시험 구현](../stage1_3d_preview.md), [형태 검수](../../design/stage1_3d/actor_refinement/README.md), [환경 장식](../../design/stage1_3d/environment_dressing/README.md) |
| 스테이지 2~5 3D 전장 | 각 스테이지의 기존 맵 크기·길·건설칸·포탈·코어 위치를 유지하고 공용 Blender 원본의 길·건설 타일과 포탈·코어·포탑·적 모델을 배치한다. 스테이지 1 전용 전체 지형·환경 장식을 다른 맵에 겹쳐 놓지 않는다. 1장 공통 재질·조명·고정/드론 시점·HUD·로딩 전환을 사용하며, 전투 수치·웨이브·저장·해금 조건을 유지한다. | [본게임 연결·검증](../stage1_3d_preview.md) |

스테이지 1 Blender 작업은 [현행 원본·작업 허브](../../design/stage1_3d/blender_workspace/README.md)에서 시작한다. 원본·제작 경로·게임 적용 미리보기를 변경하면 해당 목록과 내부 안내도 함께 갱신한다. 이전 폭발 `.blend`를 현재 게임의 필드 캐시 효과 원본으로 취급하지 않는다.

스테이지 1의 [표면 질감·전투 효과 개선](../stage1_surface_effects.md)은 사용자가 추가 전달한 [최소 외형 기준](../../design/stage1_3d/surface_effects/target-reference.jpg)의 두꺼운 석재 측면·선명한 요철·깊은 틈·겹친 식생·접촉 그림자를 따른다. 밝은 윗면과 맵·HUD를 유지하면서 측면과 접촉부의 명암을 분리한다. 참고 영상의 어두운 조명이나 전체 bloom으로 질감을 대신하지 않는다. 입체 연기·폭발은 지형·적의 깊이에서 자연스럽게 가려지게 한다. 실기기 병목 측정 없이 설정했던 24,000삼각형 상한은 외형을 제한하는 기준으로 사용하지 않으며, 요청 외형을 확보한 뒤 실제 병목에 따라 최적화한다. 지형·포탑·적·식생은 공통 주광 그림자 기준을 따른다. 얇은 잎은 LOD에서도 투영 면적·겹침을 보존하여 군락 아래 음영을 확보하고, 건설 점유로 본체가 숨으면 같은 기하의 그림자도 함께 제거한다. 고사리만을 위한 별도 외피는 현행 제작 기준으로 사용하지 않는다.

스테이지 1 표면은 돌의 완만한 반사와 이끼의 거친 반응을 구분하고, 밝은 윗면에서 측면·기단의 접촉 음영으로 자연스럽게 이어져야 한다. 고사리 그림자는 실제 잎이 덮는 범위를 유지하면서 군락 중심은 짙고 바깥 경계는 풀리게 한다. 불투명 검은 다각형이나 중심 음영까지 사라진 결과는 이 기준을 충족하지 않는다. [재질·조명·고사리 후속 구현 계획](../stage1_surface_effects.md#시안의-재질명암을-맞추는-후속-구현-계획)을 따른다.

## 챕터 3 (스테이지 11~15)

챕터 3 타일은 [두꺼운 멀티뷰](../../design/chapter3_3d_concepts/2026-09-18/tiles-multiview-thick-approved.png)의 1×1 평면·두꺼운 몸체를 유지하고, 실제 게임 외형은 사용자가 다시 제시한 [용광로 인게임 참조](../../design/chapter3_3d/stage11/reference-fix/target.jpg)를 따른다. 길은 따뜻한 회색 주조 철판과 열 배출 격자, 건설칸은 청흑색 금속판·가는 어두운 청동 링·둥근 고정 볼트 4개로 구분한다. 상하 플랜지와 깊은 측면 케이싱, 격자 아래와 측면 창의 국소 주황 열기를 살리며, 넓고 밝은 금색 링이나 전체가 회색으로 뜨는 재질은 채택하지 않는다. 철판 돌기 5개와 실제 관통 격자 5×5를 유지한다. 포탑 설치칸은 [중앙 원 없는 추가 타일](../../design/chapter3_3d/environment_concepts/plain-turret-tile-multiview.png)과 원형 고정구 타일을 섞어 배치하며 두 종류 모두 설치 가능하다. 측면은 실제 빈 좌석에 막힌 철판 또는 매립형 환기구 패널을 교체 장착한다. 기본은 막힌 패널이고 환기구는 길·원형 설치 타일·원 없는 설치 타일의 노출된 측면 전체를 후보로 무작위 혼합 배치한다. 격자 주변만 우선하지 않는다. 같은 맵에서는 같은 배치를 유지한다. 환기구는 벽 위에 발광 표면을 붙이지 않고 프레임 뒤의 구멍·격자·후퇴한 열원으로 구성한다. 고정 시점에서 주황 세로 슬롯 3개가 읽히도록 얕은 매립 깊이를 사용하며, 열기가 점처럼 가려지는 깊은 구조는 피한다. 환경 소품은 [승인된 Blender 시안](../../design/chapter3_3d/environment_props/README.md)의 엘보 파이프·측면 연결관·짧은 배기구를 사용한다. 게임용 모델은 같은 형태·벽 접합을 보존한 [경량본](../../design/chapter3_3d/environment_props/optimized-game-distance/README.md)을 사용하며 고해상도 제작 원본은 보관한다. 청흑색 철·청동 테두리·실제 중공 관과 국소 주황 열원을 보존하며 외곽에 드문드문 분산한다. [벽체 연결형 멀티뷰](../../design/chapter3_3d/environment_concepts/integrated-mounts/multiview-v2.png)에 따라 얇은 외곽 받침을 없앤다. 엘보는 수직 벽 플랜지에서 위로 굽는 중공 관, 배기구는 타일 기단과 높이를 맞춘 두꺼운 돌출 하우징과 짧은 굴뚝으로 만든다. 연결관은 벽에 밀착한 고정대로 체결한다. 이동·설치 상면과 기존 매립 환기구, 내부의 좁은 빈칸을 가리지 않는다. 스테이지 11~15에 이식하며 기존 맵 좌표와 공용 포탈·코어·전투 계약을 보존한다.  [Blender 원본·제작 결과](../../design/chapter3_3d/tiles/README.md). [스테이지 11 적용·검수](../../design/chapter3_3d/stage11/README.md).

3장 전 스테이지(11~15·26~30)의 판 주변에는 [부유 철골](../../design/chapter3_3d/floating_debris/girders/README.md)을 띄운다. 볼트 끝판형·휜 형·비틀린 짧은 조각의 부러진 I형 철골 3종이며, 건설칸과 같은 청흑 흑연 철·마모 모서리·리벳과 찢긴 단면의 가는 주황 열선을 쓴다. 판 안쪽의 빈 공간과 판에서 두 칸 이내의 빈칸에만 두고 플레이 칸·벽 소품과 겹치지 않는다. 활성 영역 빈칸 12칸당 1개(3~7개)를 원본 1.45~1.85배 크기로 놓고, 전투 시간에 따라 0.035타일 이내로 느리게 오르내린다. 시안의 넓은 형태로 두꺼운 H형 토막과 따뜻한 회색 주철의 두꺼운 찢긴 철판(위면 볼트 2개·계단형 홈)을 맵마다 1개(기본 6개 이상이면 2개)만 섞는다. 외곽 설비 받침과 나머지 잔해(철판·슬래그·볼트)는 [미승인 시안](../../design/chapter3_3d/environment_concepts/outrigger-floating/README.md) 단계다.
