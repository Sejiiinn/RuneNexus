## 추가 체력의 기존 체력바 통합 (2026-10-13)

- 상단 HUD와 코어 방어 상세의 추가 체력은 별도 설명 줄 없이 기존 체력바에 합친다. 기존 일반 체력의 녹색을 유지하고, 바로 오른쪽에 더 밝은 녹색 구간으로 남은 추가 체력을 표시한다.
- 표시 분모는 일반 최대 체력 + 현재 남은 추가 체력이다. 일반 체력 100/100과 추가 체력 15는 115/115, 추가 체력 5는 105/105, 소진 후에는 100/100으로 표시하며 기존 바가 끝까지 찬다. 일반 체력 80과 추가 체력 10은 90/110으로, 일반 80/110 → 추가 10/110 → 빈 구간 20/110 순서로 그린다.
- 상·하단 모두 기존 숫자 한 줄과 바 높이를 보존한다. 추가 체력의 회복 불가 설명은 툴팁에만 둔다. 이 표시 합산은 전투의 일반 체력 회복 상한이나 추가 체력의 비회복 규칙을 바꾸지 않는다.
