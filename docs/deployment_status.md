# 배포 상태와 세션 간 인계

배포 요청은 이 문서와 [파이프라인 지도](deployment_pipeline.md)에서 시작한다.
서버·DB·운영 설정 또는 그 계약이 바뀌는 경우 [API 운영 절차](self_hosted_api_deployment.md)를 함께 확인한다.
이 문서는 마지막 검증 이력이며 실시간 운영 상태가 아니다. 배포 대상의 실제 공개 버전·커밋과
서버 실행 이미지·DB 버전을 확인한다.


## 현재 미배포 변경

앱 복귀 동기화 수정은 **소스에 반영했으며 미배포**다. 유효한 동일 계정으로 돌아오면 인증 저장소를 매번 복원하거나 재연결 화면을 열지 않고 기존 writer·저장·경제 확인을 조용히 수행한다. 실제 권위 확인 실패는 기존 재연결·계정 게이트로 복구한다. 회귀 검사에서 수정 전 재연결 표시·불필요한 인증 복원을 재현했고, 수정 후 로그인 복귀13조건·실제 네이티브 전투 상태 유지·401 토큰 갱신·인증 실패 차단과 계정/AppServices·백그라운드 영수증·우편함 검사가 통과했다. 별도 소스/저장 스냅샷의 Metal Mobile 실제 전장·HUD에서 복귀 전/서버 확인 중/확인 후 화면과 동일 체크포인트·epoch·일시정지 유지, 재연결/계정 창 미표시를 확인했다(HTTP는 격리 대역). 상세 로컬 로그·화면은 Git 제외 `build/ignored/foreground-resume-20261025/`에 보관한다. Android 실기기·실계정 및 독립 검증은 수행하지 않았다. 사용자의 별도 배포 요청 전에는 공개하지 않는다.

관통 젬 선택 설명도 ‘투사체 관통 2회 추가’만 남기도록 소스에 반영했으며 미배포다. 장착 조건·피해 감소 없음·별도 관통 규칙 안내를 제거하고 실제 장착 제한은 유지했다. 기존 보상·호환성 검사와 Metal Mobile의 320/440px 보상 화면을 확인했다. 로컬 근거는 Git 제외 `build/ignored/piercing-copy-20261025/`에 보관하며 Android 실기기·독립 검증은 수행하지 않았다.

지원 코어(첫 계열 피해 증가, 3-2 해금)는 **소스에 반영했으며 미배포**다(`c050f0e0`·`4e8cd381`, [설계](support_core_design.md)). 앱은 클라이언트 세대 14이며, 세대 14를 받는 서버(`53fb799d`)는 2026-10-26에 반영했다. DB 마이그레이션은 없다.

콘텐츠 식별자 단일 원본화의 앱 쪽은 **미배포**다. 젬·포탑·모듈 식별자와 모듈 풀·계열·범위를 [레지스트리 생성기](../scripts/compile_content_registry.py)가 Godot·서버 코드로 만들며, 클라이언트가 코어 부품의 피해 증가를 [모듈 설계](turret_module_design.md#roll-테이블)·서버의 코어 범위(유니크 25~36) 대신 공통 범위(22~30)로 잘라 적용하던 결함을 고쳤다. 서버·DB(migration021) 쪽은 2026-10-26에 반영했다.

차등 패치 생성기 개선과 공개 APK의 `x86_64` 제외도 **소스에 반영했으며 미배포**다. 생성기는 PCK 안 파일 단위로 이전 APK를 재사용하며, 공개 6054→6055 APK로 실측한 패치가 111,501,697 bytes(현행 생성기, 공개본과 같음)에서 4,383,917 bytes로 줄었고 Python 복원 결과가 6055와 바이트 단위로 같았다. 패치 형식과 앱 적용기는 그대로라 기존 설치 앱이 그대로 적용한다. Kotlin 적용기 검사는 로컬에 Java가 없어 실행하지 못했으며 배포 CI의 복원 검증으로 확인한다. `x86_64`(약 75MB) 제외로 전체 APK가 그만큼 줄며, 이 ABI 기기의 기존 설치는 다음 업데이트를 설치하지 못한다(실기기 사용 예상 없음). APK 빌드·Android 실기기 확인은 하지 않았다.

마지막 공개 앱은 모듈 개별·일괄 분해 진입 오류를 수정한6055 / 0.2.26(`34d05903`), **필수 업데이트·최소 지원 코드6055**다. 현재 운영 서버는 `53fb799d`·DB22다. 세대·선택적 저장 보호는 [앱 저장 계약](../godot/app/README.md), 훈련 수치·해금은 [밸런스 기준](gameplay_balance_reference.md#영구-업그레이드)을 따른다.

실제 Google 계정·운영 서버에 연결한 앱 젬 덱 플레이와 Android 본게임·실기기 지속 성능의 미검증 범위는 [체크리스트](implementation_checklist.md)에 유지한다.

## 기록 유지 규칙

- 이 문서에는 미배포 변경과 마지막 앱·서버 배포 기록만 둔다. 새 배포를 기록하면 같은 구성 요소의 직전 기록을 [배포 이력](archive/deployment_history_godot.md) 맨 위로 옮긴다.
- 배포가 필요한 코드 변경에는 필요한 migration·환경 설정·선행 조건을 함께 기록한다.
- 배포 후 구성 요소별 커밋, workflow/release, 검증 결과와 한계를 갱신하고 미배포 항목을 정리한다.
- 실패·부분 완료는 구성 요소별로 기록한다. 과거 대화나 로컬 작업 기록만으로 완료를 판단하지 않는다.
- 비밀번호, 토큰, 암호화 키, DB 백업 내용은 이 문서나 커밋에 넣지 않는다.
- 운영 작업 폴더(`~/Library/Application Support/RuneNexus/operations/`)에는 실행 중인 API의 compose가 있는 폴더와 다음 배포 준비 폴더만 둔다. 나머지는 외장 `/Volumes/KIOXIA_MAC/RuneNexus/operations-archive/`로 옮기며, 기록에 적힌 `operations/<폴더>` 경로는 그 아래에서 찾는다.
