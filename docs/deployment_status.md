# 배포 상태와 세션 간 인계

배포 요청을 처리할 때 이 문서와 [운영 배포 절차](self_hosted_api_deployment.md)를 먼저 확인한다.
이 문서는 마지막으로 검증한 이력이며 실시간 운영 상태가 아니다. 배포 직전 실제 DB 버전,
실행 중인 API 이미지, 공개 웹 커밋, 최신 APK release를 다시 확인한다.

## 마지막 확인된 운영 상태

2026-09-09 배포 완료 기준:

- 배포 커밋: `6c5529ea204b84a105c0ee982a73ea19a42fa02e`.
- API: `rune-nexus-api:6c5529e`, 운영 DB migration 010 유지. HTTPS health/live·health/ready 정상.
- 웹 workflow: `34288497022` 성공. 공개 웹 HTTP 200, main.dart.js의 배포 커밋과 운영 API 주소 확인.
- Android workflow: `34288499530` 성공. 최신 공개 release는 `apk-10`, versionCode 10, versionName 0.1.9.
  CI에서 기존 서명 동일성 및 차등 패치 생성·Kotlin 복원 검증을 통과했다.
  공개 update.json의 버전과 APK 크기·SHA-256 및 apk-7·8·9용 공개 패치 크기·SHA-256이 일치한다.
- 배포 전 DB 백업의 pg_restore 목록 검사와 별도 PostgreSQL 18 인스턴스 전체 복원 완료.
  복원 DB 통합 테스트 통과. 백업과 비밀 설정은 Git에 넣지 않는다.

## 이번 배포 변경

- 인증 갱신 응답을 다음 갱신 성공·세션 종료까지 보존하며 만료 access가 포함된 응답도 복구한다.
- 일시 인증 오류의 저장 재시도 및 재로그인 후 인증 차단 Outbox 복구를 적용했다.
- 보상 젬 선택·장착 시 기존 전장 시점을 유지하고, 가려진 포탑은 직접 드래그해서 선택한다.
- 메인 로비 배경은 상하좌우 끝까지 채우고 메뉴만 안전영역에 맞춘다. 전체 스크롤 고정을 유지한다.
- 추가 migration·저장 형식·환경값 변경 없음. 운영 인증 receipt 암호화 키를 포함한 API 환경값이
  교체 전과 동일함을 확인했다. API 내 정리 worker도 같은 이미지로 함께 교체했다.

## 검증 범위와 복구 참고

- 웹·APK CI의 Flutter 정적 분석·전체 테스트 통과. 서버 단위 테스트·go vet·복원 DB 통합 테스트 통과.
- 로비는 안전영역·반응형·메뉴 접근 테스트와 Flutter 테스트 렌더로 확인했다.
  인앱 브라우저는 중복 실행 잠금으로 로비 실제 화면 확인이 제한됐다.
- 운영 계정으로 실제 기기 Google 로그인·진행 저장·APK 설치를 수행한 검증은 포함하지 않았다.
- 이미 구버전에서 갱신 응답 암호문이 삭제됐거나 세션이 폐기됐다면 한 번 재로그인이 필요할 수 있다.
  서버 변경으로 이미 폐기된 세션을 되살리지는 않는다.
- 이전 API 이미지 `rune-nexus-api:ddde673`를 유지한다. 다만 구버전 정리 worker는 최신 유효
  갱신 응답의 암호문을 삭제할 수 있으므로 인증 복구 문제로 롤백할 때 이 영향을 먼저 확인한다.
- 010은 기존 기록을 보존한다. 저장 출처 기록이 생긴 뒤에는 010 down이 거부되므로 기록을 삭제해
  down을 강제하지 않는다. API 롤백과 DB down은 별도로 판단하고 확장된 스키마 유지를 우선한다.

## 미배포 항목

이번 배포 범위의 미배포 코드 변경 없음.

## 기록 유지 규칙

- 배포가 필요한 코드 변경에는 필요한 migration·환경 설정·선행 조건을 이 문서에 함께 기록한다.
- 배포 후 검증된 커밋, DB 버전, workflow/release, 검증 결과를 갱신하고 미배포 항목을 정리한다.
- 실패·부분 완료는 구성 요소별로 기록한다. 과거 대화나 로컬 작업 기록만으로 완료를 판단하지 않는다.
- 비밀번호, 토큰, 암호화 키, DB 백업 내용은 이 문서나 커밋에 넣지 않는다.
