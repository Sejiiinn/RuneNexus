# 지원 코어 설계

역할: 맵에 설치해 인접 포탑을 강화하는 구조물인 지원 코어의 결정과 시작 수치. 정리: 2026-10-25 KST.
상태: 방향, 첫 계열(피해 증가)의 규칙·시작 수치, 이름, 해금 시점을 정했다. 구현·검증은 하지 않았다. 연결 이펙트·본체 시안, 우선순위·일정은 미정이다([TODO](TODO.md#지원-코어)).

## 결정 요약

- 건설 타일 하나를 차지하는 비공격 구조물이다. 골드와 아무 젬 하나를 소비해 짓는다.
- 첫 계열은 피해 증가 하나다. 상하좌우로 맞닿은 포탑의 피해를 올리며 대각선은 제외한다.
- 한 포탑에는 같은 계열의 코어 중 가장 강한 하나만 적용한다. 서로 다른 계열의 코어는 함께 적용한다.
- 코어와 강화받는 포탑 사이에는 실제로 연결된 것처럼 보이는 이펙트를 그린다.
- 3-2(고정 ID12) 최초 클리어로 해금한다.
- 의도: 스테이지마다 수치 축이 아닌 배치 선택지를 늘린다. 쓸모없는 젬에 소비처를 준다. 골드·젬·타일 비용으로 무분별한 설치를 막는다.

## 규칙

### 해금

- 3-2(고정 ID12)를 처음 클리어하면 해금한다. 챕터 3 초반의 빈 해금 칸이다. 3-1은 연구 상한 확장만 주므로, 챕터 3에 들어서자마자 새 배치 선택지가 생긴다.
- 독 포탑과 같이 새 콘텐츠로 취급한다. 구 진행의 보존 권한·구 해금·과거 런 기록으로는 해금하지 않는다.

### 건설과 철거

| 항목 | 값 |
| --- | --- |
| 건설 비용 | 골드 150 + 젬 1개(종류 무관) |
| 추가 건설 비용 | 없음. 몇 번째 코어든 같은 비용이다. |
| 차지 공간 | 포탑과 같은 건설 타일 1칸 |
| 레벨업 | 없음 |
| 철거 | 골드 비용의 75% 환불(포탑 환불과 같은 비율). 소비한 젬은 돌려주지 않는다. |

- 소비한 젬의 종류는 효과에 영향을 주지 않는다. 젬은 비용이다.
- 건설할 때 가방 젬 목록을 띄우고, 소비할 젬을 플레이어가 직접 고른다. 자동으로 고르지 않는다. 포탑에 장착된 젬은 목록에 나오지 않는다.

### 효과

| 계열 | 효과 | 범위 |
| --- | --- | --- |
| 피해 증가 | 포탑 피해 +15% | 상하좌우로 맞닿은 포탑 |

- 피해 증가는 모듈의 피해 증가(`damageIncreaseRate`)와 같은 계층에서 합산한다. 별도 곱셈 계층을 만들지 않는다. 포탑 피해를 기준으로 하는 화상·독도 함께 오른다. 구현 시 [데미지 계층 규칙](damage_calculation_rules.md)에 등록한다.
- 코어끼리는 강화하지 않는다. 코어 자체는 공격하지 않는다.

### 중첩

- 한 포탑에 같은 계열의 코어가 여럿 맞닿으면 가장 강한 하나만 적용한다. 지금은 계열이 하나이고 강도가 같으므로 피해 증가는 최대 +15%다.
- 서로 다른 계열의 코어는 각각 적용한다. 계열은 앞으로 추가할 수 있다.

### 연결 이펙트

- 코어와 강화받는 포탑 사이의 맞닿은 변을 따라, 코어에서 포탑 쪽으로 흐르는 빛줄기를 그린다. 포탑 받침에는 작은 강화 표시를 켠다.
- 포탑·코어를 짓거나 철거하면 연결이 바로 생기거나 끊긴다. 어떤 포탑이 강화받는지 화면에서 바로 알 수 있어야 한다.
- 연결 빛줄기는 게임 상태에 반응하는 보조 표현이므로 인게임 렌더링으로 만든다. 코어 본체는 Blender 원본의 3D 모델로 만든다. 형태·색·재질은 [DESIGNS.md](../DESIGNS.md) 기준으로 시안을 먼저 승인받는다.
- 화면 문구는 "연결"을 쓴다. "링크"는 포탑의 젬 홈을 뜻하므로 쓰지 않는다.

## 구현 영향

구현할 때 확인할 범위다. 구현 순서와 세부 계약은 착수할 때 정한다.

- 서버: 젬 소비는 서버 소유 젬 합계를 줄이므로 일반 저장이 아닌 서버 명령으로 처리한다([서버 경제 계약](server_authoritative_economy_design.md)). 새 명령 유형의 DB migration과 클라이언트 호환 세대 상향이 필요하며, 앱과 서버를 함께 배포한다.
- 런 저장: 코어의 위치·계열을 진행 중 런에 저장하고 복원한다.
- 전투: 포탑·코어 배치가 바뀔 때 인접 포탑의 스탯을 다시 계산한다.
- 화면: 건설 메뉴에 코어와 가방 젬 선택 단계를 추가한다. 포탑 상세에 코어 강화를 표시한다.
