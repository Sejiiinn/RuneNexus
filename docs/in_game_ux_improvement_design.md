# 인게임 UX 현행 결정과 검토 범위

역할: 2026-09-08 초기 제안에서 채택·철회된 범위를 구분하는 안내.
정리: 2026-09-09, 사용자 후속 피드백과 design/ 구현 기록 기준. 전체 UX의 신규 승인이나 전수 검증이 아니다.

## 채택한 방향

- 전면 개편보다 요청한 부분의 국소 개선을 우선한다. 전투 버튼을 상세 패널 아래로 이동하는 초기안은 채택하지 않았다.
- 설치·장착의 기존 재탭 실행은 별도 버튼으로 손가락을 옮기는 비용을 줄이기 위한 의도적 경로다. 재탭 자체를 결함으로 보고 제거하지 않는다.
- 포탑의 보유 젬은 한 줄 인벤토리, 스탯·젬 링크는 연결형 탭, 스탯은 2열 수치표와 고정 높이 내부 스크롤을 사용한다.
- 젬 소켓·연결부는 게임 에셋을 사용하고 비용·수량·효과의 의미를 보존한다.
- 보상 젬 선택·장착·교체 및 완료 시 전장을 자동으로 이동·축소하지 않으며, 포탑 터치도 기존 시점의 화면 좌표를 따른다. 설명에 가려진 포탑은 대상 선택 중 직접 드래그해 노출할 수 있고, 교체 메뉴에서는 전장 드래그를 막는다.
- 상세 시각 기준·적용 화면·검증 중단 기준은 [DESIGNS.md](../DESIGNS.md)를 따른다.
- 보상 젬의 전장 장착·교체와 현재 배포 범위는 [배포 인계](deployment_status.md)와 해당 구현에서 확인한다. 이를 전역 젬 목록의 모든 상호작용이 구현됐다는 의미로 확대하지 않는다.

## 미채택·과거 제안

[초기 종합안 원본](archive/in_game_ux_proposal_2026-09-08.md)은 당시 코드 분석과 가설을 보존한 역사 기록이다. 자동 홈 선택, 패널 접기, 탭 이름 변경, 일괄 정보 구조 개편 등 초기 제안을 현재 요구로 간주하지 않는다. 새로운 요청에 직접 필요할 때만 다시 검토한다.

초기 문서의 코드 라인·화면 문제·완료 체크리스트는 당시 기준이다. 현재 기능 조사에는 관련 코드·테스트를 사용하고, 과거 제안에 맞추려고 동작을 되돌리지 않는다.
