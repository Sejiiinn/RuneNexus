# 과거 Flutter 혼합 호스트 측정 도구

이 경로의 `build_validation.py`, `run_baseline.py`, `run_native.py`, `analyze_validation.py`, `summarize_results.py`, Android 호스트 안내와 검증 장면은 [2026-09-24 보관본](../../docs/archive/godot_performance_legacy_20260924/)으로 이동했다. 삭제된 Flutter 빌드 스크립트·Activity·Dart 진입점에 의존하므로 현재 Android 앱 빌드·성능 검증 명령으로 실행하지 않는다. 당시 Dart 원본은 [Flutter 보관 압축](../../docs/archive/flutter_reference_20260924.tar.gz)에 있다.

현재 앱 검증은 [인앱 가이드](../../.agents/in_app_test_guide.md), 기기 성능 기준과 결과는 [최적화 지침](../../docs/performance_optimization_guidelines.md) 및 관련 `docs/analysis/`의 당시 측정 기록을 따른다.
