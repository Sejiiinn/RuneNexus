# Rune Nexus

Flutter + Flame 기반 모바일 로그라이트 타워 디펜스 데모입니다.

## 현재 범위

- 세로형 게임 화면
- 8 x 10 고정 Grid 맵
- 고정 경로 적 이동
- 포탑 3종 선택 및 배치
- 자동 타겟팅, 투사체, 피해 처리
- 3라운드 기본 웨이브
- 성공/실패 임시 처리

## 실행

현재 작업 환경에는 Flutter SDK가 설치되어 있지 않아 실행 검증은 보류되어 있습니다.

Flutter 설치 후 아래 명령으로 실행합니다.

```bash
flutter create .
flutter pub get
flutter run
```

`flutter create .`는 Android/iOS/Web 등 플랫폼 폴더를 생성하기 위한 단계입니다.
