# 로비 그래픽 설정

2026-09-13 구현·검증 기록. 로비의 기존 설정 모달에 기기별 라디오 선택을 추가했다.

- MSAA: 끄기 / 2배(기본).
- 그림자: 끄기 / 낮음(512) / 중간(1024) / 높음(2048, 기본).
- 기존 게임 테마와 계정 및 저장 버튼 유지. 작은 화면은 선택지 줄바꿈과 모달 내부 스크롤로 수용한다.
- 게임·계정 저장과 분리한 로컬 설정이며 새 전투와 앱 재시작 후 이어서 하는 저장된 전투에 적용한다. 저장 실패는 기존 선택을 유지하고 오류를 표시한다.
- Flutter→Godot 초기 연결·옵션 변경에 값을 전달한다. 3D 렌더 해상도와 전투 규칙은 변경하지 않는다.

## 확인

- `flutter analyze` 통과.
- 설정 파일·오류 복구, 작은 화면 라디오 조작, Godot 채널 전달·카메라 변경 후 유지 테스트 12개 통과.
- 일반 웹 앱의 실제 로비에서 390×844 및 320×568 화면, 선택 변경, 새로고침 후 값 유지 확인. [실제 설정 화면](lobby-settings-web.png)은 안내 문구 수정 전 웹 로비 캡처이며 Android 3D 캡처가 아니다. 현재 문구는 자동 저장과 앱 재시작 후 저장된 전투 이어서 진행에도 적용됨을 명시한다.
- `godot/verify_graphics_options.gd`: headless 및 Metal Mobile 런타임에서 단계 적용·잘못된 값 복구·반복 옵션 전달 확인.
- 기존 로비 테스트 11개 중 10개 통과, 전투 재개 테스트 1개는 Godot 로딩 오버레이 아래 버튼을 탭하는 경로에서 실패했다. 해당 테스트와 게임 동작은 이번 작업에서 변경하지 않았다.

## 미검증

전체 Godot 프로젝트 준비는 기존 6스테이지 `chapter2_stage6_geology.glb` 누락으로 중단되었다. Godot 옵션 검증은 기존 준비 프로젝트에 변경 스크립트를 반영해 진행했다. 새 APK의 통합 실행 및 저사양 Android 실기기 성능 개선 폭은 확인하지 못했다.
