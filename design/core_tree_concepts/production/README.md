# 코어 트리 스프라이트 적용

2026-09-10. 승인된 A안과 확장 트리 시안을 기준으로 만든 정적 스프라이트 묶음이다.
제작은 내장 ImageGen, 원본은 `source/`, 게임 번들용 PNG는 `assets/images/core_passive_tree/`에 보관한다.
각 상태는 정지 프레임 1장이다. 점등 타이밍과 진행 길이는 런타임이 제어하되, 금속 질감·빛의 모양은 이미지에 담는다.

## 사용 방식과 기존 에셋 재사용

- 노드: 기본 프레임 → 스킬 아이콘 → 점등 프레임/선택 링 순으로 상태에 맞게 조합한다. 점등 프레임의 중앙은 투명하므로 스킬 아이콘을 가리지 않는다.
- 점등: 기본·점등 PNG의 투명도를 전환하여 표현한다. 고정 애니메이션 시트를 새로 재생할 필요는 없다. 연결선은 경로를 따라 점등 스프라이트의 표시 범위를 늘린다.
- 연결선: 이미지의 유효한 가로 조각을 가져와 길이에 맞춰 배치한다. 곡선/방향/점등 진행 범위는 기존 경로 계산을 유지하면서 스프라이트 표시 범위를 제어한다. 연결부 장식은 별도 마름모 PNG를 겹친다. 전체 경로를 한 장의 그림으로 고정하지 않는다.
- 중앙: 기존 `nexus_core.png`와 코어 스킬 아이콘을 재사용할 수 있도록 받침의 중앙을 비워두었다.
- 배경과 개별 스킬 아이콘은 기존 `tree_circuit_background.png`, `core_abilities/`, `core_passives/`를 재사용한다. 포인트 숫자, 랭크, 설명, 선택 버튼 문구는 텍스트 UI를 유지한다.
- `pubspec.yaml`의 기존 `assets/images/core_passive_tree/` 등록으로 번들에 포함된다. 메뉴 진입 시 Flutter 이미지 캐시로 로드하며 연결선 painter는 ImageStream 수명에 맞춰 디코딩 이미지를 사용한다.

## 이번 UI 반영 범위

코어 메뉴의 전투 스킬/패시브 트리 탭을 제거하고 트리 중앙에서 코어 스킬 선택 패널을 열도록 변경했다. 트리 탐색 영역은 상단 헤더와 하단 탭 사이 전체를 채우고, 포인트 요약과 변경 취소·초기화는 트리 위에 고정된 반투명 패널로 표시한다. 선택 패널은 기존 해금·장착/해제 API를 사용한다. 트리의 줌과 미확정 포인트 투자는 유지한다.

A안 기본·점등 프레임, 선택 링, 금속 연결선, 연결부와 중앙 받침을 현재 트리에 적용했다. 노드 프레임은 48·68·96 크기를 사용한다. 기존 21개 노드의 배치·연결·투자 규칙과 점등 순서는 유지하며, 확장 트리 배치는 이번 범위에 포함하지 않는다.

## 중앙 스킬 명패

- `skill_nameplate_v1.png`: 396×55 투명 PNG, 정지 프레임 1장. 내장 ImageGen 생성 후 GIMP에서 투명 여백 크롭·축소. 원본은 `source/skill_nameplate_v1.png`. PNG 내보내기는 `flatten: false`로 알파를 보존하며, 최종 396×55 파일의 알파 채널과 위젯 렌더에서 투명 외곽을 확인한다.
- `ExactAssetImage(scale: 2)`와 논리 좌표 `Rect.fromLTRB(16, 4, 182, 23.5)`의 9분할 확장으로 양끝 장식을 보존한다. 문자는 별도 UI 텍스트로 표시하며 장착명 또는 미장착 시 ‘스킬 선택’만 노출한다.

## 확인 자료

- [에셋 크기·투명도 미리보기](asset-preview.png): 이미지 박스 기준 실제 크기와 확대 비교. 실제 게임 화면 캡처가 아니다.
- [중앙 스킬 선택 테스트 렌더](core-center-selection-test.png): 실제 메뉴 위젯에 고정 진행 상태를 전달한 400×800 테스트 렌더이며 실제 앱 캡처가 아니다.
- [스프라이트 적용 트리 렌더](core-tree-sprites-test.png): 현재 메뉴 위젯의 400×800 화면을 2배 해상도로 렌더했다. 오른쪽 공격 경로는 투자·점등 상태, 나머지는 미투자·잠금 상태다. 저장 데이터를 변경하지 않는 테스트 상태이며 실제 앱 캡처가 아니다.
- 재현: `scripts/in_app_server_macos.sh flutter test tool/core_tree_asset_render_test.dart tool/core_tree_render_test.dart --no-pub`.
- 제작 프롬프트: [prompts.md](prompts.md).
- PNG 캔버스 크기와 본체 영역 참고: [sprite-bounds.json](sprite-bounds.json). 연결선은 상태별 유효 영역이 다르므로 같은 원본 좌표를 공통으로 사용하지 않는다.
- 크기 위계 참고: [GGG 공식 패시브 트리 데이터](https://github.com/grindinggear/skilltree-export). PoE의 아트 파일을 게임 에셋으로 사용하지 않았다.

## 검증 결과

- 11개 PNG의 알파 채널, 투명 모서리, 프레임/링/받침의 투명 중앙, 원본·게임 번들 사본 일치를 확인했다.
- 기본/점등 상태의 중심·외곽과 소형→중형→대형 크기 위계를 실제 목표 이미지 박스 및 확대 렌더에서 확인했다.
- 스프라이트 적용 후 코어/메뉴/트리 테스트와 대표 렌더 총 43개가 통과했다. 대표 렌더에서 프레임 크기 위계·아이콘·랭크·연결선의 방향과 점등 상태를 확인했다.
- 스프라이트 적용 당시 정적 분석과 웹 빌드가 통과했다. 이후 전체 화면 배치 변경은 메뉴 테스트 27개와 위젯 렌더로 확인했으며, 이 배치의 실제 브라우저 검증은 Mac 잠금으로 미완료다.
- Mac 잠금으로 실제 브라우저 캡처는 사용할 수 없어 사용자 요청에 따라 위젯 테스트 렌더를 제공한다.
