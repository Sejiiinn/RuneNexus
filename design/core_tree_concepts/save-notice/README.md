# 저장 성공 안내 제거

2026-09-26. [디자인 기준](../../../DESIGNS.md)의 로비 저장 성공 안내 제거를 적용했다. `godot/ui/lobby.gd`의 성장 명령·수동 저장·그래픽 설정 저장 성공 시 메시지만 비운다. 저장 호출, 실패 안내, 연구 완료·중단 반환 정보는 유지한다.

Godot 4.7.2/macOS OpenGL Compatibility, 440×900, 사용자 저장과 분리한 기존 로비 fixture로 실제 장착·해제 버튼을 mouse 입력했다. 실제 앱 컴포넌트의 테스트 상태이며 사용자 플레이 저장 캡처가 아니다.

- [수정 전 로그](before/run.log): 장착·해제 뒤 `저장했습니다.`가 추가되며 코어 영역 높이가 760→741px로 줄었다.
- [수정 후 로그](after/run.log): 장착·해제 후 높이 760px, 위치·줌 유지. 장착 상태 변경 정상, 성공 문구 없음, 실패 안내 유지, 다음 성공 시 이전 실패 안내 제거, 수동 저장 성공 문구 없음.
- [장착 후](after/equipped.png), [해제 후](after/unequipped.png).

Android 전용 변경이 없어 APK 빌드·실기기 검증은 수행하지 않았다.

별도 Astra가 최종 코드·실제 캡처 3장·실행 로그를 직접 대조해 독립 검증 PASS. 저장 디스크 쓰기 자체는 이 UI fixture에서 검증하지 않았으며 저장 구현 변경은 없다.
