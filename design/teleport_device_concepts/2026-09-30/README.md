# 순간이동 장치 컨셉

사용자 요청: 순간이동 기믹 장치 이미지 시안과 공통 구조, 파랑·주황 두 연결 쌍 및 입출구 흐름 구분. 2026-09-30에 K안(12번)의 3D 제작을 승인했다. A~J는 탐색용 ImageGen 2D 시안이며 현재 제작 기준은 K안이다. 게임 적용 결과는 아니다.

## 형태 후보

- [A — 낮은 룬 발판](01-rune-pad.png)
- [B — 쌍기둥 문](02-twin-pillars.png)
- [C — 분절된 고리](03-broken-ring.png)
- [D — 수정 틈새](04-crystal-rift.png)
- [E — 석재 아치](05-rune-arch.png)

각 이미지의 두 장치는 입구·출구 한 쌍을 제안한다. 방향 표식과 실제 타일 점유 크기는 후속 제작에서 정제한다. 5안은 챕터 2 균열 유적의 석재·청록/보라 발광으로 탐색한 형태 후보이며 공통 구조로 선택된 결과는 아니다.

## 추가 공통 구조

[F — 공통 본체와 챕터별 표면 변형](06-common-structure-v2.png): 낮은 사각 본체, 팔각 전송면, 모서리 고정부, 연결 룬과 방향판을 공통으로 유지한다. 기능 발광도 청록으로 유지하고 챕터별 석재와 외곽 장식만 달리한다. 상단 세 장치는 입구의 챕터별 변형, 하단은 IN/OUT 방향판 비교다.

[상세 구조 제안](common-structure.md). `06-common-structure.png`는 방향판 보정 이전의 중간안이며 현재 비교에는 v2를 사용한다.

## 걸어서 통과하는 구조

[G — 걸어서 통과하는 공통 전송 장치](07-walk-through-transfer.png): 낮은 사각 발판과 짧은 쌍기둥 사이에 세로 전송면을 세운 제안이다. 상단은 입구·출구 구조, 하단은 같은 개체가 전송면을 지나며 부분적으로 사라지고 반대편에서 나오는 연출 예시다. 개체는 동작 설명용이며 실제 게임 에셋이 아니다.

## 기존 타일과의 통합

[H — 기존 타일에 통합한 전송 장치](08-tile-integrated-transfer.png): 기존 1-6 맵 렌더를 ImageGen 참조로 사용했다. 황토색 돌길 상면·층진 석재 측면과 길 높이를 이어가며, 타일 양옆의 기둥과 세로 전송면으로 구성한다. 왼쪽은 연결부 확대, 오른쪽은 맵 배치 예시다. 실제 맵 변경이나 인게임 캡처가 아니다. 공용 기둥·전송면을 유지하고 바닥은 해당 챕터 타일에 맞추는 제안이다.

## 파랑·주황 바닥형 두 쌍

[I — 타일 매립형 파랑·주황 포탈](09-blue-orange-floor-pairs.png): 사용자 요청에 따라 파랑 입·출구 한 쌍과 주황 입·출구 한 쌍을 같은 맵에 표시한다. 파랑은 파랑으로, 주황은 주황으로 연결한다. 본체는 같은 팔각 금속 테두리·룬 구조를 사용하고 발광색으로 짝을 구분한다. 황토 돌길 타일에 수평으로 매립하며 기존 타일 높이·층진 석재 측면을 유지한다. 왼쪽은 색별 확대, 오른쪽은 네 개의 배치 예시다. ImageGen 내장 도구로 만든 시안이며 맵 배치·전송 동작의 실제 게임 구현은 아니다.

## 타일 상면 전체를 덮는 수정안

[J — 상면 전체형 파랑·주황 포탈](10-full-tile-blue-orange-pairs.png): I안에서 포탈이 타일 윗부분을 아예 덮도록 수정한 사용자 요청 대응 시안이다. 외곽의 얇은 사각 금속 테두리와 전송면이 상면 전체를 덮고, 층진 석재는 측면에 유지한다. 주변 길 높이와 파랑→파랑·주황→주황의 두 연결 쌍을 보존한다. 확대와 맵의 네 포탈에 같은 변경을 적용했다. ImageGen 내장 편집 결과이며 미승인 시안·게임 미적용 상태다.

## 입·출구 소용돌이 흐름 구분

[K — 안으로 모이는 입구·밖으로 퍼지는 출구](12-in-out-vortex-single-tile.png): 사용자 요청은 같은 색의 연결 쌍 안에서 소용돌이의 입·출 방향으로 역할을 자연스럽게 구분하는 것이다. 입구는 가장자리에서 어두운 중심으로 모이며 사라지는 흐름, 출구는 밝은 중심에서 가장자리로 퍼지는 흐름을 제안한다. 파랑·주황 모두 같은 구분을 적용하며 상면 전체형 본체·층진 석재 측면·주변 타일 높이를 보존한다. 비교를 위해 파랑 IN/OUT와 주황 IN/OUT의 네 확대를 배치했다. ImageGen 내장 편집으로 만든 정지 시안이므로 실제 움직임·게임 크기의 직관성 검증은 후속 구현 범위다. 회전 방향 차이만으로 입출구를 구분하지 않고 중심으로의 수렴/바깥으로의 발산을 동작에서도 유지하는 방향이다.

`11-in-out-vortex-flow.png`는 이웃 타일이 좁게 생성된 중간안이다. 현재 비교에는 한 칸 크기 관계를 보정한 `12-in-out-vortex-single-tile.png`를 사용한다.
