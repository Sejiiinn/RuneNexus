# 챕터 2 환경 에셋 시안

2026-09-13. 상태: 사용자 구현 승인 시안. 실제 원본·게임 적용은 [챕터 2 3D](../chapter2_3d/README.md)에서 관리한다.

사용자 요청에 따라 기존 챕터 2 환경 예시(로컬 시안 기록 `design/chapter_battlefield_concepts/`)의 ‘균열에 잠식된 성소’를 개별 에셋으로 구체화했다. 기존 예시는 미확정 자료이며, 이번 4종을 확인한 후 실제 타일 구현을 승인받았다. 현재 코드의 `chapterTwoRift` 테마와 함께 색·소재의 근거로 사용했다.

| 이미지 | 의도 | 최종 프롬프트 |
| --- | --- | --- |
| [01 석재 길·건설 기반](01-terrain-module.png) | 밝은 회보라 길, 어두운 청회색 빈 기반, 두꺼운 석재 측면 | [01](01-prompt.txt) |
| [02 부서진 룬 기둥](02-rune-pillar.png) | 침식된 석재와 작은 청록 룬, 오래된 황동 봉인띠 | [02](02-prompt.txt) |
| [03 수정 군집](03-crystal-cluster.png) | 암보라 뿌리와 청록 끝, 내부 광물층과 반투명 깊이 | [03](03-prompt.txt) |
| [04 공허 균열](04-void-fissure.png) | 외곽 암반 틈의 국소적인 보라 공허와 파손 봉인 고리 | [04](04-prompt.txt) |

모두 내장 ImageGen으로 생성한 불투명 배경의 PNG다. 3D 모델이나 게임용 투명 스프라이트가 아닌 제작 방향 검토용이며, 에셋 전체의 형태·재질·빛을 보기 위한 독립 이미지다. 01의 3×3 모듈은 재질 구분 예시이며 실제 스테이지 맵을 재현하거나 바꾸는 제안이 아니다. 02~04는 비플레이 외곽 장식용 방향이다. 균열은 새로운 피해 지형이나 전투 규칙을 의미하지 않는다.

이미지 제작 단계에서 석재의 두께와 틈, 수정의 면·내부층, 절제된 발광, 전체 에셋의 여백을 확인했다. 후속 구현은 이 형태·재질을 편집 가능한 Blender 원본으로 만들고 실제 Android 게임 크기에서 검증한다. 제작·검수 기록은 위 3D 안내에 둔다.
