# 외곽 소품의 연결 암반 시안

2026-09-13. 사용자 요청: 공중에 떨어져 보이는 외곽 소품을 지형에 자연스럽게 연결하는 시안을 먼저 확인한다. 상태: 검토용, 게임 미적용.

[시안 이미지](01-connected-rock-ledge.png)는 기존 4종 시안을 참고해 내장 ImageGen으로 생성했다. [최종 프롬프트](01-prompt.txt).

기둥 아래 기단, 수정이 자라는 바위, 공허 균열의 양쪽 암반이 본판 측면과 이어지는 한 덩어리 지형이다. 길과 건설 중심은 비워 둔다. 연결된 지지 암반과 소품 접지, 기존 석재·수정·룬의 색과 소재를 이미지에서 확인했다. 배치 방식 설명용 모듈이며 실제 스테이지 맵 변경안이나 게임 캡처가 아니다.

## 연결·독립 지형 혼합 시안

사용자가 본판과 연결된 땅과 별개의 땅 모두 가능하다고 설명한 후 만든 [02 혼합 암반 지형](02-mixed-rock-ground.png). 기둥은 본판에 연결하고, 수정·균열은 본판과 떨어진 넓고 두꺼운 독립 암반에 배치했다. 소품보다 충분히 넓은 지면과 바닥까지 이어지는 지지 암반이 보이는지 확인했다. 내장 ImageGen으로 생성했으며 [프롬프트](02-prompt.txt)를 보관한다. 검토용이며 게임 미적용이다.
