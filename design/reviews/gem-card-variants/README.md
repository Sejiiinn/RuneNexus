# 젬 카드 설명 시안 4개

2026-09-09 사용자 요청에 따라 A·B·C는 각각 독립 하위 에이전트가 작성하고 D와 통합 비교는 주 에이전트가 작성했다. 아래 4개 비교 이미지는 선택 전 시안 기록이다. 현재는 사용자가 선택한 A안을 구현에 적용했다.

## 현재 적용: A안 + 간격 정렬 + 제약사항 분리

[적용 화면](implemented-a-bottom-restriction.png)은 현재 Flutter 위젯의 320×800 테스트 렌더다.

- 폭발·중화기 효과명과 값은 중앙 정렬한 두 줄 묶음으로 표시한다.
- 효과 묶음 안 간격은 2px, 묶음 사이 간격은 8px이며 같은 높이의 묶음으로 같은 항목의 위치를 맞춘다.
- 중화기 전용은 효과에서 분리하여 설명 맨 아래, 보유 표시 위에 회색 제약 문구로 표시한다. 다른 카드도 아래 제약사항 줄의 공간을 확보해 보유 표시 위치를 맞춘다.
- 설명 영역은 위쪽 정렬이며 젬 이름 아래 간격은 2px다. 제약 문구 공간은 설명 아래로 옮겨 효과 시작 위치를 올리고 보유 표시 위치를 유지한다.
- 이름과 효과 묶음 높이는 글자 확대 배율에 맞춘다. 기존 미보유·보유 수량, 아이콘, 상세 규칙은 유지한다.
- 관련 테스트 7개와 320폭 렌더 테스트, 정적 분석을 통과했다. 320·390 폭과 130% 글자 확대, 제약사항의 위치, 동일 효과 항목의 세로 정렬을 검증했다. 실제 브라우저는 기존 중복 실행 안내로 미확인 상태다.

## 선택 전 시안 기록

[PNG 비교](comparison.png) / [통합 원본](comparison.html)

- A 중앙 묶음: 효과마다 설명·수치를 가까이 묶어 차분하게 읽기.
- B 요약표: 효과명과 결과를 정렬된 두 열로 비교. 좁은 폭 때문에 표 내부 두 줄 표기가 많음.
- C 수치 우선: 수치를 크게 먼저 보여 빠른 수치 비교. 효과명은 아래에서 연결.
- D 핵심 효과 강조: 주효과를 먼저 읽고 보조 효과와 조건을 아래에서 확인.

카드 논리 폭 80px, 높이 210px 기준. 통합 비교는 1.5배 확대다. 공정한 비교를 위해 카드 외곽·배경·이름·미보유 표시를 통합 원본에서 통일했다. 기존 아이콘과 NotoSansKR 폰트를 사용한다. 모든 효과·수치·전용 조건을 유지하며, 카드 아래 공통 상세 규칙은 이번 설명 영역 비교에서 생략해 그리지 않았지만 삭제 제안은 아니다.

개별 variant-a/b/c/d.html은 작업자 원본이고 통합 원본에 공통 외곽 보정이 포함되어 있다. 브라우저에서 렌더와 주요 문구를 확인하고 PNG를 저장했다. 시안 제작 당시에는 기능 코드를 수정하지 않았다. A안 적용 검증은 위의 현재 적용 절을 따른다.
