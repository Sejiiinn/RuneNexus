# 젬 카드 설명 초기 적용 기록

이 기록의 항목별 왼쪽 정렬은 이후 A안으로 대체됐다. [현재 적용 기준](../../gem-card-variants/README.md)을 따른다.

2026-09-09 사용자 승인: 기본 설명 글자 소폭 축소와 의미 단위 줄바꿈, 보유 0의 회색 미보유 표시, 폭발·중화기 증폭의 항목별 정렬과 수치 강조.

- 일반 설명은 효과 대상과 수치·배율을 의미 단위로 나눈다.
- 폭발·중화기 증폭은 효과명을 작은 보조색으로, 수치·배율은 밝고 굵게 표시한다. 폭이 부족하면 수치·배율을 통째로 다음 줄에 둔다.
- 중화기 전용 조건은 간격을 두고 아래에 분리한다.
- 카드 아래 상세 규칙, 이름, 아이콘, 1개 이상 보유 수량은 유지한다. 0개는 회색 미보유로 표시한다.

[최신 적용 화면](grouped-effects.png)은 현재 Flutter 위젯의 320×800 테스트 렌더이며, 실제 브라우저 캡처가 아니다. 관련 테스트 12개와 해당 렌더 테스트, 정적 분석을 통과했다. 테스트는 320·390 폭과 130% 글자 확대도 포함한다. 실제 브라우저 진입은 중복 실행 안내로 미확인 상태다.
