# 적 공통 화상 효과

현재 기준은 사용자가 승인한 **V3의 짧은 수명 불꽃 입자**다. Godot 공통 화상 효과로 연결했으며 원본 불꽃을 구운 공유 아틀라스와 종별 부착 자료를 사용한다. 적별 단일 MultiMesh의 입자 운동·소멸은 GPU에서 외부 전투 시계로 계산한다. 원본 적 모델·재질과 화상 판정은 유지한다.

[Godot 이식·검증 기록](integration/README.md) · [승인 V3 영상](burn-v3-preview.mp4)

후속 정리에서 당시 Godot·Android 비교 캡처는 제거됐다. 이 문서는 승인 원본·제작 및 이식 계약을 보존하며 새 화면 검증을 주장하지 않는다.

아래는 V1부터 V3까지의 제작 기록이다. 각 절의 게임 미이식 표기는 해당 시안 제작 당시의 상태이며, V1·V2는 채택하지 않았다.

## 첫 시안 V1 — 제작 당시 기록

게임에 이식하지 않은 시각 검토용 시안이다. 기존 적 원본은 수정하지 않았다.

- 일반·탱커·중장갑 적의 몸체 표면에 같은 불꽃 원형을 부착했다.
- 불꽃 메시 2개와 불티 메시 1개를 공유하고, 적별 부착 위치·크기만 맞췄다.
- 전면 핵과 몸체 색을 유지하며 어깨·등·옆면에서 불꽃이 피어오른다.
- 24fps, 120프레임: 착화 → 지속 연소 → 소멸.
- Blender 볼륨 재질·변형 애니메이션으로 만든 외형 시안이며, Godot용 변환 결과가 아니다.

## 산출물

- `enemy-burn-study.blend`: 편집 가능한 원본, 대표 프레임 48.
- `burn-preview.mp4`: 5초 동영상.
- `burn-preview.gif`: 반복 미리보기.
- `burn-preview.png`: 지속 연소 대표 이미지.
- `build_burn_study.py`: 제작 스크립트. 프로젝트의 기존 불꽃 제작 함수를 참조한다.
- `attachment-study.json`: 공유 메시 수와 적별 로컬 부착 좌표.

게임 코드·게임용 에셋·화상 판정 및 피해 로직은 이번 시안 작업에서 변경하지 않았다.

## 수정 시안 V2

첫 시안의 가늘고 반복적인 불꽃이 머리카락·스티커처럼 보인다는 피드백을 반영한 별도 후보다. 승인된 게임 외형으로 채택하지 않았다.

- `enemy-burn-v2.blend`: 최종 수동 보정까지 포함한 V2 편집 원본.
- `burn-v2-preview.png`, `burn-v2-preview.mp4`, `burn-v2-preview.gif`: 수정 미리보기.
- 고정된 불꽃 모양 메시를 없애고, 공유 체적 재질 내부의 흐르는 노이즈로 불길을 표현했다.
- 몸체 표면에서 부착 위치를 찾고 옆면·앞쪽으로 배치했다. 밝기와 크기를 낮추고 주황색 주변광을 보강했다.
- `revise_burn_volume.py`는 V2 초기 제작 단계다. 이후 표면 위치·크기·밝기·전면 추가 보정은 `.blend`에 들어 있다.
- 게임 코드와 게임용 에셋 변경 없음.

## 수정 시안 V3 — 짧은 수명의 불꽃 입자

V2의 고정된 기둥 외곽에 대한 피드백으로 제작 방식을 바꿨다. 기존 2D의 `enemy_renderer.dart` 화상 표현과 `status_effect_sprite_cache.dart`를 읽어, 불티·주황빛이 짧게 떠오르는 움직임을 참고했다. 기존 2D를 그대로 복제한 결과는 아니다.

- `enemy-burn-v3.blend`, `build_burn_v3.py`: 수정 원본과 제작 스크립트.
- `burn-v3-preview.mp4`, `burn-v3-preview.gif`, `burn-v3-preview.png`: 4초 미리보기와 대표 이미지.
- 고정된 긴 발화 영역을 없애고, 서로 다른 위치·수명으로 태어나는 짧은 체적 불꽃 52개를 적별 배치했다.
- 각 불꽃은 몸체에서 발생해 올라가며 비틀리고 작아져 사라진다. 메시·체적 재질은 공유한다.
- 96프레임, 24fps. Blender 전용 시안이며 게임 이식 없음.
