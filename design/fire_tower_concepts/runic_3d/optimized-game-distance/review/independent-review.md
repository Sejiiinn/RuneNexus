# 화염 포탑 경량판 독립 검수

판정: **PASS** — 현재 게임 원본과 경량판을 같은 QHD 렌더 조건에서 비교했으며, 먼 카메라에서 의미 있는 형태·식별 정보 손실은 발견하지 못했다.

- 원본 46,795 → 경량 11,411 삼각형 (**75.61% 감소**), GLB 7,217,824 → 2,856,352바이트 (**60.43% 감소**). 두 파일을 직접 파싱하고 캡처 후 SHA-256을 재확인했다. 모두 3메시·5재질이다.
- 고정·드론 시점의 원본 픽셀 비교를 직접 확인했다. 긴 사다리꼴 몸체, 팔각 총구, 측면 지지대, 주황 룬, 청동 금속 반사가 유지된다. 경량판의 작은 베벨·곡률 차이는 보이지만 이 거리에서 정체성을 훼손하지 않는다. 모델 화면 범위 차이는 가로 0.63픽셀 미만이다.
- 노드 이름·부모/자식 관계·메시 분리가 일치한다. root의 0.9 배율, barrel의 9도 회전, barrel 하위 muzzle·upper_flame_port가 보존된다. 전체 노드 변환 성분 최대 차이는 7.45e-8로 검사 허용오차 1e-6 이내다. 실수 비트 단위 동일성을 요구한 결과와 기능 계약 보존은 구분했다.

## 비교 조건과 근거

실제 Godot 3D 렌더 타깃은 **1440×3120**, 3D 해상도 배율 1.0, 2× MSAA다. 저해상도 이미지를 확대하지 않았다. 앱의 440×760 기준 expand 설정에 따라 논리 영역 440×953.333, HUD 전장 영역 (8,110,424,651.333), 안전 영역 0, 줌 1.0을 적용했다. 동일한 스테이지 1 타일·방향·카메라·조명을 사용했다. 현재 게임처럼 `Runes |` 재질에 UNSHADED를 적용했다. HUD 자체는 표시하지 않으며 카메라 맞춤 영역만 재현했다.
