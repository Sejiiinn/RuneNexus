# 룬 화염 포탑 이펙트 미리보기

승인된 포탑 형태를 유지한 Blender 애니메이션 연구. 이 파일은 기준 영상으로 보존하며, 후속 승인에 따른 게임 구현은 [Godot 이관 기록](../migration/README.md)의 기본 재질·파티클 효과를 사용한다.

- [MP4 영상](runic-flame-vfx.mp4): 6초, 24fps, 960×640. 발사 2회.
- [반복 GIF](runic-flame-vfx.gif): 12fps, 720×480.
- [편집 가능한 Blender 원본](runic-flame-vfx.blend)
- [애니메이션 제작 코드](build_vfx.py), [영상 인코딩 코드](encode_preview.py)

상부 불꽃은 입체 메시의 변형과 체적 노이즈 이동으로 일렁인다. 발사 순간 포구의 화염 분출·분기 화염·주변 조명이 짧게 커진다. 화염 발사체는 밝은 중심·주황 외피·후방 화염 꼬리·흩어지는 잔불로 구성했다. 발사 시 본체에 작은 반동이 있다. 유체 시뮬레이션이나 인게임 성능 검증 결과가 아닌 형태·타이밍 검수용이다. 충돌·피격 효과는 이번 범위에 포함하지 않았다.

Blender 타임라인 1–144 프레임, 발사 시작 30·94 프레임. `05 Animated Fire VFX` 컬렉션에서 발사체와 화구를 편집한다. 기존 `04 Flame Study`의 상부 불꽃에는 변형 키와 재질 애니메이션을 추가했다. 키프레임과 노드 애니메이션이 저장되어 별도 실행 스크립트 없이 재생된다. 원래 정지 모델 파일은 유지한다.
