# Galaxy S26 Ultra 해상도 독립 검수

확인: 2026-09-26. 구현 담당과 별개의 Astra 검수. **PASS** — 1440×3120에서 새로 렌더한 고정·드론 시점의 원본 픽셀 비교에서 경량판의 의미 있는 추가 흐림이나 형태 손실이 보이지 않는다.

## 실제 확인

- [경량판 고정 전체 화면](optimized-angled-full.png)과 [고정 원본 픽셀 비교](angled-native-pair-left-original-right-optimized.png), [드론 원본 픽셀 비교](drone-native-pair-left-original-right-optimized.png)를 직접 보았다. 비교는 좌 원본·우 경량판이다.
- 원본·경량판의 고정/드론 **전체 PNG 4장의 파일 헤더를 직접 읽어 모두 1440×3120임을 확인**했다.
- [촬영 코드](capture_compare.gd)를 읽어 1440×3120 `SubViewport`, `scaling_3d_scale=1.0`, MSAA 2×에서 실제 3D 렌더한 뒤 텍스처를 저장하는 경로를 확인했다. 기존 저해상도 PNG를 확대하는 경로가 아니다.
- 두 GLB의 실제 SHA-256이 [이전 검수 입력](../asset-comparison.json)과 일치한다. 변경하지 않은 모델의 삼각형·계층 검사는 반복하지 않았다.

## 앱 배율 재현

`godot/app/boot.gd`와 `app_lifecycle.gd`의 실제 앱 설정 `content_scale_size=(440,760)`을 직접 확인했다. 이번 캡처는 이를 기준으로 expand를 적용해 논리 viewport **440×953.333**, safe inset 0에서 HUD 전장 영역 **(8,110,424,651.333)**을 계산한다. 이전 fixture의 기본 880 기준을 정식 앱 배율로 혼동하지 않았다.

동일한 stage1 지형·조명·배치·방향, zoom=1.0, 정투영 고정/드론 카메라를 사용한다. 자세한 수치는 [capture-conditions.json](capture-conditions.json)에 있다.

| 시점 | 원본 포탑 투영 크기 | 경량판 투영 크기 |
| --- | ---: | ---: |
| 고정 | 112.712×159.064 px | 112.598×158.963 px |
| 드론 | 125.075×221.991 px | 124.575×221.991 px |

고해상도 원본 픽셀에서 곡면 헤드·은색 띠·긴 포신·받침과 룬의 존재가 유지된다. 하이라이트·미세 베벨에는 작은 차이가 있지만 경량판만 흐려지거나 주요 디테일이 무너지는 변화는 보이지 않는다. 비교쌍은 보간 없이 원본 픽셀을 배치했으며 투영 경계 차이도 최대 약 0.5px다.

## 범위와 한계

이는 **Galaxy S26 Ultra의 1440×3120 화면 규격을 재현한 macOS Godot 렌더**다. 실제 Galaxy 기기 캡처·Android GPU·발열·FPS 검증이 아니다. 안전 영역은 0으로 가정했고 HUD 자체는 표시하지 않았다. 전체 PNG는 화면비와 실제 렌더 픽셀을 보존하지만, 채팅 뷰어의 표시 축소와는 구분해야 한다. 이번 요청 범위에서 미해결 사항은 없다.
