# SWIFT 3D 수정 독립 검수

확인: 2026-09-26. 구현 담당과 별개의 Astra 검수. 대상은 [승인 01 SWIFT](../receiver-variants/01-swept-wedge.png)를 반영한 실제 Blender 원본·렌더·준비 GLB다. 본게임 이식은 범위에 포함하지 않는다.

**최종 판정: PASS.** 첫 렌더의 높고 두꺼운 crown은 국소 압축 후 재검수했으며, 렌즈 전면 가림도 최종 렌더에서 해소됐다. 원안보다 상단이 약간 둥근 차이는 있으나 낮은 유선형 쐐기, 둥근 뒤어깨, 청회색 곡면·은색 어깨, 곡선 요크라는 핵심 형태를 충족한다. 추가 미세 외형 수정은 필수로 판단하지 않았다.

## 직접 확인한 시각 근거

- [정면 사선](sniper-c-hero.png): 긴 포신과 낮아진 기둥을 유지하면서 상자형 상부를 유선형으로 변경했다. 청록 원형 렌즈가 은색 하우징 전면에서 가림 없이 보이며 측면 다이아 룬, U자 은색 요크·황동 축, 금속 반사가 유지된다.
- [수직 탑뷰](sniper-c-top.png): 사선이 아닌 정투영 이미지다. 전체 포신부터 둥근 후방까지 잘림 없이 보이며, 셸과 양쪽 요크의 폭·분리·공간 관계가 읽힌다. 생성 코드의 ORTHO 카메라 및 rotation=(0,0,0), 수직 -Z 시선도 확인했다.
- [후면](sniper-c-rear.png), [상부 사선](sniper-c-drone.png): 셸의 실제 곡면 깊이, 청회색 후방 캡과 은색 띠, 곡선 요크와 축의 관계가 유지된다. 평면 이미지로 입체를 대신한 표현이 아니다.

렌더는 Blender 5.2.1 LTS/Cycles, 1200×1200의 별도 프레젠테이션이다. 타일은 게임 화면이 아니다. 고정부와 긴 포신은 이전 [낮은 기둥 제작 검수](independent-review.md)의 보존 항목이며, 이번 최종 렌더와 원본 좌표로 관련 상태를 다시 확인했다.

## 원본 구조 독립 검사

편집기를 조작하지 않고 [편집 원본](sniper-c-editable.blend)을 별도 background Blender에서 읽어 평가 메시를 검사했다.

| 연결 | BVH 표면 교차 수 |
| --- | ---: |
| 하부 브리지 → 회전 드럼 | 40 |
| 하부 브리지 → 좌/우 곡선 요크 | 각 37 |
| 관통 축 → 좌/우 곡선 요크 | 각 80 |
| 관통 축 → 하부 받침 | 30 |
| 관통 축 → SWIFT 셸 | 28 |
| 광학 하우징 → SWIFT 셸 | 58 |

받침과 셸은 관통 축을 통해 연결되며, 지지 경로에 떠 있는 요크 문제가 없다. head=(0,0,0.45), barrel 초기 위치=(0,0,0), muzzle 로컬=(0,-1.099,0.326)과 root→head→barrel→muzzle 계층을 직접 확인했다.

## 최종 GLB 직접 검사

[준비 GLB](sniper-c-preview.glb)를 직접 파싱한 결과: 43,380 triangles, 3 meshes, 5 materials, 3,228,344 bytes, 내장 PNG 3장. root→head→barrel→muzzle 계층과 barrel의 zero transform, glTF Y-up/+Z-forward 좌표를 확인했다. 스튜디오 타일·카메라·광원은 포함되지 않는다.

- editable SHA-256: `73615d0349e3b87a5ba70397d51cb47e857da965bb37019571b121c14903b8bb`
- GLB SHA-256: `ea58d1f16cf6ea3e845d72534a62d3bba8191072ad4ebf93ab10b998d6359e12`

## 한계

준비 GLB를 엔진에서 렌더한 결과, 조준·반동 애니메이션, Android 실기기 상태는 미검증이다. 탑뷰에서도 긴 포신이 프레젠테이션 타일 밖으로 뻗는다. 이는 승인한 장포신을 유지한 결과이며, 본게임에서 주변 타일을 침범하지 않는다고 주장하지 않는다. 이번 사용자 요청인 SWIFT 실제 3D 수정과 수직 탑뷰 제작 범위에는 남은 필수 검증이나 미해결 결함이 없다.
