# SWIFT 발사 애니메이션 독립 검수

확인: 2026-09-26. 구현 담당과 별개의 Astra 검수. 범위는 실제 Blender 발사 애니메이션과 인코딩 영상이며 게임 이식은 포함하지 않는다. 정적 형태는 [이전 SWIFT 검수](../independent-review-swift.md)를 재사용하고 움직임에 영향받는 영역만 확인했다.

**최종 판정: PASS.** 짧은 조준광, 청백색 단발 포구 섬광, 빠른 후퇴와 점진적인 복귀를 확인했다. 고정부는 움직이지 않고, 최대반동에서 새로운 외형 파손·부유가 보이지 않는다. 남은 필수 수정이나 미해결 결함은 없다.

- [발사](sniper-fire-shot.png), [최대반동](sniper-fire-recoil.png), [복귀](sniper-fire-restored.png) 렌더를 직접 확인했다.
- [정상속도 단일 영상](sniper-fire-single.mp4)과 [정상 2회·느린 1회 영상](sniper-fire-preview.mp4)을 직접 디코딩해 시간순 대표 프레임을 보았다. 조준 전·최대 조준광·섬광·최대반동·복귀·초말과 느린 구간의 대응 프레임을 확인했다. 파일 자체는 각각 60프레임/2초, 210프레임/7초다. 정지 렌더만으로 동영상 출력을 추정하지 않았다.

## 동작과 연결 판정

| 항목 | 독립 확인 결과 |
| --- | --- |
| 고정 기둥·발·요크 | 검사 시점에서 월드 변환 동일. root/head에 action 없음 |
| 반동 | f17까지 0, f18에 Blender +Y 0.048, f21 0.043, f27 0.018, f36 복귀 |
| 포구 섬광 | f17 scale=1, f18=0.38, f19=0. 짧은 3D 백청색 바늘·꽃잎 형태 |
| 효과 부착 | FX 부모는 muzzle, muzzle 부모는 turret_barrel. 반동 시 총구와 함께 이동 |
| 지지 경로 | 축↔셸 BVH 교차가 휴지 28, 최대반동 54, 복귀 28로 유지됨 |
| 휴지 루프 | f1과 f60 전체 오브젝트 월드 변환 완전 일치. 섬광 0, 조준광 2.2로 동일 |

포신뿐 아니라 같은 barrel 아래의 셸·렌즈도 함께 반동한다. 요크·축은 고정되어 있으며 대표 렌더와 영상 시퀀스에서 셸이 지지대에서 이탈하거나 새로운 관통이 외관상 드러나지 않는다. 셸↔요크 표면 교차는 정지 모델에도 있는 접합이므로 교차 수만으로 신규 관통 결함으로 판단하지 않았다.

조준광은 공유 청록 재질을 사용하므로 기둥 룬에도 같은 키가 적용된다. f16 emission 5.5까지 상승하지만 실제 영상에서는 몸 전체가 번쩍이는 현상으로 보이지 않고 룬·렌즈의 절제된 변화로 남는다. 정밀 단발 표현을 해치지 않는다.
