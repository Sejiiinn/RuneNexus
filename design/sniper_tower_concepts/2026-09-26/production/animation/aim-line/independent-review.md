# SWIFT 조준선 독립 검수

확인: 2026-09-26. 구현 담당과 별개의 Astra 검수. 범위는 Blender 조준선 원본과 실제 인코딩 영상이며 게임 이식은 포함하지 않는다. 기존 형태·발사 효과는 [발사 검수](../independent-review.md)를 재사용하고 조준선·추적·상태 전환의 영향만 확인했다.

**최종 판정: PASS.** 가는 청록선이 렌즈 앞면에서 움직이는 적 표면까지 이어지고, 머리의 수평 회전과 함께 추적한다. 발사 시 선이 사라지고 기존 단발 섬광·반동이 이어지며, 대상 해제 뒤 휴지 자세로 돌아온다. 추가 필수 수정이나 미해결 결함은 없다.

## 실제 시각 근거

[조준](sniper-aim-line.png), [발사](sniper-aim-shot.png), [대상 없음](sniper-aim-idle.png)을 직접 확인했다. 선은 공격빔처럼 두껍거나 과도하게 밝지 않고 조준 안내선으로 읽힌다. 적 내부를 지나 뒤로 연장되지 않으며 기존 모델의 금속 표현·낮은 고정부가 유지된다.

[최종 MP4](sniper-aim-line-preview.mp4)를 직접 디코딩해 f1/9/21/32/43/50/51/52/65/70/85/120을 시간순으로 확인했다. 실제 출력은 120프레임·30fps·1120×720·4초다. 움직이는 적에 대한 연속 추적, f51 발사 시 소멸, f65 대상 제거, f85 이후 휴지 복귀가 원본 상태와 일치한다. 최종 영상 검수에서는 이미 통과한 원본 검사를 반복하지 않았다.

## 형상 비용과 검증 한계

선 자체를 직접 집계한 결과 **20삼각형·메시 오브젝트 1개·재질 1개**, 반경 0.0022의 6각 실체 원통이다. 별도의 고밀도 메시나 평면 빔 텍스처를 사용하지 않는다. 이 수치는 선 형상 비용만 설명하며, 실제 게임에서 다수 포탑의 CPU 추적·draw call·GPU 성능을 측정했다는 의미는 아니다. 원본의 표면 raycast는 제작 시 키프레임 생성용이며 실제 게임 실행 경로가 아니다.

이번 시퀀스는 대상 횡이동·조준·발사·대상 해제를 검증했다. 범위 밖 이동이나 다른 장애물에 의한 가림, 실제 게임의 타깃 선택·전투 계약·Android 실행은 범위 밖이며 미검증이다.
