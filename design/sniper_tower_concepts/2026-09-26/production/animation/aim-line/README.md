# SWIFT 대상 추적 조준선 — Blender 시연

기존 발사 애니메이션 복사본에 대상 추적 조준선만 추가한 별도 시연이다. 기존 정적 모델·발사 원본·영상, 게임 코드와 전투 수치는 변경하지 않았다.

- `sniper-aim-line.blend`: 편집 가능한 원본과 명시적 타임라인·대상 상태 키.
- `sniper-aim-line-preview.mp4` / `.gif`: 정상속도 4초, 타워와 대상을 함께 보여준다.
- `sniper-aim-line.png`: 조준 대표 프레임. shot/idle PNG는 발사·대상해제 시 선이 없는 검사 근거다.
- `build_aim_line.py`, `render_aim_line.py`, `encode_aim_line.py`: 원본 복사·대상 표면 추적·렌더·인코딩 재현 경로.
- `aim-line-manifest.json`: 원본과 적 에셋 식별, 120프레임의 대상·선·좌표·자가 가림 검사 기록.

조준선은 **6각형 실체 원통 1개, 20삼각형**이다. 반지름 0.0022타일이며 절제된 청록 emission을 사용한다. 기존 56삼각형 발사 섬광과 0.048타일 반동은 유지했다. 화면 오버레이·빌보드·공격용 광선이 아니며 장면의 일반 깊이 검사와 가림을 따른다.

렌즈의 실제 앞면 근처인 barrel 로컬 `(0, -0.196, 0.420)`에서 출발하여, 실제 적 메시를 raycast한 **첫 표면**에서 끝난다. 표면 안으로 관통하지 않도록 끝점에 0.00025타일의 작은 바깥 여유를 둔다. 대상의 좌우 움직임에 head만 수평 회전하고 고정 기둥·지지발은 움직이지 않는다.

미리보기 적은 `assets/images/stage1_3d/enemies/armored.glb`를 원래 배율·재질로 읽었다. 약 2.4타일 거리에서 원래 높이의 상부 핵 쪽을 조준하며, 적을 확대하거나 공중으로 올리지 않았다. 이 시퀀스의 조준 구간에서 타워/포신과 선의 교차가 없는지 매프레임 확인한다.

30fps/120프레임 구성:

- 1~8: 대상 없음.
- 9~42: 적의 작은 측면 이동과 조준선 추적.
- 43~50: 조준 잠금.
- 51: 단발 발사와 동시에 조준선 숨김. 기존 반동·복귀 구간을 34프레임 뒤로 옮겼다.
- 65: 시연 대상 해제. 85부터 head까지 휴지 상태.

`preview_target_valid`, `preview_in_range`, `preview_aim_active`와 3.4타일의 시연 사거리 조건을 사용한다. 대상이 유효하고 사거리 안이며 발사 전 조준 구간이고 실제 표면 hit가 있을 때만 선을 표시한다. 이 파일의 특정 배치 검증을 모든 적·지형·사거리에 대한 보장으로 해석하지 않는다. **실제 게임의 조준선 기능이나 범용 장애물 차폐를 구현한 결과가 아니다.**
