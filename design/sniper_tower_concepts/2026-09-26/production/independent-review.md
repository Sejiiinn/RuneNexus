# 저격 C 3D 제작 독립 검수

확인: 2026-09-26. 구현 담당과 별개의 Astra 검수. 범위는 편집 가능한 Blender 원본, 실제 Blender 렌더, 준비 GLB이며 게임 이식은 포함하지 않는다.

**최종 판정: PASS.** [승인 v2의 오른쪽 C](../ingame-multiview-v2.png)를 기준으로 하되, 사용자 후속 요청인 기둥 높이 감소와 금속 반사 강화를 적용한 최종 상태를 검수했다. 후방 경사·포신 단축 시안은 기준으로 사용하지 않았다.

## 실제 시각 확인

[정면 사선](sniper-c-hero.png), [후면 사선](sniper-c-rear.png), [상부](sniper-c-drone.png)를 직접 확인했다. 최종 조건은 Blender 5.2.1 LTS, Cycles 48 samples, 1200×1200, AgX Medium High Contrast, exposure 0.6이다. 바닥은 별도 프레젠테이션 타일이며 게임 캡처가 아니다.

- 수직 기둥과 긴 가는 포신, 작은 각형 총구, 각진 헤드·다이아 룬, 은색 요크·황동 축, 청회색 큰 면이라는 C의 정체성을 유지한다.
- 기둥을 낮춰 전체 높이가 1.083에서 0.933으로 줄었고 헤드·포신 크기는 유지됐다. 의도적인 후방 기울임은 없다.
- 거친 표면 얼룩이 줄고 청회색 면과 은색 베벨에 금속 반사가 분명해졌다. 최종 세 시점에서 재질 구분과 입체감이 유지된다.
- 초기 렌더의 돌출 튜브형 룬은 얇은 평면 인레이 표현으로 바뀌었다. 실제 홈을 Boolean 절삭한 구조는 아니지만, 최종 렌더에서 이전의 둥근 선재 돌출 인상은 해소됐다.
- 발끝 장갑의 겹친 면 무늬가 없어졌으며 요크 아래 연결 브리지가 실제 지지 구조로 읽힌다.

## 원본과 준비 GLB 검사

편집기를 조작하지 않고 [원본](sniper-c-editable.blend)을 별도 background Blender에서 읽어 평가 메시를 검사했다. 초기 원본의 양쪽 요크는 받침·회전부에 연결되지 않았으나 최종 원본에서는 다음 연결 경로의 표면 교차를 직접 확인했다.

| 연결 | BVH 표면 교차 수 |
| --- | ---: |
| 하부 브리지 → 회전 드럼 | 41 |
| 하부 브리지 → 좌/우 요크 | 각 29 |
| 관통 트러니언 → 좌/우 요크 | 각 48 |
| 관통 트러니언 → 약실 받침 | 30 |
| 약실 받침 → 약실 몸체 | 56 |

head 높이 0.45, barrel 초기 위치 (0, 0, 0), muzzle 전방 위치 -1.099를 원본에서 확인했다. 룬 28조각은 각 8정점의 얇은 띠 메시로 바뀌었다. 원본 재질의 metallic/roughness는 청회색 0.88/0.34, 은색 0.94/0.26으로 확인했다.

[준비 GLB](sniper-c-preview.glb)를 직접 파싱해 36,508 triangles, 3 meshes, 5 materials, 2,860,480 bytes와 내장 PNG 3장을 확인했다. root → head → barrel → muzzle 계층, barrel의 초기 zero transform, glTF Y-up/+Z-forward 좌표를 확인했다. 스튜디오 타일·카메라·광원은 GLB 노드에 포함되지 않는다.

## 검증 한계

본게임 교체·조준·반동·실기기 렌더는 이번 제작 범위 밖이며 미검증이다. 고정부 반경 약 0.416, 회전부 반경 약 1.101이라는 현재 치수는 장포신 시안의 성격에 맞지만, 이를 본게임에서 주변 타일을 침범하지 않는다는 근거로 사용할 수 없다. 후속 이식 시 게임 배치 스케일은 별도로 정해야 한다. 준비 GLB의 구조는 확인했으나 엔진에서 렌더한 결과를 이번 Blender 시각 PASS에 포함하지 않았다.
