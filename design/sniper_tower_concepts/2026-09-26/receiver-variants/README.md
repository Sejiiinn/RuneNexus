# 저격 몸체 변경 시안 5종

기준: 높이와 금속을 수정한 [C 실제 3D 렌더](../production/before-swift/sniper-c-hero.png). 사용자가 직육면체에 가까운 상부 몸체를 더 저격답게 바꾸기 위한 이미지 시안을 요청했다.

받침·발·긴 포신·청회/은색 금속을 공통 기준으로 두고 상부 약실과 지지대의 외형을 비교한다. 내장 ImageGen으로 만든 변경 시안이며 Blender 렌더나 실제 게임 화면이 아니다. **01 SWIFT가 선택됐으며**, 실제 3D 수정과 검수는 [상위 제작 기록](../README.md)을 따른다. 나머지 4종은 미선택 제안이다.

| 시안 | 방향 |
| --- | --- |
| [01 SWIFT](01-swept-wedge.png) | 유선형 쐐기 외피와 매립 조준 렌즈 |
| [02 BOLT](02-bolt-optic.png) | 원통형 약실·볼트와 상부 조준경 |
| [03 RAIL](03-open-rail.png) | 원통 기구를 드러낸 개방 레일 프레임 |
| [04 BULLPUP](04-rear-balanced.png) | 후방에 무게를 둔 몸체와 빈 공간을 가진 프레임 |
| [05 TALON](05-curved-shell.png) | 좌우 곡면 장갑과 측면 조준 센서 |

[공통·개별 생성 프롬프트](prompts.txt). 치수·충돌·가동부와 다각도 일관성은 이미지 시안만으로 확인하지 않았다.
