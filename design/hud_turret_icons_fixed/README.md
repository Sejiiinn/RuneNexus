# 전투 HUD 고정 시점 포탑 아이콘

승인된 [HUD 시안](../combat_ui_concepts/2026-09-22/01-hud-v4-3d-icons.png)의 실제 3D 포탑 방향을 적용한 정적 PNG다. 최초 제작 시 게임에서 사용하던 GLB를 읽었으며 모델·재질·원본 파일은 변경하지 않았다. 후속 모델 교체와 최신 저격 아이콘의 범위 예외는 아래 날짜별 기록을 따른다.

- 최종 파일: `assets/images/ui/hud/turrets_3d/{arrow,cannon,magic,frost,sniper,lightning}.png` — 각각 256×256 RGBA.
- [초기 편집 원본](fixed-camera-turret-icons.blend): 포탑마다 별도 Scene, 동일 정투영 카메라·광원·프레임. 후속 냉기·저격 Scene은 아래 개별 원본을 따른다. 기존 열린 Blender 문서는 보존했다.
- [재생성](render_icons.py): Blender background에서 실행. 기존 모델 제작 스크립트는 최신 모델을 덮어쓰므로 실행하지 않는다.
- [방향·입력 해시](direction-verification.json), [이미지 검사](image-verification.json), [검수 모음](contact-sheet.png).

## 고정 전방 계약

원본 glTF는 +Y 위/+Z 전방이며 Blender 가져오기는 +Z 위/-Y 전방이다. 루트 전체 회전으로 -Y 전방에 정규화하는 경로를 사용한다. 현재 여섯 모델은 이미 같은 전방이므로 보정각은 모두 0이다. 각 모델의 실제 `muzzle - turret_head` 수평 성분도 X≈0, Y<0인지 독립 검사했다. 냉각은 포신 대신 결정의 기존 전방 계약을 사용한다. 모델 고유 포신의 높이와 상승각은 바꾸지 않는다.

카메라 위치 (4,-4,5.5), 주시점 (0,0,0.4), 기본 정투영 크기 1.45. 최신 저격은 아래 최소 수용 범위 예외 1.6918을 따른다. 6종의 수평 전방 투영은 화면 X 오른쪽/Y 아래 기준 **(-0.8309218884,+0.5563890934)**, 각도 **146.1935547°**로 정확히 같다. 카메라·모델마다 임의 각도나 픽셀 회전을 적용하지 않는다. 모델의 실제 크기·받침 좌표를 보존하며 아이콘별 모델 확대·크롭은 하지 않는다. 최신 저격의 전체 수용을 위한 정투영 범위 예외는 아래에 명시한다.

## 검증

원본 GLB SHA-256 불변, 256×256 RGBA, 알파 여백 존재, 불투명 부분 잘림 없음, 동일 전방 벡터 자동 검사를 통과했다. `verify_icons.py`는 입력 PNG를 읽기만 하며 256px 및 64px QA 모음을 만든다. 6종 모음에서 형태·재질·좌하단 전방을 시각 확인했다. 후처리 없이 Blender 렌더 PNG를 그대로 사용한다. UI에서는 정적 텍스처만 표시하며 실시간 3D 렌더를 추가하지 않는다.

최종 인게임 배치·크기·터치 검증은 HUD 통합 담당 범위다. 이 원본은 모델 아이콘 제작 검증을 기록한다.

2026-09-22: 화염만 사용자 요청에 따라 모델 전체를 90%로 줄이고 동일 카메라·조명으로 다시 렌더했다. [원본·검증](../fire_tower_concepts/runic_3d/scale-90/README.md). 다른 5종은 유지했다.

2026-09-23: 냉기를 승인된 냉각핀형 모델로 교체하고 동일 카메라·조명으로 frost 아이콘만 다시 렌더했다. 최신 원본과 방향·입력 검증은 [냉각핀 제작 기록](../frost_tower_concepts/2026-09-23/production/README.md)에 있다. 위 초기 6종 모음과 해시 기록은 교체 이전 기록이다.

2026-09-30: 저격 설치 아이콘의 구형 모델을 승인된 [SWIFT 9,816삼각형](../sniper_tower_concepts/2026-09-26/production/optimized-game-distance/README.md)으로 갱신했다. [저격 전용 재생성](render_sniper_swift.py)은 공용 렌더 레시피를 재사용하며, [편집 Scene](hud-sniper-swift.blend)만 별도 저장한다. 초기 여섯 Scene 원본·다른 다섯 PNG·게임 GLB·승인 GLB는 보존했다. 이 아이콘 갱신 시점의 게임 GLB는 기존 1,048삼각형 모델이었으며 당시 변경은 공유 HUD PNG에 한정했다. 이후 승인된 전투 본체 적용 상태는 [저격 현행 기록](../sniper_tower_concepts/2026-09-26/README.md#전투용-본체-게임-적용)을 따른다.

긴 포신은 기존 정투영 크기 1.45에서 왼쪽 프레임 밖으로 잘린다. 저격 아이콘에만 **1.6918**의 최소 수용 범위를 적용했다. 카메라 `(4,-4,5.5)`, 주시점 `(0,0,0.4)`, 광원·전방·전체 회전 0·모델 스케일 1은 동일하다. 실제 메시 정점 전체에 8px 여백을 확보하며, 포신 단축·비균일 스케일·픽셀 회전·크롭은 적용하지 않는다. 다른 다섯 아이콘의 일반 정투영 크기 1.45 규칙은 유지한다. 알파 안티앨리어싱까지 포함한 유효 영역은 `(7,55)–(191,206)`이다. 메시 bound-box 모서리의 투영은 빈 공간까지 포함하므로 실제 정점 경계와 구분한다.

최신 입력·카메라·방향·정점 경계는 [방향 검사](sniper-swift-direction-verification.json), PNG와 보존 검사는 [이미지 검사](sniper-swift-image-verification.json)에 기록했다. Godot 4.7.2 Mobile 렌더러의 정규 앱 모드·440×900에서 실제 건설 명령을 실행하고 설치 목록 40px·선택 패널의 공유 PNG를 확인했다. 선택 패널은 기존 투명 여백 제거용 AtlasTexture를 유지한다. 실행·캡처는 `build/sniper-hud-icon-verification/`에 격리했으며 사용자 저장·열린 Blender 원본을 변경하지 않았다. 로비 모듈·보상도 같은 PNG 소비 경로이므로 파일 갱신을 공유한다.
