# 전투 HUD 고정 시점 포탑 아이콘

승인된 [HUD 시안](../combat_ui_concepts/2026-09-22/01-hud-v4-3d-icons.png)의 실제 3D 포탑 방향을 적용한 정적 PNG다. 게임에서 사용하는 최신 GLB를 읽었으며 모델·재질·원본 파일은 변경하지 않았다.

- 최종 파일: `assets/images/ui/hud/turrets_3d/{arrow,cannon,magic,frost,sniper,lightning}.png` — 각각 256×256 RGBA.
- [편집 원본](fixed-camera-turret-icons.blend): 포탑마다 별도 Scene, 동일 정투영 카메라·광원·프레임. 기존 열린 Blender 문서는 보존했다.
- [재생성](render_icons.py): Blender background에서 실행. 기존 모델 제작 스크립트는 최신 모델을 덮어쓰므로 실행하지 않는다.
- [방향·입력 해시](direction-verification.json), [이미지 검사](image-verification.json), [검수 모음](contact-sheet.png).

## 고정 전방 계약

원본 glTF는 +Y 위/+Z 전방이며 Blender 가져오기는 +Z 위/-Y 전방이다. 루트 전체 회전으로 -Y 전방에 정규화하는 경로를 사용한다. 현재 여섯 모델은 이미 같은 전방이므로 보정각은 모두 0이다. 각 모델의 실제 `muzzle - turret_head` 수평 성분도 X≈0, Y<0인지 독립 검사했다. 냉각은 포신 대신 결정의 기존 전방 계약을 사용한다. 모델 고유 포신의 높이와 상승각은 바꾸지 않는다.

카메라 위치 (4,-4,5.5), 주시점 (0,0,0.4), 정투영 크기 1.45. 6종의 수평 전방 투영은 화면 X 오른쪽/Y 아래 기준 **(-0.8309218884,+0.5563890934)**, 각도 **146.1935547°**로 정확히 같다. 카메라·모델마다 임의 각도나 픽셀 회전을 적용하지 않는다. 실제 크기 차이와 받침 위치를 보존하며 아이콘별 확대·크롭도 하지 않는다.

## 검증

원본 GLB SHA-256 불변, 256×256 RGBA, 알파 여백 존재, 불투명 부분 잘림 없음, 동일 전방 벡터 자동 검사를 통과했다. `verify_icons.py`는 입력 PNG를 읽기만 하며 256px 및 64px QA 모음을 만든다. 6종 모음에서 형태·재질·좌하단 전방을 시각 확인했다. 후처리 없이 Blender 렌더 PNG를 그대로 사용한다. UI에서는 정적 텍스처만 표시하며 실시간 3D 렌더를 추가하지 않는다.

최종 인게임 배치·크기·터치 검증은 HUD 통합 담당 범위다. 이 원본은 모델 아이콘 제작 검증을 기록한다.
