# 탱커 몹 시안과 3D 제작

2026-10-01. 탱커 디자인 개선을 위한 탐색 시안과 후속 이미지. 현재 역할은 방어구 없이 체력이 높은 몹이다. 탐색 당시 사용자는 일반형 대비 약 1.5배 크기를 가정하도록 지정했고, A 넓은 어깨 가디언(08)에서 파생한 넓은 가슴형(12)을 가장 선호해 5시점 멀티뷰(15)를 요청했다. 최우선 외형 기준은 승인된 16번 멀티뷰이며, 12의 오른쪽 탱커는 불명확한 연결을 보완하는 참조다. 시안 이미지는 내장 `image_gen`으로 생성했다. 승인된 16번의 후속 정적 Blender 제작은 [3D 원본과 실제 렌더](3d/README.md)를 따른다. 현재 제작 요구는 일반형 높이의 약 1.25배, 시안에 가까운 둥근 비정형 바위와 풍화 질감, 최종 삼각형 약 2만 개다. 승인된 모델·이동 애니메이션의 후속 게임 교체는 [게임 적용 기록](3d/game-export/README.md), 무릎과 팔로 버티다가 무너지는 사망 모션은 [사망 원본·게임 검증](3d/death/README.md)에서 관리한다.

- [멀티뷰](01-heavy-guardian-multiview.png): FRONT·SIDE·BACK·TOP·3/4. 기존 큰 머리·황동 장갑·청록 룬·호박색 가슴 코어를 보존한 형태 참조. SIDE는 약간 사선이고 TOP은 높은 각도에서 내려다본 뷰이므로 치수 추출용 정투영 도면으로 취급하지 않는다. [생성 프롬프트](01-heavy-guardian-multiview-prompt.json).
- [장갑을 줄인 버전](01-heavy-guardian-lighter-armor.png): 어깨 장갑을 작은 상부 커버로, 팔 장갑을 좁은 손목띠로 줄여 석재 노출을 늘렸다. 기존 체형·얼굴·룬·코어는 보존했다. 별도 미선택 후보이며 위 멀티뷰는 기존 중장갑 버전에 대응한다. [생성 프롬프트](01-heavy-guardian-lighter-armor-prompt.json).

독립 검증자가 원본과 후속 이미지 2장을 직접 대조해 시안 범위 PASS로 판정했다. 전신 잘림이나 주요 부품·재질 모순이 없고 장갑 감소가 보인다. 정투영 치수·상세 제작 구조·인게임 재현은 검증 범위에 포함하지 않았다.

## 방어구 없는 고체력 탱커

[맨몸 거구 가디언 시안](05-unarmored-high-hp-guardian.png). 추후 방어구 몹과 구분하도록 모든 장갑과 금속 관절을 제거하고 큰 몸통·두꺼운 배·큰 주먹과 발·짧고 굵은 다리로 체력과 무게감을 표현했다. 1번의 얼굴·청록 눈·호박색 가슴 코어·석재 질감은 이어가고 이마 룬은 돌에 직접 새겼다. 사용자가 비만 인상을 지적해 이 체형은 채택하지 않는다. 이전 1번 중장갑 및 장갑 완화 후보도 제작 기록이며 현재 고체력 역할의 외형 기준으로 취급하지 않는다. [생성 프롬프트](05-unarmored-high-hp-guardian-prompt.json).

독립 검증자가 원본과 05 시안을 직접 대조해 방어구 제거·체형 변화·얼굴과 룬 계열 보존·전신 가시성에 대해 시안 범위 PASS로 판정했다. 이는 사용자의 미적 채택을 뜻하지 않는다. 실제 게임 화면은 아니며 모델 제작과 인게임 재현은 검증하지 않았다.

## 배를 줄인 석재 거한

[수정 시안 06](06-unarmored-stone-bruiser.png). 05의 둥근 돌출 배를 줄이고 넓은 어깨·두꺼운 팔·좁아지는 단단한 허리로 무게감을 옮겼다. 다리를 더 드러내며 얼굴·청록 눈과 이마 룬·호박색 코어·맨몸 석재 표현을 보존했다. 일반형과 나란히 비교한 뒤 큰 머리·짧은 팔다리의 일반형과 작은 머리·긴 팔다리의 06이 어울리지 않는다는 피드백을 받았다. 최종 채택되지 않은 제작 기록이다. [생성 프롬프트](06-unarmored-stone-bruiser-prompt.json).

별도 검증자가 05·06 실제 이미지를 대조해 배 감소·역삼각 체형·다리 가시성·탱커 무게감·얼굴과 재질 보존·전신 잘림 없음에 대해 시안 범위 PASS로 판정했다. 사용자 미적 최종 채택·모델 제작·인게임 재현은 미확인이다.

## 인간형 추가 컨셉

일반형의 [Blender 원본 렌더](../../2026-09-26/medium-guardian-3d/preview-three-quarter.png)를 같은 계열의 얼굴·큰 머리·짧은 팔다리·석재 질감 참조로 사용했다. 방어구 없이 몸체 부피로 체력과 무게감을 표현하고 청록 눈/이마 룬·호박색 코어를 공통으로 둔다. 각 이미지의 화면 점유율은 상대적인 실제 게임 크기를 뜻하지 않는다.

사용자는 최근 4개 중 첫 번째인 **A 넓은 어깨 가디언(08)**을 먼저 선호했고, 이후 그 변형인 **넓은 가슴형(12)**을 현재 기준으로 선택했다. 최신 사용자 지시에 따라 Blender 제작 크기는 동일한 좌표·표시 조건의 일반형 대비 머리 최고점~발바닥 전체 높이 약 1.25배로 맞춘다. 이전 1.5배 크기 비교는 탐색 기록이며 현재 크기 요구가 아니다. 폭과 깊이는 선택된 넓은 가슴형의 비율을 보존한다. 일반형의 현재 표시 크기를 상대 기준 1.0으로 삼으며, 기존 일반형 확대 배율 1.15를 새 1.25배 기준에 다시 중복 적용하지 않는다. 선택된 12의 큰 머리·넓은 가슴/어깨·굵은 팔·짧은 다리·맨몸 석재 외형을 보존한다. 이는 제작 기준이며 현재 게임에 배율을 적용했다는 뜻은 아니다.

## 일반형과 크기 비교

### A안의 1.5배 크기 추가 시안

사용자가 선호한 A(08)의 얼굴·석재·청록 룬/눈·호박색 코어와 맨몸 인간형 체형을 이어 3개 변형을 추가했다. 각 이미지에서 왼쪽은 기존 일반형, 오른쪽은 일반형보다 약 1.5배 큰 탱커이며, 같은 바닥·카메라 거리에서 크기 의도를 볼 수 있게 배치했다. 생성 시안의 근사 높이 비교이고 정확한 모델 실측 도면은 아니다.

| 굵은 팔형 | [13](13-a-heavy-arms-150.png) | 전완과 주먹의 부피를 강조 |
| 단단한 각진형 | [14](14-a-squared-150.png) | A의 얼굴을 유지하며 몸통·팔다리 면을 각지게 표현 |

[추가 생성 프롬프트](a-150-variants-prompts.json). 사용자는 넓은 가슴형(12)을 가장 선호해 후속 멀티뷰를 요청했다. 13·14는 미선택 대안이며 게임에는 적용하지 않았다.

별도 검증자가 A·일반형 참조와 최종 12·13·14 PNG를 직접 대조해 A 계열 보존·맨몸 석재·비만 배/잘림 없음·약 1.5배 크기 의도를 시안 범위 PASS로 판정했다. 화면상 근사 높이비는 12 약 1.51, 13 약 1.48, 14 약 1.53이다. 왼쪽 일반형도 참조에서 생성된 비교 표현이며 모델 실측은 아니다. 세 안은 같은 A 계열의 국소 변형이므로 차이는 비교적 작고, 14는 C처럼 극단적인 사각 체형이 아니다.

### 넓은 가슴형 멀티뷰

[최신 5시점 멀티뷰 16](16-wide-chest-multiview-unified-back.png): FRONT·SIDE·BACK·TOP·3/4를 한 장에 배치했다. 12의 오른쪽 탱커만 대상으로 큰 머리·넓은 가슴/어깨·짧고 굵은 팔다리·석재·청록 눈/이마 룬·호박색 코어를 보존한다. 사용자가 [최초 멀티뷰 15](15-wide-chest-multiview.png)의 등과 엉덩이 분할을 지적해, 16은 등과 뒤 골반을 각각 중앙 홈 없는 단일 석재 덩어리로 정리했다. 앞면의 넓은 가슴 분할은 유지한다. [16 수정 프롬프트](16-wide-chest-multiview-unified-back-prompt.json) · [15 최초 프롬프트](15-wide-chest-multiview-prompt.json).

별도 검증자가 선택 원본 12와 실제 15 PNG를 직접 대조해 5개 구분 시점·핵심 외형/재질 보존·주요 연결 모순 없음·전신 가시성에 대해 다각도 시안 범위 PASS로 판정했다. TOP은 수직 탑뷰보다 높은 사선 시점이며, 손가락·석재 경계 등 시점별 세부 차이가 있다. 정확한 정투영 치수 도면이나 동일 3D 모델의 렌더로 취급하지 않는다. 상세 3D 제작 시 불명확한 연결·뷰 일관성을 원본 12 기준으로 보완한다. 이 멀티뷰 이미지 제작 당시에는 모델 제작·게임 이식을 포함하지 않았다. 이후 승인된 16번으로 정적 3D 제작을 요청받았다.

별도 검증자가 12·15·16을 직접 대조해 16의 후면 등/골반 분할 제거·앞면 가슴/얼굴/비율 보존·5시점 유지·잘림 없음에 대해 수정 시안 범위 PASS로 판정했다. TOP의 고각 시점 및 생성 멀티뷰의 치수/세부 일관성 제한은 그대로다.

### 승인 멀티뷰의 정적 3D 제작

[편집 가능한 Blender 원본](3d/tank-wide-chest.blend)과 [실제 렌더·제작 방법](3d/README.md)을 제작했다. [일반형과 최신 크기 비교](3d/preview-normal-tank-125.png)는 같은 정투영 카메라와 바닥 높이로 렌더했다. 현재 요구는 승인 16의 넓은 가슴·둥근 비정형 석재·풍화 표면·청록 눈과 음각 룬·호박색 구형 코어·단일 등과 뒤골반을 유지하고, 실제 일반형 높이의 1.25배·최종 삼각형 약 2만 개로 맞추는 것이다. 리깅·애니메이션·게임 이식은 포함하지 않는다.

초기 모델은 일반형에 살만 붙인 인상이라는 지적을 받았다. 이후 어깨·흉곽·골반·사지 중심을 바꾼 모델도 시안보다 지나치게 각진 형태라는 지적을 받았다. 이전의 부품·치수 및 골격 검사 PASS는 최신 외형 요구의 통과 근거로 사용하지 않는다. 두 모델과 중간 렌더는 Git 제외 로컬 기록에 보존한다.

최신 수정에서는 주요 돌 덩어리의 곡면과 굵은 사지 구조를 다시 만들고, 작은 눈·숨은 연결부의 메시를 줄여 주요 곡면에 삼각형을 배분했다. 돌 표면·실제 균열·구형 코어를 승인 원본과 대표 전신 렌더로 직접 대조했다. 가슴만 지나치게 큰 인상이라는 지적을 반영해 전방 돌출과 아래쪽 부피를 줄였다. 이후 재첨부된 16번을 최우선으로 머리의 과한 좌우 폭, 가슴·허리·허벅지 사이의 가는 연결, 가슴의 직육면체 인상을 보완했다. 머리와 얼굴 부착을 함께 좁히고, 낮은 단일 골반과 허벅지 뿌리의 받침을 맞물렸으며 가슴은 비대칭의 큰 사면과 짧고 둥근 면 전환으로 재조형했다. 사용자가 지정한 Astra / high 구현자가 골반·허벅지의 실제 맞물림과 등 상단의 연속된 큰 사면을 보완했다. 최종 결과·실측·독립 검증 범위는 [3D 제작 기록](3d/README.md)에 모은다. 후속 요청에 따른 일반형 방식의 [이동 애니메이션](3d/walk/README.md)은 별도 편집 원본과 실제 영상으로 관리한다.

### 이전 06 체형의 배율 탐색

아래 비교는 이전 06 체형과 배율 탐색의 기록이며, 현재 선호한 넓은 가슴형과 최신 1.25배 제작 기준은 위 「인간형 추가 컨셉」을 따른다.

[높이 조절 비교](normal-tank-size.html)는 기존 일반형의 [실제 Blender 렌더](../../2026-09-26/medium-guardian-3d/preview-three-quarter.png)와 06 원본 시안을 보존해 발 최하단을 맞춘다. 기본값은 일반형 높이 1.0 : 탱커 1.2이며 탱커를 1.0~1.5배로 조절한다. 원본 이미지의 머리 최고점~발 최하단(일반형 y=110~1017, 탱커 y=100~1212)을 기준으로 균일 확대·축소한다. 원근이 다른 시안의 2D 표시 높이 비교이며 모델 실측·인게임 크기 확정이 아니다. 현재 일반형은 `godot/presentation/guardian_preview.gd`의 `NORMAL_VISUAL_SCALE = 1.15`로 기존 대비 15% 확대되어 있고, 비교에서는 그 일반형을 상대 기준 1.0으로 삼는다.

부모가 Chrome에서 기본 화면·배율 조작·360px 폭을 확인했다. 별도 검증자가 원본·HTML·실제 브라우저 화면을 대조해 원본 정체성·전신 가시성·1.20 표시 높이·최하단 발 정렬을 PASS로 판정했다. 생성 이미지 07은 표기와 실제 높이가 달라 최종 비교로 사용하지 않으며 로컬 중간 기록으로 제외했다.

기준은 [DESIGNS.md](../../../../DESIGNS.md)의 공통 테마와 일반형·빠른형 적이다. 참조는 기존 석재 가디언, 룬 사냥개, 기존 금색 탱커이며, 정확한 참조 경로와 최종 생성 프롬프트 4개는 [prompts.json](prompts.json)에 보관했다.
