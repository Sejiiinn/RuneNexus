# 유적 감시대장 — 보스 외형 제작 참조

2026-10-03. 사용자가 무기 없는 **16번 유적 감시대장**을 가장 선호하고 3D 제작용 멀티뷰를 요청했다. 외형 원본은 [선택한 16번](16-relic-marshal-unarmed.png)이며, [5시점 멀티뷰](multiview/16-relic-marshal-multiview.png)는 같은 캐릭터의 정면·측면·후면·상면·사선 구조를 보완한다. 14·15번은 다른 후보로 보관한다.

작은 각진 돌머리와 근엄한 얼굴, 작은 붉은 눈·이마의 소용돌이 룬, 단일 붉은 구형 가슴핵과 청동 링, 양쪽 각진 석재 어깨의 청동 띠·리벳·각 하나의 붉은 룬, 굵은 석재 팔다리와 맨주먹, 손목띠·골반의 중앙 금속판을 유지한다. 모든 시점에 무기를 두지 않는다. 석재는 풍화된 따뜻한 회색, 금속은 오래된 청동·어두운 관절, 붉은색은 눈·룬·핵에 국소 적용한다.

멀티뷰는 내장 ImageGen으로 생성했다. [생성·수정 프롬프트](multiview/prompts.json). 별도 검증자가 원본과 최종 이미지를 직접 대조하여 주요 외형 보존·5시점 구분·무기 및 전신 누락 없음·측면 룬 중복 해소를 시안 범위 PASS로 확인했다.

생성된 형태 참조이며 정밀 치수 도면이나 동일 3D 메시의 렌더가 아니다. 상면에서 머리·어깨·몸통의 깊이와 발 방향을 읽을 수 있으나 정확한 90° 투영은 보장하지 않는다. 후면은 원본에 없는 구조를 같은 석재·청동 부품의 단순한 연속 형태로 보완했으며, 세부 표면과 투영 차이는 실제 모델 제작에서 맞춘다.

사용자가 Astra 하위 에이전트로 요청한 후속 정적 Blender 제작은 미완료 로컬 실험이며 채택된 결과가 아니다. 해당 `3d/README.md`·실험 원본은 로컬 제작 기록으로 보관하고 이 참조 시안의 추적 대상에 포함하지 않는다. 리깅·애니메이션·게임 적용은 후속 제작의 범위에 포함하지 않는다.
