# 빠른 룬 사냥개 게임 적용

승인된 [v9 원본](../run/gallop-kick-v9/fast-rune-hound-run.blend)을 기존 `fast` 역할에 적용했다. 청회색 석재·청록 눈/등 룬과 승인 달리기를 유지한다. 게임용 원본은 [fast.glb](../../../../../assets/images/stage1_3d/enemies/fast.glb)이다.

- 기존 속도·크기·경로·전투/저장 계약을 유지한다. 1배속 1.1375타일/초, 표시 폭 0.48타일, Run 34/60초·보폭 0.6445833333타일이다. 정지/감속/배속은 실제 이동 거리로 위상을 결정한다.
- 일반형의 거리 기반 애니메이션·몸 방향 보간 경로를 함께 사용한다. 빠른 적의 사망은 기존 제거를 유지하며 새 사망 모션을 추가하지 않는다.
- 공통 화상/냉각 재질과 시계를 유지하며, 종별로 미리 구운 세 상태 메시가 새 스킨을 공유한다. 일반형의 부착 자료와 성에 재질은 섞지 않는다.
- 게임용 데이터는 20,214삼각형·24본·단일 메시/재질/스킨이다. [내보내기 근거](../run/gallop-kick-v9/runtime-export.json), [상태 효과·관련 자동 검사](status-bake.json), [독립 확인](independent-review.md).

## 실제 실행 근거

Godot 4.7.2, macOS Metal/mobile 렌더러의 격리 프로젝트에서 실제 스테이지 1 웨이브 4의 일반형 7기·빠른 적 3기를 실행했다. 검수용 건설 자금만 1000으로 설정하고 실제 포탑 구매·전투·HUD 경로를 사용했다. 사용자 저장과 열린 편집기 실행은 변경하지 않았다.

- [1배속 냉각·화상 전투](hound-gameplay.mp4): 실제 냉각/화염 포탑, fast 사망 제거 포함.
- [4배속 드론 전투](hound-gameplay-4x.mp4): 실제 기관총/대포와 두 적 종류의 이동·회전.
- [고정 시점 화면](captures/angled-status/00180.png), [드론 시점 화면](captures/drone-4x/00035.png).

정지 위상·거리 위상·일반형 유지·종별 상태 재질·제거는 관련 Godot 자동 검사로 확인했다. 화면 영상의 고정 시간 간격 캡처는 성능 측정이 아니다. Android APK 설치/배포와 실기기 성능은 이번 작업에서 수행하지 않았다.

`prepare_review.py`와 기존 가디언 검수 실행기를 재사용한 `capture_combat.gd`로 같은 격리 게임 장면을 준비한다. 공개 게임 소스·에셋 경로에 변경을 반영했으며 검수 전용 프로젝트에만 변경을 남기지 않았다.

## 효과·크기 후속 수정

빠른형 석재를 룬으로 오판하던 색비 판정을 실제 발광 마스크로 교체하고 부착 메시를 다시 생성했다. 화염은 종별 원본 좌표 환산을 적용한다. 일반형 표시를 15% 확대, 빠른형을 10% 축소하며 보폭과 일반형 사망 크기도 같은 비율로 조정했다. 전투 스탯·판정 크기는 유지했다.

최종 [냉각 전투](hound-effects-fixed.mp4)와 [화염 전투](hound-burn-fixed.mp4)는 실제 포탑 상태 적용 경로다. 종류별 활성 프레임 집계에서 fast 냉각 155프레임, 화상 30프레임을 확인했다. 화상 첫 시각은 전투12.63초(캡처00124 이후)다. 관련 Godot 자동 검사는 최종 소스로 PASS. 이전 영상 대신 이 두 영상을 최신 근거로 사용한다.
