- 제작: [Blender 원본](../fast-rune-hound-death.blend), [제작 스크립트](../build_death.py), [내보내기](../export_runtime.py).
- 런타임: `fast_death.glb`의 고정 Death 클립(24본·20,214삼각형), 기존 빠른형 표시 크기 0.432 유지.
- 실시간 물리·IK·입자 시뮬레이션 없음. 작은 청록 점 12개는 공유 메시와 셰이더로 정해진 궤적을 재생한다. 성능 무부하를 의미하지 않으며 모바일 프레임 성능은 측정하지 않았다.
- 애니메이션·투명도·잔광은 같은 전투 시계를 사용한다. 전투 판정과 보상·도착 처리는 변경하지 않는다. 일반형 사망은 기존 0.6초 붕괴를 유지한다.
- 준비 과정에서 달리기/사망 GLB의 네 텍스처 해시가 동일하고 공유 텍스처 경로로 연결됨을 확인했다. APK 빌드·설치는 수행하지 않았다.
