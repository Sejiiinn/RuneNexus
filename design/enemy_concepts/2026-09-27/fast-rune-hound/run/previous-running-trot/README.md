# 빠른 룬 사냥개 — 연속 달리기

2026-09-27. “깡총거리는 모션이 아니라 연속적으로 뛰는 모션” 요청에 맞춘 편집 가능한 달리기 시안이다. [승인 3D 원본](../3d/README.md)의 외형·석판·청록 눈/룬과 **102개 메시·20,214삼각형**을 보존한다. 게임 이식은 포함하지 않는다.

- [Blender 원본](fast-rune-hound-run.blend): 19본 강체 리그, `Run` 액션, 정방향 `-Y`, 위쪽 `+Z`.
- [반복 영상](run-preview.mp4): 실제 Blender 3/4·드론 렌더. [측면](run-side.mp4)도 제공한다.
- [실제 타일 속도 영상](tile-run-preview.mp4): 1타일 격자에서 1배속 이동. [검수용 Blender](fast-rune-hound-tile-review.blend).
- [애니메이션 GLB](fast-rune-hound-run.glb): 원래 구운 PBR atlas·기하를 그대로 사용하며 정점마다 본 하나에 가중치 1을 적용한다. 1메시·1재질·1스킨, `Run`을 240Hz 키프레임으로 베이크했고 런타임 IK·물리가 필요 없다.

앞오른발+뒤왼발, 앞왼발+뒤오른발을 반 주기 간격으로 교대하는 낮은 러닝 트롯이다. 대각 발 사이에 0.01주기 지연을 두고 각 발은 37%를 접지한다. 반 주기마다 0.04초의 짧은 공중 전환을 두어 걷기와 구분하며, 앞뒤 다리를 묶어 크게 뛰는 동작은 사용하지 않는다. 앞발 지지를 몸 아래로 가져와 뒤로 밀고, 이륙 직후 발끝을 32° 굴린 뒤 회수 때 -18°로 접어 무릎을 빠르게 접고 다시 전방으로 뻗는다. 몸통은 낮고 약간 앞으로 기울이며 상하폭은 모델 단위 0.06이다. 머리는 안정시키고 흉곽·꼬리에는 작은 후행을 남긴다. 석판은 강체로 회전하며 고무처럼 늘어나지 않는다.

## 재생·거리 계약

[motion-contract.json](motion-contract.json)이 수치의 원본이다. 주기는 20/60초, 보폭은 **0.3791666667타일**이다. 콘텐츠 속도 `54.6`과 `1/48` 거리 변환으로 1배속 **1.1375타일/초**에 맞췄다. 제작 원본은 in-place이며 루트 본은 이동하지 않는다.

`phase = (실제 누적 이동거리 / stride_tiles) % 1`로 위상을 구하고 `Run`의 `phase × cycle_seconds`를 샘플링한다. 이동이 멈추면 위상도 멈춘다. 감속·가속·4배속은 실제 이동거리에 반영되므로 별도의 재생 속도 상수를 중복 적용하지 않는다. Blender는 프레임 1~20을 반복하고 프레임 21은 1과 같은 접속 키다. GLB 시간은 **0~20/60초**다.

GLB는 원래 정적 폭 `1.9156095982`를 1로 정규화하고 발바닥을 0에 맞춘다. 런타임 표시 배율 `.48`을 적용하면 폭 .48타일이 된다. 제작 원본의 바닥은 `-.0286999680`이며 검수용 바닥과 GLB 오프셋은 이 좌표를 따른다.

## 검증과 재현

[source-validation.json](source-validation.json)은 최종 원본의 루프 접속, 177위상 접지·밀림, 강체 행렬, 루트 고정과 8대표위상 삼각형 교차 검사를 기록한다. 인접 석판·관절 코어의 원래 겹침은 제외하고 서로 다른 다리, 발/몸통, 하퇴/머리의 불필요한 관통을 검사했다. 베이크 키 사이 보간의 접지 오차 허용값은 0.0001모델 단위(약 0.0000251타일)다. [runtime-export.json](runtime-export.json)은 기하 매핑, 삼각형 수, 스킨·액션·시간 범위를 기록한다. 독립 검증 기록은 같은 폴더에 보관한다.

Blender 5.2.1 LTS. 원본 석재 재질·스튜디오에서 EEVEE로 실제 포즈를 렌더했다. 제작용 원본은 원래 procedural 재질, GLB는 기존 2048px PBR atlas를 유지한다. Godot·Android 화면은 이번 작업의 검증 범위가 아니다.

[독립 검증 결과](independent-review.md): 최종 낮은 달리기, 원본·GLB·수정된 타일 영상 PASS. 시간순 MP4 디코드 포즈와 궤적 검사를 함께 대조했으며, 확인 범위와 한계는 해당 기록에 명시했다.

[build_run.py](build_run.py)는 기존 Blender MCP에서 별도 `Fast_Hound_Run` 씬만 생성한다. 이후 저장한 파일을 독립 background Blender로 열어 [validate_run.py](validate_run.py), [export_run.py](export_run.py), [render_run.py](render_run.py), [render_traversal.py](render_traversal.py)를 실행한다. [encode_previews.py](encode_previews.py)는 실제 렌더 프레임을 MP4로 묶는다. 기존 열린 파일과 다른 씬·미저장 작업은 교체하지 않는다.
