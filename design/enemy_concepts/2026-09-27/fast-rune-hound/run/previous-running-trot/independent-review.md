# 낮은 달리기 독립 검토

2026-09-27. 구현 담당과 별도 Astra 검증. 사용자 최종 요구는 걷기처럼 보이지 않는 연속 달리기이며, 앞뒤 발을 묶어 높이 튀는 동작도 피한다. 항상 접지하던 [이전 버전](previous-grounded-trot/README.md)에 대한 시각 PASS는 사용자 거절로 철회했고, 이번 결과에 재사용하지 않았다.

**PASS.** 모션·원본·GLB와 수정된 최종 타일 영상이 검증 범위를 충족한다. 완료를 막는 미해결 결함은 없다. 새 버전은 낮은 체고에서 뒤로 미는 지지, 무릎과 발목을 접은 회수, 다시 뻗는 착지, 짧은 공중 전환이 구분된다. 게임 이식·죽음 모션·Android 성능은 범위 밖이다.

## 시각 판정

최종 [측면 MP4](run-side.mp4)의 첫 주기에서 10개 시간순 포즈를 직접 디코드해 대조했다. [사선 실제 렌더](frames/three-quarter/0010.png)도 추진·이륙 전환 위상에서 확인했다. 이전의 항상 펴진 다리 교대보다 발목을 말아 올리고 무릎을 접는 회수가 분명하며, 몸 아래에서 뒤로 밀고 다음 대각 발로 넘어간다. 앞뒤 발이 묶인 도약은 없고 큰 귀·낮은 머리·청회색 강체 돌판·청록 눈과 등 핵이 유지된다. 확인한 대표 위상에서 부품 분리나 뚜렷한 불필요 관통은 보이지 않는다.

짧은 공중 전환이 실제 기하에서도 확인되어 걷기와 구분된다. 주기 1/3초, 접지 37%, 대각 발 차이 0.01주기로 공중 구간은 위상 약 0.38~0.50 및 0.88~1.00, 각 약 0.04초다. 네 발 중 가장 낮은 발의 최대 높이는 **0.01223타일**로 낮다. 몸통 상하폭은 약 0.015타일이며 큰 상하 도약 대신 다리 회수로 달리기를 표현한다.

도구상 시각 검토는 영상을 시간 흐름으로 직접 지각한 것이 아니라, 최종 MP4의 시간순 디코드 포즈·대표 프레임을 실제 재생시간 및 177위상 궤적 검사와 함께 대조한 것이다. 사용자 취향의 최종 승인이나 인게임 결과를 대신한다고 주장하지 않는다.

## 최종 영상 확인

[타일 영상](tile-run-preview.mp4)의 사선·드론 패널은 새 달리기와 실제 이동을 보존한다. 드론 패널의 사선 카메라 location 키 간섭으로 모델이 화면 밖으로 나가던 결함은 구현자가 렌더용 카메라 키를 분리해 수정했다. 수정 후 실제 MP4의 t=0.8초 합성 화면과 t=2.4초 드론 화면을 각각 직접 디코드하여 모델 추적·외형·타일 접지가 정상임을 확인했다. 원본·GLB·사선은 변경되지 않아 해당 검사를 반복하지 않았다.
