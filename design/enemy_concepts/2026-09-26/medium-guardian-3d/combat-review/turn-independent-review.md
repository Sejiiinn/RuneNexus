# Guardian 정식 적용·몸 회전 독립 검증

> 원시 로그·일회성 검사·측정 덤프는 로컬 기록으로 Git 추적에서 제외했다. 본문의 요약 결과와 유지되는 회귀 테스트는 보존하며, 아래 로컬 기록은 새 체크아웃에 포함되지 않는다.

판정: **PASS — 정식 소스/패키징 연결과 데스크톱 실제 Godot 전투 범위**. 구현 담당과 별개로 최종 소스·승인 GLB·실제 시간순 프레임을 대조하고, 회전 경계 검사를 직접 작성·실행했다. Android 설치·실기기 GPU 성능은 미검증이다.

## 승인 외형과 책임 경계

- 정식 `assets/images/stage1_3d/enemies/normal.glb`, `normal_death.glb`를 승인 보행 GLB와 v4 whole-exit GLB에 byte 단위로 대조했다. 두 파일 모두 동일하다. 다른 적 5종 GLB와 `godot/combat`, `godot/session`, `godot/app`에는 변경이 없다. [직접 대조 결과](turn-independent-assets.json).
- `battlefield_units.gd`의 기본 normal 경로가 새 모델을 사용하고, 다른 종의 기존 인스턴스·방향·부유 경로는 유지한다. 보행은 기존 실제 누적 이동 거리를 사용한다. 변경은 표시 방향·애니메이션·모델별 효과 부착에 한정되며 이동 경로·속도·스탯·저장 데이터를 수정하지 않는다.
- 정식 준비 경로에 보행/죽음 GLB와 상태 메시 3개가 포함되고, preview GLB 중복이나 폐기한 상태 JSON이 포함되지 않는다. [공식 준비 검사](guardian-shipping-package-check.json). 최종 상태 `.res` 3개와 캡처 프로젝트 입력도 직접 byte 대조했다.

## 회전·시간·죽음

- [독립 검사](check_turn_independent.gd)를 Godot 4.7.2에서 직접 실행해 **12/12 PASS**. 실행 로그 (`turn-independent-check.log`, 로컬 기록). 초기 방향 즉시 적용, 90도 0.12 전투초, 끝 감속, ±179도 최단 2도, 같은 전투 시각 반복 동기화의 정지, 도중 목표 변경의 연속성, 목표 도달, 시계 되감기를 검사했다.
- 90도 회전의 0.03초 간격 각도는 `0 → 39.375 → 67.5 → 84.375 → 90`도로 후반 각도 변화가 줄어든다. 실제 60fps 전투 기록에서도 같은 감속 곡선을 확인했다.
- [1x 실제 캡처](turn-captures/drone/) 135/138/143, 319/322/327, 595/598/603을 시간순으로 직접 검토했다. 세 코너에서 이동은 이어지고 몸이 중간 각도를 거쳐 돌아가며 갑작스러운 반전·뒤로 이동·형태 분리가 없다.
- [4x 실제 캡처](turn-captures/drone-4x/) 35/36/37과 81/82/83을 직접 검토했다. `90 → 17.778 → 0`, `0 → 72.222 → 90`으로 1프레임당 0.0667 전투초를 반영한다. 4x에서는 약 0.03 실제초의 짧은 회전으로 보인다.
- 죽음은 실제 native kill에만 생성되고, 마지막 보이는 몸 방향을 인계한다. 이벤트 중복 방지·0.6 전투초 제거·pause·4x·감속·도착 제외·자원 해제는 최종 36개 계약 검사 (`guardian-shipping-contract-check.log`, 로컬 기록)의 스크립트와 결과를 직접 검토했다. 원본이 그대로인 보행/죽음 스킨과 승인 외형 검증은 기존 [검증 기록](independent-review.md)의 해당 근거를 재사용했다.

## 공통 화상·서리 보존

- 기존 공통 화상 아틀라스/입자 운동과 서리 셰이더/결정 원형·면색·판정·만료를 유지한다. 새 guardian의 골격을 따르도록 부착 자료만 사전 제작하며, 런타임에서 본체 메시/텍스처를 샘플링하지 않는다. 화상 1개·서리 2개의 공유 스킨 메시로 묶어 효과당 본별 draw 그룹 증가를 피한다. 기존 적은 기본 shader 분기를 그대로 사용한다.
- 검토 중 발견된 본별 그룹 증가, inverse-bind 배율 중복, headless MultiMesh readback의 identity/0 자료는 구현 담당이 수정했다. 최종 생성기는 원본 JSON의 CPU 자료를 직접 읽는다. 최종 계약 검사는 52개 화상 row/서로 다른 앵커와 40개 결정 variant 및 3개 단일 surface를 확인한다.
- 최종 5개 보행 위상 스킨 경계 검사 (`guardian-status-skin-bounds.log`, 로컬 기록)의 계산 방식과 결과를 확인했다. 최종 효과가 몸체 규모 안팎에서 유지되고 보행 중 분리되지 않는다.
- 최종 [상태 전투 캡처](turn-captures/drone-status/) 240/330/420/480을 직접 재검토했다. 서리가 몸에 붙고 해제되며, 짧은 주황 불꽃이 적의 이동·회전을 따라 나타난다. 최종 입력은 실제 냉각/화염 포탑 공격이며 최대 동시 감속 7마리·화상 1마리다. HP/피해 표시가 유지되고 전장 여러 타일을 덮는 과대 결정이나 잔류 효과가 없다.
- [최종 전면 동시효과 진단](guardian-status-final-diagnostic.png)을 직접 확인했다. 원래 자홍 눈·룬·핵 색이 서리 코팅에서 보존된다. 일부 결정의 자연스러운 앞뒤 겹침은 존재하며, 부모가 정한 완료 범위에 따라 공통 결정 외형을 추가 변경하지 않았다.

## 검증 한계

실제 화면은 440×900 데스크톱 Godot Mobile 렌더러의 결정적 전투 캡처이며 FPS 측정이 아니다. 동영상의 시간순 원본 프레임을 직접 확인했으며 실시간 플레이어로 영상을 시청했다는 주장은 하지 않는다. Android 설치·기기 입력·모바일 GPU 성능·APK 크기는 이번 검증에서 확인하지 않았다. 확인한 요청 범위에 미해결 결함은 없다.
