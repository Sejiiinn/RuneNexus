# 중형 일반몹 — 걷기 V1 (비교용 보존)

**현재 권장본은 [타일 속도와 상체 움직임을 보완한 V3](tile-speed-review/v3-upper-body/README.md)다.** 아래 V1은 초기 제자리 시안이다. 실제 게임 표시 크기/이동속도를 함께 검증한 결과 보폭과 주기 개선이 필요하여 V2로 보정했다.

[편집 원본](medium-guardian-walk.blend) · [두 시점 반복 영상](walk-preview.mp4) · [3/4 영상](walk-three-quarter.mp4) · [25° 드론 영상](walk-drone-25.mp4) · [접지/스윙 위상](contact-sheet.png)

정적 원본 `../medium-guardian.blend`에서 파생한 제자리 걷기다. 큰 둥근 돌머리, 파인 눈구멍, 자주색 눈과 핵, 소용돌이 룬, 두꺼운 돌 팔다리와 후면 석판을 유지했다. 89개 모델 메시의 정점·면·재질은 보존하고 실제 관절 위치를 기준으로 14개 본을 만들었다. 메시 전체를 하나의 본에 강체 parenting하여 돌이 휘거나 표면 텍스처가 미끄러지지 않는다. 다리 관절은 2절 analytic IK로 길이를 보존하며, 결과는 편집 가능한 본 키프레임이다.

- Scene: `Medium_Guardian_Walk`, rig: `Guardian_Walk_Rig`, action: `Walk`.
- **30fps / 1~36프레임 / 1.2초**, 37프레임은 1프레임과 같은 루프 폐쇄 키다. 재생 구간에서 37을 제외한다.
- 전방 **-Y**, 위 **+Z**, root는 원점에 고정한다. 발은 좌우 반 주기 차이로 움직이며 각 발의 지지 구간은 주기의 60%다. 양발 지지가 짧게 겹친다.
- 한 지지 구간의 발 이동은 +Y **0.42 unit**, 들어 올리는 높이는 **0.16 unit**다. 골반은 지지 다리 쪽으로 최대 0.036 unit 움직이고 작은 상하/좌우 회전을 더했다. 반대 팔은 약 ±9°로 흔들며 머리 회전은 ±0.25°로 안정시켰다.
- 이 제자리 애니메이션에 대응하는 전진 속도는 **-Y 0.583333 unit/s**다. 해당 속도로 root를 이동시키면 지지발이 월드 바닥에 머문다. 제자리 영상에서 지지발이 뒤로 움직이는 것은 이 계약에 따른다.
- 짧은 다리가 늘어나지 않도록 기본 골반을 0.075 unit 내렸다. 스케일과 메시는 변경하지 않았다. 리그의 Rest Position은 원본 정적 자세다.
- 모든 본의 transform은 0.1프레임 간격으로 베이크하고 `Cycles` 반복을 사용한다. 프레임 사이의 지지발 오차를 줄이기 위한 밀도이며 게임용 키 경량화는 이번 범위에 포함하지 않았다.

영상은 기존 스튜디오/재질/조명과 실제 Blender Cycles 24 samples, denoising, AgX Medium High Contrast로 각 시점 720×720의 36프레임을 렌더했다. MP4는 이 프레임을 **5회 반복한 6초** 영상이다. 합본은 왼쪽 3/4, 오른쪽 수직에서 25° 드론 시점이다. 접지 시트는 위/아래 같은 시점 순서, 각 행은 **1 / 12 / 19 / 30프레임**(왼발 접지 / 오른발 스윙 / 오른발 접지 / 왼발 스윙)이다.

## 수치 확인

[측정 원자료](walk-metrics.json)는 0.25프레임 간격 145개 평가 상태를 기록한다. [본 할당](rig-map.json)은 89개 메시의 소유 본과 원본 Rest 행렬 대조 결과다.

| 확인 | 최종 측정 |
| --- | --- |
| 원본 Rest 변환 최대 오차 | 0.000000238 unit |
| 지지발 바닥 높이 최대 오차 | 0.00000222 unit |
| 지지발 대응 속도 최대 오차 | 0.0000432 unit/s |
| 다리 연결 관절 최대 벌어짐 | 0.000000431 unit |
| 1↔37 전체 메시 월드 행렬 차이 | 8.82e-18 |

원본 발바닥/스튜디오 바닥의 높이는 Z=0.035다. 미세 음수 오차는 부동소수점 및 키 사이 보간 수준이다. 스윙 발만 들리고 지지발은 수평을 유지한다. 수치 검사는 모든 메시 조합의 충돌 부재를 증명하는 검사는 아니며 실제 렌더에서 원본 외형, 관절 연결, 손·몸통 및 발의 관계를 함께 확인한다.

## 재생성

열린 원본과 다른 씬을 보존하기 위해 `build_walk.py`를 Blender MCP로 실행한다. 원본 `Medium_Guardian_Concept` 씬이 있는 열린 인스턴스에서 Walk 씬만 별도로 만들고, 기존 Walk 씬 재실행 시 해당 파생 씬만 갱신한다.

1. `build_walk.py` — 89개 메시 복제, 본 계층/키 및 파생 라이브러리 저장.
2. 별도 background Blender에서 `medium-guardian-walk.blend --python finalize_walk.py` — 기본 활성 씬과 UI를 저장하여 직접 열 수 있는 프로젝트로 정규화.
3. 같은 파일을 새 background Blender에서 `--python measure_walk.py`로 실제 재오픈하여 수치 측정.
4. `--python render_walk.py` — 두 시점 36프레임 생성. `-- draft`는 낮은 해상도 4위상 확인용이다.
5. `pack_preview.sh` — 기존 ffmpeg로 프레임을 MP4와 접지 시트로 패킹한다. 환경변수 `FFMPEG`로 실행 파일을 지정할 수 있다.

원본 정적 `.blend`와 기존 열린 씬은 수정·덮어쓰기하지 않는다. 걷기 제작과 Blender 검수까지의 결과이며 게임 이식·공격/피격/죽음 애니메이션·최적화·APK 작업은 포함하지 않는다.
