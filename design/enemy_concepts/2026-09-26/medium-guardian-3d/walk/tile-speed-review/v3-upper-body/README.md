# 일반몹 걷기 V3 — 발디딤에 반응하는 상체

**현재 권장 걷기 원본은 [medium-guardian-walk-v3.blend](medium-guardian-walk-v3.blend)다.** V2의 타일 이동속도와 접지는 유지하면서, 고정되어 보이던 몸통과 머리에 발디딤에 따른 무게 이동과 약간 늦은 머리 반응을 추가했다.

[완성 V3 영상](walk-v3.mp4) · [V2/V3 비교](upper-body-comparison.mp4) · [3/4 비교](upper-body-three-quarter.mp4) · [25° 드론 비교](upper-body-drone-25.mp4) · [확대 위상 시트](upper-body-motion-sheet.png)

비교 영상은 각 화면 **왼쪽 V2 / 오른쪽 V3**, 합본은 **위 3/4 / 아래 드론**이다. 실제 타일 위에서 60fps로 렌더한 **2주기 52프레임을 3회 반복**한 2.6초 검수 영상이다. 각 반복은 같은 2주기 구간을 다시 보여주므로 바닥 이동도 그 구간으로 되돌아간다. 3타일 전체를 새 영상으로 렌더한 결과로 표기하지 않는다. 편집 가능한 [전진 검수 씬](upper-body-traversal.blend)에서는 이전과 같이 3.2047타일 전체 전진을 수치 평가했다.

## 상체 동작 변경

- 발이 닿은 직후 몸통이 작게 낮아지고, 지지발 위를 지날 때 다시 올라온다. 골반 상하 진폭은 **±0.060 model-unit**, 좌우 이동은 **±0.080**이다. V2의 ±0.012 / ±0.032에서 읽을 수 있는 크기로 늘렸다.
- 지지하는 쪽으로 골반을 **±1.8°**, 흉곽을 합계 **약 ±2.6°** 기울인다. 흉곽 좌우 회전은 **±3°**, 발디딤의 전후 반응은 **약 ±1.8°**다. 좌우 이동과 기울기가 서로 상쇄되던 기존 조합을 체중 이동 방향으로 맞췄다.
- 머리는 목 위치를 몸통에 정확히 연결한 채, 현재 몸통 회전과 **0.08주기(약 35ms, 60fps 약 2프레임)** 늦은 반응을 함께 따른다. 몸통 회전을 거의 취소하던 V2의 월드 고정을 없앴다. 머리와 모든 돌은 강체이며 변형하거나 독립적으로 떠다니지 않는다.
- 다리 IK를 매 키마다 다시 풀어 상체의 이동을 흡수한다. 발 궤적과 월드 접지는 유지한다.

| 머리 중심 상하 이동 범위 | 0.00321 tile | **0.01582 tile** |

## 보존한 계약과 검사

원본 89개 메시·15,351삼각형, 정점·재질, 큰 돌머리와 짧은 팔다리, 표시 폭 **0.55 tile**, 이동속도 **0.65625 tile/s**, 주기 **26/60초**, 지지 비율 **55%**를 유지한다. V2 원본과 비교 영상은 상위 폴더에 보존했다. 게임 적용과 게임 이동 수치 변경은 하지 않았다.

[편집 원본](medium-guardian-walk-v3.blend)의 씬은 `Medium_Guardian_Walk_V3`, 리그는 `Guardian_Walk_V3_Rig`, 액션은 `Walk_WeightShift`다. 60fps 1~26프레임을 재생하고 27은 폐쇄 키로만 사용한다. [루프 검사](loop-check.json)의 1↔27 메시 월드 행렬 차이는 **1.96e-17**이다.

전체 3.2047타일 전진을 0.25프레임 간격 1,173상태로 평가한 [수치 근거](tile-review-metrics.json)에서 V3 지지발 최대 잔여속도는 **0.000458 tile/s**, 최대 접지 높이 오차는 **3.55e-6 tile**, 목 연결 오차는 **1.28e-7 tile**다. 상체 이동 범위 내에서 모든 IK 도달범위 검사와 원본/검수 복제본의 메시 월드 변환 대조를 통과했다. 실제 표면의 관통·연결과 움직임 가독성은 두 시점 최종 렌더로 함께 확인한다.

이동 거리 기반 위상은 V2와 같은 `phase = (distance_travelled / 0.284375) mod 1`이다. 감속과 배속은 이동과 위상에 같이 적용한다. 4배속에서 이동 2.625tile/s, 주기 0.108333초로 같은 발 접지 관계를 유지한다. [V2 타일 속도 계약](../README.md#향후-게임-연결-계약)을 따른다.

## 재생성

`build_walk_v3.py` → 별도 background Blender의 `finalize_walk_v3.py` → `build_upper_body_review.py` → `measure_upper_body.py` → `render_upper_body_review.py -- short` → `pack_upper_body.sh` 순서다. 제작은 Blender MCP의 별도 V3 씬에서 수행하고 기존 열린 씬과 V2를 보존한다. 렌더는 실제 Blender EEVEE 800×600, 60fps이며, 단독 영상과 확대 시트는 해당 프레임을 크롭/패킹한 것이다. 상체가 읽히는 모델 픽셀 크기를 유지하면서 불필요한 전체 경로 재렌더를 피했다.

`upper-motion-summary.json`은 각 리그의 한 주기 실제 변위를, `tile-review-metrics.json`은 전진 중 발·목·상체 좌표를 담는다. [독립 검증](independent-review.md)에서 상체/머리 동작 가독성, 원본 형상·재질과 단단한 돌 연결, 루프 및 전체 전진 중 접지를 통과했다. 이 작업 범위의 미해결 결함은 없다.
