# 타일 이동 속도 독립 검증

2026-09-27, 구현 담당과 별개 Astra 검증. 범위는 Blender 걷기 시안과 실제 일반몹 속도의 타일 전진 비교다. **PASS**, 이 범위의 미해결 결함 없음. 게임 이식·실기기 검증 결과는 아니다.

## 기준과 직접 확인

- `godot/content/game_content.json`의 일반몹 speed 31.5, 48단위 타일, presentationScale 0.55와 `native_combat_runtime.gd`의 타일 좌표 변환·rows[5], `battlefield_units.gd`의 root.scale 전달을 직접 확인했다. 표시 폭 0.55타일, 이동 0.65625타일/초를 고정한다.
- 독립 background Blender 5.2.1에서 [V2 원본](medium-guardian-walk-v2.blend)과 [전진 검수 씬](tile-traversal-review.blend)을 직접 열고 평가했다. 열린 제작 Blender는 조작하지 않았다.
- V2는 `Walk_TileSpeed`, 26프레임/60fps, 0.433333초 주기다. 89메시·15,351삼각형, 큰 돌머리·보라 룬/눈/핵·분절 팔다리 외형을 유지한다. 루프 1→27 월드 행렬 오차는 7.84e-18이었다.
- 모델 폭 4.12951922416687에 0.55/폭을 적용한 V2의 1/4프레임 독립 평가에서 지지발 월드 잔여 속도는 최대 0.000524타일/초였다. 대응 이동 속도의 0.08% 미만이다.
- 실제 전진 씬 1~294프레임을 독립 평가했다. 기존 지지발의 평균 미끄럼은 -0.578557타일/초, 개선본은 -1.94e-7타일/초였다. 정수 프레임의 개선본 최대 잔여 속도는 2.15e-5타일/초, 접지 높이 오차는 4.05e-8타일이었다. 두 캐릭터는 같은 속도로 약 3.2047타일을 전진한다.

## 시각 판정과 근거

[최종 3/4 프레임](frames/three-quarter/)의 1/7/14/20/27/100/180/294, [최종 드론 프레임](frames/drone-25/)의 1/7/14/20/27/180/235/294 및 [한 주기 연속 위상](v2-cycle-strip.png)을 시간순으로 직접 확인했다. 첫 주기와 전진 중간·종료를 같은 60fps 시간 기준으로 대조했다.

개선본은 발의 전후 이동과 좌우 지지 교대가 분명하고, 팔은 반대로 움직이며 머리와 몸통은 안정적으로 유지된다. 실제 타일 위에서도 큰 몸체에 비해 발만 느리게 움직이던 기존 불일치가 해소된다. 초당 약 4.62걸음의 짧고 빠른 보행이며, 과도한 상하 튀기·부품 분리·뚜렷한 표면 관통을 발견하지 않았다. 두 시점에서 돌 재질과 보라색 표식이 유지된다.

초안 전진 씬의 bone parent inverse 복사 오류는 부모가 발견하여 구현자가 수정했다. 수정 후 대표 화면과 실제 전진 씬의 수치를 다시 확인했으며, 해당 실패 초안은 위 판정 근거로 사용하지 않았다.

검증자는 MP4 플레이어의 실시간 재생을 직접 관찰한 것이 아니라 최종 영상 원본의 시간순 프레임과 실제 리그의 프레임별 변환·속도를 함께 판정했다. 임의 정지 자세만으로 움직임을 통과시킨 결과는 아니다. 게임의 감속·배속 연동 구현과 Android 화면은 이번 범위 밖이다.
