# 중형 일반몹 — 0.45초 죽음 3D 시안

현재 권장본은 [V3 — 사전 계산한 돌무더기 붕괴·조각별 소멸](v3-rubble/README.md)이다. [V2 흡수 시안](v2-absorb/README.md)과 아래 0.45초 원본은 비교용으로 보존한다.

[두 시점 영상](death-preview.mp4) · [3/4 영상](death-three-quarter.mp4) · [25° 드론 영상](death-drone-25.mp4) · [대표 위상](phase-sheet.png) · [편집 원본](medium-guardian-death.blend)

기존 승인 돌 수호자가 짧게 움찔하고, 눈·가슴 핵·룬이 어두워지며, 몸통이 내려앉고 머리와 두 팔이 발 주변에 떨어진 뒤 잔해가 가라앉는 시안이다. **실제 죽음 동작은 0.45초**다. 게임 적용·전투 판정·커밋은 포함하지 않는다.

## 시간과 동작

| 사망 후 시간 | 실제 3D 동작 |
| --- | --- |
| 0~0.08초 | 앞에서 맞은 방향을 기준으로 상체가 뒤로 짧게 움찔한다. 눈·핵·룬은 복사한 전용 재질에서 색과 광택을 낮춰 꺼진 상태가 된다. |
| 0.08~0.28초 | 다리 관절이 접히고 몸통이 내려앉는다. 머리는 0.105초부터 눈·룬·이끼를 함께, 팔은 0.125/0.135초부터 어깨돌·팔꿈치·주먹·손가락을 같은 덩어리로 떨어뜨린다. 목과 어깨 연결축은 몸통에 남는다. |
| 0.25~0.28초 | 양팔과 머리가 바닥에 닿는다. 머리가 위로 튀거나 길게 구르지 않으며, 팔은 타일 안 양옆에 낮게 눕는다. |
| 0.28~0.45초 | 낮은 위치의 작은 3D 먼지 8개와 함께 잔해가 부드럽게 바닥 아래로 가라앉는다. 0.38초에는 낮은 잔해가 남고, 0.45초에는 모델과 먼지가 사라진다. |

시안은 실시간 물리 시뮬레이션이 아닌 **정해진 강체 본 키프레임**이다. 떨어지는 덩어리의 실제 정점 최저점을 계산해 착지 높이를 맞췄다. 먼지는 작은 실제 3D 메시 8개에 가장자리·노이즈·시간에 따른 반투명 표면을 적용했다. 접촉부에 낮게 잠깐 나타나며 큰 연기로 모델의 형태를 가리지 않는다.

원본 승인 89개 메시·15,351삼각형과 기존 돌 형상/비율을 유지한다. 돌 재질은 보존하고, 소등되는 눈·핵·룬 재질만 이 시안의 복사본으로 애니메이션한다. 원본 및 기존 걷기의 공유 재질은 수정하지 않는다.

## 타일 크기와 미리보기

[타일 프리뷰 씬](death-tile-preview.blend)은 기존 실제 길 타일 `path_tile_natural_surface`와 표시 폭 **0.55 tile**를 사용한다. 모델 전방은 **-Y**, 위는 **+Z**다. 죽기 전 크기는 기존 걷기와 같으며, 분리된 팔은 같은 타일 안의 발 양옆에 떨어진다.

편집 원본은 **60fps, f1 시작→f28 종료**로 27개 시간 간격, 정확히 0.45초다. 액션 이름은 `Death`, 씬은 `Medium_Guardian_Death`, 리그는 `Guardian_Death_Rig`다.

미리보기에는 읽기 쉽게 시작 전 **0.3초**, 종료 후 **0.3초**를 추가했다. 60fps의 f1~63, 총 1.05초이고, 실제 사망은 f19→f46이다. MP4는 이 구간을 **3회 반복한 3.15초** 영상이다. 합본은 왼쪽 3/4·오른쪽 수직에서 25° 드론 시점이며, 실제 Blender EEVEE 800×600 렌더를 패킹했다. 정지 위상 시트는 각 행이 0/.08/.20/.28/.38/.45초, 위 3/4·아래 드론이다.

## 확인 근거

[수치 검사](death-metrics.json)는 직접 다시 연 편집 원본을 0.1프레임 간격으로 271상태 평가한다.

- 원본 모델 89메시, evaluated 15,351삼각형.
- 머리 분리 이후 위로 움직인 최대 오차 **2.38e-7 model-unit**: 눈에 보이는 튐 없이 내려간다.
- 침강 전 전체 모델의 바닥 침범 최대 **3.69e-7 model-unit**: 부동소수점 오차 수준이다.
- 0.28초 머리·좌우 팔의 실제 최저점은 모두 Z≈0.035인 바닥에 닿는다. 양팔의 최고점은 약 0.97 model-unit로 낮게 누운 자세다.
- 마지막 모델 최고점은 Z=-0.2169로 바닥 Z=0.035 아래에 있다. 침강 구간의 바닥 통과는 퇴장 연출이며 충돌 오류로 분류하지 않는다.

실제 시간순 렌더에서 소등·몸통 붕괴·부품 묶음·낙하/착지와 종료 화면을 확인했다. [독립 검증](independent-review.md)에서 모션·형태·타이밍을 확인했고, 먼지 수정 후 양시점 가독성과 종료 시 투명도 0을 재확인했다. [최종 영상 검사](video-check.json)에서 MP4 3개의 60fps·189프레임·3.15초 및 전체 디코드를 확인했다.

## 재생성

1. Blender MCP에서 `build_death.py` 실행: 기존 `Medium_Guardian_Walk_V3`의 동일 모델/본 구조를 복사한 별도 Death 씬 생성. 열린 원본/걷기 씬 보존.
2. 별도 background Blender에서 `medium-guardian-death.blend --python finalize.py`: 직접 열 수 있는 기본 씬으로 정규화.
3. Blender MCP에서 `build_preview.py`: 재질·본·먼지 애니메이션을 함께 18프레임 옮긴 타일 미리보기 생성.
4. Blender MCP에서 `refine_dust.py`: 두 별도 씬의 먼지에 부드러운 반투명 3D 표면을 적용하고 파일을 저장한다. 이후 편집 원본에 `finalize.py`를 다시 실행한다.
5. 별도 background에서 `death-tile-preview.blend --python render_death.py -- phases`로 대표 위상, `--python render_death.py`로 전체 63프레임 두 시점 렌더.
6. `medium-guardian-death.blend --python measure_death.py`로 실제 평가, `pack_death.sh`로 영상/위상 시트 패킹. `FFMPEG` 환경변수로 실행 경로를 지정할 수 있다.

진행 중 발견한 큰 침강거리와 비스듬히 선 팔 자세를 국소 보정하고, 소형 볼륨 먼지의 낮은 가독성을 반투명 3D 표면으로 개선했다. 원본 형상과 합의한 단계는 그대로 유지했다.
