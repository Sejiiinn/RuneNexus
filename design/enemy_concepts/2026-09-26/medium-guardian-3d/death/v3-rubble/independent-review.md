# 돌무더기 붕괴·베이크 GLB 독립 검증

2026-09-27, 별도 Astra 검증. **PASS**. 선택한 돌무더기 붕괴 시안과 게임 연결 준비용 GLB 범위의 미해결 결함 없음. 게임 통합과 실기기 성능은 미검증이다.

## 외형과 움직임

최종 [3/4 연속 원본](frames/three-quarter/)의 25/31/36/45/54/59/63/67/72프레임, [드론 원본](frames/drone-25/)의 31/45/59/67/72프레임과 초기·착지 위상을 시간순으로 직접 확인했다. 머리·몸통·사지가 거의 수직으로 내려앉고, 14개 주덩어리가 비대칭의 낮은 돌무더기로 남는다. 팔을 수평으로 크게 벌리거나 몸 전체가 바닥으로 내려가는 이전 표현은 없다. 승인한 석재·눈구멍·관절 부품의 형태를 유지한다.

0.28~0.43초에 무더기가 유지되고 작은 부품부터 순차적으로 소멸한다. 개별 조각은 짧은 구간에 축소되어 사라지지만, 몸 전체를 고무처럼 찌그러뜨리는 동작으로 읽히지 않는다. 소멸 끝까지 확인했고, 명백한 외부 관통·부유는 발견하지 않았다. 내부의 가려진 작은 겹침은 부모가 허용한 범위다. 첫 규칙적 2×2 분할 배치가 아닌 수정된 최종 배치를 판정했다.

## GLB의 실제 재임포트

첫 GLB는 원본 대비 석재 요철이 약해져 FAIL로 반환했다. 최종 노멀 보정 후 [재임포트 3/4](glb-reimport/three-quarter/)와 [재임포트 드론](glb-reimport/drone-25/)의 0.00/0.28초를 원본과 직접 비교했다. 거친 돌 표면의 명암·재질 정체성이 회복되었고, 눈·핵·룬과 검은 관절 구분을 유지한다. 3/4의 0.65/0.80초도 확인하여 분리·소멸 동작의 전달을 확인했다. 절차적 재질이 자동으로 보존된다고 가정하지 않았다.

별도 factory-startup Blender 5.2.1에서 **최종 GLB 자체를 직접 임포트**하여 검사했다. 0/0.28/0.43/0.65/0.80/0.883333초에 스킨 메시를 실제 평가했다. 0.28~0.43초의 경계는 동일하며, 마지막에는 모든 주덩어리와 소등 본의 scale이 0이 되어 남는 표면이 없다. 런타임 constraint·driver는 0이다. 임포터가 만드는 본 표시용 Icosphere는 GLB 원본 노드가 아니므로 산출물 메시 수에 포함하지 않았다.

또한 제작 원본의 정점과 직접 재임포트한 GLB의 평가 정점을 7개 시점(0/0.145/0.28/0.43/0.65/0.80/0.883333초)에서 최근접 대조했다. 확인한 최대 오차는 표시 폭 0.55타일 기준 약 **0.00008336타일**이었다. 제작자의 531상태 전체 검사와 구분되는 독립 표본 검사다.

## 경량화 확인 범위

최종 GLB 바이너리의 JSON을 직접 읽어 **1 mesh / 1 primitive / 1 material / 1 skin / 18 joints / 1 animation·54 channels**, **4,088,764바이트**를 확인했다. 초기 산출물의 불필요한 dense 애니메이션이 제거됐다. 제작 통계의 최종 본 키는 11,340개이며, 제작 원본의 93개 메시를 런타임 한 표면으로 묶는다. 원본 89메시에서 머리·몸통 분할에 필요한 제작 조각만 늘렸고, 최종 삼각형 수는 15,809다.

이 결과는 런타임 물리·IK·드라이버 없이 베이크 키를 재생하는 준비다. 애니메이션 보간·스키닝·렌더 비용은 여전히 필요하다. CPU/GPU 프레임 시간·FPS·실기기 메모리는 측정하지 않았으며, 파일·키·표면 감소를 전체 게임 성능 개선율로 해석하지 않는다. [상세 통계](runtime-stats.json)와 [제작자 동작 검사](motion-check.json)를 따른다.
