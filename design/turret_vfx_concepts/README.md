# 포탑 이펙트 개선 제안

상태: 검토용 시안, 미구현·미확정. 2026-09-10.

## 현행 확인

`projectile_component.dart`는 기관총·대포 등을 원형 중심으로 그리고 최근 위치 최대 9개에 잔상을 표시한다. 화염탄은 불꽃 윤곽을 사용하지만 잔상은 원형 기반이다. `turret_shape_renderer.dart`에는 발사 반동과 기관총 섬광이 있고, `impact_effect_component.dart`에는 스파크·화염·냉기·번개 및 대포 폭발 스프라이트 12프레임 경로가 있다. 따라서 효과의 부재보다 발사·비행·명중 사이의 시각적 연결과 무기별 실루엣 차이를 개선 대상으로 본다. 실제 플레이 화면의 이펙트 노출 정도나 에셋 로딩 성공 여부는 이번 조사로 검증하지 않았다.

## 핵심 제안

| 포탑 | 발사 | 비행 | 명중 |
| --- | --- | --- | --- |
| 기관총 | 짧은 백황색 총구 섬광, 작고 빠른 반동 | 가늘고 끝이 뾰족한 예광탄, 짧게 사라지는 선형 잔상 | 진행 방향을 따르는 작은 금속 스파크와 먼지 |
| 대포 | 넓고 짧은 포구 화염, 무거운 반동, 옅은 연기 | 어두운 포탄 실루엣과 가는 연기 꼬리 | 기존 폭발을 활용한 순간 섬광 → 불규칙 충격파·파편 → 연기 소멸 |
| 화염 | 화염 중심이 모였다가 빠져나가는 발사 반응 | 비대칭 물방울형 화염탄, 뒤로 갈라지는 불꽃 꼬리 | 적 윤곽을 감싸는 짧은 불꽃과 잔불 |

추가 포탑에도 같은 구분 원칙을 적용할 수 있다. 저격은 단발의 날카로운 섬광과 곧은 순간 궤적, 냉기는 각진 얼음 결정과 성에 파편, 번개는 기존 충전·연쇄 타격에 맞춘 굴절 방전과 접점 스파크를 사용한다. 각 포탑의 실제 공격 방식에 맞춰 범위를 정한다.

## 타이밍과 우선순위

아래 시간은 첫 구현에서 조절할 제안값이며 현재 수치나 확정 기준이 아니다. 공격 속도·탄속·명중 시점은 기존 전투 로직을 따른다.

- 기관총: 발사 섬광 약 40–70ms, 짧은 예광 잔상 약 40–80ms, 타격 스파크 약 80–140ms. 빠른 반복 속에서 한 발씩 끊기는 인상을 우선한다.
- 대포: 포구 섬광 약 60–100ms, 반동 복귀 약 160–240ms. 기존 420ms 폭발 안에서 첫 섬광은 짧고 강하게, 후반 연기는 어둡고 투명하게 분리한다.
- 화염: 진행 방향으로 늘어난 불꽃 윤곽을 순환시키고, 명중 후 짧게 퍼졌다 사라지게 한다. 연소 상태 표현은 실제 연소 상태에만 연결한다.
- 게임 배속에서 효과가 한 프레임에 사라지는지 구현 시 확인한다. 가시성 보정이 필요해도 판정 시점과 비행 위치를 늦추지 않는다.

첫 적용은 비행체 실루엣·방향성 잔상과 발사 타이밍 연결, 다음은 무기별 명중 반응, 마지막은 작은 탄피·먼지 등 보조 표현 순서가 적절하다. 지속적인 화면 흔들림이나 화면 전체 플래시는 기본 효과로 추가하지 않는다.

## 제작·통합 방향

- 실제 이펙트 제작 시 기존 대포 폭발 에셋과 로딩 구조를 먼저 확인하고 활용한다.
- 불꽃·연기·섬광 본체는 투명 PNG 애니메이션 에셋으로 만들고, 게임 상태에 반응하는 가벼운 궤적·회전·알파 변화는 렌더링에서 제어한다. 실제 제작 전에 개별 에셋 크기·프레임 수를 정한다.
- 잔상은 이동 방향과 거리를 기준으로 형태를 유지하도록 하고, 저프레임·배속에서도 점 구슬이 끊겨 보이지 않도록 확인한다.
- 포구 연출은 실제 포신 끝에 붙인다. 기존 충돌 계산을 바꾸지 않고 발사체와 연결되는 시각적 출발점을 정렬한다.
- 연기·파편은 투명도와 동시 노출 수를 제한한다. 피해 범위·체력바·적 실루엣을 가리지 않는다.
- 색만 바꾸지 않고 기관총은 선, 대포는 질량과 연기, 화염은 찢어지는 유기적 윤곽으로 구분한다.

화염은 현재 단발 투사체 공격이므로 이번 제안에서 연속 화염방사·부채꼴 피해로 바꾸지 않는다. 장식 궤적은 피해 판정이 아니며 범위 표현은 실제 범위 공격과 일치시킨다. 탄속·발사 수·데미지·저장 형식은 제안 범위 밖이다.

## 산출물·검증

- `turret-vfx-storyboard.png`: 발사·비행·명중을 나눈 정지 시안 1장, 불투명 PNG. 실제 적용 화면·실제 애니메이션·로딩용 스프라이트 시트가 아니다.
- `prompt.txt`: 내장 ImageGen 생성 프롬프트.
- 시안의 포탑·적 외형은 설명용이며 리디자인 제안으로 취급하지 않는다. 효과 크기는 확대 비교용이다.
- 시안에서는 형태와 단계별 차이를 확인했다. 실제 속도·배속·다수 포탑 상태·성능 검증은 구현 단계에서 수행한다.
- 게임 코드를 변경하지 않았으며 Flutter 검사·빌드는 수행하지 않는다.
