# 냉각 포탑 표면 서리 시안

사용자 요청: 구현된 3D 샘플의 형태를 변경하지 않고 서리가 더 묻은 이미지 시안.

- 기준: [현재 Blender 모델 렌더](../production/detail-refinement/detail-hero.png).
- 결과: [표면 서리 시안](frost-coated.png).
- 제작: 내장 ImageGen 이미지 편집. [전체 프롬프트](prompt.txt).
- 3D 적용: [Blender 원본·Godot 적용과 검증](integration/README.md).
- 표면 처리: 상판 가장자리·볼트 주변·기둥 테두리·하부 접합부에 얇은 청백색 결정성 서리. 금속과 청록 냉각핀을 드러내고 기존 6개 판과 틈·기둥·렌즈·지지발 구성을 보존하는 방향이다.

이 이미지는 사용자 승인된 표면 재질 기준이다. 시안 생성 단계에서는 Blender 메시·게임 에셋·효과 코드를 변경하지 않았으며, 이미지 자체를 실제 3D 재질이나 게임 렌더 검증 결과로 사용하지 않는다.
