# 파이프·배기구 경량판 독립 검수

**PASS.** 실제 스테이지 11의 동일 배치·forge 조명·카메라에서 원본과 경량판을 직접 비교했다. 열린 엘보 입구, 연결관의 금속/열창, 배기구의 중공 굴뚝과 주황 3슬롯, 벽 접합과 기단 연결이 유지된다. 원거리에서 의미 있는 식별 정보 손실은 발견하지 못했다. 미해결 결함 없음.

실제 스테이지 11 배치(엘보 2 + 연결관 2 + 배기구 1)는 **174,292 → 38,268삼각형, 78.04% 감소**다. GLB는 **8,091,672 → 4,026,984바이트, 50.23% 감소**다. 공유 1재질·종별 1메시/1표면을 유지한다.

## 독립 근거

- 두 GLB를 직접 파싱해 세 이름/identity 루트, 부품별 정점 AABB 동일(최대 오차 0), 벽면 local Z=0·안쪽 침범 없음·기단 Y≥-.505를 확인했다. 배기구는 Y=-.5까지 내려오고 승인 굴뚝 높이를 유지한다.
- 삼각형 ray 검사로 연결관 양 끝 관통, 엘보의 열린 상향 깊이, 굴뚝의 깊은 중공 및 전면 세 슬롯의 매립된 깊이를 각각 확인했다. [수치 결과](asset-comparison.json), [검사 스크립트](check_glb.py).
- 경량 라이브러리의 자동 배치도 원본과 5개 종류·칸·방향이 동일하다. 비교 렌더는 원본이 선택한 변환을 양쪽에 고정했다. 종류별 크기 조정은 없다.
- 게임 원본 SHA `c4eb491ef578b6e91219b75b3a854ad4bb3b4b3e565cd0d866d55a5daacd7952` 유지. 검수 경량 SHA `00f95bb711cfd703726bd164a73065df6007c10cac6875042d59bc113a8130bd`.
