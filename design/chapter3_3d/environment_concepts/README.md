# 챕터 3 환경 소품 멀티뷰 시안

2026-09-18 요청에 따라 컨셉 이미지의 배관과 짧은 배기구를 확장한 이미지 설계. [Blender 시안 제작](../environment_props/README.md) 후 승인받아 [스테이지 11 외곽 장식](../stage11/environment-props/README.md)으로 이식했다.

- [멀티뷰 이미지](foundry-props-multiview.png): 정면·측면·상면·타일 장착 사선 뷰.
- 01 엘보 파이프: 외곽 모서리 서비스 받침에 장착하는 짧은 굽은 관.
- 02 측면 연결관: 타일 수직 측면에 두 고정대로 부착. 상면의 이동·건설 영역은 비운다.
- 03 배기구: 속이 빈 짧은 굴뚝과 전면 세 줄 열 배출구. 외곽 받침에 장착.
- 재질은 현재 타일의 청흑색 주철·절제된 청동·국소 주황 열기에 맞춘다. 전체 표면 발광과 높게 솟은 장식은 피한다.

참조: [사용자 컨셉](../stage11/reference-fix/target.jpg), [현재 타일 원본 렌더](../export/glb-reimport-hero.png). ImageGen 내장 도구 사용. [생성·수정 프롬프트](prompts.md).

이미지는 형태 설계 기준이며 치수 도면은 아니다. 제작 시 실제 1타일 크기에 맞춰 외곽 돌출·시야 가림을 검증한다. 최초 생성에서 엘보 정면이 측면과 중복되고 연결관의 전면 열 창이 상면에도 나타나 해당 뷰를 수정했다. 볼트 세부 수·투영의 미세한 차이는 실제 원본의 공통 구조로 정리한다.
