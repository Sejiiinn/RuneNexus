# 벽체 연결형 환경 설비 멀티뷰

2026-09-18. 얇은 선반에 소품을 올린 느낌을 개선하는 이미지 설계안. ImageGen 내장 도구 사용. 사용자 승인 후 [Blender 원본](../../environment_props/README.md)과 [스테이지 11](../../stage11/integrated-mounts/README.md)에 반영했다.

- 최종: [멀티뷰 v2](multiview-v2.png). 왼쪽부터 정면·측면·상면·사선. 원본 부품의 세부 형태는 향후 공통 3D 모델에서 일관되게 정리한다.
- 엘보: 얇은 받침 삭제, 벽에 체결한 두꺼운 플랜지에서 관이 나와 위로 굽는다. 보어를 유지한다.
- 배기구: 별도 선반 삭제, 타일 기단 높이까지 이어지는 돌출 하우징과 짧은 굴뚝. 전면 매립 열 창 3개.
- 연결관: 두 고정대를 벽에 체결, 기존 청동 끝단과 전면 열 창 유지.

청흑 철재·절제된 청동·국소 주황 열기를 유지하며 이동·건설 상면을 비운다. v1 상면도에 중복된 연결관 열 창을 v2에서 제거했다. 정밀 치수 도면이나 실제 Blender 렌더가 아닌 제작 방향 시안이다.
