# 스테이지 12 3D 전장

기존 11×7 맵 좌표·길·건설칸·포탈·코어를 보존하고, 스테이지 11에서 승인된 두꺼운 금속 타일과 벽체 연결형 엘보·연결관·배기구를 재사용한다. 새 모델이나 별도 텍스처는 추가하지 않는다. 원 없는 설치칸과 원형 설치칸, 길/건설칸의 드문 매립 환기구, 이동 경로 그레이팅을 같은 규칙으로 배치한다.

표시 범위는 Android 1~12이며 13~15는 기존 2D를 유지한다. 저장·웨이브·전투·해금 조건은 변경하지 않는다.

검수는 같은 Android17 arm64 에뮬레이터·1080×2424·Godot4.7.2·기본 MSAA2x/높음 그림자·공용조명에서 진행한다. 별도 godotpreview 앱에서 실제 RuneNexusApp/HUD를 사용하며, `android_preview.dart`는 메모리 저장과 11개 스테이지 해금으로 일반 설치본 진행을 보존한다. 디버그바는 끈다.

사용자 요청에 따라 형상·배치·장 전환은 자동 검사하고, 메뉴 이동은 XML로 처리하며 최종 인게임 대표 화면만 캡처한다. Blender/에셋은 입력이 동일하므로 다시 렌더하지 않는다. 공개 배포 없음.

검증 완료: 타일46·그레이팅6·매립환기구4·소품5(엘보2/연결관2/배기구1). 기존3칸간격에서5개가 확보되지 않는 맵만2칸간격으로 재선정하며 실제모델 간격.12·플레이 영역·환기구 회피는 유지한다. 스테이지11 기존좌표는 그대로다.

Flutter 관련18개 테스트·analyze PASS, 패키징 준비 테스트 PASS, Godot11·12 및 장전환 실렌더러 검사0fail. 로그 `flutter-tests.log`, `flutter-analyze.log`, `preparation-test.log`, `runtime.log`.

Android 최종 시각 확인 PASS: [고정 시점](android-stage12.png), [포탑 설치 후 드론 시점](android-drone.png). 총2장으로 새11×7 맵의 가림·잘림·부착을 확인했고 메뉴/설치조작은 XML을 사용했다. 건설입력에서 금액170→110, 전투력15.9, 기관총레벨1 확인(`ui-built.xml`). 기존 HUD와 포탈·코어를 유지한다. 장시간 전투·실기기 성능 측정은 이번 범위에 포함하지 않았다.
