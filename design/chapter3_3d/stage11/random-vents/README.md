# 설치 타일 포함 무작위 환기구 배치

사용자 지적에 따라 격자 타일 가까운 순서로 뽑던 잘못된 우선순위를 제거했다. 길·원형 설치 타일·원 없는 설치 타일의 노출된 측면 전체를 후보로 삼는다. 맵 데이터에서 얻은 seed와 별도 RandomNumberGenerator를 사용하며 같은 맵의 재구성·앱 재진입 시 위치를 유지한다. 전투 난수와 저장 데이터는 바꾸지 않는다.

무작위 후보에서 원형·원 없는 설치칸과 길을 각각 포함하고 나머지는 전체 후보에서 선택한다. 타일당 최대 한 면, 인접 칸에 과하게 몰리지 않도록 하며 총 5개를 유지한다. 막힌 패널/환기구의 동일 교체 슬롯을 사용한다.

스테이지11 최종 선택(index, side): 31/1 평판 설치칸, 35/0 길, 42/1 길, 65/0 원형 설치칸, 78/0 원형 설치칸. 설치칸3+길2. `layout.log` 참조.

실제 렌더러 검증: 53타일·5격자·212패널·5환기구, 모든 종류의 후보 포함·노출 측면·원점/회전·공유 메시·반복 생성 안정성 검사 0 failures (`runtime-check.log`). 환기구 GLB·깊이·발광·타일 메시·설치 계약·카메라·조명은 이전 열기 가독성 수정판과 같다.

[최종 실제 Android 화면](android-stage11.png). 아래쪽 원형 설치칸 두 곳과 길의 전면 환기구가 읽히며, 원 없는 설치칸의 오른쪽 측면 환기구는 고정 시점의 좁은 측면 각도에서 가려진다. 해당 배치는 실제 렌더러 검사에서 원점·방향·모델을 확인했다. 같은 Android17 arm64 검수 앱, RuneNexusApp/Godot/HUD 및 메모리 저장 격리, 기본 MSAA2x/높음 그림자 조건이다. 빌드 성공, 원본 GLB는 직전 판과 동일. 입력 해시 final-inputs.json, 패키지 기록 apk-audit.json. 공개 배포 없음.
