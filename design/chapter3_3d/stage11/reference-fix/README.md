# 사용자 참조에 맞춘 용광로 외형 수정

기준: [사용자 제공 이미지](target.jpg). 이전 `../verification/android-stage11-built.png`는 밝은 회색 타일·큰 금색 링·약한 측면 깊이로 목표 외형 재현 실패였다. 메시 연결이나 테스트 통과를 외형 완료로 해석했던 판정을 정정한다.

기존 8×10 스테이지 11의 경로·건설 가능 위치·53개 타일·5개 격자는 보존한다. 참조 이미지의 다른 맵 배치나 포탑 종류·수치는 복제하지 않는다. Blender 원본에서 청흑색 건설판, 가는 청동 링과 둥근 볼트, 철판 테두리·리벳, 격자 속 열판과 케이싱 주황 슬롯을 제작했다. 원본과 GLB는 `../../tiles/README.md`, `../../export/README.md` 참조.

Godot은 별도 내장 반사 하늘과 용광로 전용 조명으로 금속 표면이 회색으로 뜨는 문제를 줄인다. 고정 시점 고도는 약 63°→55°로 낮춰 하부를 보인다. 드론 시점 및 다른 장의 시점은 유지하며, 장 전환 시 공용 하늘·조명이 복원되는 것을 검사한다. 런타임 메시 스케일이나 평면 명암으로 입체를 대체하지 않는다.

Android 검증은 이전과 같은 별도 godotpreview 앱의 실제 RuneNexusApp·Godot·HUD, 메모리 저장 진입점을 사용한다. production 저장은 보존한다. 현재 Android 17 arm64, Godot 4.7.2, 1080×2424, 기본 MSAA2×/높음 그림자 설정이다.

최종 몸체 깊이는 0.50이다. 0.34 깊이의 첫 재질 수정 캡처 `android-stage11.png`에서도 측면이 참조보다 얇아 후속 수정했다. 상판 아래 -0.065보다 낮은 케이싱·하부·벤트만 늘리고, 상판·링·격자/내부 열판의 좌표와 재질은 보존했다. 런타임 축 스케일은 1이다. 최종 GLB SHA-256 `7825ba07acc4357b5a2b658fc7698234551ea0135b1603a9bae58a07dc8cbf16`.

초기 재질 수정 상태에서 Android 실제 터치로 기관총 설치(170→110G, 전투력15.9) 및 선택 해제를 확인했다. `build-check-installed.png`는 전투 시작 전 실제 설치 상태다.

최종 Android 캡처: [전장](android-stage11-final.png), [포탑 설치](android-stage11-final-built.png). 어두운 건설판/청동 고정부, 회색 길, 깊은 측면과 주황 격자·슬롯이 구분됨을 확인했다. 수정 전보다 핵심 소재와 깊이 대비가 회복되었다. 참조의 배관 소품·다른 맵 실루엣까지 동일한 결과라고 판정하지 않는다. 최종판에서도 실제 터치 설치와 금액·전투력 변화를 확인했다.
