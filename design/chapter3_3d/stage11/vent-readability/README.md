# 환기구 열기 가독성 복원

사용자는 교체형 패널로 바꾸기 전처럼 세로 주황 슬롯이 잘 보이는 표현을 요청했다. 이전 .092 깊이의 환기구는 실제 내부 구조가 있었지만 55도 인게임 시점에서는 점처럼 작게 보여 부족했다. [수정 전](before.png).

이번 변경은 환기구 패널만 대상으로 한다. 원형10/평판18 혼합·환기구5개 배치·막힌 패널·타일 상판·맵·조명·카메라는 유지한다. 실제 빈 개구부와 격자·입체 열원은 유지하되 열원을 전면 쪽으로 옮기고 보이는 세로 개구부를 확보한다. 깊이 수치보다 이전의 분명한 주황 슬롯과 실제 매립 구조를 함께 살리는 것이 완료 기준이다.

최종 프레임 Z=.485, 열원 Z=.465, 실제 후퇴 .020. 개구 높이 .200·열원 폭 .044로 세로 슬롯을 복원했으며 발광 강도는 유지했다. 다른 네 타일과 막힌 패널 원본 메시 보존, 좌석 ray 검사, GLB 6루트 재임포트 오차0 검사 통과.

[최종 Android 화면](android-stage11.png): 고정55도 실제 게임 크기에서 전면 두 환기구의 주황 세로3슬롯이 읽힌다. 같은 Android17 arm64 검수 앱에서 production RuneNexusApp/Godot/HUD, 메모리 저장 격리, MSAA2x/그림자높음으로 확인했다. 이전 혼합 타일·설치 입력·회전 배치 검증 코드와 원점 계약은 변경하지 않았다.

패키지 크기·입력 해시는 final-inputs.json, PCK 상세는 apk-audit.json. 단일 arm64 ABI, 중복 payload0, 원본 GLB/Blender/design 중복 포함 없음. 공개 배포 없음.
