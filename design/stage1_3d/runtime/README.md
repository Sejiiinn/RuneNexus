# 스테이지 1 실제 웹 실행 검수

2026-09-10. Blender 렌더가 아닌 Flutter 웹 앱의 실제 실행 기록이다. Mac 잠금으로 데스크톱 창 조작을 진행할 수 없어 새 임시 프로필의 헤드리스 Chrome으로 동일한 로컬 앱을 조작했다. 계정·정식 저장을 사용하지 않았다.

- `stage1-live-combat.png`: 440×900 기본 시점의 실제 전투 화면.
- `stage1-gameplay.mp4`: 약 15.2초, 440×900 H.264. Chrome 합성 화면을 약 30fps로 기록하고 실제 캡처 타임스탬프로 인코딩했다. 게임 성능 벤치마크는 아니다.
- `stage1-pan-zoom.png`: 실제 포인터 드래그와 터치 핀치 확인 기록.
- `verify_web.cjs`: 로컬 시험 앱 진입, 테스트 골드 추가, 기관총·대포·냉각 설치, 웨이브 시작 및 실제 Chrome 합성 화면 기록.
- `encode_capture.swift`, `verify_video.swift`: macOS AVFoundation 인코딩 및 3개 시점 디코딩 검증.

확인: 지형/GLB 로딩, 정확한 타일 선택, GLB 건설 미리보기·설치, 포탑 조준·발사, 적 이동·체력바, 처치 골드, 1웨이브 완료 후 2웨이브 준비, 카메라 확대·이동, 기존 HUD의 비용·문구 표시. 최종 브라우저 검사에서 런타임 오류는 없었다(플랫폼 뷰의 기본 width/height 경고만 존재).

정적 분석·전체 Flutter 테스트 통과. 표시 입력의 저장 불변성/입력 역변환·실제 카메라 투영·초기화 전 위젯 종료·디버그 패널 동작은 별도 관련 테스트로 확인했다. 웹 빌드는 인앱 검증용 디버그 플래그를 포함한 로컬 빌드다. 배포하지 않았다. Android/iOS/데스크톱 네이티브의 실기기 성능과 회전·종료는 미검증이다.
