# 고사리 군락 그림자

2026-09-13 사용자 요청: 고사리 아래에 잎 하나하나가 아니더라도 읽히는 그림자가 필요하다.

잔잎 자체의 그림자는 켜져 있었지만 가는 잎과 틈 때문에 게임 크기에서 차폐가 약했다. 첫 결과는 잎층별 외피를 12% 축소해 그늘이 작고 나뉘었다. 사용자 피드백에 따라 축소를 제거하고 여섯 잎층 전체의 끝을 감싸는 군락 외피로 바꿨다. 수평 범위는 원본 잎 덮개에 맞추고 높이를 바닥 가까이 낮춰 잎 본체를 어둡게 덮지 않는 넓은 접촉 그림자로 수정했다. 외피는 Godot `SHADOWS_ONLY`로만 렌더하며 본체 색·형태·배치는 변경하지 않았다. 바닥에 검은 판을 표시하지 않는다.

- 원본: [fern-shadow-proxies.blend](../../fern-shadow-proxies.blend), Scene `Fern Canopy Shadows`. [생성 코드](../../build_fern_shadows.py)는 기존 식물 마스터와 배치 manifest를 읽는다.
- 게임: `assets/images/stage1_3d/environment/fern_shadow.glb`, 한 메시·1,200삼각형·152,616바이트·텍스처 0. 기존 고사리 마스터 해시 `4eb09cf6c7503f720c4b5bc69f29a89b3e566e9ce20ed992aa165acaa7a667d7` 보존.
- 바람·건설 점유는 실제 식생과 같은 ShaderMaterial을 공유한다. 건설 슬롯 1·6·27·21에 설치하면 고사리와 그림자가 함께 숨고 철거하면 복구된다. 맵 전환·재진입도 지형 수명에 연결한다.

- 같은 데스크톱 장면의 드로콜은 81→82, GPU primitive 계수는 138,625→142,579이다. 그림자 패스 한 번이 추가되며 모바일 성능 수치로 해석하지 않는다.
