# 식생 풍성함 확대와 전체 에셋 캡처

확인: 2026-09-12. “아직 시안같은 풍성함은 없네” 피드백에 따라 Astra 하위 에이전트가 대표 군락의 수평 피복을 확대했다. 이전의 [1차 형태 개선](../art-directed-20260912/README.md) 이후 수행한 군락 확대의 과거 검증 기록이다. 현재 게임은 [독립 마스터 11종의 맵 적용](../master-assets-20260912/README.md)을 사용한다.

## 결과

- [전체 식생 88개를 모은 한 장](../../foliage-catalog-20260912.png): 영구 61개·설치 시 숨기는 중앙 27개를 같은 배율로 배열한 Blender 원본 렌더. 번호·종류·타일·중앙/영구 구분은 [목록 데이터](../../foliage-catalog-20260912.json)에 대응한다. 지형·돌·뿌리는 제외했다.
- [실제 Android 고정 시점](final-fixed.png), [드론 시점](final-drone.png), [4배속 연속 사격](final-4x.png). 별도 검수 APK의 실제 화면이며 제작 렌더와 구분한다.
- [확대 전 같은 화면](baseline-fixed.png)과 비교해 여섯 초점에서 돌 주변부터 빈 타일 안쪽까지 큰 부채·중층 잎·지피가 연속해서 이어진다. 선택한 일곱 칸에 중간 밀도 연결 군락을 배치했다. 길·포털·코어와 포탑 가독성을 확인했다.

대표 중앙 군락의 윤곽은 폭 약 0.91타일·깊이 약 0.81타일이다. 기존 높이 범위에서 수평 피복을 넓혔다. 기존 지형·카메라·전체 조명·바람 셰이더·전투 규칙은 변경하지 않았다. 최종 에셋은 두 메시·두 재질·22,766삼각형·추가 텍스처 0, GLB 1,532,092바이트다.

## 성능과 용량

Android 17 ARM64 에뮬레이터, 1080×2424, 확대 1.0×, 대포 6문·표적 3기, 그림자·폭발 볼륨 켜짐. 표본 수집 중 Blender 렌더·APK 빌드를 함께 실행하지 않았다.

| 상태 | 확대 전 UI 표본 3개 | 확대 후 UI 표본 3개 |
| --- | --- | --- |
| 고정·정지 FPS | 60, 58, 60 | 60, 59, 58 |
| 고정·정지 프레임 시간 | 16.8, 17.4, 16.7ms | 16.8, 16.9, 17.2ms |
| 4배속 사격 FPS | 58, 58, 58 | 58, 57, 54 |
| 4배속 사격 프레임 시간 | 17.3, 17.2, 17.2ms | 17.3, 17.6, 18.5ms |

정지 드로 콜은 전후 70으로 동일하다. 1초 단위 UI 표본이며 폭발 단계·주변 부하에 따라 달라진다. 성능 향상이나 실기기 수용 통과를 뜻하지 않는다. 실기기는 연결되지 않아 장시간 전투·프레임 백분위·메모리·발열은 미측정이다.

검수 APK는 229,691,429→229,798,725바이트로 107,296바이트(+0.047%) 증가했다. PCK 디렉터리의 내용 해시 비교에서 변경된 파일은 장식 장면 하나뿐이다. 기존 텍스처·엔진·Flutter 자산·ARM64 구성은 동일하며, 장식의 Flutter 중복 포함과 `design/` 원본 포함은 0이다. 앞선 버전에서 발생한 기존 텍스처 재임포트 용량 변화는 [이전 기록](../art-directed-20260912/README.md)에 별도로 남아 있다.

- 검수 APK: `build/apk-preview/rune-nexus-stage1-environment-lush-arm64.apk`.
- 본게임 APK: `build/apk-main/rune-nexus-stage1-environment-lush-arm64.apk`, 233,731,077바이트, 디버그 패널 없음.
- 공용 PCK SHA-256: `ed25ec8eb25ef53230c71c15b7397980ae93107d5e7e498e87eca0ca35bf8e6e`.

로컬 검증 결과이며 커밋·푸시·공개 배포는 수행하지 않았다.
