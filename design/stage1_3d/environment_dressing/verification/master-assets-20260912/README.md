# 독립 마스터 11종의 맵 적용 검증

확인: 2026-09-12. 식물 4종과 추가 환경 장식 7종의 저장된 Blender 메시를 스테이지 1 장식으로 연결했다. 로컬 `../lush-20260912/`의 이전 군락 확대 이후의 현행 적용 기록이다.

## 결과와 실제 화면

- [Android 고정 시점](final-fixed.png), [드론 시점](final-drone.png), [4배속 사격](final-4x.png): 별도 검수 APK의 실제 화면. 길·포털·코어와 포탑의 가독성, 고사리·넓은 잎·흰꽃의 구분을 확인했다.
- [본게임 로비](main-launch.png) → [스테이지 1](main-stage1.png): 일반 `lib/main.dart` APK를 기존 데이터 위에 설치하고 저장된 스테이지를 이어서 열었다. 보상 선택 화면 뒤에서 새 3D 장식과 기존 포탑·HUD가 로드됐다. 기존 보상은 선택하지 않았다.
- [변경 전 고정 시점](baseline-fixed.png), [변경 전 드론](baseline-drone.png): 기본 형태로 구성했던 이전 장식의 비교 자료다. 독립 원본과 기존 파일의 해시는 [적용 전 기록](baseline-artifacts.json)에 보존했다.

맵의 여섯 권역에 돌·고사리·중층 잎·풀·낮은 이끼를 서로 겹치게 두고, 흰꽃 세 군락과 덩굴 네 곳, 뿌리 세 곳을 선택 배치했다. 총 58개 인스턴스 중 식생은 45개, 정적 돌·뿌리는 13개다. 식생 27개는 건설 시 숨고 철거 후 복원되며, 영구 식생 18개는 남는다. 독립 마스터는 11종이다.

최종 출력은 **2메시·2재질·23,964삼각형**, GLB **1,552,836바이트**, 추가 텍스처 0이다. [원본·배치 명세와 편집 절차](../../README.md)를 따른다. 독립 원본 세 파일의 SHA-256은 적용 전과 모두 일치한다. 원본은 보존하고 맵 복사본의 LOD로 기존 예산을 유지했다. 단순화가 실측 병목 때문에 반드시 필요했다고 판단한 결과는 아니다.

실제 화면 보정은 외곽 돌의 눌린 폭·높이·위치·각도를 한 차례 조정했다. 고사리 접합과 자갈 변환의 구조 결함은 독립 검토에서 확인하고 수정했다. 이후 별도 디자인 반복은 하지 않았다. 카메라·전체 조명·바람 셰이더·전투 규칙은 이번 변경 대상이 아니다. Dart 변경이 없어 Flutter 분석·전체 테스트는 반복하지 않았으며 두 Android release 빌드와 변경된 Python 구문 검사, Godot 실행 검사를 통과했다.

본게임의 저장된 상태는 5웨이브 보상 선택 대기였다. 보상·재화·건설 상태를 변경하지 않아 본게임 건설·철거 UI 조작은 이번에 다시 수행하지 않았다. 해당 동작은 같은 장면의 GPU 검사로 확인했다.

## GPU 픽셀 비교의 허용 범위

기존 바이트 완전 일치 검사에서 슬롯 16 영역 6,970픽셀 중 1~2픽셀의 한 채널이 1단계 차이로 실패했다. 설치 슬롯 0에서는 493픽셀·최대 채널 차이 89가 발생했고 철거 후 전체 화면은 완전히 복원됐다. 추가 정착 프레임 후에도 제어 영역의 최대 차이는 1이었다. [진단 수치](occupancy-pixel-diagnostic.json)와 [진단 로그](godot-occupancy-settled.log)를 보존했다.

`godot/verify_environment.gd`는 설치 영역에 **1보다 큰 실제 변화**를 요구하고, 미설치 제어 영역은 **8비트 채널 1단계**만 허용한다. 철거 후 전체 화면의 완전 일치 조건은 유지했다. 제품 셰이더를 변경하지 않았으며, 실제 식생 제거와 채널 한 단계의 래스터 오차를 구분한다.

## 성능과 APK 용량

Android 17 ARM64 에뮬레이터, 1080×2424, 확대 1.0×, 대포 6문·표적 3기, 그림자·폭발 볼륨 켜짐. 표본 수집 중 Blender 렌더와 APK 빌드는 실행하지 않았다.

| 상태 | 적용 전 UI 3표본 | 적용 후 UI 3표본 |
| --- | --- | --- |
| 고정·정지 FPS | 60, 59, 58 | 60, 59, 57 |
| 고정·정지 프레임 시간 | 16.8, 16.9, 17.2ms | 16.7, 17.1, 17.7ms |
| 4배속 사격 FPS | 58, 57, 54 | 58, 56, 58 |
| 4배속 사격 프레임 시간 | 17.3, 17.6, 18.5ms | 17.3, 17.8, 17.3ms |

고정 상태 드로 콜은 전후 70으로 같다. 이는 1초 단위 UI 표본이며 실기기의 지속 프레임·GPU 시간·메모리·발열 수용을 뜻하지 않는다. 실기기는 연결되지 않았다.

검수 APK는 **229,798,725→229,877,189바이트**, **+78,464바이트(+0.034%)**다. PCK 내용 해시 비교에서 변경된 파일은 임포트된 장식 장면 하나뿐이다. 기존 텍스처·엔진·네이티브 ARM64 라이브러리·Flutter 자산은 동일하며, 장식 GLB의 Flutter 중복 포함과 `design/` 원본 포함은 없다.

- 검수 APK: `build/apk-preview/rune-nexus-stage1-environment-masters-arm64.apk`.
- 본게임 APK: `build/apk-main/rune-nexus-stage1-environment-masters-arm64.apk`, 233,809,541바이트, 디버그 패널 없음.
- 공용 PCK SHA-256: `cbac69c636e334d2b07acd97f500f34ec7cbdf82fb18d20d71209102c1e0bae5`.

본게임 최초 로컬 설치는 기존 versionCode 2002보다 낮은 기본 2001로 인해 차단됐다. `--build-number=2002`로 로컬 APK만 기존 설치본과 맞춰 재빌드·설치했으며, `pubspec.yaml`의 버전이나 배포 설정은 변경하지 않았다. 데이터 삭제·강제 다운그레이드는 하지 않았다.

Blender 허브는 새 조립본과 독립 원본 연결을 반영했고 `USER_` 메모를 보존했다. 커밋·푸시·공개 배포는 수행하지 않았다.
