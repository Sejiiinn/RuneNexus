# 환경 장식 원거리 시점 개선 검증

역할: 1차 형태 개선의 검증 기록. 이후 사용자의 “아직 시안같은 풍성함은 없네” 피드백에 따라 군락 피복 면적을 추가 확대했다. 현행 결과는 [풍성함 보정 검증](../lush-20260912/README.md)을 따른다. 아래 화면·수치는 추가 확대 전 버전이다.

확인: 2026-09-12. Astra 하위 에이전트가 Blender 원본·생성기·출력을 수정하고, 통합 검증에서 원거리 형태·잎 법선·대표 군락의 겹침을 보정했다. 기존 지형·카메라·전체 광원·바람 셰이더·전투 규칙은 이번 개선에서 변경하지 않았다.

- [Blender 제작 렌더](../../blender-preview-0001.png)는 실제 앱 캡처가 아니다. [데스크톱 Godot 보조 캡처](final-godot-angled.png)도 Android 검수와 구분한다.

상단 우측·우측 중단·하단 양쪽의 대표 군락에서 고사리, 굽은 넓은 잎, 낮은 지피와 회색 이끼돌이 겹친다. 내부의 드문 식생과 밀집 군락 사이에 밀도 차이가 있으며, 이동 경로·포털·코어와 포탑이 계속 읽힌다. 시안의 원거리 구성·종류 구분·겹침을 기준으로 확인했으며, 미세 텍스처나 픽셀 일치를 검증한 것은 아니다.

관련 근거: [원본 검사](../../source-verification.json), [환경 GPU 로그](godot-environment.log), [공용 런타임 로그](godot-runtime.log), [Android 로그](final-logcat.txt), [수치·해시 종합](comparison.json).

환경 GPU 검사는 바람 시간을 고정하고 포탑 본체를 가린 뒤, 슬롯 0의 중앙 식생 제거·복원과 슬롯 16의 불변을 픽셀로 검사한다. 기존 검사가 사용하는 기본 880×760 설정에서 통과했다. 중간 모델 검증에 임의로 `--resolution 1080x1440`을 붙인 보조 실행에서는 두 픽셀 단정이 실패했다. 크기 변경과 캡처 시점의 관계는 별도 분석하지 않았으며, 이를 제품 결함이 수정됐다는 근거로 사용하지 않았다.

본게임은 일반 release APK 빌드와 내장 팩의 동일성을 검사했다. 이번에는 본게임의 보상 선택·건설 UI를 통한 진행을 다시 수행하지 않았다. 중앙 식생의 설치·철거 회귀는 위 공용 장면 GPU 검사로 확인했다. Dart 코드 변경이 없어 Flutter 분석·전체 테스트를 반복하지 않았다.

## 성능 표본

Android 17 ARM64 에뮬레이터 `emulator-5554`, 1080×2424, 확대 1.0×, 그림자·폭발 볼륨 켜짐. 같은 검수 배치에서 각 상태의 1초 단위 UI 수치 3개를 기록했다. 최종 표본 수집 중 Blender 렌더나 APK 빌드를 함께 실행하지 않았다.

| 상태 | 이전 APK FPS / 프레임 시간 | 최종 APK FPS / 프레임 시간 |
| --- | --- | --- |
| 고정·정지 | 59, 60, 59 / 17.0, 16.7, 16.9ms | 60, 58, 60 / 16.8, 17.4, 16.7ms |
| 고정·4배속 연속 사격 | 57, 54, 58 / 17.5, 18.4, 17.3ms | 58, 58, 58 / 17.3, 17.2, 17.2ms |

정지 장면의 드로 콜은 전후 모두 70이다. 장식 원본은 23,628→19,658삼각형으로 약 16.8% 감소했고, 두 메시·두 재질·추가 텍스처 0을 유지했다. 이 수치만으로 실성능 향상을 단정하지 않는다. 아래의 기존 텍스처 import 형식 차이 때문에 APK 간 FPS 차이를 장식만의 효과로 분리할 수도 없다. 폭발 단계에 따라 전투 중 드로 콜과 삼각형 수가 변한다.

실기기는 연결되어 있지 않았다. 이 검증은 실기기의 지속 전투, 95/99백분위 프레임 시간, 메모리·발열 수용 검증을 대신하지 않는다.

## APK 용량과 전달 파일

| 대상 | 이전 | 최종 |
| --- | ---: | ---: |
| 같은 ARM64 검수 APK | 219,825,369B | 229,691,429B |
| 내장 Godot PCK | 47,438,448B | 57,304,508B |
| PCK 안의 장식 장면 | 950,061B | 853,906B |
| 원본 dressing.glb | 1,993,372B | 1,338,828B |

APK는 9,866,060B(+4.488%) 증가했다. 증가분은 전부 공용 PCK다. 기존 지형·포탑 등의 텍스처가 재임포트되며 기존 `.ctex`에서 `.etc2.ctex`로 교체된 결과다. 저장소의 기존 Android ETC2 설정은 변경하지 않았다. 장식 장면 자체는 96,155B 감소했다.

ARM64 네이티브 라이브러리 8개의 이름·바이트 수, Flutter 에셋과 기존 Flutter 3D 에셋은 이전 APK와 동일하다. 장식의 Flutter 중복 포함과 `design/` 제작 파일 포함은 0건이다. PCK는 모바일용 텍스처를 로드하며 이전 텍스처와의 중복 포함은 확인되지 않았다. 기존 다른 렌더러 의존성·공용 3D 자산은 실제 기존 경로에서 사용하므로 이번 장식 변경에서 제거하지 않았다. ZIP/PCK 항목과 무결성은 [이전 패키지](baseline-package.json), [최종 검수 패키지](final-package.json), [최종 본게임 패키지](main-package.json)에 보존했다.

- 검수 APK: `build/apk-preview/rune-nexus-stage1-environment-refined-arm64.apk` — 위 실제 화면의 별도 설치 앱.
- 본게임 APK: `build/apk-main/rune-nexus-stage1-environment-refined-arm64.apk` — 일반 진입, 디버그 패널 없음, 233,623,781B.
- 두 APK의 PCK SHA-256: `56f73b086163911f702fa4992db04fec48422f1ad67223e76ef755d4596f173d`.

로컬 검증 산출물이며 공개 배포·커밋·푸시는 수행하지 않았다.
