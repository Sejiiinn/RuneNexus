# 스테이지 1 환경 요소 시안

2026-09-12 사용자 승인 시안. **실제 게임 적용 화면이 아니다.** ImageGen 내장 도구로 제작한 정적 콘셉트 이미지이며, 승인 후의 Blender 원본·Godot 구현·실제 검수는 [환경 장식 제작 기록](../environment_dressing/README.md)을 따른다.

- 시안: [돌길 가장자리의 풀과 이끼](01-overgrown-stone-edges.png), 1086×1448, 불투명 PNG, 1프레임.
- 기준: [현재 Android 본게임 화면](../main_runtime/stage1-camera.png). [승인 Blender 렌더](../actor_refinement/stage1-actors-refined.png)는 재질·시각 스타일 참고용이다.
- 재현 프롬프트: [prompt.txt](prompt.txt). 요청 크기는 근삿값이며 위 크기가 실제 생성 결과다.

풀·낮은 고사리·작은 이끼돌을 외곽에 불균일한 군락으로 배치하고, 타일 틈의 이끼와 측면의 짧은 뿌리로 연결하는 방향이다. 돌길과 건설칸 중앙을 읽기 쉽게 유지하며, 청록·녹회색·황갈색의 기존 전장 색을 따른다.

시안에서 전체 길의 연결, 포털·코어·두 포탑의 식별, 식생 군락과 석재의 구분을 육안 확인했다. 생성 이미지의 개별 타일·장식 좌표는 게임 배치 데이터가 아니다. 실제 구현은 게임 타일 배열을 기준으로 내부 식생까지 분산하고, 설치 시 중앙 식생만 숨기면서 가장자리·틈 식생과 이동 경로의 여유를 유지한다. 성능과 게임 적용의 검증 근거는 위 제작 기록에서 구분한다.
