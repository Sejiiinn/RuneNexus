# 그래픽 마감·발사 실제 웹 검수

2026-09-11. Flutter 웹 앱의 실제 전투 화면이다. Mac 잠금 상태에서 새 임시 Chrome 프로필의 헤드리스 실행으로 조작·녹화했다. 시안 렌더나 합성 영상이 아니다.

- `stage1-gameplay.mp4`: 입구 가까이 배치한 대포의 조준·발사·반동·착탄. 약 15.2초, 440×900 H.264.
- `machinegun/stage1-gameplay.mp4`: 기관총을 입구에 배치한 별도 사격 검수. 약 15.2초, 440×900 H.264.
- `stage1-live-combat.png`: 마감 후 실제 전투 화면.
- `cannon-impact.jpg`: 첫 영상에서 대포 착탄이 보이는 실제 프레임.
- `terrain-first-pass.png`: 배우 배치 전 시점·지형 검수.
- `verify_web.cjs`, `verify_machinegun.cjs`: 기존 테스트 패널로 골드 추가·포탑 설치·웨이브 시작 후 Chrome 합성 화면을 타임스탬프와 함께 기록한다.
- 인코딩은 `../runtime/encode_capture.swift`, 디코딩 확인은 `verify_video.swift`를 사용한다. 두 스크립트의 인자는 영상 디렉터리 절대 경로다.

확인: 기울어진 카메라의 전장 맞춤·타일 선택, PBR 지형·그림자, 포탑 설치·조준, 기관총 사격·짧은 탄환, 대포 반동·포구 효과와 지면/빌보드 착탄, 적 이동·피해 표시·처치 골드, 기존 HUD의 문구·비용 표시. 새 발사 PNG의 웹 경로를 수정한 최종 실행에서 리소스 오류와 JS 런타임 오류가 없었다. 플랫폼 뷰 기본 너비·높이 경고만 남았다.

검증: 정적 분석, 관련 Flutter 테스트 10개, 웹 빌드 통과. 두 MP4는 각 3개 시점의 H.264 디코딩과 방향을 확인했다. 캡처 프레임률은 게임 성능 벤치마크가 아니다. 계정·정식 저장은 사용하지 않았고 배포하지 않았다. 네이티브 실기기 검증 범위는 기존 시험 화면 문서와 같다.
