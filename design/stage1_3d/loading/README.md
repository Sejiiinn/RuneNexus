# 스테이지 1 3D 준비 화면

2026-09-13. Android 본게임 스테이지 1 진입에서 기존 2D 전장이 잠깐 보이던 구간을 공용 `AppStartupScreen`으로 가린다. 기존 룬 배경·코어·금속 프레임 진행 표시와 ‘3D 전장 준비 중’ 문구를 사용한다. 새 이미지나 네이티브 자원을 추가하지 않는다.

현재 장면과 화면 크기에 맞는 Godot 적용 응답을 받은 뒤 로딩과 입력 차단을 해제한다. 로딩 중 전투 시간·자동 웨이브는 멈추되 Flame 구성과 전장 프레임 전달은 계속한다. 앱 복귀도 새 장면 응답을 기다린다. 단순 경과 시간으로 정상 준비를 중단하지 않으며, 명시적인 렌더 오류에는 기존 2D 복귀를 유지한다.

검증: 관련 Flutter 테스트 13개와 정적 분석 통과. 첫 응답 지연(45초 포함), 초기 오류, 앱 복귀, 이전 장면 응답, view 제거·교체, 전투 정지와 프레임 생성을 확인했다. Android ARM64 에뮬레이터의 일반 `lib/main.dart` debug 앱에서 실제 로딩 화면과 준비 후 3D 전장·HUD를 확인했다. 에뮬레이터의 첫 3D 처리 시간이 30초를 넘었으므로 임의 시간 제한을 두지 않는다. 실기기 로딩 속도·지속 전투 성능을 측정한 검수는 아니다. 공개 배포와 커밋은 수행하지 않았다.
