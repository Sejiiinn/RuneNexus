# 공통 서리 패키지 감사

실제 `build/app/outputs/flutter-apk/app-debug.apk` 안의 PCK를 `scripts/audit_godot_pack.py`로 조사했습니다. APK에 든 PCK와 `build/godot/android-assets/rune_nexus.pck`의 SHA-256이 같습니다. 이전 종별 서리의 `runtime/pack-audit.json`은 유지했습니다.

| 비교 대상 | PCK 크기 |
| --- | ---: |
| 서리 추가 전 | 86,210,120 B |
| 종별 성에 텍스처·서리 메시 | 92,601,776 B |
| 공통 셰이더·결정·성에 데이터 | 86,698,680 B |

공통화로 PCK는 종별 방식보다 **5,903,096 B 감소**했습니다. 서리 추가 전 대비 증가분은 6,391,656 B에서 488,560 B로 **92.36% 줄었습니다**. 이는 패키지 용량 비교이며 프레임 성능이나 GPU 메모리 감소율이 아닙니다.

현재 공통 서리 payload는 487,547 B입니다. 주요 구성은 압축 마스크 217,331 B, 부착 위치 데이터 180,556 B, 임포트한 grain 텍스처 78,142 B, 공통 결정 메시 3,278 B이며 나머지는 스크립트·셰이더·임포트 정보입니다. 전체 PCK 증가분과 차이 1,013 B에는 메타데이터 및 기존 코드 변경이 포함됩니다.

- PCK 231개 항목, 논리적 중복 및 서로 다른 저장 구간의 중복 모두 0 B.
- 이전 6종 서리 장면과 12개 색·노멀 텍스처는 PCK에 남아 있지 않습니다.
- 원본 GLB·PNG, 디자인 `.blend`, `verify_` 파일은 PCK에 없습니다. Flutter 영역에도 GLB 중복이 없습니다.
- 실제 debug APK는 509,347,950 B로 이전 debug APK보다 5,903,096 B 작습니다. 공개 release APK와 비교한 수치는 아닙니다.
- 서리 외 기존 텍스처의 개별 시각 사용 여부까지 재검사하지 않았습니다.

상세 항목과 해시는 같은 폴더 `pack-audit.json`에 있습니다.
