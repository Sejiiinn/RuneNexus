# 공통 성에 데이터

`../bake_shared_noise.py`를 독립 Blender 백그라운드 프로세스에서 실행해 만든 공통 재질 데이터입니다. 승인 `.blend`의 Noise/ColorRamp 노드를 직접 복사하며, 원본 씬과 게임 적 메시를 변경하지 않습니다.

- `rime_mask.bin`: 런타임 폴더의 64³ R8 볼륨. Blender 로컬 XYZ 범위 `(-0.7,-0.7,-0.1)`–`(0.7,0.7,1.3)`. x가 가장 빠르고, 다음 y, 다음 z 순서입니다. 각 voxel은 중심 `(index+0.5)/64`에서 측정했습니다. GPU 선형 보간 샘플 좌표는 `(position-min)/(max-min)`입니다.
- Godot 로컬 좌표를 Blender로 되돌릴 때 `(x,-z,y)`를 사용합니다. 여섯 적의 전체 메시 범위가 도메인 안에 들어갑니다.
- 패치 마스크는 원본 Noise Scale 5.3 / Detail 3 / Roughness 0.68 및 0.42–0.56 ColorRamp의 결과입니다. 원시 noise가 아닙니다.
- `grain.png`: 런타임 폴더의 512² 비색상 RGB8 PNG로 R 채널을 사용합니다. 원본 미세 Noise의 Detail 2 / Roughness 0.5를 유지하고, Scale 1의 `(8u,8v,0)` 평면을 구웠습니다. 반복 사용 시 고주파 질감의 통계적 외형을 재사용하며, 원본의 전체 3차원 미세 무늬를 그대로 저장한 데이터는 아닙니다.
- `rime-mask-atlas.png`: 검수용 8×8 슬라이스 아틀라스. Blender 이미지 좌표 기준 아래쪽 행부터 z가 증가합니다.
- `manifest.json`: 메시별 범위, raw SHA-256, 값 범위 및 검증 결과입니다.

검증은 서로 다른 voxel 세 점을 동일 좌표의 상수 노드 베이크와 비교했고, R8 반올림 오차 안에서 일치합니다. PNG를 Blender에서 비색상으로 다시 읽었을 때 최대 오차는 약 0.001961로 RGB8 양자화 범위 안입니다. 이 검증은 볼륨 사이의 보간 오차나 런타임 조명 차이까지 같다는 의미는 아닙니다.
