# 대포 이펙트 단독 검수 영상

`effect-preview.mp4`는 게임 적용 전 Blender 장면을 렌더한 영상이다. 효과 1.1초를 정상 속도로 3회 반복하며, 시작 전후 빈 구간을 포함해 약 6.39초다. 640×640 H.264, 약 29.09fps. `effect-preview.png`는 같은 장면의 대표 프레임이다.

이전의 갈래 모양 화염을 연속 난류 체적으로 새로 구성했다. 뜨거운 화염만 발광하고 차가운 부분은 빛을 흡수하여 내부 주름을 드러낸다. 초기 석재 조명, 불티 70개, 작은 금속 파편 15개를 함께 렌더했다. 화염은 약 0.825초부터 사라지고, 먼지는 약 0.378초부터 남지 않는다. 마지막 프레임은 빈 바닥이다.

- 편집 원본: `impact-review.blend`. 본체 원본과 최종 재질은 상위 README 참조.
- 재현: `build_scene.py` → `render_scene.py` → `prepare_video.py` → 컴파일한 `encode.swift`.
- 검수: 초반·중간·마지막 렌더에서 형태, 잘림, 소멸 확인. H.264의 서로 다른 세 시점을 디코딩하여 방향·영상 내용 확인. 브라우저 정상 재생도 확인했다.
- `index.html`은 같은 영상을 재생하는 단독 페이지다. 정확한 위치 탐색은 영상 파일의 플레이어를 사용한다.

게임 코드와 게임에서 사용하는 에셋은 이번 검수 작업에서 변경하지 않았다.
