# 실시간 3D 착탄 적용 검수

2026-09-11. `stage1-gameplay.mp4`는 스테이지 1 시험 전장에서 실제 대포를 설치하고 첫 웨이브를 진행한 Chrome 실행 영상이다. Blender 단독 렌더나 이미지 시퀀스를 게임 위에 합성한 영상이 아니다.

- 착탄 화염·먼지는 텍스처 없는 48단계 체적 셰이더로 렌더한다. 불티 70개·금속 파편 15개는 실제 입체 인스턴스이며 탄도와 회전을 갱신한다.
- 전체 수명은 1.1초. 화염은 progress 0.75, 먼지는 0.34, 불티는 0.97에서 종료한다. 고정 PointLight 4개로 주변 지형·적·포탑의 빛 반응을 유지한다.
- 처음에는 밝은 부분이 과도하게 흰색으로 보여 게임의 AgX 처리에 맞춰 열원 범위와 발광을 보정했다. 최종 GPU 셰이더는 열원 임계값 0.42·배율 3.25, 발광 계수 16을 사용한다.
- 착탄 PNG 로딩은 제거했으며 중간 이미지는 `../production/`에만 보관한다. 기존 포구 섬광·포구 연기는 별도 경로다.

## 확인 결과

- `flutter analyze` 및 관련 테스트 8개 통과. 이미지 Sprite 없이 체적 재질·3D 파편을 쓰는지, 팽창·소멸·풀 재사용·광원 종료를 확인했다.
- 웹 빌드 및 실제 GPU 셰이더 컴파일·전투 렌더 확인. JavaScript·셰이더·HTTP 오류 없음. 기존 Platform View 크기 기본값 경고는 남아 있다.
- 초기 착탄, 유지 중 화염, 소멸 구간의 실제 화면을 확인했다. `stage1-impact.jpg`는 실제 녹화 프레임이다.
- 영상은 720×1080 H.264 약 14.57초이며, CDP가 기록한 874개 프레임의 시각을 보존했다. 서로 다른 세 시점에서 영상 디코딩·방향·내용을 확인했다. 이 캡처는 네이티브 기기의 성능 검증을 대신하지 않는다.

`verify_web.cjs` → `encode_capture.swift` → `verify_video.swift`로 실행·캡처·영상 검증을 재현한다. 인코딩은 프레임별 autorelease pool과 높은 타임스탬프 정밀도를 사용한다. 실제 효과는 `lib/game/rendering/stage1_3d/battlefield_impact_effects.dart`에 있다.
