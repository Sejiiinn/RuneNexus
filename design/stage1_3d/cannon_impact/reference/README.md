# 사용자가 지정한 이펙트 품질 참고

https://x.com/anshuc/status/2097821160981385696 — Anshu의 VESPER 데모(2026-09-10).

`anshu-demo.mp4`는 게시물의 공개 Twitter CDN 720p 원본을 검토용으로 내려받은 12.15초/60fps 영상이다. `reference-frame-0..7.png`는 0.5,2,3.5,5,6.5,8,9.5,11초 추출본이다. 제3자 참고자료이며 게임 에셋이나 자체 제작물로 사용하지 않는다.

대포 폭발 자체를 복사하는 참고가 아니라 발광 핵·가는 불티·자연스러운 화염과 주변 석재에 반응하는 빛의 품질을 기준으로 삼는다. 새 폭발은 Blender로 별도 제작한다.
