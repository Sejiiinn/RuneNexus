# Blender 착탄 실제 게임 검증

2026-09-11. 53000 인앱 테스트 빌드의 스테이지 1 3D 전장에서 대포를 설치하고 첫 웨이브를 진행했다.

- `stage1-gameplay.mp4`: 실제 Chrome 전투 화면, 720×1080, 약 14.6초. CDP의 실제 프레임 시각을 보존했다.
- `stage1-impact.jpg`: 영상 4.74초의 착탄 섬광·파편과 지형 조명 반응. 이어지는 0281/0286 프레임에서 주황 화염, 0296 프레임에서 잔상 소멸을 확인했다.
- `stage1-live-combat.png`: 실제 전투 전체 화면. Blender 자산 미리보기와 구분한다.
- `browser-check.json`: HTTP 400 이상 및 JavaScript 예외 없음. 기존 Platform View 크기 기본값 경고는 남아 있다.
- `verify_web.cjs`, `encode_capture.swift`: 전투 캡처와 영상 생성 절차. H.264 영상의 세 시점 디코딩을 확인했다.

관련 테스트 8개, `flutter analyze`, 인앱 웹 빌드를 통과했다. 테스트는 착탄 수명·좌표·아틀라스 프레임·풀 재사용·광원 종료 및 기존 투영/전투 표시 동작을 포함한다. 최종 에셋은 제작 경로에서 12프레임 알파·여백·frame8 연기 제거를 별도로 확인했다. 네이티브 기기 검증은 이 웹 검증 범위에 포함하지 않는다.
