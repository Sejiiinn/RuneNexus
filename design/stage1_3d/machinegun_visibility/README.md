# 기관총 발사 이펙트 가독성 수정

2026-09-11. 이전 영상에서 기관총 이펙트가 보이지 않는다는 사용자 피드백에 따른 수정이다. 기존 마감 검수는 이펙트의 실제 가독성을 충분히 확인하지 못했다.

원인: 투명 여백을 포함한 셀 크기를 기준으로 표시해 초기 연기 내용이 기본 화면에서 1픽셀 미만이었다. 낮은 불투명도와 짧은 재생 시간도 겹쳤다. Blender 원본은 섬광의 발광 재질과 연기의 볼륨 재질을 투명 프레임으로 렌더한 것이다.

기관총만 섬광 내용 크기·재생 시간(0.12초), 연기 내용 크기·명암·소멸 곡선·재생 시간(0.65초)을 보정했다. 대포와 피해·공격 주기는 변경하지 않았다.

- `stage1-gameplay.mp4`: 수정 후 실제 웹 전투. 440×900, 약 15.2초. 확대·슬로모션 없는 기본 시점.
- `machinegun-fire.jpg`: 영상 프레임 0130의 실제 포구 섬광.
- `verify_web.cjs`: 시험 골드 추가, 기관총·냉각 설치, 웨이브 시작 및 Chrome 실제 합성 화면 기록.
- `frames.json`과 `frames/`: 실제 캡처 타임스탬프·원본.

기본 화면에서 백황색 포구 섬광과 소멸하는 회색 연기의 표시를 확인했다. 정적 분석·관련 발사 효과 테스트·웹 빌드를 통과했고, 최종 브라우저 리소스/JS 오류는 없었다. MP4는 3개 시점에서 디코딩했다. 이전 검수와 같은 헤드리스 Chrome 경로이며 네이티브 실기기 검증은 포함하지 않는다.
