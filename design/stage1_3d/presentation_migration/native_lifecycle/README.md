# 피해 숫자·사망 파편·젬 장착 수명 이관

측정 원자료·재현 스크립트·실행 로그·캡처·영상은 로컬 검수 자료로 보관하며 이 커밋에는 포함하지 않는다. 아래 해당 링크는 로컬 작업 폴더 기준이다.

2026-09-18. 대상은 Android Godot 전장의 표시 전용 효과 3종이다. 기존 전투 판정·재화·저장·Flutter HUD와 시각 자산은 유지한다. [현행 표시 계약](../../../../docs/godot_presentation_migration_plan.md)을 따른다.

## 변경

- Godot의 이벤트 지원과 effects 적용 확인 후 생성 이벤트로 전환한다. 해당 Flame 컴포넌트의 트리 등록·매 프레임 update와 진행도 스냅샷 전송을 생략한다.
- Godot은 초기 입력과 공용 전투 시계로 움직임·수명·만료를 계산한다. 시계는 기존 컴포넌트에 전달하던 dt를 사용하며 정지·배속·보상·로딩·코어 파괴 감속을 따른다. 낙하 피해 숫자는 누적 dt²를 함께 사용해 기존 적분 결과를 보존한다.
- 실제 적용 확인 전에는 생성 이벤트를 재전송하고 확인 후에는 중단한다. 중복 프레임은 효과를 재시작하지 않는다. 유한한 보관 범위 안에서 짧은 효과의 누락을 방지한다.
- 지원 철회·2D 복귀 시 아직 살아 있는 효과를 현재 나이에서 복원한다. 전투 정리와 장면 전환에서는 취소된 효과가 남거나 재생되지 않게 한다.
- 이 기록 당시 다이아 획득·착탄·번개·코어 빔 등 나머지 효과와 이미지 전용 피해 숫자는 기존 경로를 유지했다. 이후 non-blast 착탄의 이벤트 전환은 [후속 기록](../impact_lifecycle/README.md)을 따른다.

## 성능 해석

이 변경은 Flame의 표시 효과 갱신과 반복 전송을 줄이는 작업이다. 2D 오류 복귀용 초기 Component 객체는 유한한 보관 목록에 남기므로 모든 객체 할당을 제거한 것은 아니다. 공용 전투 시계와 전투 시뮬레이션은 Dart에 남으며, Godot 렌더와 Flutter 합성 비용도 남는다. 전체 FPS·실기기 p95/p99·발열 개선은 미측정이다. 공개 배포·커밋·푸시는 수행하지 않았다.
