# 번개 연쇄선 수명·좌표 계산 이관 — 2026-09-19

`nativeChainEffectEvents` 지원 확인 뒤 초기 양끝·대상 ID·원래 픽셀 기준 seed와 공용 전투 시계를 전달한다. Godot이 기존 6점 지그재그 수식·수명·양끝 추적을 수행하며, 사라진 끝점은 마지막 수신 생존 위치에 독립적으로 고정한다. 연결 대상인 적만 논리 좌표를 추가한다. 기존 `_beam` 그리기·투영 함수, 충전·연쇄 공격 타이머·포탑 코드는 해시가 동일하다.

구형 runtime은 기존 스냅샷을 유지하며 새로운 capability 없이 chain 이벤트를 보내지 않는다. ACK·세대 변경·개별 수명·정지/배속·지원 철회 시 살아 있는 Flame 효과 복원·리사이즈 계약을 유지한다. 표시 객체 자체의 생성과 Godot의 지그재그 계산까지 없앤 변경은 아니다.

Android 검수 원자료·스크립트·로그·캡처·영상은 로컬 자료로 보관한다.

Android 17 ARM64 에뮬레이터(1080×2424), 일반 `main.dart` release build 2007에서 스테이지 1/18웨이브를 검수했다. 원본 저장을 별도 백업하고 동일한 복제 저장의 포탑 8개를 번개로 설정해 build 2006/2007을 비교했다. 실제 앱의 충전→발사→연쇄선, 이동 대상 추적·종료, 메뉴 정지 후 전장 유지·재개, 4× 전투, 홈→앱 복귀를 확인했다. 기존 선 굵기·발광·지그재그 외형을 유지했다. 시점은 드론이며 영상은 540×1212다. 타이밍·난수까지 고정한 픽셀 비교 또는 FPS 측정은 아니다.
