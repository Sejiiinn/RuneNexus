# 시안 기준 재질·조명·고사리 그림자 적용

2026-09-13. [실행 계획](../../../../../docs/stage1_surface_effects.md)에 따라 Astra 세 에이전트가 영역별 구현을 맡고 주 에이전트가 통합·시각 검수·결함 수정을 감독했다. Godot Mobile과 현재 맵·카메라·HUD를 유지했다.

## 결과와 판정

| 영역 | 구현 | 실제 화면 판정 |
| --- | --- | --- |
| 석재 | 원본 돌 맵·이끼 마스크를 유지한 roughness 조정. 실제 중앙값 건설 `.749`, 길 `.569`; normal scale `1.2/1.0`. | 돌무늬를 지우는 흰 반사면 없이 면의 빛 변화가 보인다. 이끼는 돌보다 거친 반응을 유지한다. |
| 조명 | 환경광 `.16`, 주광 `1.50`, 보조광 `.14`; PCF Soft Medium, blur `1.25`. 기존 방향·색·bias `.03/.35` 유지. | 밝은 윗면과 어두운 측면·포탑 기단이 구분된다. 전장을 어둡게 만들거나 bloom으로 덮지 않았다. |
| 고사리 | 실제 전체 잎 외곽에서의 거리로 중심 `.80`·외곽 전이 `.16`의 Alpha Hash 차폐. 원래 낮은 외피 높이·전체 수평 범위 유지. | 검은 다각형 경계가 풀리고 군락 중심 음영이 남는다. 가시 고사리의 색·형태·배치는 유지했다. |

실제 Android 본게임의 고정 시점 (`android-fixed.png`, 로컬 자료)과 드론 시점 (`android-drone.png`, 로컬 자료)을 직접 확인했다. 변경 전 (`before-android-fixed.png`, 로컬 자료)과 비교하면 고사리의 단단한 검은 경계가 완화되고 돌 표면·측면의 명암 연결이 부드러워졌다. 시안과 식생의 조형·밀도가 동일하거나 포탈·코어의 별도 유리 이관까지 완료됐다는 판정은 하지 않는다.

## 통합 중 수정한 결함

새 고사리 그림자 메시를 자동 LOD로 단순화하면 낮은 외피가 납작해져 원거리에서 차폐를 잃었다. 기존 불투명 셰이더에서도 같은 소실이 발생했고, LOD를 제한한 실제 렌더에서 복구되는 것을 확인했다. 준비 스크립트는 이 1,200삼각형 에셋만 `meshes/generate_lods=false`로 가져온다. 런타임의 임시 LOD bias, 높이 증가, 워밍업 연장은 남기지 않았다. 전역 shadow bias를 낮추는 후보는 지형에 자기 그림자 줄무늬를 만들어 배제했다.

고사리 그림자는 별도 재질을 사용하며 기존 식생과 동일한 GPU 바람 시계·UV·점유 마스크를 받는다. 포탑 설치/철거·맵 초기화·재진입 때 본체와 그림자의 상태를 함께 갱신한다. 석재 담당 기록 (`stone-report.md`, 로컬 자료), 조명 담당 기록 (`lighting-agent.md`, 로컬 자료), 고사리 담당 기록 (`fern-agent.md`, 로컬 자료)에 원본과 근거를 정리했다.

## 검증과 패키징

- 기존 환경 검사 실패 0건. 네 고사리 슬롯의 본체·그림자 점유, 철거, 초기화·재진입을 확인했다.
- 기존 프로젝트 준비 테스트 통과. 최초 준비와 반복 준비에서 해당 LOD 설정·기존 UID·다른 import 설정을 보존한다.
- 최종 공용 장면 GPU 고정/드론 캡처 오류 0건, 두 시점 모두 82드로콜·143,743프리미티브. 로그 (`integrated-gpu.log`, 로컬 자료). 이 계수는 Mac 검수 장면의 값이며 실기기 성능 수치가 아니다.
- Android 17 ARM64 에뮬레이터의 일반 본게임 versionCode 6012에서 재질·그림자·입체 측면·시점 전환을 확인했다. 실기기 4배속 성능은 미검증이다. 이번 검수에서 웨이브를 진행하거나 저장을 초기화하지 않았다. 7웨이브·HP 13/20·403G·조각 16, 고정 시점·1배속 대기 상태를 유지했다.
- 설치 파일: `build/apk-main/rune-nexus-reference-material-arm64.apk`. 직전 6011 대비 **241,986,489→242,214,137바이트**, **+227,648바이트(+0.094%)**. Flutter 내 기존 지형 GLB 압축분 +110,005바이트, Godot PCK +117,644바이트가 주요 차이다. 네이티브 라이브러리는 동일하며 ARM64만 포함한다. Blender·design 원본과 Flutter 내 고사리 그림자 중복은 없다. APK 검사 (`apk.json`, 로컬 자료). 공개 배포·커밋·푸시는 하지 않았다.
