# 공통 카메라 깊이 범위 구현

2026-09-13. 담당 변경은 `godot/main.gd`의 카메라 경계·깊이 계산과 기존 `godot/verify_camera.gd`다. 주광·재질·고사리 코드와 프로젝트 렌더러 설정은 이 담당에서 변경하지 않았다.

기존 near 0.1 / far 100을 제거하고 지형·모델·전투 효과를 포함한 월드 경계의 여덟 꼭짓점을 현재 카메라 깊이에 투영한다. 가장 가까운 면과 먼 면에 각각 0.5타일 여유를 둔다. 고정·드론·0.7초 전환·전환 중 재입력에서 같은 계산을 수행하며 위치·회전·줌·HUD 정렬·투영 반환 계약은 유지한다. HUD h/v 오프셋은 시선에 수직이므로 깊이 범위는 바뀌지 않는다.

## 경계 근거와 비용

- 맵이 생성되면 실제 지형·장식·포탈·코어 메시 AABB를 한 번 수집하고 0.05타일 여유를 준다. 식생의 최대 바람 이동 0.022타일을 포함한다. 같은 맵을 재시작해도 새 지형 인스턴스를 감지해 이전 전투의 확대 경계를 버린다.
- 기존 `TURRET_MODELS`·`ENEMY_MODELS` PackedScene에서 한 번만 기하 경계를 읽고 임시 노드를 해제한다. 수평 반경으로 바꿔 모든 조준·적 회전을 포함한다. 실제 브리지 적 scale 최대값에 맞춰 확장한다. 본게임의 현재 적 배율이 0.48~0.83이어도 검수·새 입력의 더 큰 배율을 자르지 않는다.
- 모델 경계에 1타일 여유를 둔다. 기관총 연기는 총구에서 최대 0.37 전진에 박스 반길이 0.35가 더해지고, 상승 0.17에 반폭 0.22가 더해진다. 이 여유에 포구 화염·반동·건설 미리보기 부유도 포함된다.
- 탄체는 기존 최장 예광 1.10타일과 포탄 코끝을 포함해 수평 최소 여유 1.35타일을 사용한다. 전달된 발사점·현재점·종료 피격점이 맵 밖에 있으면 그 좌표도 경계에 포함한다.
- 포탄 효과는 `godot_impact.gd`의 전체 입자 수명 AABB인 수평 ±5r, 높이 -0.25r~3.75r를 사용한다. 이는 체적 캐시의 ±2.35r, 높이 0~2.9r도 포함한다. 반경은 고정 최대값을 가정하지 않고 실제 브리지 입력을 읽는다.
- 프레임마다 읽는 것은 기존 배열의 좌표·적 scale·착탄 radius뿐이다. 메시를 매 프레임 순회하지 않는다. 맵 수명 동안 관측된 최대 경계를 유지해 효과 소멸 때 near/far와 그림자 범위가 왕복하지 않는다. 매우 큰 새 효과가 처음 나타나면 필요한 범위로 확장된다.

## 검증

주 에이전트가 통합 프로젝트를 준비하고 Godot 4.7.2 headless로 기존 `verify_camera.gd`를 실행했다. [camera.log](camera.log): **0 failures**.

검사에는 최초 시점의 깊이 낭비 감소, 실제 표시 메시·효과 경계 포함, 전환 중 네 구간, 정지 전투의 VFX 광선 갱신, 확대·빠른 재입력, scale 1.7 보스와 맵 경계 radius 2.4 폭발, 폭발의 초기·중기·말기, 종료 후 경계 유지, 세로·가로 viewport와 HUD 오프셋, 같은 맵 재생성이 포함된다. 코드 diff 검사도 통과했다.

이 결과는 깊이 포함과 기존 카메라 동작 회귀 검사다. 그림자 외형·실제 Android 화면·성능 판정은 주 에이전트의 통합 GPU·APK 검수에서 수행한다.
