# 포탑 스탯 UX 개선

2026-09-22. Godot 독립 앱의 기존 2열 수치표·세 줄 스크롤 높이를 보존하며 표시를 개선했다.

- 항목명과 우측 수치를 분리하고 기본 수치를 13px로 표시한다. 강화 미리보기는 현재값 아래 청록 변경값과 화살표를 표시하며, 조준시간 감소도 같은 방식으로 비교한다.
- 공격 속도는 회/초, 시간은 초, 투사체·연쇄는 정수 발/회로 표시한다. 사거리는 `_stats`의 tileSize=48 좌표를 48로 나눠 칸 단위로 표시한다. 스탯 계산·강화 비용·실행 계약은 변경하지 않는다.
- 공격 목표 버튼은 피해 계열·누적 피해 행에 통합한다. 제목에서 문맥상 중복인 ‘포탑’을 빼 강화 미리보기 때 이름이 쪼개지지 않게 한다.
- 새 카드나 외곽 패널 확대 없이 96px 내부 영역에서 추가 스탯을 스크롤한다. 스크롤바는 보이지 않는다.

## 검증

Godot 4.7.2, macOS Metal, 격리 프로젝트 `hud-review-v4`와 별도 사용자 저장으로 실제 앱을 실행했다. 검증 fixture의 포탑 종류·레벨·강화값을 변경했으며 사용자 저장에는 적용하지 않았다.
