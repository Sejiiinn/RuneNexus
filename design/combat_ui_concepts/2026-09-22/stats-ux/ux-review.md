# 포탑 스탯 UX 독립 검토

2026-09-22. `DESIGNS.md`와 `design/stats_layout_concepts/README.md`의 A안(2열 수치표, 얇은 구분선, 기본 3행 내부 스크롤, 외곽 패널 확대 억제)을 기준으로 변경 전후 실제 Godot 캡처와 `godot/ui/battle_hud.gd`를 검토했다. 구현 담당과 별도로 검토했으며 소스는 수정하지 않았다.

## 최종 판정

**검토한 320×760·440×900 데스크톱 Godot 화면에서 UX PASS. 차단 결함 없음.**

- `before-320.png`, `before-preview-320.png`: 기존에는 항목과 값·전후 비교가 같은 11px 문자열로 연결되어 수치를 훑기 어려웠다. 공격 빈도·시간·발수의 단위가 생략되고, 320px 미리보기에서 포탑 이름 끝 글자가 다음 줄로 밀렸다.
- `after-320.png`, `after-preview-320.png`, `after-preview-440.png`: 항목과 값 분리, 값 우측 정렬, 기본 13px 수치로 읽기 쉬워졌다. 미리보기는 현재값을 위에, 다음값과 화살표를 아래에 표시해 2열 폭을 유지하면서 양쪽 수치를 비교할 수 있다. 변화하지 않는 치명 수치는 하나만 표시한다. 주요 6항목은 3행 안에 온전히 보인다.
- 단위는 공격 속도 회/초, 사거리 칸, 지속·조준 시간 초, 투사체 발로 읽힌다. 사거리 환산은 담당자가 확인한 48 단위 타일 계약에 근거하며 이 검토에서 전투 계산 자체를 변경하거나 승인하지 않았다.
- `after-preview-cannon-320.png`, `after-preview-magic-320.png`, `after-extra-cannon-320.png`, `after-extra-frost-320.png`, `after-extra-magic-320.png`, `after-extra-sniper-320.png`: 조건부 효과 범위·감속·지속시간·투사체·조준 시간에 내부 스크롤로 접근할 수 있다. 저격의 조준 시간이 감소하는 개선도 현재값과 다음값으로 명확하다. 끝으로 스크롤한 화면의 상단 일부 행 가림은 정상 스크롤 클리핑이며 마지막 항목은 온전히 노출된다.
- 목표 선택을 메타행으로 통합하면서 공격 유형·누적 피해·현재 목표가 유지된다. 헤더의 중복 단어를 정리해 레벨 미리보기와 강화 비용·판매·특성 버튼이 한 줄에 들어간다. 스탯 외곽 패널이 전장을 더 가리지 않으며 기존 연결형 탭을 유지한다.
- `after-long-values-320.png`: 별도 격리 검수 상태의 피해 5331.8→6398.1, DPS 4923.4→6203.5, 누적 피해 1234567.8과 긴 목표명 ‘최대 체력’을 함께 확인했다. 값·라벨·버튼의 잘림 또는 겹침이 없다. 이 검수 상태는 표시 한계를 확인하기 위한 fixture이며 실제 진행·해금·전투 규칙 변경을 의미하지 않는다.

## 검증 한계

판정은 제공된 실제 Godot 캡처와 UI 코드에 한정한다. HUD 회귀 PASS는 구현 담당자의 별도 기능 검증 결과이며 시각 판정과 구분한다. 실제 Android 터치·폰트 확대·플랫폼 수명주기는 검증하지 않았다. 목표 버튼은 30px 높이의 조밀한 보조 조작이므로 실기기 터치 편의는 별도 확인 범위다. 젬·보상·판매 동작은 이번 UX 수정 대상이 아니며 새 동작을 제안하지 않았다.
