# 승인 02 스테이지 모달 독립 합격 기준

2026-09-22. 기준은 `../01-four-concepts.png` 상단 오른쪽02의 실제모달(x약628–1189,y60–621)이다. 번호02와 외부 비교캔버스는 게임UI 요소가 아니다. 구현코드는 수정하지 않는 독립검증 기준이다.

## 외형과 정보 구성

1. 외곽: 어두운 청록 석재/금속 표면과 얇은 금색 외곽·비스듬한 모서리 장식. 제목 뒤의 큰 원형 룬 문양을 보존한다. 기존의 두꺼운 회색 철판/주황 테두리로 대체하지 않는다. 모서리·룬이 패널 크기 변화로 부자연스럽게 늘어나지 않아야 한다.
2. 헤더: 제목과 작은 기록 pill이 상단 중앙, 금속 닫기 버튼이 우상단이다. 01/03의 좌측 대형 깃발 박스는 없다. 닫기 버튼과 제목이 겹치지 않아야 한다.
3. 지표: 최고 기록/총 라운드/룬 보상의 3열. 청록 아이콘, 작은 지표명, 굵은 흰 값, 가는 세로구분선이다. 개별 지표카드나 중복외곽을 추가하지 않는다. 위아래의 가는 금색장식선과 배치 위계를 보존한다.
4. 보상: 별 문양+클리어보상 제목 아래, 각 보상은 모달 안의 넓은 가로행이다. 좌측아이콘/작은청록카테고리/큰흰이름/우측chevron 구조와 청록·금속 테두리를 보존한다. 기존 작은 3열칩grid로 대신하지 않는다. 상태별 보상의 실제수·명칭·카테고리와 기존 동작 계약은 데이터에 따른다.
5. 주요행동: 하단넓은청록발광 버튼, 얇은금색베벨과 각진 윤곽, 흰 play와 시작문구. 기존주황/갈색버튼은 불합격이다. 본문하단과정돈된간격이며 외곽밖으로나가지 않는다.
6. 한줄상태/지표/카테고리는 세로글자로 분해되지 않는다. 긴보상이름·잠금안내는 실제320/440에서 읽히고 잘리지 않아야 한다. 자동1–5px축소로 폭검사만 통과시키지 않는다. 원본이안내하는형태·색·재질과비율이기준이며 고정내용픽셀복제가목적은아니다.

## 구조·동작·검증

- Control/Container, 공통 또는 전용 Theme, 완성형PNG의 StyleBoxTexture와 고정모서리/콘텐츠여백분리. 수동9조각조립/전체패널강제scale/임시Canvas대체가 없어야 한다.
- 기존 모달의 배치wrapper와 애니메이션wrapper 분리, 고정닫기헤더와본문스크롤을 보존한다. 실제Lobby/AppLifecycle 경로에서 애니메이션ON·재진입·같은모달resize 후중앙/경계가유지된다.
- stage1기록없음, 잠김stage8(긴연구보상), stage11최초보상/상태변형을 실제320/440에서검사한다. logical440×760/physical440×900과짧은창이관련실패조건이다. 기존통과한동작은변경영향이있는부분만검사한다.
- 실제마우스/터치이벤트로 닫기/시작(또는재개)/잠김무동작을검사한다. pressed.emit만으로입력PASS라하지않는다. 화살표가새상세동작을뜻한다면기존계약과승인범위를확인하며 원본의임의기능을추가하지않는다.
- 승인원본과실제캡처를직접비교한다. 소스/런타임에셋해시·리소스누락·실행오류를확인하고 실제확인/다른담당로그/미검증을구분한다.
- 사용자실행·저장·공유editor를보존하며독립프로젝트/userdir만사용한다. Android실기기/배포는실시하지않았다면PASS에포함하지않는다.
