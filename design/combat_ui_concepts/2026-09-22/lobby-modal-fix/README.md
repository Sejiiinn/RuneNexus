# 스테이지 상세 모달 결함 수정

2026-09-22. 사용자 실제 실행에서 확인한 글자 세로 줄바꿈과 아래로 벗어난 모달을 수정했다. 원본 프레임·폰트·색·정보·현재 로비 헤더는 유지한다.

## 원인과 변경

- `lobby_stages.gd`의 공통 상세 라벨이 모두 자동 줄바꿈이었다. 자연 너비가 필요한 상태 칩과 HBox의 비확장 캡션이 최소 너비를 확보하지 못해 ‘기록 없음’, ‘클리어 보상’, ‘강화’, ‘연구’, ‘시작하기’가 한 글자씩 내려갔다. 단문은 자동 줄바꿈을 끄고 긴 잠금 안내만 명시적으로 줄바꿈한다.
- `lobby.gd`의 `_layout_modal`과 공용 등장 tween이 같은 `position`을 썼다. 애니메이션 도중 900→1100px 창 변경에서 중앙 재배치가 y262.5로 적용된 후 tween이 이전 y162.5로 돌리는 것을 재현했다([로그](before-resize.log)). 중앙 배치 노드와 내부 애니메이션 노드를 분리해 기존 fade/scale/slide 표현을 유지하며 충돌을 없앴다. 전역 AppTheme는 변경하지 않았다.
- 기존 상세 헤더 확장 지점 `set_modal_header`를 구현해 닫기 버튼을 본문 스크롤 밖에 고정했다. 짧은 창에서도 본문을 스크롤해 시작 버튼에 접근하고 닫기는 계속 표시된다.

## 긴 보상 이름 추가 보정

최초 보정 이후 독립 검수에서 320px의 ‘전투 강화 비용 최적화’가 지나치게 작게 표시되는 기존 경로를 발견했다. 크기 변경 때마다 글꼴을 1px까지 축소하던 콜백을 제거했다. 기존 10px 글꼴과 원본 칩 이미지는 유지하며, 아이콘·문구의 자연 너비를 기준으로 3/2/1열을 선택한다. 스테이지 8은 320px에서 한 열, 440px에서 두 열로 표시한다. 짧은 문구는 가능한 경우 기존 세 열을 유지한다.

최종 보상 영역 캡처: [320 스테이지 8](rewards-320-stage8.png), [440 스테이지 8](rewards-440-stage8.png). `rewards-*.png`가 해당 영역의 최종 결과이며 앞선 `after-*.png`는 첫 결함 수정 시점 근거다. 320/440의 스테이지 1·8·11에서 10px 글꼴·전체 문자열 자연 너비·모달 경계, 짧은 창에서 스크롤·닫기 접근을 확인했다([보상 검사](rewards-test.log)).

## 검증

Godot 4.7.2 / macOS Apple M4 / OpenGL Compatibility. 별도 `build/godot/lobby-modal-review`, `RuneNexus-lobby-modal-review` 사용자 경로. 사용자 실행 프로세스·저장은 수정하지 않았다.

- 변경 전 실제 사용자 화면: [user-live-before.png](user-live-before.png). 독립 하네스에서 세로 글자 현상을 재현했다([before.png](before.png), [before.log](before.log)). 고정 440×900에서 사용자 모달 위치 이탈까지는 독립 재현하지 못했으며, 애니메이션 중 resize로 동일 position 경합을 확인했다.
- `godot/verify_lobby_modal.gd`: 애니메이션 ON, 물리 창 320/440×900과 논리 320/440×760의 expand 조건. 실제 스테이지 행 포인터 클릭 전에 1초 대기하고 열린 뒤 0.4초 대기했다. 스테이지 1·잠김 8·보상 11의 단문 한 줄·경계·중앙 배치·실제 시작/닫기 hit·재진입 PASS. 애니메이션 중 resize, 짧은 논리 320×260에서 스크롤/닫기/시작 접근 PASS. [실행 로그](after-test.log).
- 실제 화면 직접 확인: [320 스테이지 1](after-320-stage1.png), [440 잠김 8](after-440-stage8.png), [320 보상 11](after-320-stage11.png). 같은 폴더에 두 너비의 세 스테이지 캡처를 보존했다.
- 기존 [스테이지 회귀](stages-regression.log), [로비 회귀](lobby-regression.log) PASS. 입력 소스·원본 모달 프레임 해시: [input-sha256.txt](input-sha256.txt).

부모는 기존 `RuneNexus-Local-Play` 테스트 저장을 유지해 실제 앱을 다시 실행했다. Metal Forward Mobile, 물리 440×900·앱 기본 논리 440×760에서 스테이지 1 상세창의 최종 영역은 `(25,267,390,366)`이며, 수평 라벨·중앙 배치·시작 버튼 전체 표시를 직접 확인했다. [수정된 실제 실행 화면](user-live-after.png), [실행 로그](user-live-after.log). 실행 복사본의 두 수정 소스는 최종 원본과 일치한다.
