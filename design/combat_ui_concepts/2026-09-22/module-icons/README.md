# 포탑 모듈 아이콘 정렬과 3D 적용

선택 목록의 소켓·포탑과 인벤토리의 부품 아이콘은 중앙 앵커를 설정한 뒤 절대 좌표를 지정해, 부모 크기가 결정될 때 왼쪽 위로 치우쳤다. MarginContainer·CenterContainer로 정렬을 맡겨 수정했다.

포탑 선택 목록과 장착 미리보기는 [기존 좌하단 고정 시점 3D 아이콘](../../../hud_turret_icons_fixed/README.md) 6종을 공통으로 사용한다. 원본 PNG의 방향·투명 여백·모델별 크기를 유지하며 새 렌더·회전·크롭은 하지 않았다. 미리보기의 이름 영역은 기존 프레임 안에서 분리했다.

320/440에서 6종 선택을 실제 마우스 입력으로 확인했고, 선택 아이콘과 모듈 아이콘 중심이 각 축 0.5px 픽셀 정렬 오차 이내인지 검사했다. [검사 로그](check.log), [기관총 440](after-440-arrow.png), [번개 320](after-320-lightning.png), [기존 화면](before-440.png). 부모와 독립 검수 에이전트가 정렬·원본 방향·프레임 내부 표시를 확인해 통과했다. 장착·해제·필터 계약은 [기존 회귀 검사](regression.log)로 확인한다.

실제 사용자 앱은 [user-live.png](user-live.png). Godot 4.7.2 / Metal Forward Mobile이며 기존 테스트 저장을 보존했다. Android 실기기와 이번 범위 밖 모듈 화면 전체 레이아웃은 검증 범위에 포함하지 않는다.
