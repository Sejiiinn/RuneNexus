# 인게임 모달 컴포넌트 시안

내장 ImageGen으로 생성한 승인 시안과 컴포넌트 추출용 원본. 현행 적용은 [Godot 공통 테마](native/README.md)를 따른다. 아래 생성·분할 절은 제작 과정 기록이다.

- [시안](concept-v1.png), [프롬프트](prompt.txt)
- 얇은 금속 프레임, 청록 주요 버튼, 어두운 보조 버튼, 주황 종료 버튼, 금색 선택 상태, 연결형 탭을 제안한다.
- 이미지 속 설명 문구와 새 아이콘·확정 버튼은 시각 예시이며 기능 변경 요구가 아니다. 특히 ‘진행 중인 내용은 저장되지 않습니다’는 생성 오류로 현행 저장 동작을 설명하지 않는다. 구현 시 기존 저장·종료 계약과 문구를 유지한다.

## 컴포넌트 추출용 이미지

- [추출용 원본](components-sheet-v1.png), [요청 프롬프트](prompt-components-sheet.txt)
- 게임 에셋: `assets/images/ui/combat_components/components_sheet.png`, Godot 에셋 목록 등록. 1774×887 RGBA, 실제 투명 알파 확인.
- 프레임 2종, 버튼 5종, 선택 행 2종, 연결형 탭, 넓은 주요 버튼, 보조 아이콘을 문구 없는 시트로 분리했다.
- 사용자 후속 지시에 따라 원본 직접 추출 대신 승인 시안을 참조한 추출용 이미지 생성을 요청했다. 생성 결과이므로 승인 시안과 픽셀 단위로 동일한 파일은 아니다. 탭 좌우는 연결된 형태로 생성되었으며 개별 추출 시 경계 분리가 필요하다.

## 조립형 이미지 V2

- [조립형 생성 원본](modular-sheet-v2.png), [요청 프롬프트](prompt-modular-sheet.txt).
- 모달과 버튼 5색을 모서리·변·중앙의 분리 형태로 다시 생성했다. 제목 구분선·아이콘·탭 테두리를 따로 배치했다.
- 내장 ImageGen 출력 1774×887 RGBA, 투명 알파 확인. 이번 범위는 이미지 생성이며 인게임 교체는 하지 않았다.
- 아직 접합 규격을 검증한 최종 9-slice 파일은 아니다. 각 조각의 실제 경계·두께·접합부와 외곽 알파 노이즈를 정리하고 크기별 조립 검증을 거쳐야 한다. 생성만으로 픽셀 단위 동일성이나 무봉합을 보증하지 않는다.

## 완성형 9분할 원본 V3

- [원본](nine-slice-source-v3.png), [프롬프트](prompt-nine-slice-source.txt). 내장 ImageGen 생성.
- 분리 조각을 따로 그리는 V2 대신 하나로 이어진 빈 프레임과 버튼 5종을 생성했다. 이후 동일 이미지에서 모서리·변·중앙을 잘라 연결 불일치를 줄이는 방식이다.
- 생성 원본이며 최종 자르기 좌표·최소 크기·다중 크기 렌더는 아직 검증하지 않았다. 기존 에셋과 게임 UI는 교체하지 않았다.

## 실제 분할 완료

V3 원본을 GIMP에서 54개 개별 PNG로 잘랐다. [분할 파일·미리보기·검증](sliced/README.md). 통짜 원본만 전달했던 단계를 마무리한 결과이며 개별 리소스를 Godot 에셋 목록에 등록했다.
