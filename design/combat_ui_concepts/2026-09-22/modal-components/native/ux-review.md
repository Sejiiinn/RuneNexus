# 젬 장착·교체 UX 독립 검토

2026-09-22. 최종 사용자 기준은 원본 소켓·링크 보존, 미해금 소켓 완전 숨김, 최대 6개 표시 대응이다. 초기의 잠긴 소켓 표시 검토는 이 최종 기준으로 대체한다. 기존 보상 선택 카드 변경은 범위에 포함하지 않는다.

## 최종 판정

**검토한 데스크톱 Godot 캡처 범위에서 UX PASS. 차단 결함 없음.** 검토 범위는 320×760 및 440×900의 교체 모달과 일반 장착 탭이다. 실제 Android 터치·수명주기는 미검증이며, 6개 상태 표시는 현재 해금 규칙을 6개로 변경했다는 의미가 아니다.

- `replacement-320/10-gem-replace.png`: 구매한 소켓 1개만 보이며 미해금 소켓은 잠김 형태로도 노출하지 않는다. 새 젬 이름·효과, 대상 포탑, 별도 슬롯 추가 옵션과 비용·보유 골드를 한 창에서 읽을 수 있다.
- `replacement-320/10a-buy-slot.png`: 슬롯 추가 옵션은 선택되면 체크와 금색으로 바뀐다. 기존 젬 유지, 사용 골드·남는 골드를 먼저 보여주고 별도의 단일 확정 버튼으로 구매 후 장착을 실행한다. 소켓 선택과 구매 옵션 선택이 실행과 구별된다.
- `replacement-320/10d-insufficient.png`, `replacement-320/10f-level-locked.png`: 정확한 부족액 또는 요구 레벨을 설명하고 기존 젬 교체 경로를 안내한다. 레벨 미달에서는 구매 버튼과 미해금 소켓을 숨긴다.
- `replacement-320/10g-six-slots.png`, `replacement-{320,440}/10h-six-selected.png`: 6개를 3열×2행으로 모두 노출한다. 원본 연결부가 같은 행의 소켓 중심을 잇고, 6번째 선택도 청록 테두리·체크로 식별된다. 새 젬 효과·빠지는 효과·반환 안내·확정·포탑 다시 선택이 같은 화면에서 보인다. 이름은 단어 기준 줄바꿈으로 글자 중간 분절을 수정했다.
- `replacement-{320,440}/10i-six-equipped.png`: 일반 젬 링크 탭에서도 6개 소켓을 2행으로 노출한다. 확장된 도크 안에 최대 슬롯 상태·선택 안내·보관함 상태와 하단 탭까지 보이며 잘림이나 겹침이 없다.
- 이전 검토에서 연결부가 지나치게 작고 소켓 중심보다 아래 놓인 문제를 지적했다. 교체 모달의 원본 연결 이미지를 24px 폭으로 표시하고 라벨 높이와 무관하게 소켓 중심에 정렬한 결과를 직접 확인했다.
- 440 캡처 중간본의 실제 크기 880×760 불일치를 발견해 재촬영했다. 최종 `replacement-440/10h-six-selected.png`는 실제 440×900임을 이미지와 메타데이터에서 확인했으며, 최종 440 판정은 재촬영본을 기준으로 한다.

## 기능 근거와 한계

`close_back()` 코드에서 포탑 선택으로 되돌아가는 흐름을 확인했다. 선택 무변이·원자 결제·보관함 반환·뒤로가기 보존 및 일반 HUD 회귀 PASS는 기능 담당자의 별도 검증 결과이며, 캡처로 증명한 것으로 취급하지 않는다. 실제 모바일 터치 체감, 플랫폼 시스템 뒤로가기 전달, 화면 회전은 독립 실행 검증하지 않았다. 현재 게임의 최대 슬롯 데이터와 6개 검수 상태의 차이는 도메인 확인 사항이며, 이 UX 검토는 해금 규칙 변경을 승인하지 않는다.
