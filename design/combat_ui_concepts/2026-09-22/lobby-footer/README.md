# 로비 하단 탭

스테이지·코어·강화·연구·포탑의 기존 기능과 이미지를 유지하고, 26px 아이콘 위 / 12px 이름 아래의 세로 배치로 정돈했다. 선택 탭은 기존 금색 `tab_active.png`를 native `StyleBoxTexture`로 표시하고, 비선택 상태는 통합 도크 면에 놓는다. 마우스 hover와 키보드 focus에도 테두리를 표시한다.

표준 HBox/VBox Container와 기존 이미지로 구성했다. 하단 전체 높이는 64px, 버튼 높이는 56px이며 모바일 안전영역 안에 배치한다. 생성 이미지나 새 아이콘은 추가하지 않았다.

부모와 별도 검수 에이전트가 최종 320/440 캡처를 확인해 잘림·겹침 없이 통과했다. 실제 사용자 앱도 최신 형상으로 실행하고 화면을 확인했다. [소스·이미지 해시](inputs-sha256.json)는 사용자 실행과 일치한다. 실행 환경은 Godot 4.7.2 / Metal Forward Mobile이다.

`verify_footer.gd`에서 320/440 화면의 다섯 탭을 실제 마우스 이벤트로 전환했다. 아이콘·라벨이 버튼 안에 있고 하단 도크가 화면 안에 들어가는지 검사했다. [검사 로그](check.log), [440 스테이지](440-stage.png), [320 연구](320-research.png). 최종 실제 사용자 앱 화면은 [user-live.png](user-live.png). Android 실기기 검증은 수행하지 않았다.
