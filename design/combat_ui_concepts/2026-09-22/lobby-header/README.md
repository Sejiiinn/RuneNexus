# 로비 메뉴 상단 배치

2026-09-25. 사용자 요청에 따라 제목을 왼쪽에 정렬하고 로비 복귀 버튼을 작게 줄여 제목 아래에 배치했다. [현행 디자인 기준](../../../../DESIGNS.md)의 메뉴 탭 상단 행을 따른다.

## 구현

- `godot/ui/lobby.gd`의 공통 상단에서 VBoxContainer로 제목 그룹 → 작은 ‘‹ 로비’ 버튼 순서를 고정했다. 5개 탭 모두 같은 구조를 사용한다.
- 제목은 왼쪽 정렬, 복귀 버튼은 최소 40×26·글자 11px·왼쪽 정렬이다. 이전 42×36·12px보다 작게 표시한다. 제목과 버튼 간격은 2px이다.
- 기존 제목 아이콘·스테이지 로고·퀘스트 진입을 유지하고 스테이지 로고도 왼쪽 기준으로 표시한다. 자원 프레임은 오른쪽 독립 영역이며 긴 숫자를 줄이거나 생략하지 않는다.
- 새 에셋·상단 배경띠는 추가하지 않았다. 본문·하단 탭·구매·저장 계약과 앞서 제작한 강화 프레임을 보존한다.

## 최종 검증

Godot 4.7.2 stable / macOS Apple M4 / GL Compatibility. 별도 `build/godot/lobby-header-under-title-review/godot` 프로젝트와 `RuneNexus-header-under-title-review` 이름을 사용했다. 사용자 저장·공유 편집기·사용자의 기존 플레이 세션은 변경하지 않았다.

- `godot/verify_lobby_header.gd` PASS: 320/440px × 5탭 × 일반/18자리 재화 20상태에서 헤더 경계·제목과 자원 비겹침·숫자 전체 표시·작은 복귀 버튼의 제목 아래 위치/왼쪽 정렬을 확인했다. 모든 탭의 실제 포인터 복귀 클릭과 스테이지 퀘스트 클릭, 하단 탭 이동을 확인했다. [검사 로그](../../2026-09-25/lobby-header/verification.log).
- 기존 `verify_lobby.gd` PASS: 8페이지·잠금/구매/코어 모달·홈·작은 화면·모달 복귀/이벤트. [회귀 로그](../../2026-09-25/lobby-header/lobby-regression.log).
- 실제 Lobby UI와 테스트 진행도로 캡처: [440 강화](../../2026-09-25/lobby-header/440-강화-normal.png), [320 긴 재화/코어](../../2026-09-25/lobby-header/320-코어-long.png), [320 스테이지](../../2026-09-25/lobby-header/320-스테이지-normal.png). 부모가 직접 시각 확인했다. [입력 해시](../../2026-09-25/lobby-header/input-sha256.json).
- 기존에 이 작업에서 열어둔 강화 프레임 확인 창만 종료하고 새 헤더를 반영한 격리 확인 창을 열었다. Android 빌드·실기기 검증은 수행하지 않았다.
- 별도 Astra 독립 검증 PASS: 다섯 탭의 대표 실제 화면·포인터 검사·최종 실행 소스 일치를 확인했다. 제목/복귀 정렬, 긴 재화 가독성, 기존 아이콘·로고·퀘스트 보존에 미해결 사항이 없다.
