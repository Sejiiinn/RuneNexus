# 스테이지 통계 아이콘

승인 원본: [04 형태 + 03 금테두리](04-gold-border.png). 최고 기록은 트로피, 총 라운드는 각진 깃발, 룬 보상은 금색 테두리의 빈 육각 프레임과 중앙 보석이다.

`extract_gimp.py`로 승인 원본의 큰 아이콘을 직접 크롭하고, GIMP 연속 영역 선택으로 외부 배경과 내부 구멍을 투명 처리했다. 재생성하거나 형태를 다시 그리지 않았다. 편집 가능한 각 `*.xcf`와 원본 크기 `*-cutout.png`를 보관한다. 게임용은 `assets/images/stage_details/stats/`의 96×96 PNG 세 개이며 22px 슬롯에서 원래 비율로 표시한다. 금색이 변하지 않도록 기존 청록색 modulate를 제거했다.

실제 Godot 모달에서 320/440 너비와 스테이지 1·8·11을 확인한다. 검증 로그는 `check.log`, 캡처는 `after-*-stage*.png`, 사용자 실행의 최종 화면은 `user-live.png`다. APK 빌드는 수행하지 않는다.
