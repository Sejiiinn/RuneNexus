# 전투 HUD 적용·검증

2026-09-22. [V4 시안](../01-hud-v4-3d-icons.png)과 사용자의 고정 시점 지시를 Godot `--app` 전투 HUD에 적용했다. 시안의 예시 수치·포신 각도는 구현 기준으로 복제하지 않았다.

- 상단 설명 타이틀 없이 자원 HUD부터 표시하고 ‘전투력’을 유지한다. 자원 수치를 키우고 체력·웨이브·홈 버튼을 첫 줄, 체력바를 두 번째 줄, 적·보상을 그 아래에 정렬했다. 상단 HUD는 기존 여백을 유지하고, 하단 포탑 선택란·탭은 화면 좌우·하단에 붙인다. 두 영역의 틈과 외곽 모서리 장식을 없애고 기존 패널 이미지의 내부·직선 금속 테두리를 사용한다. 배속·시작 버튼의 좌우 여백과 형태는 유지한다. 홈 버튼은 [전용 생성 이미지](../../../hud_home_button/README.md)를 28px로 중앙 배치하고 중복 프레임을 제거했다. 로비의 실제 패널·버튼 텍스처를 재사용하며 내부 배속·탭·포탑 선택의 중첩 프레임을 줄였다.
- 준비의 시작, 전투 중 정지/진행 중, 정지 후 재개를 기존 앱 명령에 연결했다. 진행 방식은 하나의 버튼에서 기존 세 선택지를 열며 카메라도 고정↔드론 버튼 하나다. 전장 위의 별도 일시정지 표시는 사용자 지시에 따라 제거했다.
- [고정 시점 3D 아이콘](../../../hud_turret_icons_fixed/README.md) 6종을 정적 텍스처로 사용한다. 해금된 종류만 한 줄에 표시하며 잠긴 종류와 잠금 문구는 숨긴다. 기본 4종에서 기존 스테이지 클리어 조건에 따라 5·6종으로 늘어나고, 320px에서도 6종의 이름·가격이 가로 스크롤 없이 보인다. 선택칸과 아이콘 높이를 줄였다. 포탑·젬 목록과 상세·모달의 스크롤바는 숨기고 스크롤 동작은 유지한다.
- 기본 도크 높이를 전장 카메라의 안정된 기준 영역에 반영했다. 상세 패널을 열 때마다 카메라를 다시 맞추지 않는다. 전투 수치·저장 형식·해금 계약은 유지한다.

## 검증

Godot 4.7.2, macOS Metal Mobile 렌더러. 기존 실행 중인 공용 프로젝트와 편집기를 보존하고 `build/godot/hud-review-v4`에 독립 복사해 검사했다. 사용자 데이터는 `RuneNexus-HUD-review-v4` 디렉터리로 분리했다.

- [HUD 회귀](hud-test.log): 설치·강화·특성·젬·보상·결과 및 320/390/440px 레이아웃 통과. 시작→진행 중→정지→재개, 배속, 진행 방식, 시점 버튼, 3D 텍스처 연결·미해금 숨김과 4→5→6종 표시, 전장과 기본 도크 비중첩, 하단 도크의 좌우·하단 밀착, 스크롤바 숨김과 6종 동시 표시, 여러 적이 등장하는 10웨이브의 +N 표기와 단일 행 제목도 확인했다.
- [선택·사거리](selection-test.log): 기존 선택·설치 미리보기·강화 범위·보상 대상 회귀 통과.
- [앱 수명주기](lifecycle-test.log): 저장·복원·실패 처리 회귀 `failures=[]`.
- [실제 실행 기록](visual.log): 실제 `main.tscn`과 `app_lifecycle.gd`에서 준비·전투·정지 팝업·고정/드론·좁은 화면·미해금 포탑 숨김을 렌더했다. 스크립트 오류 없음.

실제 화면: [440px 준비](hud-440-preparation.png), [440px 전투](hud-440-wave.png), [440px 정지/진행 방식](hud-440-paused.png), [320px 정지](hud-320-paused.png), [320px 드론](hud-320-drone.png), [320px 미해금 숨김](hud-320-locked.png), [320px 다종 적·큰 자원 수치](hud-320-dense-information.png). 마지막 화면의 자원·웨이브 값은 표시 검증용 격리 상태다.

Android APK 빌드·실기기 터치·안전영역 검증은 이번 작업에서 수행하지 않았다. 일반 Flutter 호스트의 HUD를 교체하거나 배포한 결과가 아니다. 현재 실행 경로·이관 상태는 [로드맵](../../../../docs/godot_unified_app_roadmap.md)을 따른다.
