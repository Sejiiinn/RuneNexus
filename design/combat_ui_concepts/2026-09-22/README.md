# 전투 UI 개선 시안

역할: 2026-09-22 사용자 요청에 따른 미승인 디자인 제안. 게임 코드/데이터 변경 없음. ImageGen 내장 도구 사용.

[전체 갤러리](index.html) · [생성 프롬프트](prompts.json)

시안이며 실제 적용 화면이 아닙니다. 숫자·특성 문구·일부 아이콘은 예시입니다. 생성 이미지에 남은 아이콘-명칭 불일치, 하단 탭 순서 및 선택 표시, 중복 강화 버튼은 채택 대상이 아닙니다. 실제 구현은 기존 에셋/데이터를 사용하고 포탑 → 업그레이드 → 젬 순서를 유지합니다. 보드의 작은 상태 예시는 동시 노출 화면이 아닙니다.

## 화면별 개선

- [1. 전투 HUD](01-hud.png): 준비·진행·정지를 같은 HUD에서 구분. 자원/웨이브 정보는 상단, 조작은 하단 고정. 자동 시작은 버튼 위 팝업.
- [2. 포탑 설치와 강화](02-turrets.png): 포탑 정보와 구매 행동을 분리. 피해·공격 속도·DPS를 별도 표기하고 강화 전후 비교를 정렬. 판매는 보조 행동.
- [3. 특성과 전투 선택](03-decisions.png): 특성은 선택 후 확정, 공격 목표는 즉시 적용, 판매는 반환 자원과 젬 귀속을 확인. 잠금 조건과 파편 비용 유지.
- [4. 젬 보관과 링크](04-gems.png): 보관함은 아이콘·수량·효과 비교, 포탑에서는 연결 소켓과 선택 젬 상세에 집중. 해제·중복·호환 불가·잠금 이유를 명시.
- [5. 보상과 장착 대상](05-rewards.png): 보상 선택 → 전장 대상 선택 → 필요 시 교체. 보관·다시 선택 유지. 구매 선택에는 파편 대체가 없으며 파편 수령은 별도 확정.
- [6. 코어와 웨이브 정보](06-intel.png): 코어 체력·스킬 지표와 웨이브 적 정보를 구분. 적 상세는 수치 열을 정렬하고 저항/취약은 색과 부호를 함께 사용.
- [7. 홈과 종료 확인](07-menu.png): 저장 후 이동과 런 종료를 분리. 종료 전 정산 예상, 저장 실패 시 정지와 다시 저장. 모달 뒤 전투 입력 차단.
- [8. 결과와 진입 상태](08-results.png): 승리/패배는 같은 구조로 보상·기록·다음 행동 표시. 로컬 저장 대기와 서버 정산 대기 구분. 로딩은 불투명 차단.
- [9. 복구와 상세 기록](09-recovery.png): Flutter 잔존 흐름의 보존 제안: 진행 복구, 이어하기 이후 카운트다운, 피해 내역, 엔진 연결 끊김. Godot 구현 완료를 뜻하지 않음.

## 기능·상태 보존

- 설치: 해금 6종, 가격, 재화 부족, 연구 잠금. 건설 중 기존 사거리 표시와 선택 포탑 사거리 계약 유지.
- 포탑: 공격 속도와 DPS 분리, 종류별 스탯, 누적 피해, 강화 미리보기/확정/MAX, 공격 목표 연구 해금.
- 특성: 1차 Lv.3/2차 Lv.7, 선행 특성, 파편 비용/부족, 선택 확정, 런 동안 변경 불가.
- 젬: 원형 소켓, 빈/선택/장착/잠김, 확장 비용/Lv.5, 중복/호환 불가/재화 부족/빈 보관함. 실제 젬 14종을 유지하며 시안 예시로 축소하지 않음.
- 보상: 보유 수량/특수 규칙, 선택·장착·보관·교체, 기존 젬 반환, 파편 별도 확정. 구매 선택에 파편 대체 없음.
- 코어: 수호 광선/균열 낙인/스킬 없음. 포탈: 준비/전투 중/완료, 실제 적별 저항과 취약 수치.
- 메뉴: 종료 불가 초기 상태, 저장 성공 후 이동, 종료 정산, 실패 시 상태 유지 및 재시도.
- 결과: 첫 클리어 해금, 로컬 기록 저장 완료/대기, 서버 정산 대기. 재화 확정 상태를 혼동하지 않음.
- 복구: Flutter 잔존 화면은 별도 보존 후보. 이어하기를 선택한 이후 카운트다운. 엔진 연결 오류를 인터넷 오류로 단정하지 않음.

## 이미지 검토에서 남은 차이

- 01: 준비 상태의 사격 그림과 전투 중 적 표시는 삽화 수준. 자동 시작 팝업을 새 버튼으로 추가하지 않고 기존 모드 버튼에 연결.
- 02: 기관총 모델이 대포 예시에도 사용됨. 실제 포탑별 원본 재사용. 초당 공격 횟수와 DPS를 혼동하지 않으며 강화 버튼 중복 제거. 부족 상태는 별도 예시.
- 03: 특성 이름/수치는 실제 정의로 교체. 비용과 레벨 요구를 생략하지 않음.
- 04: 일부 젬 그림-명칭 매칭과 하단 탭 순서가 잘못 생성됨. 기존 gem 타입별 이미지 매핑과 고정 탭 순서 사용. 잠금과 열린 소켓 상태는 분리.
- 05: 젬 레벨 표시는 제안 대상 아님. 실제 젬 이름/파편 수량 사용. 대상 선택 중 기존 하단 도크는 가리고 전장 선택과 보관/되돌리기만 유지.
- 06: 적 초상은 정확한 원본 복제가 아님. 실제 enemyType별 아이콘 사용. 작은 화면에서는 지표를 2~3열로 줄바꿈하여 6열 압축 방지.
- 07: 종료 확인의 닫기 표현은 계속 진행과 동일한 안전 취소. 저장 실패는 전투 정지 유지.
- 08: 상단 골드가 룬 아이콘으로 잘못 변형됨. 전투 HUD 골드와 결과 룬을 분리. 기록/최고 피해는 실제 텍스트·포탑명/값을 연결.
- 09: 재개 카운트다운 작은 박스는 후속 상태 설명이며 복구 모달과 동시 노출하지 않음.
