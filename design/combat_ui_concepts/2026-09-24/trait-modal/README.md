# 특성 선택 모달 개선 시안

역할: 2026-09-24 사용자 요청에 따른 특성 모달 시안과 Godot 적용·검증 근거. 사용자가 02번 시안과 완성한 특성 아이콘을 기준으로 모달 구현을 요청했다.

[현재 시안: 아이콘과 정돈된 행](02-icon-rows.png) · [내장 ImageGen 프롬프트](prompt-02-icon-rows.txt)

[이전 특성 시안](../../2026-09-22/03-decisions.png)의 특성 아이콘·정돈된 행 구성·선택 후 확정 흐름이 사용자가 만족한 핵심이다. 제거 요청은 모달 제목 옆 포탑 초상에만 해당한다. 현재 시안은 좌측 원형 소켓의 특성 아이콘, 중앙 이름·설명, 우측 선택 표시를 복원했다. 외곽과 확정 버튼에는 현재 테마의 금속·남색·청록 표현을 사용하되 개별 행은 얇은 선과 은은한 면으로 정리한다. [현재 실화면](../../2026-09-23/turret-stats-ux/implementation/trait-selection-440.png) · [승인된 포탑 UI 테마](../../2026-09-23/turret-stats-ux/06-action-order.png).

기관총 1차의 실제 두 특성인 과열 탄창·경량 총열, 모달의 보유 파편 1,000과 1차 비용 12를 사용했다. 과열 탄창은 가열된 탄약, 경량 총열은 가벼운 총열과 속도 궤적 아이콘으로 구분한다. 선택한 행은 청록 테두리·채워진 라디오 표시로 구분하고, 하단 선택 확정 버튼에 비용을 함께 표시한다. 2차 탭에는 1차 선택 선행 조건을 표시한다. 기존 반복 1차 제목은 제거했다.

Godot 구현은 행을 눌러 미리 선택하고 별도 ‘선택 확정’ 버튼으로 확정하는 흐름을 따른다. 기존 행 재클릭 확정 방식은 제거했다. 시안 이미지는 1차 선택 미리보기만 표현하며, 모달 밖 배경은 과거 HUD와 서로 다른 파편 수치를 포함한다. 해당 배경·수치는 구현 기준으로 사용하지 않는다.

[01번](01-metal-selection.png)과 [프롬프트](prompt-01.txt)는 거절된 탐색 기록이다. 포탑 아이콘만 제거하라는 의도를 특성 아이콘 제거로 확대했고, 사용자가 만족한 행 구성보다 프레임을 강조했다. 당시 이미지 검수 PASS는 사용자 UX 방향 승인으로 취급하지 않는다.

02번의 이미지 단계 독립 Astra 검수는 원본 03의 행 구조·특성 아이콘·선택 표시, 포탑 초상 제거, 두 특성 내용·모달 보유량·비용, 테마 및 겹침 여부를 확인했다. 실제 게임 검증은 아래 적용 기록과 구분한다.

## Godot 적용

- [구현](../../../../godot/ui/hud_turret_panel.gd): 공통 금속 모달 안에 보유 파편, 1·2차 탭, 원형 소켓의 전용 특성 아이콘, 이름·효과·라디오 선택 표시, 확정 버튼과 변경 불가 안내를 구성한다.
- [특성 아이콘 24종](../../../trait_icons/2026-09-24/README.md)은 `godot/ui/assets.json`에서 패키징하고 `res://assets/app/ui/traits/`로 로드한다.
- 확정할 때 현재 특성과 레벨·선행 조건·보유 파편·실제 견적을 다시 확인한다. 선택만으로 비용을 지불하지 않으며, 이미 확정한 특성을 다시 바꾸거나 중복 차감하지 않는다.
- 설명은 12px과 효과별 줄바꿈을 사용한다. 행 및 모달 높이는 실제 컨테이너 최소높이 변경에 반응하며, 좁거나 낮은 화면에서는 모달 내부를 스크롤한다.
- 검증 실행은 `build/godot/run-upgrades-review`, 저장은 `RuneNexus-TurretStats-Review`로 격리한다. 사용자 플레이 창·저장은 검증에 사용하지 않는다.

## 구현 검증 결과

- 별도 Astra가 작성한 [검증 스크립트](implementation/review.gd)를 실제 Godot 앱에서 실행: [614개 검사, 실패 0](implementation/review-result.json). 행 재클릭 미확정, 별도 확정·정확한 단일 차감, 취소, 1·2차 레벨·선행 조건, 재화 부족, 기선택 불변, pause/resume을 확인했다. 6개 포탑×1·2차를 440×900·320×760·320×480에서 검사했다.
- 최종 실화면: [기관총 440](implementation/arrow-primary-440.png), [기관총 320](implementation/arrow-primary-320.png), [라이트닝 2차](implementation/lightning-secondary-440.png), [짧은 화면 하단](implementation/short-320-bottom.png). 실제 `--app`에서 테스트 상태를 구성한 캡처이며 시안 이미지가 아니다. 포탑 6종과 잠금·재화 부족·기선택 캡처도 같은 폴더에 있다.
- 부모와 독립 Astra가 대표 최종 화면을 직접 대조했다. 아이콘·정돈된 두 행·선택 라디오·명시적 확정과 현재 금속 테마를 보존하며, 좁은 화면의 가림과 과대 높이를 수정했다. 짧은 화면 하단 안내와 버튼도 스크롤로 접근 가능하다.
- [관련 HUD 회귀 검사](implementation/hud-regression.log) PASS. 소스·게임용 PNG와 실행 사본의 일치를 [해시 근거](implementation/source-evidence.json)에 기록했다. Godot 4.7.2 / Metal Forward Mobile / Apple M4에서 검증했다.
- 초기 파편 제목 줄바꿈·큰 버튼 아이콘을 수정했다. 모달 높이를 초기 줄 수로 고정하던 방식도 제거하고 최종 폭에 반응하는 컨테이너 이벤트로 수정했다. 검증 중 추가한 내용 대비 48px 여백 상한은 승인된 균일 행 여백을 잘못 거부하는 검사여서 제거했으며, 실제 과대행 재발 검사와 텍스트 경계 검사는 유지했다. 스크롤 경계는 렌더링 소수점에 대해 1px 오차를 허용한다.
- Android 빌드·기기 검증은 수행하지 않았다. 데스크톱 UI 검증 결과이며 계정·배포·저장 이관의 완료를 뜻하지 않는다.
