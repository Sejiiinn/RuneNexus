# 공격 목표 목록 프레임 시안 — 2026-09-30

사용자는 기존 목록 방식은 유지하고, 프레임 위에 붙어 보이는 배경을 제거한 새 프레임 이미지 후보를 요청했으며 3번 룬 장식형을 최종 선택했다. 내장 ImageGen으로 기존 실제 앱 캡처를 편집한 비교 시안이며 게임 적용 결과가 아니다. 목록 5개 이름과 우측 위치를 유지한다.

| 후보 | 방향 | 권장 이유 |
| --- | --- | --- |
| [01 얇은 금속](01-thin-metal.png) | 얇은 청록·gunmetal 테두리, 작은 깎은 모서리 | 가장 절제되고 명료해 추천 |
| [02 금속 베벨](02-beveled-metal.png) | 은청색 입체 테두리와 깎은 모서리 | 기존 금속 탭·버튼과 조화 |
| [03 룬 장식](03-runic-edge.png) | 청동 모서리·작은 청록 측면 룬·선택행 강조 | 룬 분위기 강조 |

부모와 독립 검증자가 최종3종을 원본과 직접 비교했다. 시안 범위 PASS: 상단 추가 배경 제거, 깨끗한 연속 프레임, 이름5개·선두 선택·우측 위치·주변 HUD 내용 보존, 후보 구분과 테마 적합성. 생성 과정에서 확대·선명도 변화가 있으며 픽셀 동일한 실제 앱 캡처가 아니다. 승인한 03의 현재 목표 행·radio의 청록색 강조도 실제 구현에 포함한다. [제작 원본·실제 적용 검증](../runic-frame/README.md)을 따른다. 하단 검은 줄은 기존 액션 패널의 하단 HUD 테두리로 대조해 보존 대상으로 인정했다.
