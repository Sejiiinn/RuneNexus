## 비교

1. **확장 캡슐**: 가격 태그가 선택 시 가격·해금이 붙은 가로 캡슐로 확장된다. 비용과 액션이 한 덩어리라 이해하기 쉽고 높이가 낮다. 최대 6소켓에서는 캡슐의 가로 폭과 이웃 가격 태그가 충돌하지 않도록 배치가 필요하다.
2. **일체형 명패**: 소켓 하단에 가격·해금을 담은 세로 금속 명패가 붙는다. 물리적으로 가장 일체감 있지만 세 안 중 무게감이 크다.
3. **청록 해금 탭**: 기존 가격 태그 바로 아래 얇은 청록 탭을 연결한다. 독립된 중복 금속 액자를 없애며 현재 배치를 가장 적게 바꾼다. 가로 폭이 좁아 최대 6소켓 대응에도 유리하므로 우선 추천한다.

## 보존·검수

- 각 안 장착 1개·잠금 2개, 정확히 3개 원형 소켓. 선택 잠금의 가격 90 G와 다음 잠금 가격 180 G는 각각 한 번만 표시한다.
- 해금 버튼은 ‘해금’만 표시하며 가격 태그 바로 아래 또는 같은 물체의 옆 부분에 연결한다. 독립된 큰 중복 외곽 액자는 제거한다.
- 전장 일부, 선택 포탑의 강화·특성·판매, 스탯·젬 링크 탭, 하단 내비게이션을 보존했다.
- 보유 젬 6종과 그 뒤 오른쪽 끝까지 이어지는 빈 2칸을 모두 유지했다. 실제 목록 칸은 48×48px 정사각형 기준이며 생성 이미지의 테두리 실측치·간격은 구현 요구가 아니다.
- 세 안의 패널·목록 위치가 같고 해금 때문에 목록이 사라지거나 패널이 커지지 않는 구조다.
- 실제 44px 터치 영역, 가격 미리보기에서 선택 상태로 전환하는 동작, 최대 6소켓의 밀집 배치는 구현 이후 검증 대상이다.

## 함께 반영한 인벤토리 수정

사용자는 2번 일체형 명패를 선택했다. 가격과 해금을 하나의 연속 금속 명패로 묶고, 분리된 외곽 프레임과 연결 막대는 제거한다. 포탑 보유 젬 줄은 화면 폭에 맞춰 정사각형 칸을 배치하고, 부족한 칸을 빈 프레임으로 채우도록 실제 구현했다. 320px에서는 내부 폭 304px에 6칸, 440px에서는 내부 폭 424px에 8칸이 맞는다. 칸은 정수 크기 정사각형으로 유지하고 남는 폭을 4~5px 간격에 나눠 마지막 칸의 잘림을 막는다. 젬 원본 이미지는 34px 고정이며 넘치는 보유 젬은 가로 스크롤한다. 별도 전역 젬 보관함은 변경하지 않았다.

## 2번 일체형 명패 적용 검증

가격과 청록 해금 면을 단일 금색 StyleBoxTexture 프레임에 넣었다. 선택 가격 태그의 원래 위치에서 명패가 이어지며, 기존 태그는 배치 공간만 유지한다. 중복 외곽과 연결 막대를 제거했다. 최초 실제 화면에서 발견한 18px 정렬 오차와 빠른 닫기 시 지연 콜백의 삭제 노드 참조를 수정했다.

독립 검증은 320/440px·3~6개 소켓, 가격 1회 표시, 태그/명패 상단 정렬, 고정 목록·패널 높이, 실제 입력 구매·가격 영역·닫기·연타·재화/레벨/순차 조건을 확인했다. 최종 로그 `../../2026-09-22/gem-ui-final/implementation/verify-gem-unified-plate.log`는 오류 없이 PASS. 승인 2번 이미지와 실제 440/320px 화면의 독립 시각 대조도 PASS다. 사용자 저장과 APK는 변경하지 않았다.

## 시안 재대조 후 외형 교정

기존 card_frame 착색은 시안의 굵은 금속 베벨·사선 모서리를 재현하지 못했으며, 최초 시각 PASS는 기능 구조 위주로 판단한 것이었다. 전용 [무문자 PNG](assets/gem_unlock_plate.png)를 ImageGen과 GIMP로 제작해 게임 `assets/images/ui/components/gem_unlock_plate.png`에 등록했다. 전체 StyleBoxTexture 54×45px로 원본의 상하 면 비율을 유지하고 글자·입력은 별도 노드로 둔다.

고정 상세 예약을 64px에서 기본 30px로 줄여 명패 아래부터 보유 젬 목록까지 약 41px였던 간격을 15px로 줄였다. 긴 장착 설명만 필요한 최소 높이를 허용하며, 기본 선택과 해금 상태는 일정한 배치를 유지한다. 실 데이터·가격·순차·레벨·중복 거래 조건과 인벤토리 끝 채움은 보존한다.

자동 검사: `verify-gem-approved-plate.log`는 전용 이미지·명패 비율·3~6소켓·320/440px·조건 문구와 14종 상세 겹침·실제 입력·거래 검사를 포함한다. 실제 캡처는 앞서 링크한 `unlock-440.png`, `unlock-320.png`이며 과거 프레임 방식 캡처를 최신 결과로 간주하지 않는다.

최종 독립 시각 대조: 실제 54×45px에서 약 3px 금속 베벨·4~5px 사선 모서리·상하 면 비율·15px 목록 간격을 확인했다. 승인 2번의 핵심 외형 재현 PASS이며 픽셀 단위 복제 판정은 아니다. 6소켓에서도 54×45 비율을 고정한 마지막 검사 `verify-gem-approved-plate-final.log`는 오류 없이 PASS다.
