# 승인 2번 명패용 전용 이미지

- `gem_unlock_plate.png`: 428×356 RGBA, 글자·숫자 없는 황동 명패. 상부 네이비 가격 면, 하부 청록 버튼 면, 연속 황동 베벨과 사선 모서리.
- `generated-original.png`: 내장 ImageGen 원본 1375×1144. `prompt.txt`는 실제 생성 프롬프트.
- 승인 기준: 상위 `comparison.png` 가운데 2번의 명패. 논리 크기54×45 권장, 텍스트는 별도 표시한다.

## 처리와 확인

ImageGen 제작 후 기존 GIMP MCP 인스턴스로 원본을 열었다. 알파 8 초과 원본 가시 영역은 (90,179)–(1282,956). 외곽 알파 노이즈·패딩을 제거하기 위해 (88,177),1196×781 영역으로 자르고 428×356으로 비율을 맞췄다. 기존 열린 다른 원본은 보존했다. 최종 RGBA 알파 0~254 및 투명 모서리를 확인했다.

추천 표시 방법은 전체 이미지를 54×45로 비율 유지 축소하는 TextureRect다. 고정 크기 명패이므로 9-patch보다 전체 축소가 내부 가격/버튼 분할 비율을 잘 보존한다. StyleBoxTexture를 사용할 경우 물리 소스 마진 좌우 60, 상 48, 하 56px 정도를 시작점으로 하고, 논리 확장 여백은 0으로 둔다. 논리 54×45에서 금속 외곽이 약 3px, 사선 영역 약 6px가 되도록 최종 화면 확인이 필요하다. 내부 분할선은 높이 약 47% 위치다. 가격 텍스트는 상부, 해금 텍스트는 하부에 별도 배치한다.

게임용 복사·manifest 등록·런타임 UI 검증은 부모 에이전트 담당이다.
