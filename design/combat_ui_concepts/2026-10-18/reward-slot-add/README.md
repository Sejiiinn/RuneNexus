# 보상 젬 장착 모달 · 슬롯 추가 통합 시안 (2026-10-18 채택·적용)

- 현재 화면: `current-440-r1-none.png`(미선택), `r2-replace`(교체 선택), `r3-addslot`(슬롯 추가 선택). 440×900 실제 Godot 캡처.
- 방향: 소켓 줄 아래의 별도 '새 슬롯 추가' 옵션 줄을 없애고, 소켓 줄 끝에 같은 금속 소켓의 `+` 새 슬롯을 둔다. 교체·추가를 같은 소켓 줄에서 한 번에 고르고, 고른 소켓에 새 젬이 들어간 결과를 미리 보여준다.
- `01-socket-add-selected.png`: 새 슬롯 선택. 반투명 새 젬 미리보기, 아래 '새 슬롯 · 가격', 안내 '기존 젬은 그대로 유지됩니다.', 확정 '슬롯 추가 후 장착 · 가격'.
- `02-socket-replace-selected.png`: 교체 선택. 새 젬과 작은 기존 젬 배지, '위력 증폭 → 급소', 안내 '위력 증폭은 보관함으로 돌아갑니다.', 확정 '교체'.
- 제작: Codex 이미지 생성(`codex-imagegen` 스킬), 현재 캡처를 `--edit`, 승인 3번 수정 시안(`../../2026-10-01/gem-replacement/03-socket-anchored-v3.png`)을 `--ref`로 사용.
- 시안 결함: 상단 HUD 글자('13기', '젬 파편')가 생성 중 깨졌다. 변경 범위 밖이며 구현 기준이 아니다.

## 적용 (`godot/ui/battle_rewards.gd` `_replacement`)

- 실제 Godot 캡처 `implemented-{440,360}-{r1-none,r2-replace,r3-addslot,r4-poor,r5-level}.png`: 미선택, 교체 선택, 새 슬롯 선택, 골드 부족, 레벨 미달.
- 시안과의 차이: 미선택 확정 버튼은 비활성 ‘장착’, 구매 불가 새 슬롯은 어둡게 하고 가격 아래에 ‘골드 부족’·‘포탑 Lv.N 필요’를 붉게 표시한다. 선택 전환에서 높이가 변하지 않도록 소켓 이름·효과는 교체 전후 문구 중 큰 쪽 높이를 예약한다.
