# 상단 HUD 가벼운 룬 프레임

역할: 상단 HUD의 두꺼운 청동 코너·금속 브래킷을 제거한 제작 원본과 실제 앱 검증 근거. 확인: 2026-10-01.

기존 [룬 프레임 XCF](../resource-hud-runic-panel.xcf)를 GIMP에서 파생 편집했다. 원래 레이어는 숨겨 보존하고 새 배경·얇은 외곽·작은 룬을 별도 레이어로 두었다. 공격 목표 목록의 원본은 변경하지 않았다.

- [최종 PNG](../../../../../assets/images/ui/hud/resource_runic_slim_panel.png): **104×88 RGBA**, 소스·논리 픽셀 1:1.
- 편집 원본: `resource-hud-runic-slim-panel.xcf`.
- 배경: 위 `#07131e`에서 아래 `#04090e`로 이어지는 기존 남청색.
- 외곽: 모서리 약 3px를 깎은 단일 1px 냉색 금속·청록 테두리. 넓은 청동 삼각 코너와 두꺼운 룬판은 제거했다.
- 룬: 기존 측면 룬에서 양쪽 4×8px 작은 부분만 추출하여 62% 불투명도로 표시했다. 배경 위 캡이나 추가 장식은 없다.
- 9patch texture 고정 영역: **좌 8 / 위 49 / 우 8 / 아래 6px**. y40–47의 룬을 고정하고 빈 직선 구간만 늘린다. 최소 높이 55px이므로 기존 HUD의 94px 높이를 유지할 수 있다.
- 콘텐츠 여백: 기존 **상하좌우 8px** 유지.

## 실제 적용·검증

`battle_hud.gd`의 상단 `ResourceHUD`에 이 PNG와 위 고정 영역을 연결했다. 관련 `verify_battle_hud.gd` 회귀가 통과했다. 별도 검증자가 Godot 4.7.2 / macOS Metal Forward Mobile의 격리된 실제 `main.tscn --app` 실행을 확인했고, 부모도 최종 440×900·320×900 화면을 직접 검토했다.

두꺼운 청동 삼각 코너와 금속 룬판이 제거되고 얇은 냉색 외곽·작은 깎인 모서리·남청색 바탕·미세한 청록 룬만 남았다. 두 화면 폭에서 늘어짐·잘림·상단 추가 배경이 없고, 일반·긴 자원 수치가 읽힌다. 네 비교 상태에서 전체 자식 위치·크기·폰트·정렬·텍스트·카메라가 기존 기록과 같았으며 HUD 높이 94px과 여백 8px을 유지했다. 홈·메뉴 닫기·전투 재개는 관련 네 함수가 기존 검증본과 같아 실제 조작 근거를 재사용했다. 독립 판정은 PASS이며 미해결 결함은 없다.

[최종 440px](verification/resource-hud-slim-440x900.png) · [최종 320px](verification/resource-hud-slim-320x900.png) · [긴 수치 320px](verification/resource-hud-slim-long-320x900.png).

상세 실행·비교·최종 입력 해시는 Git에서 제외된 `build/godot/resource-hud-runic-slim-review/`에 로컬 보관한다. 첫 실행 중 겹친 다른 콘텐츠 변경의 초기화 오류는 해당 변경이 수정된 현재 소스로 다시 확인했다. 최종 실제 실행은 `failures=[]` / 종료 0이며 소스·PNG 11개가 실행본과 일치했다. Android 전용 변경이 아니므로 APK·실기기 검증은 수행하지 않았다.
