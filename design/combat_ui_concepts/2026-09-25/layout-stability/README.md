# UI·모달 크기 안정화

2026-09-25. 여러 화면에서 UI·모달 크기가 간헐적으로 화면을 가득 채우도록 바뀐다는 사용자 제보를 조사했다. 외형·버튼 의미·저장 및 전투 계약은 유지하며 재현된 배치 결함을 수정했다.

- 전투 공용 모달: 처음 정한 최소 폭을 계속 유지해 440→320 화면 축소 시 390px 모달이 화면 밖으로 넘쳤다. 본문 폭·줄바꿈이 확정되기 전 종료 확인창 높이가 497.76px였다가 295px로 줄어드는 초기 변동도 확인했다. 요청 최대 폭은 보존하면서 화면·본문 최소 크기·배치 변화에 따라 재측정하고, 최초 컨테이너 배치 두 프레임 후 fade를 시작한다. 특성 모달에만 있던 재측정 연결을 공통 경로로 통합했다.
- 로비 설정·이벤트: 앱 포커스 알림의 자식 순회 중 창을 재생성해 `add_child` 오류가 발생하고, 설정 본문이 32px로 붕괴했다. 재생성을 알림 순회 이후로 미루고 중복 요청을 합친다.
- 포탑 모듈 목록: 가로 행의 ‘보유 개수’가 최소 폭으로 배치되며 한글이 세로로 줄바꿈되어 ‘일괄 분해’ 버튼까지 과도하게 높아졌다. 짧은 개수 문구를 한 줄로 유지한다.

근거: [로비 수정 전 로그](before.log), [전투 수정 전 로그](battle-before.log), [수정 후 실제 실행](after.log), [관련 회귀 결과](regression.log), [검사 코드](../../../../godot/verify_ui_layout_stability.gd), [최종 입력 해시](inputs-sha256.json). 로비 연구 상세의 반복 새로고침·크기 변경에서도 정상 크기를 확인했다. 전투의 긴 본문을 짧게 바꾸면 770→110px로 줄어드는 것과 최초 표시 프레임의 높이 상한, 모달을 연 채 320↔440 변경, 로비 포커스 알림 반복, 빈 모듈 목록과 보유 목록을 검사했다.

Godot 4.7.2, macOS Apple M4, OpenGL Compatibility. 사용자 저장을 읽지 않는 격리 fixture로 실제 UI와 Godot focus notification 순회를 실행했다. Android 실기기 OS 수명주기·APK는 실행하지 않았다. 제보된 모든 상황의 재현을 주장하지 않으며 위에서 확인한 결함과 검증 범위를 기록한다.
