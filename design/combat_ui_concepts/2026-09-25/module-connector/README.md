# 포탑 모듈 연결부 비율 보존

2026-09-25. 포탑과 모듈 사이의 연결 장치가 가로로 늘어나 보인다는 사용자 요청에 따라, 원본 PNG 전체 확대를 부품별 배치로 교체했다. [현행 기준](../../../../DESIGNS.md), [기존 포탑 아이콘 기준](../../2026-09-22/module-icons/README.md)을 따른다.

[연결부 구현](../../../../godot/ui/module_connector.gd)은 기존 `turret_connector_assembly.png`의 영역을 `AtlasTexture`로 참조한다. 원본 파일·금속 재질·청록 발광은 변경하지 않는다. 단자와 세 접합부는 원본의 0.22배 균일 비율로 표시하고, 관은 `NinePatchRect`로 두께와 양끝 마감을 유지한 채 직선 구간만 늘린다. [포탑 탭](../../../../godot/ui/lobby_collection.gd)은 슬롯 중심에 관을 맞추고 조립 영역을 최대 380px로 중앙 정렬한다. 세로 관은 포탑 단자에서 모듈 슬롯까지 구간의 64% 위치에 두어, 원본처럼 포탑 쪽 공급관과 모듈 쪽 분기관의 길이 균형을 유지한다. 좁은 화면에서는 기존 포탑 미리보기 크기를 유지하며 금색 단자가 프레임 가장자리에 맞물리도록 위치를 조정했다. 실제 너비를 배치하므로 창을 다시 줄일 때 최소 크기가 고착되지 않는다.

검증은 사용자 저장을 읽거나 변경하지 않는 격리 Godot 프로젝트에서 실제 Lobby UI와 테스트 모듈 상태로 실행했다. Godot 4.7.2 / OpenGL Compatibility / Apple M4이며 Android 실기기·APK는 이번 작업에서 실행하지 않았다. [검증 스크립트](verify_connector.gd), [실행 로그](balanced-runtime.log), [관련 회귀 결과](regression.log), [입력 해시](inputs-sha256.json).

- 320 → 440 → 900 → 320px 연속 리사이즈: 접합부 비율·관 두께·끝 마감, 슬롯 중심, 최대 폭·중앙 정렬 확인.
- 실제 입력: 포탑 6종 선택, 장착 슬롯 상세 선택, 빈 슬롯 필터 확인. 기존 회귀로 장착·해제·필터 계약 확인.
- 최종 적용 화면: [320px](balanced-320.png), [440px](balanced-440.png), [900px](balanced-900.png), [빈 슬롯 440×900](balanced-empty-440.png). 시안이 아닌 Godot 앱 UI 실행 캡처다.
