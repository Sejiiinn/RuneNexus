# 주황 대포 그래픽 개선 시안

2026-09-10. 사용자가 전장 환경에 만족하고 대포만 개선한 캡처 한 장을 요청했다.

- `battlefield-cannon-refined.png`: 2160×1620 실제 Blender 렌더 1장.
- `battlefield-cannon-refined.blend`: 대포 개선본이 들어 있는 독립 3D 원본.
- `refine_cannon.py`: 기존 `../production/battlefield-3d-final.blend`의 대포 하위 모델만 교체하는 제작 스크립트.

주황색과 한 칸의 받침 크기를 유지하면서 경사 측면 장갑, 단계적으로 좁아지는 포신, 팔각 포구와 안쪽 강선, 반동 실린더·피스톤·호스, 회전 기어와 고정 볼트, 금속 룬 상감과 국소 마모를 추가했다. 기존 포탑 회전·반동 계층을 유지했다.

환경 오브젝트·카메라·광원 위치가 동일함을 스크립트에서 확인하고, 기존 정지 화면과 같은 90프레임을 렌더해 형태·재질·환경과의 조화를 검토했다. 화면 해상도만 높였으며 조명과 구도는 변경하지 않았다. Blender MCP가 연결되지 않아 저장된 원본을 Blender background 모드로 열었다.

게임 적용이나 모바일 성능 검증 결과가 아닌 시안이다. 게임 코드·기존 영상·원본 환경 파일은 변경하지 않았다. 석재 텍스처는 `../production/textures/`의 기존 파일을 참조한다.
