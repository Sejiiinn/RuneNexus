# 대포 재질 수정 시안

2026-09-10 사용자 정정: 화려한 장식이나 복잡한 형태가 아니라, 너무 매끈해서 장난감처럼 보이는 재질이 문제다. 앞선 `cannon_refinement/`의 장갑·기어 추가안은 이 요구를 충족하지 못했다.

`../production/battlefield-3d-final.blend`의 원래 대포 형태로 돌아가 대포 재질만 수정했다. 주황 도장의 코팅 광택을 제거하고 도장층의 금속성을 낮췄으며, 불균일한 무광 거칠기·미세 요철·드문 칠 벗겨짐을 적용했다. 금속 부품도 균일한 반사를 줄였다. 대포에서 사용하는 재질은 복사하여 적과 환경에 영향을 주지 않는다.

- `battlefield-cannon-matte.png`: 2160×1620 실제 Blender 렌더 1장.
- `battlefield-cannon-matte.blend`: 편집 가능한 원본. 기존 석재 텍스처를 참조한다.
- `refine_materials.py`: 원본 장면에서 대포 재질만 교체하는 스크립트.

기존 90프레임·환경·카메라·조명 유지. 오브젝트와 대포 정점 수가 변하지 않았음을 검사했고, 렌더에서 광택 감소와 주황색 유지 여부를 확인했다. 게임 코드와 런타임 에셋은 변경하지 않았다.
