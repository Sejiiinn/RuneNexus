# 고품질 전장 그래픽 목표 시안

2026-09-10. 3D 또는 이미지 에셋 기반 2D 방향을 결정하기 위한 미확정 목표 이미지.

- `battlefield-art-target.png`: 내장 ImageGen 생성, 1536×1024 불투명 PNG 정지 시안 1장.
- `prompt.txt`: 최종 생성 프롬프트.
- 형태·색상 참고: `../cannon_tile_concepts/cannon-on-stone-tile-orange.png`.
- 목표: 주황색 대포, 유적의 입체적인 높낮이, 닳은 석재와 젖은 부분의 선택적 반사, 금속 재질, 따뜻한 발사광과 차가운 코어 조명, 방향성 있는 섬광·파편.
- 생성 결과의 맵·적·코어·환경 소품은 그래픽 설명용이다. 기존 스테이지 배치나 적 외형을 변경하라는 확정 요구가 아니다.

이 이미지는 실제 3D 렌더·엔진 화면·성능 검증 결과가 아니다. 이미지의 품질만으로 실시간 3D와 사전 렌더 2D의 우열을 결정하지 않는다. 고정 배경 재질·정적인 조명은 2D 에셋으로도 표현할 수 있다. 자유로운 포탑 회전, 일관된 동적 조명·그림자·반사, 시점 변화는 실제 구현 샘플에서 비교할 항목이다. 2D에서도 일부 동적 효과는 별도 셰이더와 레이어로 구현할 수 있다.
