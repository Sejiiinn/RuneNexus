# 전장 3D 시험 장면

2026-09-10. 생성된 목표 이미지를 참고해 실제 지오메트리·재질·조명·애니메이션으로 만든 Blender 장면. 실시간 3D와 이미지 에셋 기반 2D 중 방향을 판단하기 위한 시안이다.

## 산출물

- `battlefield-3d-preview.mp4`: 1280×960, 24fps, 216프레임, 9초 H.264 영상.
- `battlefield-3d-still.png`: 1440×1080, 발사 순간의 실제 3D 렌더.
- `battlefield-3d-final.blend`: 최종 장면, 재질, 조명, 카메라와 애니메이션 원본. 활성 장면은 `RuneNexus_ArtTarget_3D`.
- `textures/`: PBR 원본과 [출처·라이선스 기록](textures/SOURCES.md). `.blend`와 함께 보관한다.

기존 시험 장면의 주황색 대포를 재사용하고, 석재 타일·낮은 폐허 외벽·기둥·횃불·보라색 포털·청록색 코어를 구성했다. 포탑은 이동하는 적을 향해 회전하고 포구광·반동·충격 효과를 재생한다. 바닥과 외벽에는 Poly Haven의 석재 PBR 텍스처를 적용했다.

## 제작 경로

Blender MCP 연결을 사용할 수 없어 기존 Blender 원본을 background 모드로 열어 제작했다. 이미지 생성 결과를 영상으로 변환한 것이 아니라 3D 장면을 EEVEE로 렌더했다.

1. `build_battlefield.py`: `../../cannon_3d_preview/cannon-preview.blend`에서 대포를 가져와 전장과 애니메이션 생성.
2. `apply_materials.py`: PBR 텍스처와 표면 세부 재질 적용.
3. `refine_and_render.py`: 첫 렌더에서 확인한 조명·코어 과노출·주변 식생·카메라 구도 보정.
4. `export_video.py`: 최종 식생 색상·약한 bloom 적용, 정지 화면과 영상 출력. Blender 5.2.1 기준.
5. `verify_video.swift`: AVFoundation으로 영상 길이·크기·프레임 속도와 세 시점의 디코딩 확인.

검증 결과: 9.0초·1280×960·24fps 확인, 0.5초·3.9초·8.5초 H.264 디코딩 성공. 실제 렌더와 중간·후반 프레임에서 포탑 방향 변화와 적 이동을 확인했다.

## 판단 범위

석재 질감과 주황색 대포, 따뜻한 횃불과 차가운 코어의 대비, 움직임에 따른 입체감이 검토 대상이다. 목표 이미지와 비교하면 적 모델·자연물·이펙트의 조형과 세부 묘사는 아직 단순하다. 이 결과를 생성 이미지와 같은 완성도나 상용 게임 최종 품질로 간주하지 않는다.

사전 렌더 출력이므로 24fps는 영상 설정이며 게임 실행 성능이 아니다. 엔진 도입·게임 코드·스테이지 데이터·런타임 에셋은 변경하지 않았다. 화면만으로 렌더 방식의 성능이나 유지 비용을 판정할 수는 없다.
