# 스테이지 1 타일·환경 개선 제안

상태: 검토용 시안, 미구현·미확정. 2026-09-10.

## 방향

‘전투 흔적이 남은 룬 유적 방어선’. 현재 스테이지 1의 8×10 맵, 적 이동 경로, 건설 가능 칸, 포털·코어 위치를 유지하면서 타일의 재질과 외곽 환경을 개선한다.

| 영역 | 제안 |
| --- | --- |
| 이동 경로 | 닳은 석재와 다져진 흙이 연결된 길. 따뜻한 회갈색으로 건설 지형과 구분하고, 수레 자국·파편·그을음은 낮은 대비로 제한한다. |
| 건설 지형 | 이끼 낀 낮은 석조 기반. 칸 경계는 얕은 이음매로 읽히게 하고, 중앙은 비워 포탑과 선택 표시가 선명하게 보이도록 한다. |
| 타일 연결 | 칸마다 두드러지는 검은 틈과 동일 무늬 반복을 줄인다. 기본 타일의 재질 변형과 경계·모서리 조합을 사용한다. |
| 비플레이 영역 | 플레이 지형보다 낮고 어두운 암반·흙으로 잇고, 낮은 무너진 석벽·부러진 말뚝·낡은 청록 깃발·방패 조각을 소량 배치한다. |
| 진입부 | 기존 보라 포털 주변에 깨진 룬석과 국소적인 그을음을 둔다. |
| 코어 주변 | 기존 청록 코어를 받치는 석재·금속 기반과 희미한 룬 문양으로 방어 목표를 강조한다. |
| 움직임 | 후속 단계에서 깃발의 작은 움직임, 희미한 먼지, 기존 포털·코어 빛의 호흡을 검토한다. 경로를 가리는 안개는 사용하지 않는다. |

## 단계별 적용 제안

1. 바닥 재질과 타일 연결 개선. 실제 모바일 배율에서 경로·건설 칸 식별 확인.
2. 비플레이 영역과 외곽에 소량의 환경 에셋 추가. 포탑·적·선택 표시 가림 확인.
3. 필요한 소수 요소에만 미세 애니메이션 추가. 렌더 비용 확인.

장식은 시각 요소이며 충돌·엄폐·건설 제한 등 새로운 게임 규칙을 뜻하지 않는다. 전투 UI와 저장 형식의 변경은 제안 범위에 포함하지 않는다.

## 산출물과 확인 범위

- `stage1-battlefield-concept.png`: ImageGen으로 제작한 전체 환경 방향과 재질 확대 시안. 불투명 PNG, 정지 프레임 1장. 게임에서 직접 로드하는 타일 에셋이 아니다.
- `prompt.txt`: 생성에 사용한 프롬프트.
- 기준: `lib/data/definitions/game_stage_maps.dart`의 `gameMap`, `DESIGNS.md`, `design/stats_layout_concepts/implemented-a-live.png`의 기존 화면.
- 생성 이미지의 세부 격자·소품 배치는 확정 데이터가 아니다. 실제 제작 시 맵 데이터에 맞춰 타일과 환경 에셋을 분리한다.
- 이번 작업은 시안 제안이며 게임 코드 변경·실제 적용 화면 검증은 수행하지 않는다.
