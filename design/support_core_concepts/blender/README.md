# 지원 코어 E2 — Blender 디자인 원본

2026-10-25. 사용자가 고른 [E2 시안](../2026-10-25/E2-short-obelisk-conduit.png)을 기준으로 만든 3D 디자인 원본이다. 게임 모델은 이 원본에서 [게임용 모델](../game/README.md)로 내보냈다. 규칙·저장·화면은 [지원 코어 설계](../../../docs/support_core_design.md)를 따른다.

- 편집 원본: [support-core-E2.blend](support-core-E2.blend). E2 시안을 `REFERENCE — approved concept E2` 이미지로 패킹했다.
- 제작 코드: [build_support_core.py](build_support_core.py)
- 렌더: [대표 3/4 시점](support-core-hero.png), [팔 정면 시점](support-core-axis.png), [게임 카메라 시점](support-core-game.png), [결정 근접](support-core-crystal.png), [160px 축소](support-core-hero-160.png)
- 시안 대조: [E2 시안(왼쪽)과 Blender 렌더(오른쪽)](support-core-vs-E2.png). 같은 방위(오벨리스크 모서리가 카메라 쪽)와 비슷한 고도(38°)에서 찍었다.

렌더는 Blender에서 촬영한 3D 모델 검수 이미지다. Codex 시안이나 실제 게임 화면과 구분한다.

## 구조

| 컬렉션 | 내용 |
| --- | --- |
| `01 Base & Conduit Arms` | 가운데 받침 판, `conduit_arm_0~3` 아래 같은 치수의 팔 4개(도관 몸체·꺾인 청록 홈과 어두운 턱·옆면 룬·뿌리 고정쇠와 하부 띠·겹 구조 끝 캡과 수정 창) |
| `02 Obelisk` | 아래가 넓은 팔각 오벨리스크, 네 면의 마름모 룬, 능선이 접힌 모서리 청동 기둥 |
| `03 Crown & Crystal` | 연속 청동 고리에서 솟은 왕관 블록·모서리 방패, 테두리 위 다면 발광 보석, 떠 있는 결정 `core_crystal`(두 단 면의 투명 보석 껍질, 위 면과 거들·아래 면 재질 분리), 그 안의 발광 심 `Crystal heart`, 둘레의 파편 3개 |
| `90 Studio` | 카메라·조명·남색 바닥 |
| `99 Recess Cutters` | 홈을 파는 불리언 절단체(렌더 제외) |

- 좌표: Z 위, 팔은 ±X·±Y 방향이다. 타일 폭 1.0 기준이며, 끝 캡 바깥면이 중심에서 .46에 있어 타일 가장자리에 닿는다. 결정 끝 높이는 약 .665다.
- 끝 캡: 결속 테두리(낮은 단), 양쪽 두꺼운 측면 슬랩, 하단 문턱·상단 인방이 어두운 수정 하우징을 감싼다. 바깥 창과 윗면 창은 낮은 피라미드 면으로 하이라이트를 나눈다.
- 재질: 금속은 화염 포탑의 [단조 마감](../../fire_tower_concepts/runic_3d/finish_materials.py)을 공유하고 `apply_metal_finish()`에서만 지원 코어용으로 재정의한다. 청동은 더 어둡고 갈색 쪽에, 균열 요철은 약하게, 모서리 마모는 넓고 밝게 했다. 철은 석판색이다. 떠 있는 결정은 투과(IOR 1.6) 청록 보석이고, 안쪽 심이 빛을 낸다. 사용자 요청(2026-10-25)으로 밋밋한 단색 결정을 시안처럼 투명한 보석으로 바꿨다. 청동은 게임 거리에서 황동처럼 번들거리지 않게 금속성·광택을 낮추고 홈 음영을 늘렸다. 청록 기준은 #3FE6D6이다.
- 삼각형은 스튜디오를 빼고 약 10,800개다.

## 검증

2026-10-25 사용자 요청으로 Codex 독립 검증을 네 차례 받으며 고쳤다. 처음에는 전체 비율·받침만 PASS였다. 최종 판정은 전체 비율·팔·끝 캡·오벨리스크·왕관과 우물·받침·재질·게임 시점의 결정 분리 모두 PASS다.

- 선택 개선으로 남은 차이: 게임 시점에서 결정 윗부분이 뒤쪽 팔의 청록 홈과 겹친다. 밝기 차이와 윤곽으로 구분된다. 청동 마모 대비는 시안보다 약하다.
- 형상 검사: Codex 쪽 Blender 실행이 충돌해 Codex는 미확인으로 판정했다. 저장 파일을 Blender로 직접 검사한 결과, 평가 메시 178개에서 NaN·비다양체·뒤집힌 닫힌 메시는 없었다. 면적 0 면은 오벨리스크 마름모 룬 홈 바닥 중앙의 일직선 삼각형 4개뿐이며, 홈 안 발광체에 가려진다.
- 실제 게임 화면은 [게임용 모델 기록](../game/README.md#실제-화면)에 있다.
- 시안의 청록 빛 번짐(블룸)은 렌더 후처리로 넣지 않았다. 게임에서는 발광 재질의 배율로 표현한다.

## 재생성

저장소 루트에서 실행한다. 인자 없이 실행하면 위 렌더 다섯 장을 모두 다시 찍고, `-- hero`처럼 시점 이름을 주면 그 시점만 찍는다.

```sh
cd design/support_core_concepts/blender
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python build_support_core.py
```
