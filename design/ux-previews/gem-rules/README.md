# 젬 규칙 오프라인 렌더 검증

2026-09-08. Mac 화면 잠금 상태에서 Flutter 테스트 엔진으로 생성한 실제 위젯·전투 컴포넌트 렌더입니다. 실제 사용자 저장 데이터는 사용하지 않았습니다.

- `reward_320x800_*`: 320×800 논리 화면, 2배 PNG. 선택 전·선택 후.
- `reward_640x360_*`: 640×360 논리 화면, 2배 PNG. 선택 전·선택 후·하단 스크롤.
- `frost-range.png`: 실제 서리 포탑 선택 표시. 사거리 76 유지, 폭발 젬 장착 시 효과 반경 76→95.
- `cannon-chain.png`: 실제 포탄 이동·충돌·연쇄 처리 뒤 명중 프레임 3개. 각 행은 별도 시점이며 1.7배 확대. 최초 폭발 반경 52.5, 후속 두 번 모두 26.25. 적 HP는 1000에서 최초 975, 후속 각각 987.5. 적 이동은 고정하여 투사체 처리와 렌더를 분리 확인.

## 재현

저장소 루트에서 실행:

```sh
flutter test tool/gem_combat_render_test.dart tool/gem_reward_render_test.dart
```

검증: 렌더 테스트 3개 통과, 두 하네스 정적 분석 이상 없음, PNG 직접 확인. 문구 잘림이나 오버플로 없이 선택·스크롤 상태가 표시됩니다.

폰트는 프로젝트 NotoSansKR를 로드했습니다. 보상 캡처에서 폰트 미지정 커스텀 버튼은 테스트 엔진의 기본 폰트로 한글을 표시하지 못해, 캡처 하네스에서 해당 RenderParagraph의 fontFamily만 NotoSansKR로 보정했습니다. 제품 파일의 텍스트·스타일 수치·레이아웃 코드는 변경하지 않았습니다.

이 결과는 오프라인 렌더 확인이며 실제 브라우저·기기의 입력 동작, 연속 재생 성능, 플랫폼별 글꼴 fallback 확인을 대신하지 않습니다.
