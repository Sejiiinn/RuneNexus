# 스탯 컴포넌트 시안

2026-09-08. 사용자의 직접 컴포넌트 시안 요청에 따라 HTML/CSS로 그린 비교 자료입니다. 이미지 생성 모델을 사용하지 않았으며 게임 코드 반영은 포함하지 않습니다.

- `index.html`: 수정 가능한 원본. 실제 프로젝트 Noto Sans KR 글꼴을 사용합니다.
- `stats-comparison.png`: 848×1060 브라우저 캡처. 각 포탑 패널은 360px 폭입니다.

A: 2열 수치표. 항목·수치를 한 줄로 배치하고 행 구분선만 유지.
B: 열린 3열. 기존 항목 순서를 유지하며 카드 배경·테두리 제거.
C: DPS 강조. 왼쪽 주 지표와 오른쪽 세부 수치 분리.
D: 항목별 목록. 공격·성능·치명 세 줄로 분류.

게임 스크린샷에서 확인한 대포 레벨 1 및 레벨 2 미리보기 수치를 사용했습니다. 상단 공통 요소는 배치 맥락을 위한 표현이며, 비교·수정 범위는 스탯 영역입니다. 각 시안은 기본 상태와 미리보기를 함께 보여줍니다. 화상·감속 등 조건부 정보와 긴 숫자의 줄바꿈은 실제 구현 시 유지해야 합니다.

## A안 반영

후속 승인으로 게임의 포탑 스탯에 A안을 적용했습니다. 피해/DPS, 초당/사거리, 치명 확률/치명 피해를 2열로 배치하고 개별 카드 대신 가로 구분선을 사용합니다. 화상·감속 추가 항목, 화상 DPS 구분, 레벨업 미리보기는 유지합니다. 값은 가용 너비에 따라 줄바꿈합니다.

`implemented-a-live.png`는 실제 게임 360×800 스크린샷입니다. 320px 화면에서도 레벨업 미리보기의 모든 수치가 보이는 것을 확인했습니다. HUD 테스트 8개, 정적 분석, 웹 빌드를 통과했습니다.

스탯 수가 늘어도 창이 위로 커지지 않도록 스탯 뷰포트를 기본 세 줄 높이로 고정했습니다(기본 글자 크기 74px, 시스템 글자 확대 반영). 일곱 번째 이후 항목은 스크롤바 없이 영역 안에서 세로로 탐색합니다. `seven-stats-scroll.png`는 화염 포탑의 추가 화상 정보를 아래로 넘겨 본 실제 화면입니다. 6개/7개 스탯 간 창 높이·탭 위치 동일 및 추가 항목 접근 회귀 테스트를 포함한 HUD 테스트 9개를 통과했습니다.
