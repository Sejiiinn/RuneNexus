## 공통 적용 원칙

실제 제작 시 기존 이동 경로·건설 칸·포털·코어 위치를 보존한다. 생성 이미지의 격자나 세부 소품 배치는 확정 데이터로 사용하지 않는다. 장식은 비플레이 영역에 제한하고, 빛과 입자는 경로·포탑·적 식별을 방해하지 않는 강도로 조절한다. 균열과 열광은 시각 표현이며 피해 지형 등 새 게임 규칙을 뜻하지 않는다.

이번 요청에서는 시안만 제작하며 게임 코드·현행 디자인 기준은 변경하지 않는다. 실제 게임 크기의 조작·렌더링 검증은 구현 단계에 수행한다.
