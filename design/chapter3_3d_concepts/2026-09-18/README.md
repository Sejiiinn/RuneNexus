# 챕터 3 타일 멀티뷰 설계안

2026-09-18. 사용자가 첫 멀티뷰의 두꺼운 형태를 선택하고 Blender 제작을 승인했다. [승인된 두꺼운 시안](tiles-multiview-thick-approved.png)이 형태·재질 기준이다. 이미지는 내장 ImageGen 제작이며 인게임 적용 결과가 아니다.

- [승인된 두꺼운 멀티뷰](tiles-multiview-thick-approved.png): 상면 / 측면 / 3⁄4.
- [얇은 보정안](tiles-multiview.png)은 비교 이력이며 제작 두께 기준으로 사용하지 않는다.
- [초기·보정 프롬프트](prompt.txt).
- 공통 제안 치수: 1×1 타일, 몸체 높이 약 0.34 (두꺼운 시안 기준), 모서리 절삭 0.055, 상판 두께 0.045. 평면 크기와 기본 윗면 높이를 통일한다. 접합부는 타일 밖으로 돌출하지 않는다.
- 주조 철판: 돌기 5개, 모서리 볼트 4개. 밝은 회갈색 금속으로 길을 식별한다.
- 열 배출 격자: 같은 몸체, 구멍 5×5, 볼트 4개. 철판 길의 시각 변형이며 새로운 피해 지형이 아니다. 내부 주황광만 약하게 사용한다.
- 건설 기반: 어두운 금속 상판, 막힌 평면 중앙 디스크와 낮은 원형 고정부, 상하좌우 청동 고정쇠 4개, 모서리 볼트 4개. 중앙을 포탑 설치 공간으로 남긴다.
- 측면: 상하 플랜지, 수직 보강대 2개와 오목한 구획 3개. 외곽 지층과 포탈·코어는 이번 타일 설계와 별개이며 기존 공용 포탈·코어를 재설계하지 않는다.

시각 검토: 승인된 첫 이미지의 사선 철판 돌기 6개와 상면 5개는 모순이므로 제작은 상면의 5개를 따른다. 격자 5×5·고정쇠 4개를 유지한다. 생성 이미지의 정투영 뷰 간 표시 축척과 두께는 엄밀한 치수 도면 수준으로 일치하지 않으므로 위 수치를 제작 기준으로 사용해야 한다. 상세 제작 전에 공통 몸체 블록아웃으로 치수·접합을 확인한다. 실제 Android 게임 크기의 재질·가독성 검수는 아직 수행하지 않았다.

승인 범위는 Blender 타일 원본 제작이며 게임 이식은 포함하지 않는다.

## Blender 제작 결과

두꺼운 승인안을 기준으로 [3종 편집 원본·실제 렌더](../../chapter3_3d/tiles/README.md)를 제작했다. 동일 몸체 높이와 부품수, 실제 격자 관통을 확인했다. 시안보다 청동·건설 상판이 밝게 보이는 차이는 제작 기록에 남겼으며 인게임 이식·검수는 아직 수행하지 않았다.
