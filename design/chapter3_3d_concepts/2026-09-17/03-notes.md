# 인게임 이미지 시안

내장 ImageGen으로 기존 `design/stage1_3d/material_match/final-combat-phone.png`를 편집한 이미지 목업. 실제 게임 적용이나 Blender 제작 결과가 아니다.

금속 리브 통행판·열 배출 격자·기계식 원형 건설 소켓을 기존 게임 카메라와 HUD 안에서 확인하기 위한 시안이다. 생성 결과는 입력 화면의 기존 경로를 유지했으며 프롬프트의 스테이지 11 격자를 정확히 재현하지 않았다. 실제 챕터 3 이식에는 기존 스테이지 11 맵 좌표를 사용해야 한다. 생성된 UI 글자나 코어 형태를 새 디자인 기준으로 취급하지 않는다.
