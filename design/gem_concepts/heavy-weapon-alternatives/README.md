# 중화기 증폭 젬 대체 시안

분류: 다른 젬에 재사용할 수 있는 미채택 형태 후보. 아래 내용은 당시 검토 기록이며, 현재 적용 스타일은 [현행 젬 안내](../README.md)를 따른다.

2026-09-09. 기존 중화기 증폭과 폭발 젬의 주황색 균열 원석 형태가 비슷하다는 피드백에 따른 비교용 시안. 아직 게임에 적용하지 않았다.

- A — 대구경 포탄형: 단일 탄두 형태와 굵은 원석 받침으로 중화기의 무게감 표현.
- B — 포신형 원석: 굵은 육각 개구부와 청록빛 내부로 중화기 기능을 직접 표현.
- C — 압축 동력핵형: 두꺼운 흑철 결정 사이에 보라색 에너지가 응축된 형태.

각 시안은 별도 하위 에이전트가 내장 ImageGen으로 생성했다. 프롬프트는 `a-prompt.txt`, `b-prompt.txt`, `c-prompt.txt`에 보존한다. 제작 요청 규격은 1024×1024 PNG, 단일 프레임, 투명 배경이다. 생성 파일의 실제 규격과 알파 상태는 아래 검증 기록을 따른다.

게임에 채택할 때는 기존 공용 에셋 규격인 512×512 RGBA와 464px 내부 영역에 맞춰 제작한다. 이름·효과·저장 식별자·공용 로딩 구조는 유지한다.

## 검증 기록

세 원본 모두 실제 출력은 1254×1254 RGBA PNG이며 알파 0–255와 완전 투명 배경을 확인했다. 요청한 1024와 달라 원본 그대로 보존했다.

[비교 이미지](comparison.png)와 [비교 화면](comparison.html)에 기존 폭발·중화기 증폭과 새 시안 3개를 나란히 배치했다. 24px·40px 표시도 확인했다. B는 포구 형태로 중화기 컨셉이 가장 직접적이지만 작은 크기에서 전체가 어둡게 보이는 편이다.

## 추가 시안 D · E · F

사용자의 다른 컨셉 3개 추가 요청에 따라 동일한 하위 에이전트들이 내장 ImageGen으로 각각 1회 생성했다. 게임에 적용하지 않은 비교용 이미지다.

- [D 공성추형](d-ram.png): 넓은 사선 타격면과 층진 황철석 등뼈로 묵직한 일격 표현. [프롬프트](d-prompt.txt)
- [E 반동 버팀쇠형](e-brace.png): 굵은 역U형 원석과 열린 하단으로 중량·반동을 버티는 구조 표현. [프롬프트](e-prompt.txt)
- [F 중력 광석형](f-gravity.png): 높은 적철광 주상과 주변의 큰 위성 광석으로 고밀도·중력 표현. [프롬프트](f-prompt.txt)

세 원본 모두 1254×1254 RGBA, 알파 0–255와 완전 투명 배경을 확인했다. D는 오른쪽 외곽이 이미지 끝에 닿아 채택 시 여백 보정이 필요하다. [추가 비교 화면](comparison-2.html) / [추가 비교 PNG](comparison-2.png).

## D + F 혼합 시안 G

사용자가 D와 F를 좋아하며 섞은 느낌으로 하나 더 요청했다. [G 중력 공성추](g-gravity-ram.png)는 D의 넓은 사선 타격면과 층진 황철석, F의 어두운 위성 광석 3개와 자홍빛 광물맥을 결합했다. 두 원본을 직접 참조하여 내장 ImageGen으로 1회 생성했다. [최종 프롬프트](g-prompt.txt).

실제 출력은 1254×1254 PNG이며 알파 채널이 없고 체크무늬 배경이 포함되어 있다. 컨셉 검토용 원본으로 보존했으며 게임 적용 시 투명 배경 처리가 필요하다. 게임 에셋은 아직 교체하지 않았다.
