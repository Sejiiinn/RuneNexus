# 중화기 증폭 — 굵은 기둥 결합 시안

분류: 다른 젬에 재사용할 수 있는 미채택 형태 후보. 아래 내용은 당시 검토 기록이며, 현재 적용 스타일은 [현행 젬 안내](../README.md)를 따른다.

2026-09-10 사용자의 두꺼운 기둥 여러 개가 합쳐진 형태 3개 요청. 하위 에이전트가 각각 내장 ImageGen으로 단일 시안을 생성했다. 주황색 결정과 검은 암석의 기존 재질을 유지하며, 둔탁함을 기둥의 굵기·짧은 몸체·넓은 평단면과 배치로 표현한다.

- [W 밀집 묶음형](w-cluster.png): 다섯 기둥이 밀집한 하나의 덩어리. [프롬프트](w-cluster-prompt.txt)
- [X 계단형](x-stepped.png): 높이가 다른 기둥들이 나란히 융합. [프롬프트](x-stepped-prompt.txt)
- [Y 엇물림형](y-interlocked.png): 세 기둥이 다른 각도로 결합. [프롬프트](y-interlocked-prompt.txt)

[비교 이미지](comparison.png) / [비교 화면](comparison.html). 24px·40px 미리보기도 포함한다. 게임 에셋은 아직 변경하지 않았다.

세 이미지 모두 실제 1254×1254 RGBA PNG이며 알파 0–255와 완전 투명 배경을 확인했다. 비교 화면에서 전체 형태와 작은 아이콘 크기를 확인했다. X는 요청한 여백보다 좁지만 전체 잘림은 없다.

## Y 수정 — 중앙 기둥 추가

2026-09-10 사용자 요청에 따라 기존 Y의 세 기둥 사이 앞쪽 중앙에 네 번째 굵은 기둥을 추가했다. 기존 뒤쪽 높은 기둥과 좌우 각도·주황색 광물 재질은 유지했다. [4기둥 시안](y-interlocked-four.png) / [ImageGen 편집 프롬프트](y-interlocked-four-prompt.txt).

내장 ImageGen 편집 1회. 실제 1254×1254 RGB PNG이며 체크무늬 배경이 포함되어 있다. 컨셉 검토용 원본으로 보존하고, 게임 적용 시에는 투명화가 필요하다. 게임 에셋은 아직 교체하지 않았다.
