# 중화기 증폭 — 새 컨셉 9개

분류: 다른 젬에 재사용할 수 있는 미채택 형태 후보. 아래 내용은 당시 검토 기록이며, 현재 적용 스타일은 [현행 젬 안내](../README.md)를 따른다.

사용자가 앞선 A–G와 다른 컨셉 9개를 요청하여 3개 하위 에이전트가 각각 3개씩 내장 ImageGen으로 제작한 비교용 시안이다. 각 이미지별 독립 프롬프트로 생성했다. 게임 에셋이나 코드는 수정하지 않았다.

제작 요청은 단일 프레임, 1024×1024 PNG, 투명 배경이다. 원본을 보존하며, 채택 시 게임의 512×512 RGBA·464px 내부 영역 규격에 맞춘다.

## 확인 결과

9개 모두 실제 출력은 1254×1254 RGBA PNG이며 알파 0–255와 완전 투명 배경을 확인했다. 비교 화면에서 전체 외곽과 24px·40px 표시를 확인했다. O는 전면에 큰 3층이 두드러지는 결과다. 생성 규격 그대로 보존한 시안이며 게임 적용은 하지 않았다.
