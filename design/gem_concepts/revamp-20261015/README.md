# 젬 개편 시안

세트 전체가 개편된다는 가정 아래 젬별 시안을 만드는 폴더다. 게임에는 적용하지 않았고, 현행 기준은 [젬 안내](../README.md)를 따른다. 나머지 시안은 사용자 요청으로 삭제했다.

## 물리 피해 증폭 (효과: 물리 포탑 피해 40% 증폭)

현재 유지 시안: [Y1](physical-y1.png) — 은백색 가공 보석을 금 주먹 세공이 감싼 형태. 프롬프트는 [prompt.txt](prompt.txt).

## 개편 설계 규칙 (PoE 서포트 젬 22종 비교 + 사용자 피드백)

- **보석은 가공한 보석이다.** 윤곽이 또렷하고 표면이 매끈하게 다듬어졌으며 넓고 둔탁한 면 몇 개로 깎였다. 불규칙한 원석·돌덩이 질감도, 정밀하게 반짝이는 브릴리언트 컷도 쓰지 않는다.
- **둔탁함은 윤곽과 면 크기의 문제이고 내부 정보를 없애는 것이 아니다.** 반투명한 깊이, 밝은 중심에서 가장자리로의 음영, 면 모서리의 흰 발광선, 모서리 마모를 유지한다. 금에는 망치 자국·홈·틈새 그림자를 둔다.
- **색은 현행 젬 색을 유지한다**(물리 = 은백색).
- **금은 손으로 벼린 세공 조각 2~4개**가 보석을 쥐거나 감싸며 그 형태가 효과를 뜻한다. 얇은 가장자리 선, 두꺼운 문양 테두리, 장식 징 반복은 쓰지 않는다.
- **보석이 주인공이다**(약 65%), 금은 약 35% 이하.
- 검·망치·손 같은 **사실적인 소품은 붙이지 않는다**(상품 이미지처럼 보임). 모티프는 금 조각의 추상적인 형태로 표현한다.
- 젬마다 금 조각이 만드는 실루엣을 다르게 한다. 모든 젬을 둥근 테두리로 통일하지 않는다.
- PoE 원본 아이콘은 참고용이며 이 저장소에 저장하지 않았다.
