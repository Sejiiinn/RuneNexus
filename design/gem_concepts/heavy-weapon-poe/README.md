# PoE 보조 젬 참고 — 중화기 증폭 5개 시안

분류: 다른 젬에 재사용할 수 있는 미채택 형태 후보. 아래 내용은 당시 검토 기록이며, 현재 적용 스타일은 [현행 젬 안내](../README.md)를 따른다.

사용자의 PoE 유사 효과 젬 참고 요청에 따라 PoE 1의 기능과 실제 아이콘을 확인하고, 하위 에이전트 3개가 내장 ImageGen으로 5개를 각각 생성했다. 색 보석의 큰 면과 금속 외곽의 인상을 Rune Nexus 원석 질감으로 새롭게 해석했다. 게임 적용 전 시안이며 기능·수치는 변경하지 않았다.

PoEDB의 원본 아이콘을 브라우저 화면 또는 이미지 파일로 직접 확인했다. PoE 원본 이미지·페이지 캡처는 참고용이며 게임 배포 에셋에 포함하지 않는다.

각 이미지의 최종 생성 프롬프트는 같은 이름의 `-prompt.txt`에 보존한다. [전체 비교 PNG](comparison.png) / [비교 화면](comparison.html).

## 산출물 확인

5개 모두 실제 출력은 1254×1254 RGBA PNG이며 알파 0–255와 완전 투명 배경을 확인했다. 24px·40px 비교와 전체 외곽을 확인했다. 이 시안은 기존보다 가공된 보석의 인상을 강화한 후보이며, 현재 디자인 기준이나 게임 에셋을 교체하지 않았다.

## T 수정 — 주황색 원석

사용자가 확장 청옥을 현재 젬과 같은 주황색 톤에 약간 거친 원석 느낌으로 요청했다. [수정 시안](t-area-orange-rough.png)은 T의 넓은 타원·겹친 확장층을 유지하고 현재 heavyWeapon 에셋을 색·질감 참고로 사용해 주황색 결정과 불규칙한 광물 가장자리를 더했다. 내장 ImageGen 편집 1회. [최종 프롬프트](t-area-orange-rough-prompt.txt).

게임 에셋은 교체하지 않았다. 실제 출력은 1254×1254 PNG이며 알파 채널 없이 체크무늬 배경이 포함되어 있다. 컨셉 검토용으로 보존하며 채택 시 투명화가 필요하다.

## T 수정 2 — 자연 원석 강화

2026-09-10 사용자가 더 원석처럼 수정 요청. [수정 2 시안](t-area-orange-raw-v2.png)은 매끈한 타원 고리를 끊어진 결정층으로 바꾸고, 중앙을 비대칭의 큰 자연 파단면으로 변경했다. 주황색·넓은 타원·확장층 인상은 유지했다. 내장 ImageGen 편집 1회. [최종 프롬프트](t-area-orange-raw-v2-prompt.txt).

생성 원본은 1254×1254 PNG이며 체크무늬 배경이 포함된 컨셉 검토용이다. 게임 에셋은 아직 교체하지 않았다.
