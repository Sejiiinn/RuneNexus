# 보존 전용 시각 자료

현재 적용·제작·재사용에 쓰지 않고 이력 보존만 필요한 자료를 둔다. `design/legacy/` 아래에는 저장소 기준 원래 경로를 유지한다. 이 폴더의 이미지·설명·과거 승인 기록을 현재 제작 기준으로 사용하지 않는다.

현재 적용본, 이를 수정·재생성하는 제작 원본, 재사용할 도구와 입력, 검토 중 시안은 기존 작업 경로에 유지한다. 파일의 나이·해상도만으로 보존 전용 여부를 판단하지 않는다. 상세 절차는 [에셋 작업 절차](../../.agents/asset_workflow_guide.md#보존-전용-자료-분리)를 따른다.
