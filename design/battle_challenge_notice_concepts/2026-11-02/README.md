# 전투 도전 조건 안내 시안 (2026-11-02)

[도전과제 설계](../../../docs/stage_difficulty_design.md#도전과제)의 「전투에서는 시작할 때 조건을 한 번 보여 주고 조건이 깨지면 한 번 알리며, 전투 HUD에 상시 표시는 더하지 않는다」를 그린 배치 시안이다. 바탕은 실제 앱 전투 캡처(3-6, 440×900, `verify_chapter_three_combat_render.gd --startup-smoke`)이고, 안내는 실제 글꼴·업적 아이콘으로 위에 얹었다. 모양은 로비 스테이지 카드의 조건 줄(어두운 반투명 바탕, 얇은 금색 테두리, 금색 「도전」)을 따르고 실패는 주황 테두리로 바꾼다.

| 파일 | 내용 |
| --- | --- |
| `A_start.jpg`, `A_fail.jpg` | A: 상단 HUD 바로 아래 가운데 띠(젬 소켓과 「고정」 사이). 시작 안내 두 줄(조건 / 실패 규칙), 실패 알림 두 줄(이유 / 클리어 보상은 그대로) |
| `B_start.jpg`, `B_fail.jpg` | B: 전장 가운데 큰 카드 |
| `C_start.jpg`, `C_fail.jpg` | C: 하단 조작줄 위 왼쪽 한 줄 알림 |
| `mock_battle_notice.gd` | 시안 합성용 일회성 스크립트(빌드 사본에서 `BASE_DIR`·`CAPTURE_DIR`로 실행) |

A안을 승인해 구현했다([전투 UI 결정](../../../docs/design_decisions/combat_ui.md) 「도전 조건 안내」).

시안 한계: 정지 화면이라 등장·유지·사라짐 시간은 그리지 않았다. 하드 난이도 표시와 포탑 조건(설치로 깨지는 조건) 문구는 같은 틀에 문구만 바뀐다.
