# 업적 열람 화면 시안 (2026-11-02)

[도전과제 설계](../../../docs/stage_difficulty_design.md#도전과제)의 열람 화면 시안이다. 실제 로비 코드와 기존 UI 컴포넌트(행 프레임, 세그먼트 탭, 선택 판, 다이아·모듈권 아이콘)로 그린 Godot 캡처(440×900)이며, 팝업 내용과 로비 단축 줄 5번째 칸은 빌드 사본에만 임시로 넣었다. 수치·달성 상태와 「포탑 N기」의 N은 예시다.

| `lobby_challenge_icon.png` | 단축 줄 「업적」 아이콘 원본(ImageGen, 기존 리더보드·이벤트 아이콘 참고, 1254px 투명) |
| `home_with_challenges.jpg` | 스테이지 홈 하단 단축 줄에 「업적」을 5번째 칸으로 추가, 받을 보상이 있을 때 빨간 느낌표 |

시안 한계: 훈장 그림은 단축 줄 「업적」 아이콘에 색만 입힌 임시 표현이며, 누적 업적 종류·단계 수치와 훈장 능력치(「예시」 표기)는 미정이다. 1차 시안은 컬렉션 완성 보상을 즉시 적용으로 그렸으나, 2차에서는 완성하면 훈장 탭에서 훈장을 받는다. 긴 완성 보상 문구(「모든 포탑 피해 증폭 +3%」)는 진행 막대 폭을 줄인다.
