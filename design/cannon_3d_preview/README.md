# 고정 시점 3D 대포 동작 샘플

2026-09-10. 게임에 통합하기 전 표현 방향을 확인하는 Blender 렌더 샘플.

- `cannon-3d-preview.mp4`: 960×720, 24fps, 8초. 고정 직교 카메라, 주황색 대포의 표적 추적, 포신 반동, 네 차례 발사와 명중 표현. 무음.
- `cannon-preview.blend`: 편집 가능한 실제 3D 원본. `RuneNexus_Cannon_Preview` 장면 사용.
- `build_scene.py`, `finalize_scene.py`: 제작 과정을 재현하는 Blender Python 코드. 기본 장면을 만들고 보정 스크립트를 순서대로 한 번씩 실행한다.
- `orange-prompt.txt`와 주황색 이미지 시안은 `../cannon_tile_concepts/`에 보관되어 있다.

이번 샘플은 모델이 실제로 회전할 때의 실루엣·고정 조명·접지 그림자와 발사 동작을 확인하기 위한 간단한 제작물이다. 기존 포탑의 주황색 정체성을 유지한다. 타일과 표적은 샘플용이며, 기존 시안의 모든 표면 디테일을 구현한 최종 에셋은 아니다.

Blender MCP로 모델·재질·카메라·애니메이션을 제작하고 Blender EEVEE로 MP4를 렌더했다. 이미지 한 장을 회전시킨 영상이 아니다. 초기 2D 제안에서 만든 그림을 동영상으로 변환한 것도 아니다.

게임 코드·외부 의존성·저장 형식은 변경하지 않았다. 이번 렌더링 속도로 웹·모바일 실시간 프레임률을 추정하지 않는다. 실제 엔진 통합, 터치 선택, 배속 및 다수 포탑 성능은 후속 검증 대상이다.

검증: AVFoundation으로 MP4의 8초·960×720·24fps를 확인하고 0.5초·3.5초·6.8초 프레임을 디코딩해 조준 방향 변화와 명중 장면을 확인했다. 실시간 플레이 검증은 아니다.
