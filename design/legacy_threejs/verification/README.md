# ThreeJS·ANGLE 제거 검증

확인: 2026-09-13. 로컬 구현·검증 기록이며 공개 배포 기록이 아니다.

## 제거 범위

- ThreeJS 화면·장면·조명·효과·검수 진입과 전용 테스트를 실행되지 않는 텍스트로 보관했다.
- `three_js`, `flutter_angle` 및 전이 의존성 총 28개, 웹 바인딩 로드, Gradle의 ANGLE C++ 중복 제외, 과거 검수 패키지 분기, CI의 ANGLE 전용 SDK 설치를 제거했다.
- 3D 입력 원본은 보존하고 Flutter asset 등록만 해제했다. Godot 런타임·PCK 생성과 Flame 전투·2D 복귀는 유지했다.
- 패키지 재생성 결과 모든 플랫폼 등록에서 ANGLE이 빠졌다. 작업 전 존재한 Android Gradle migration 설정은 보존했다.

## 자동 검사

- 수정 Dart 포맷, Flutter analyze 통과.
- 전체 Flutter 테스트 760개 통과, 기존 조건에 따른 11개 생략.
- 첫 전체 실행에서 냉각 범위 테스트가 무작위 5% 치명타로 실패했다. 범위 검사의 공격 스냅샷을 일반 공격으로 고정했다. 전투 규칙은 변경하지 않았다. 관련 6개와 최종 전체 검사가 통과했다.
- Godot 패키징 준비 Python 테스트 1개 통과.
- 일반 release APK, 웹 빌드 통과. 웹은 기존 build/web을 제거한 후 재빌드하여 오래된 vendor와 3D 자산이 남지 않는 것을 확인했다.
- 로그는 `build/threejs-removal/`에 있다.

## 실제 패키징

비교 대상은 작업 시작 시 존재한 로컬 `app-release.apk`와 이번 일반 release APK다. 같은 소스의 엄격한 전후 빌드나 이전 공개 APK 비교는 아니므로 전체 차이를 이번 변경만의 효과로 단정하지 않는다.

| 항목 | 기존 로컬 APK | 이번 로컬 APK | 차이 |
| --- | ---: | ---: | ---: |
| 파일 바이트 | 426,119,640 | 387,581,280 | -38,538,360 (-9.04%) |
| MiB | 406.38 | 369.63 | -36.75 |
| ZIP 네이티브 항목 크기 | 290,443,764 | 283,620,204 | -6,823,560 |
| ZIP Flutter 이미지 등 자산 크기 | 74,531,639 | 38,308,155 | -36,223,484 |
| Godot PCK | 58,453,692 | 63,005,340 | +4,551,648 |

ZIP 항목은 압축 후 바이트다. 기존 로컬 팩과 현재 팩의 내용·크기는 다르며 이번 작업은 Godot 소스·제작 자산·팩 빌더를 변경하지 않았다. 따라서 PCK 증가는 이번 제거 변경의 증가로 분류하지 않는다.

arm64-v8a·armeabi-v7a·x86_64를 모두 유지했다. 최종 APK ZIP 무결성을 확인했으며 ANGLE 라이브러리와 `assets/flutter_assets/assets/images/stage1_3d/` 중복 항목은 0개다. [항목 감사](apk-audit.json)를 참고한다. 공개 배포 시에는 당시 최신 공개 APK와 다시 비교해야 한다.

## Android 실행

일반 `lib/main.dart`, release code 6015 APK를 Android ARM64 에뮬레이터의 기존 패키지에 업데이트 설치했다. 데이터 삭제 없이 로비의 7/40 이어서 진행으로 진입했고 골드 403·코어 13/20·다이아 16과 기존 포탑이 유지됐다.

- [고정 시점](fixed.png): Godot 지형·포탑·레벨 배지와 기존 HUD.
- [드론 시점](drone.png): 시점 왕복 뒤 같은 전장·HUD.
- [포탑 선택](selection.png): 실제 대포를 눌러 기존 상세 패널과 사거리 표시 확인.

첫 Godot 초기화 직후 장면 표시 전 빈 전장 캡처가 있었으며 로딩 후 실제 3D 표시를 직접 확인했다. 실기기 4배속 지속 전투·발열·정량 성능, Google 로그인·온라인 저장 E2E, 공개 배포는 이번 검증에 포함하지 않는다. 이 작업은 기존 재질의 시각 채택 상태를 변경하지 않는다.
