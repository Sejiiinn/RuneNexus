# 전투 콘텐츠 수정 원본

적·포탑·기본 설정과 고정 ID별 스테이지를 수정하는 폴더다. 책임·수치·저장 계약과 생성·검사 명령은 [콘텐츠 기준](../README.md#원본에서-실행-입력으로-전개)에 둔다.

`stages/`의 `map`, `groups`, 보상, 표시 문구를 수정하고 컴파일러로 실행 입력을 만든다. 타일은 보드 한 행, 그룹은 한 레코드를 한 줄에 기록한다. 진행·해금은 `progression.json`, 적 정의는 `enemies.json`, 포탑은 `turrets.json`, 기본 설정·산식 버전은 `settings.json`에서만 관리한다.

`previewText`는 해당 웨이브에 실제로 출현하는 적을 설명한다. 컴파일러는 명시적인 적 이름·유형(일반, 빠른 적/빠름/고속, 탱커, 보호막/차폐, 장갑, 보스 등)에 맞는 그룹이 있는지 검사하고, `혼합`에는 서로 다른 적 유형이 둘 이상 있어야 한다. 같은 유형의 여러 그룹은 `2열`·`겹침` 등으로 표현할 수 있다. 전술적 표현 전체의 의미를 자동 판정하지는 않으므로 그룹을 수정할 때 문구도 함께 검토한다.

`compatibility`는 이관 전에 존재하던 정확한 float를 유지하기 위한 작은 보정이다. 새 밸런스 수치를 기록하는 장소가 아니다. 그룹 또는 기본 정의를 편집하면 입력 guard가 다른 기존 보정은 적용하지 않는다. `design`은 승인 시안의 운영 의도·구역 설명이며 실행 지형이나 수치를 덮어쓰지 않는다. 건설칸 순서는 승인 제작 순서로 유지하지만, 뷰의 기하 요약은 현재 맵에서 재계산한다.

`game_content.json`은 컴파일 결과이므로 직접 편집하지 않는다. 원본만 있는 새 체크아웃에서도 컴파일할 수 있으며 빌드·검사는 누락되거나 오래된 실행 입력을 거부한다. 이 폴더는 앱 패키징에서 제외한다.
