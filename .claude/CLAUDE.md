# Claude 세션 전용 보충

AGENTS.md를 그대로 따르되, 아래만 Claude 세션에 맞게 정한다.

## 구현과 독립 검증

- AGENTS.md 「독립 검증 적용」이 가리키는 공통 지침은 Codex용(`~/.codex/AGENTS.md`)이며 그 모델·하위 에이전트 설정은 Claude에 적용하지 않는다.
- 구현·관련 기본 검사·발견 결함 수정은 Claude가 직접 한다. Claude 하위 에이전트로 검증자를 따로 두지 않는다(토큰 절약).
- Codex(gpt-6-astra, high) 독립 검증은 사용자가 요청할 때에만 `codex-verify` 스킬로 실행한다. AGENTS.md·DESIGNS.md의 독립 검증 요구는 Claude 세션에서 이 규칙으로 대신하며, 변경 대상과 관계없이 자동으로 실행하지 않는다.
- 요청이 없으면 Claude가 관련 자동 검사와 실제 화면 확인으로 마무리하고, 독립 검증을 수행하지 않았음을 완료 보고에 밝힌다.
- 요청받은 Codex 검증을 실행하지 못했거나 미확인 항목이 남으면 통과로 보고하지 않는다. 결과 처리는 스킬 문서를 따른다.
