# Claude 세션 전용 보충

AGENTS.md를 그대로 따르되, 아래만 Claude 세션에 맞게 정한다.

## 구현과 독립 검증

- AGENTS.md 「독립 검증 적용」이 가리키는 공통 지침은 Codex용(`~/.codex/AGENTS.md`)이며 그 모델·하위 에이전트 설정은 Claude에 적용하지 않는다.
- 구현·관련 기본 검사·발견 결함 수정은 Claude가 직접 한다. Claude 하위 에이전트로 검증자를 따로 두지 않는다(토큰 절약).
- 독립 검증 대상(UI·시각, 저장·전투·API 계약, 여러 시스템, 복잡한 버그 수정)은 구현을 마친 뒤 완료 보고·커밋 전에 `codex-verify` 스킬로 Codex(gpt-6-astra, high)에게 검증받는다. 생략 조건과 결과 처리는 스킬 문서를 따른다.
- Codex 검증을 실행하지 못했거나 미확인 항목이 남으면 통과로 보고하지 않는다.
