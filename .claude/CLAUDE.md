# Claude 세션 전용 보충

AGENTS.md를 그대로 따르되, 아래만 Claude 세션에 맞게 정한다. AGENTS.md는 Claude에 자동으로 로드되지 않으므로 아래에서 불러온다.

@../AGENTS.md

## 구현과 독립 검증

- AGENTS.md 「독립 검증 적용」이 가리키는 공통 지침은 Codex용(`~/.codex/AGENTS.md`)이며 그 모델·하위 에이전트 설정은 Claude에 적용하지 않는다.
- 구현·관련 기본 검사·발견 결함 수정은 Claude가 직접 한다. Claude 하위 에이전트로 검증자를 따로 두지 않는다(토큰 절약).
- Codex(gpt-6-astra, high) 독립 검증은 사용자가 요청할 때에만 `codex-verify` 스킬로 실행한다. AGENTS.md·DESIGNS.md의 독립 검증 요구는 Claude 세션에서 이 규칙으로 대신하며, 변경 대상과 관계없이 자동으로 실행하지 않는다.
- 요청이 없으면 Claude가 관련 자동 검사와 실제 화면 확인으로 마무리하고, 독립 검증을 수행하지 않았음을 완료 보고에 밝힌다.
- 요청받은 Codex 검증을 실행하지 못했거나 미확인 항목이 남으면 통과로 보고하지 않는다. 결과 처리는 스킬 문서를 따른다.

## 자주 놓친 기준

AGENTS.md·DESIGNS.md에 이미 있는 내용 중 Claude 세션에서 어긴 적이 있는 것만 다시 적는다. 근거 원문이 바뀌면 원문을 따른다.

- 검사 범위: 변경한 책임에 맞는 사례만 골라 실행한다(AGENTS.md 「변경 대상별 검증」). 커밋 전이라는 이유로 전체 회귀를 돌리지 않는다. 전체 회귀는 사용자가 요청했거나 실행기·공통 기반처럼 영향 범위를 특정할 수 없는 변경일 때만 실행한다.
- 화면 확인: 의미 있는 변경 뒤 대표 상태만 캡처한다. 같은 상태를 해상도·스테이지 조합마다 반복해 띄우지 않고, 기존 검사가 다루는 경우는 다시 찍지 않는다. 화면이 필요 없는 확인은 `--headless`로 실행한다(DESIGNS.md 「검증과 완료 기준」).
- UI 완료 보고에는 실제 적용 스크린샷을 함께 제공하고, 시안과 실제 앱 캡처를 구분한다.
- 사용자가 화면 방향을 바꾸면 해당 영역 결정 문서를 갱신하며, 이전 결정을 덧붙여 남기지 않는다(DESIGNS.md 「결정 갱신」).
- 버그 수정에 요청 밖 UI 재설계를 섞지 않는다.
- 커밋: 이번 변경만 골라 스테이징하고 스테이징 목록·diff를 확인한다. 작업 트리에 섞인 다른 작업의 미커밋 변경은 넣지 않는다. 메시지는 한글과 `feat:`/`fix:`/`refactor:`/`chore:`를 쓴다.
- APK는 사용자 요청, Android에서만 확인 가능한 항목, 최종 배포 검증 중 하나가 있을 때만 만든다.
